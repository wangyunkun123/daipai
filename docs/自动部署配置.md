# 带拍 · 自动部署配置

> 大陆服务器：123.56.229.172 · guidepic.com（香港服务器已停用，2026-08 下线）

## 方式一：GitHub Webhook（推荐，即时触发）

### 1. 服务器端
```bash
# 把 deploy.sh 拷贝到服务器
scp mobile-tester/deploy.sh root@123.56.229.172:/opt/daipai/
ssh root@123.56.229.172 chmod +x /opt/daipai/deploy.sh

# 在 .env 中设置 webhook 密钥
echo "DEPLOY_SECRET=$(openssl rand -hex 32)" >> /opt/daipai/mobile-tester/.env

# 重启服务
systemctl restart daipai
```

### 2. GitHub 端
```
仓库 Settings → Webhooks → Add webhook
  Payload URL: https://guidepic.com/deploy
  Content type: application/json
  Secret: 与服务器 .env 中的 DEPLOY_SECRET 一致
  Events: Just the push event
```

### 3. 验证
```bash
# 本地 push 后，服务器自动拉取+重启
git push
# 等 5-10 秒 → 刷新 guidepic.com 确认更新生效
```

## 方式二：systemd 定时器（备用，每 5 分钟检查）

```bash
# 创建定时器
cat > /etc/systemd/system/daipai-deploy.timer << 'EOF'
[Unit]
Description=带拍自动部署定时器

[Timer]
OnCalendar=*:0/5
Persistent=true

[Install]
WantedBy=timers.target
EOF

# 创建服务
cat > /etc/systemd/system/daipai-deploy.service << 'EOF'
[Unit]
Description=带拍自动部署

[Service]
Type=oneshot
ExecStart=/bin/bash /opt/daipai/deploy.sh --auto
WorkingDirectory=/opt/daipai
EOF

# 启用
systemctl daemon-reload
systemctl enable --now daipai-deploy.timer
```
