# 带拍 · 完整工作流分析

> 基于 2026-07-24 实测（照片：SONY A7M4 海滩人像）| 模型：deepseek-v4-pro + 豆包视觉

---

## 一、AI 在哪些环节发挥作用

```
用户上传照片
    │
    ▼
[阶段 0] 环境感知 ─── 纯本地脚本，无 AI 参与
    │                  EXIF提取/地点/太阳/天气/位置搜索
    │                  耗时：2-5s，费用：¥0
    │
    ▼
[阶段 1A] 豆包视觉识别 ─── 🧠 AI 角色：感知层——"看见"照片
    │                      输入：照片 base64 + 结构化 prompt
    │                      输出：8 字段 JSON（场景/人物/光线/色彩/空间/主体/情绪/构图）
    │                      耗时：3-8s，费用：~¥0.02-0.05
    │
    ▼
[阶段 1B] 题材+设备加载 ─── 纯规则匹配，无 AI 参与
    │                      耗时：<1s，费用：¥0
    │
    ▼
[阶段 1C] AI 自由搜索 ─── 🧠 AI 角色：发现层——"在世界范围内找到最佳答案"
    │                      ├─ WebSearch × 5-7（并行）→ AI 综合判断搜索结果
    │                      ├─ 规则诚实标注（🟢🟡🔴）→ AI 推理
    │                      └─ 知识缓存对比 → AI 决策
    │                      耗时：10-20s，费用：WebSearch 免费 + AI推理 ~¥0.05-0.15
    │
    ▼
[阶段 1C.5] 审美主张引擎 ─── 🧠 AI 角色：洞察层——"这个场景最值得被拍下来的是什么"
    │                          ├─ 场景沉浸 + 生态描述（四组互动关系）
    │                          ├─ 洞察提炼（一句话说中要害）
    │                          ├─ 创作方向生长（放大/呼吸/转移/反转/致敬）
    │                          ├─ 设备翻译（优势思维，非降级思维）
    │                          └─ 排除决策（不应该，不是做不到）
    │                          耗时：5-10s，费用：~¥0.03-0.08
    │
    ▼
[阶段 1D] 方向预选 ─── 🧠 AI 角色：策展层——"三个方向，三种审美"
    │                   从全局最优池中筛选 🟢现在拍/🔥最出片/✨脑洞大开
    │                   耗时：2-3s，费用：~¥0.01-0.03
    │
    ▼
[阶段 2] 方向卡片输出 ─── 🧠 AI 角色：文案层——"把专业分析翻译成人话"
    │                      每张卡片 = 💬推荐理由（钩子+理由合并，结果承诺开头）
    │                      + 📋怎么做（一行说完）+ 📊折叠区（结构化专业分析）
    │                      耗时：10-15s，费用：~¥0.05-0.15（输出量最大）
    │
    ▼
[阶段 3] 方案生成 ─── 🧠 AI 角色：导演层——"不止一个拍法，给你四条路"
    │                  ├─ 同一风格下 3-4 套方案
    │                  ├─ 每套：要准备什么 → 就这么拍 → 💡为什么好看
    │                  └─ 方案间差异：构图/景别/机位/人物状态不重复
    │                  耗时：15-25s，费用：~¥0.10-0.25（最贵的环节）
    │
    ▼
[阶段 3.5] 自动知识沉淀 ─── 🧠 AI 角色：记忆层——"这次学到了什么，下次直接用"
    │                        检查匹配关系→不在缓存则自动注册
    │                        耗时：1-2s，费用：~¥0.01-0.02
    │
    ▼
[阶段 4] 拍摄指导 ─── 🧠 AI 角色：翻译+质检层
    │                  ├─ 4A 设备翻译（方案→设备具体操作语言）
    │                  ├─ 4B 拍摄计划总览表
    │                  └─ 4D 四维批判验证（每套方案≥6分）
    │                  耗时：3-5s，费用：~¥0.02-0.05
    │
    ▼
[生图提示词] ─── 🧠 AI 角色：视觉预览层
    │              ├─ 豆包生图中文提示词
    │              ├─ 三层标注（📷原图/🖌️后期/🤖AI生图）
    │              └─ 关键词解读 + 后期工具建议
    │              耗时：5-10s，费用：~¥0.03-0.08
    │
    ▼
完整输出交付
```

## 二、AI 角色全景图

| # | AI 角色 | 所在阶段 | 解决的问题 | 如果没有 AI |
|---|---------|---------|-----------|------------|
| 1 | **感知层** | 1A 豆包视觉 | "这个场景里有什么？光线怎么样？" | 需要用户手动输入所有信息 |
| 2 | **发现层** | 1C 自由搜索 | "全球范围内，这个场景最好的拍法是什么？" | 只能查本地知识库，无新发现 |
| 3 | **洞察层** | 1C.5 审美主张 | "这个场景最动人的那个瞬间是什么？" | 输出分类标签，不输出洞察 |
| 4 | **策展层** | 1D/阶段2 | "给用户三个方向，让他们3秒做决定" | 只给一个"最安全"的推荐 |
| 5 | **文案层** | 阶段2 | "把专业技术分析翻译成用户一眼就懂的话" | 输出摄影术语堆砌 |
| 6 | **导演层** | 阶段3 | "同一风格下，用不同构图/角度给多条路" | 只有一套方案，无选择空间 |
| 7 | **记忆层** | 阶段3.5 | "这次学到的，下次直接用" | 知识库永远是死的 |
| 8 | **翻译+质检层** | 阶段4 | "在你这台设备上具体怎么操作" | 通用建议，不针对设备 |
| 9 | **视觉预览层** | 生图提示词 | "拍完大概是什么样子" | 用户只能靠想象 |

**9 个 AI 角色，覆盖了从"看见"到"理解"到"创造"到"翻译"到"预览"的完整链路。**

## 五、优化建议

| # | 优化点 | 当前 | 优化后 | 节省 |
|---|--------|------|--------|:--:|
| 1 | 缓存豆包识图结果（相同照片不重复识别）| 每次调 | 按照片 hash 缓存 | ~¥0.01/次 |
| 2 | 知识库命中率高时跳过 WebSearch | 每次都搜 | 验证≥3 的缓存直接使用 | ~5-10s |
| 3 | 阶段 1C-1D 内部推理合并为一个 prompt | 分 4 步 | 1 次推理完成 | ~¥0.02-0.05 |
| 4 | 方向卡片+方案分两次输出（用户选了方向才生方案）| 一次性 | 阶段 2 出卡片→等待选择→阶段 3 出方案 | 40% token（用户不选就不用生方案）|
| 5 | 生图提示词按需生成 | 每套方案都带 | 用户点"查看预览"才生成 | ~¥0.03/次 |
| 6 | 预热上下文 | 每次加载完整 SKILL.md | 系统 prompt 常驻 | ~20K input token |

> **优化 4 最显著**：当前设计已经是阶段 2 先出方向卡片→用户选择→阶段 3 出方案。这是正确的——60% 的 token 消耗在阶段 3 方案生成，如果用户不选方向，这部分完全不会触发。

## 六、总结

| 维度 | 数值 |
|------|------|
| AI 参与环节 | **9 个**（感知→发现→洞察→策展→文案→导演→记忆→翻译→预览）|
| 无 AI 参与环节 | 阶段 0 全部（EXIF/地点/太阳/天气）、阶段 1B（规则匹配）、阶段 3.5（写入操作）|
| 单次耗时 | **45-70 秒**（豆包 5s + AI 推理+生成 40-65s）|
| 单次费用 | **¥0.11-0.20**（DeepSeek V4）|
| 最大 token 消耗 | 阶段 3 方案生成 + 阶段 2 方向卡片 |
| 最该优化的环节 | 知识缓存命中时跳过 WebSearch；分阶段输出（先方向卡片，选完再方案）|
