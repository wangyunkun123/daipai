# 四模型效率+质量对比 · 综合结论（网球场案例）

> 固定输入：IMG_7004 网球中心观景平台（视觉识别JSON + EXIF ISO50/1/4065s + iPhone 17 + 知识库 + 环境上下文）
> 每模型跑「方向生成 → 方案生成(best方向)」两阶段。两轮实测：首轮 4000tok / 补充 8000tok。

## 一、效率对比（端到端总耗时 = 方向 + 方案）

| 排名 | 模型配置 | 方向耗时 | 方案耗时 | **总耗时** | 方向解析 | 方案解析 |
|------|---------|---------|---------|-----------|---------|---------|
| 🥇 | **DS Flash 关思考** | 23.7s | 30.3s | **≈54s** | ✅ | ✅(4套) |
| 🥈 | **豆包 Lite** | 45.1s | 35.4s | **≈80s** | ✅ | ✅(3套) |
| 🥉 | DS Pro 默认 | 89.1s | 127.4s | ≈217s | ✅ | ✅(6套) |
| 4 | DS Flash 默认 | 87.6s(+重试80s) | 76s | ≈244s | ❌重试后过 | ❌解析失败 |
| 5 | 豆包 Pro | 124.3s | 120.5s | ≈245s | ✅ | ✅(5套) |

**效率结论：DS Flash 关思考 ≈ 豆包 Lite 的 1.5 倍快，≈ 豆包 Pro 的 4.5 倍快。**

## 二、质量对比（方向输出样本）

| 模型 | Best 方向 | 质量判断 |
|------|----------|---------|
| DS Pro | 「运动廓形」🆕新发现 | **深度最高**——摄影翻译堪称教科书级，能引用19°低角侧光具体参数 |
| DS Flash 关思考 | 「极简高级」「运动休闲大片」 | **接近 Pro**——洞察一样专业，偶发 JSON 字符级错误 |
| DS Flash 默认 | 「网球俱乐部美学」 | 有意思但 JSON 不稳定（推理吃光 token/格式错） |
| 豆包 Pro | 「杂志时尚」📚已有 | 稳定准确但保守，5套方案全命中知识库 |
| 豆包 Lite | 「杂志时尚」📚已有 | 稳定但深度最浅，3套方案 |

**质量结论：DeepSeek 系摄影知识深度明显更强（新风格发现 + 前期拍法翻译）；豆包系稳定准确但偏保守。**

## 三、关键发现

### 🚨 DeepSeek 默认「深度思考」是效率杀手
- **Flash 默认思考**：direction 阶段吃掉 **7946 推理 tokens**，max_tokens 不够直接返回**空响应**；给够 8000 也慢（87s）+ 方案 JSON 解析失败
- **Pro 默认思考**：推理 tokens 不多（446）但延迟极高（方向89s + 方案127s）
- **解法**：`thinking: {"type": "disabled"}` 一关，Flash 立刻从 48s→23s，推理 tokens 归零 ✅

### ⚠️ DeepSeek 关思考后 JSON 偶发格式错
首轮 ds-flash-nothink 方向 JSON 里混入一个字符错（`"背景留出空间',`）。线上已有 `parse_json_safe` 重试兜底（失败自动带修复提示重试一次），实测重试可自救（ds-flash-8k 方向重试后成功）。

### 豆包 Lite 的优势是「零配置开箱即用」
JSON 两次全部一次通过、无思考参数可调但稳定。代价是质量深度最浅。

## 四、推荐（用户抉择）

### 效率优先方案 ✅（推荐）
```
视觉识别   → 豆包 Pro（锁定，DeepSeek 无视觉）
方向+方案  → DeepSeek Flash + thinking disabled + JSON重试兜底
预期：单次请求端到端 ~70-90s（含视觉识别），比现网豆包Pro(>5min) 快 3-4 倍
```

### 稳定优先方案（保守）
```
方向+方案 → 豆包 Lite
预期：~90-110s，JSON 最稳，但方案深度浅一档
```

### 不建议
- **DeepSeek 默认思考**：直接不可用（flash 空响应 / pro 216s）
- **豆包 Pro**：质量好但 245s 用户等不了
