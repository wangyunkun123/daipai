## 四、香港服务器管理

```

/opt/daipai/mobile-tester/server.py ← 主程序
/opt/daipai/mobile-tester/.env     ← 豆包 API 密钥（600权限）
/opt/daipai/mobile-tester/venv/    ← Python 虚拟环境
```

### systemd 服务

```
服务名：daipai
配置：/etc/systemd/system/daipai.service
自启：已启用
```

### 常用命令

```bash
# 服务状态
systemctl status daipai

# 重启（代码更新后）
systemctl restart daipai

# 实时日志
journalctl -u daipai -f

# Nginx 重载
systemctl reload nginx

# 测试 Nginx 语法
nginx -t
```

## 八、故障排查

| 问题 | 先查什么 | 命令 |
|------|------|------|
| 网站打不开 | 服务状态 | `systemctl status daipai` |
| 图片分析失败 | 错误日志 | `journalctl -u daipai -n 50` |
| 豆包 API 异常 | 密钥有效？ | `cat /opt/daipai/mobile-tester/.env` |
| 端口不通 | 防火墙 | 阿里云控制台查规则 |
| Nginx 502 | Flask 挂了？ | `systemctl status daipai` |
