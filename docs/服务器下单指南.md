# 带拍 · 服务器下单指南

> 时间：2026-07-26 | 用途：guidepic.com 域名 + 香港轻量云服务器

## 准备工作

- [x] 火山引擎账号（豆包 API，继续使用）
- [ ] 支付宝 / 身份证（实名认证用）
- [ ] 手机号（注册阿里云）

---

## 第一步：注册阿里云

1. 打开 https://www.aliyun.com
2. 右上角「免费注册」→ 输入手机号 → 接收验证码
3. 注册完立即做**实名认证**（不认证买不了域名）
   - 个人认证：身份证正反面 + 支付宝扫码
   - 通常 5 分钟内审核通过

---

## 第二步：买域名 guidepic.com

1. 打开 https://wanwang.aliyun.com
2. 搜索框输入 `guidepic.com` → 查询
3. 如果显示「可注册」→ 加入购物车
4. 价格参考：
   - 首年约 ¥59（新用户可能 ¥35 起）
   - 建议选 **1 年**
   - 关掉「自动续费」☐
5. 填写域名所有者信息（用实名认证的姓名）
6. 支付

> ⚠️ **域名付了钱不等于到账**——实名认证通过后才算正式注册成功。
> 可以在「域名控制台」查看状态。

---

## 第三步：买香港轻量云服务器

1. 打开 https://www.aliyun.com/product/swas
2. 点击「创建服务器」
3. 按以下配置选择：

| 配置项 | 选什么 |
|------|------|
| **地域** | 🟢 **中国香港**（选完不能改！） |
| **可用区** | 随机分配（无所谓） |
| **规格族** | **国际型**（BGP_NCO，¥39/月） |
| **套餐** | **2核 2GB，40G ESSD，200Mbps** |
| **镜像类型** | 系统镜像 |
| **操作系统** | **Ubuntu 22.04** |
| **购买时长** | **1 个月**（先试一个月） |
| **自动续费** | ☐ **关掉！** |
| **台数** | 1 |

4. 点击「立即购买」→ 付钱 ¥39
5. 返回控制台，等状态从「准备中」→「运行中」（约 1-3 分钟）
6. 复制「公网 IP」保存好（如 `47.xxx.xxx.xxx`）

## 第四步：DNS 解析（域名 → 服务器）

1. 阿里云控制台 → 域名 → 点击 guidepic.com →「解析」
2. 添加一条记录：

| 记录类型 | 主机记录 | 记录值 | TTL |
|------|------|------|------|
| A | `@` | `你服务器的公网IP` | 600 |
| A | `www` | `你服务器的公网IP` | 600 |

3. 等 2-10 分钟生效
4. 验证：浏览器访问 `http://guidepic.com:8888`（部署后可用）

---

## 第五步：登录服务器（本地终端）

```bash
# SSH 登录（密码在阿里云控制台「远程连接」里重置）
ssh root@你的服务器IP

# 首次登录会提示改密码
passwd

# 更新系统
apt update && apt upgrade -y
```

## ⚠️ 避坑清单

1. **地域不能改**——下单时确认是「中国香港」，不是「新加坡」或别的地方
2. **关掉自动续费**——首月先试用，好了再手动续
3. **不要买错了规格族**——选「国际型」¥39/月，不要选「通用型」¥56/月（对我们没区别）
4. **镜像选 Ubuntu 22.04**——别选 Windows（贵）或应用镜像（带一堆我们用不到的）
5. **只买 1 个月**——不要一上来就买一年，测试下来不合适还能换腾讯云
6. **保存好公网 IP + root 密码**——写在记事本里
