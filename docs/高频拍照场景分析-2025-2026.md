## 二、场景评估矩阵

### 评估维度说明

| 维度 | 含义 |
|------|------|
| **日常频率** | 用户日常生活中遇到该场景的频率 |
| **痛点强度** | 用户在该场景拍照时"拍不好"的痛苦程度 |
| **标准化程度** | 场景元素是否可以公式化、AI分析准确率多高 |
| **AI独特价值** | AI能提供的价值是否超过"直接搜小红书教程" |
| **传播力** | 好照片是否天然适合社交分享 |
| **商业潜力** | 是否有直接的付费场景或变现路径 |
| **知识库储备** | 带拍现有知识库中该场景技法的丰富度 |
| **技术难度** | 实现该场景AI分析的技术复杂度 |

### 🥇 第一梯队：强烈推荐优先做

---

#### 1. ☕ 咖啡厅 / 室内探店

| 维度 | 评分 | 说明 |
|------|:--:|------|
| 日常频率 | ⭐⭐⭐⭐⭐ | 年轻人每周1-3次 |
| 用户痛点 | ⭐⭐⭐⭐⭐ | "室内暗、不知道怎么摆、拍出来像外卖图" |
| 标准化程度 | ⭐⭐⭐⭐⭐ | 窗光/顶灯/暖色灯三类光源，桌面/窗边/人像三个机位 |
| AI独特价值 | ⭐⭐⭐⭐⭐ | 可识别窗光方向→推荐坐位，识别室内色调→推荐穿搭 |
| 传播力 | ⭐⭐⭐⭐⭐ | 用户@咖啡店 → 店主转发 → B端+C端双循环 |
| 商业潜力 | ⭐⭐⭐⭐⭐ | 消费场景，用户已花钱到店，有付费意愿 |
| 知识库储备 | ⭐⭐⭐⭐ | 侧光/窗光/暖色调/桌面构图成熟 |
| 技术难度 | ⭐ 低 | 纯视觉分析，不需要GPS/天气 |

**为什么是首选：**
- 场景元素最固定 → AI分析准确率最高
- 用户动机最明确 → "花了钱来探店，一定要拍好"
- 传播链条最短 → 用户→朋友→店主→更多用户
- 完成后技法直接复用到美食（90%重叠）、居家（70%重叠）

#### 2. 🛣️ 城市街拍 / Photowalk

| 维度 | 评分 | 说明 |
|------|:--:|------|
| 日常频率 | ⭐⭐⭐⭐⭐ | 通勤/逛街/周末Citywalk几乎每天 |
| 用户痛点 | ⭐⭐⭐⭐ | "看到好看街景拍出来就是游客照" |
| 标准化程度 | ⭐⭐⭐⭐ | 街头摄影百年理论，技法可高度公式化 |
| AI独特价值 | ⭐⭐⭐⭐ | 可识别建筑线条→推荐几何构图，识别人流→推荐时机 |
| 传播力 | ⭐⭐⭐⭐⭐ | 城市标签自带传播 |
| 商业潜力 | ⭐⭐⭐ | 非直接消费场景，但有"摄影路线"等延伸可能 |
| 知识库储备 | ⭐⭐⭐⭐⭐ | 街头摄影是知识库中技法最多的门类 |
| 技术难度 | ⭐⭐⭐ | 户外变量多，但AI可处理 |

**为什么是第二：** 覆盖面最广，知识库最丰富，但户外变量比咖啡厅多。

#### 3. 🌅 日落 / 黄昏 / 黄金时刻

| 维度 | 评分 | 说明 |
|------|:--:|------|

| 用户痛点 | ⭐⭐⭐⭐⭐ | "眼看绝美拍出来要么黑要么白" |
| 标准化程度 | ⭐⭐⭐⭐⭐ | 时间固定（日落前30分钟），技法固定 |
| AI独特价值 | ⭐⭐⭐⭐⭐ | **环境感知已有日落倒计时，可主动推送提醒** |
| 传播力 | ⭐⭐⭐⭐⭐ | "橘子海"是现象级流量密码 |
| 商业潜力 | ⭐⭐ | 免费场景 |
| 知识库储备 | ⭐⭐⭐⭐ | 逆光/剪影/曝光控制成熟 |
| 技术难度 | ⭐⭐ | 环境感知模块已完成 |

**独特优势：** 唯一可以"主动触达用户"的场景——日落前推送通知，有拉活能力。

## 三、推荐实施路线

```
Phase 1（当前）：🛣️ 城市街拍 ← 已完成 v1
    ↓
Phase 2（建议）：☕ 咖啡厅探店
    ↓ 技法复用
    ├── 🍜 美食拍摄（90%技法重叠：室内窗光+桌面构图）
    ├── 🏠 居家生活感（70%技法重叠：室内窗光+氛围感）
    └── 🧺 野餐（60%技法重叠：消费场景+桌面构图）
    ↓
Phase 3：🌅 日落/黄昏（拉活场景：主动推送）
    ↓
Phase 4：👤👗🐱 人像/OOTD/宠物（需更多知识积累）
```

**核心策略：** 不做大而全。选一个场景做到"用户在这个场景第一个想到带拍"——然后复制模式到下一个。每加一个新场景只需添加三个模块：`XXX_KNOWLEDGE` + `XXX_DIRECTIONS_PROMPT` + `XXX_PLANS_CONTEXT`。

## 四、认知负荷降低思路（待实施）

### 核心原则：渐进式信息披露

```
L1 速览（默认展示）
├── 风格名 + 一张效果图
└── 一句话：为什么这个风格适合你

L2 拍摄要点（点一下展开）
├── ✅ 3条核心动作 Checklist
└── ❌ 1条避雷提醒

L3 完整方案（再点一下）
├── 当前4段式（subject/shooter/gear/enhance）
├── 图生图提示词
└── 后期建议
```

### 关键改动方向

- **去"分析报告"，留"行动指南"** — 用户不关心AI怎么分析的
- **方案改为子弹点** — "☀️ 站窗边让光从左边来 | ❌ 别开闪光灯"
- **默认折叠详情** — 只展示用户做决策必需的最小信息量

## 五、AR 拍摄引导可行性评估

| 等级 | 方案 | 难度 | 覆盖率 | 说明 |
|:--:|------|:--:|:--:|------|
| **L0** | 静态构图参考线模板 | ⭐ 1天 | 100% | 拍照前展示九宫格/三分线，用户手动对齐 |
| L1 | 半透明参考图悬浮 | ⭐⭐ 3天 | ~80% | getUserMedia + Canvas，微信不支持 |
| L2 | 轻量App壳 + 原生AR | ⭐⭐⭐ 2-4周 | 需安装 | iOS ARKit / Android ARCore 真·实时叠加 |
| L3 | WebXR 沉浸式AR | ⭐⭐⭐⭐ 难 | ~30% | 等标准成熟（2027+），微信完全不支持 |

**当前建议：** L0 立即可做（附构图模板图），真正实时AR等PMF验证后再投。
