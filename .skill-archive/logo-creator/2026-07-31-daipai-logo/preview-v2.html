A. 指南针取景标 Navigation + Frame

核心隐喻：「带你去」= 导航。指南针（方向引导）与取景框（拍照）合二为一。菱形指针指向右上——「带你找到好角度」。

推荐

A1 · 指南针取景标

App 图标 / 品牌图形

指南针圆环 + 内嵌取景框 + 菱形指针指右上。导航+拍照双重语义，中西方都能秒懂。

国际版

A2 · 暗色国际版

GuidePic 海外品牌

同样概念，暗色底暖橘色。专业感更强，适合海外科技产品调性。

B. 一笔画路径标 One-line Journey

核心隐喻：一条连续的线，从起点走到取景框，再变成一颗星——「带你走一遍，拍出好照片」。像 Nike Swoosh 一样的超级符号。

推荐

B1 · 一笔画路径

品牌超级符号

一条橙色线条：起点圆 → 蜿蜒路径 → 穿过取景框 → 定格为星。讲完整故事，极其独特，不会跟任何 App 撞。

B2 · 一笔画 (暗底)

技术文档 / 官网

暗色底的同一概念，更有高级感。

C. 重叠圆标 Intersection

核心隐喻：两个圆重叠——一个是"你"（拍摄者），一个是"场景"。重叠处暖橘色高亮 = 「带拍帮你找到你和场景之间的最佳交点」。

推荐

C1 · 重叠交点标

品牌图形 / 抽象符号

两个圆=拍摄者+场景，交叠处用暖橘高亮=最佳机位。像 Mastercard 一样经典耐看。极简、数学美。

C2 · 重叠圆 (暗底)

官网 / 专业场景

暗色底 + 暖橘交叠，更克制更高级。

D. 手势引导标 Hand Guide

核心隐喻：「我带你去」的最直白表达——一只抽象的引导手，指向一个对焦标记。动作感强，互动暗示明确。

D1 · 引导手标

品牌故事 / 启动页

一只手从圆中伸出，食指指向对焦标记。温暖、人性、直接。启动页做动画展开效果极好。

App 极简版

D2 · 极简手势

抽象版 / 图标

手势的极简抽象版——只用手指线条和弧线暗示手掌。更精致克制。

E. 「带」字超级符号 Kanji Mark

核心隐喻：把「带」字解构重组——上方"巾"变成相机带子，下方变成一条引导路径。中文品牌最强的差异化。

最独特

E1 · 「带」字超级符号 + 文字

完整品牌标 · 最独特不可替代

「带」字解构成三个部分：上方巾部→取景框+相机带/下方→引导路径指向对焦点。没有任何其他品牌能做到这样的中文+摄影双重语义。搭配"带拍"文字和 slogan，完整的品牌标识系统。

E2 · 纯图形标

独立图形符号

去掉文字，仅保留"带"字变形图形。可以单独用作 favicon 或 App 图标。

E3 · 暗色国际版

GuidePic 海外

同一超级符号在暗底上的表现，附 "DAIPAI" 字母。
