# 带拍 · 移动端测试工具 v3.7

> **版本单一事实源**：产品逻辑与版本以 `.claude/skills/daipai/SKILL.md` frontmatter 为准（当前 **v3.7**）。本 README 与各模板注释中的 vX.X 仅标注功能引入点，不构成产品版本；改版本号请先改 skill frontmatter。

在电脑上启动后，手机浏览器访问即可拍照上传 → AI 分析 → 获取拍摄方案。

**手机访问**：`http://<电脑IP>:8888`（手机和电脑同一 WiFi）

---

## 快速开始

```bash
cd mobile-tester

# 1. 配置豆包 API Key
echo 'DOUBAO_API_KEY=你的密钥' > .env

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动
./start.sh
# 或直接: python3 server.py
```

浏览器访问 `http://localhost:8888`，手机访问 `http://<电脑局域网IP>:8888`。

### 通过 Tailscale 远程访问

如果安装了 [Tailscale](https://tailscale.com)，`start.sh` 会自动检测 Tailscale IP，手机在**任何地方**都能访问（不需要同一 WiFi）。

## 功能概述

### 📱 拍照上传 → 渐进式分析

1. **选择设备**（顶栏）——支持 EXIF 自动识别 iPhone 型号，或手动选择 14 款设备（含 9 款小红书热门相机）
2. **上传照片**——支持 HEIC/JPEG/PNG，最大 20MB
3. **渐进式展示**（SSE 流式）：
   - 📷 EXIF 数据（设备型号、镜头、GPS）
   - 🌤️ 场景分析（地点、天气、光线时段）
   - 🎬 方向选择卡片（滑动切换 🟢/🔥/✨）
   - 📋 拍摄方案（点击方向后按需生成，支持缓存）

### 🎯 方向卡片（轮播滑动）

| 方向 | 含义 | 说明 |
|------|------|------|
| 🟢 现在就拍 | 不会出错 | 站过去就能拍，基础构图保证好看 |
| 🔥 最出片 | 朋友圈会问在哪拍的 | 精心构思，充分利用场景和设备 |
| ✨ 脑洞大开 | 还能这样拍？ | 意想不到的视角和创意 |

每个方向支持左右滑动切换，底部圆点指示器显示当前位置。

### 📋 拍摄方案（轮播滑动）

每套方案包含：
- **方案名称** + **风格标签**
- **动作指令**（口语化，"让你男朋友蹲下来，手机举到胸口高度"）
- **💡 为什么好看**（摄影原理，可折叠）
- **🎯 换个思路**（可选，有真正的观看方式变化才出现）
- **🤖 生图提示词**（9要素公式：主体→场景→光线→角度→设备→效果→风格→色调→画质）

每个方向 1-9 套方案，场景越丰富方案越多。

### 📸 Canvas 视觉标注

在原图上叠加标注图形（站位指示、取景范围、裁剪建议），文字说不清的位置用坐标说清。

### 🔧 设备上下文注入

生成方案时自动注入当前选择的设备信息：
- 设备能力和限制（焦段覆盖、弱光表现、人像模式等）
- 镜头选择（可换镜头相机）
- 设备特定的拍摄建议

### 🖼️ 生图提示词

方案末尾附带豆包 Seedream 生图提示词，包含：
- 9 要素完整公式
- 设备描述（"iPhone 17 Pro 主摄（24mm等效）拍摄"）
- 光线条件（黄金时刻/蓝调时刻 + 光线方向/质量）
- 色彩色调

## 技术架构

```
手机浏览器 ──HTTP──▶ Flask server.py (port 8888)
                        ├─ EXIF 提取（exif-extract.py）
                        ├─ 豆包视觉 API（识图）
                        ├─ 豆包 LLM API（方向 + 方案生成）
                        ├─ GPS→地点反向编码
                        ├─ 太阳位置 + 时域调度
                        └─ style_cache.json（风格匹配缓存）
                            ↓
                        SSE 流式响应 → 渐进式 UI 更新
```

### 文件结构

```
mobile-tester/
├── server.py              # Flask 后端（1864行），SSE流式 + 设备检测 + Prompt工程
├── templates/
│   └── index.html         # 前端单页（1565行），CSS scroll-snap 轮播 + Canvas 标注
├── static/                # 静态资源
├── start.sh               # 启动脚本（支持 Tailscale）
├── style_cache.json       # 风格匹配缓存（自动积累，已 gitignore）
├── .env                   # API Key（已 gitignore）
├── .gitignore
├── requirements.txt       # Python 依赖
└── README.md              # 本文件
```

### API 端点

| 端点 | 方法 | 说明 |
|------|:--:|------|
| `/` | GET | 移动端主页 |
| `/analyze` | POST | 上传照片，SSE 流式返回分析结果 |
| `/analyze/plans` | POST | 按需生成方案（用户选方向后调用） |
| `/health` | GET | 健康检查（API配置/缓存/活跃会话） |
