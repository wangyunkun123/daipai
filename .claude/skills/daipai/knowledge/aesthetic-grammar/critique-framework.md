# 审美批判框架 · Aesthetic Critique

## 一句话定义

**审美批判框架 = 一组结构化的自检维度，用来评估一张（组）照片的审美完成度。** 不是你「喜不喜欢」一张照片——是你能不能说清楚「为什么好」和「哪里可以更好」。

——框架参考 豆包·批判性评估框架 + Barnbaum 审美判断 + Barrett 摄影批评

---

## 原理

### 为什么需要审美批判框架

豆包在审查中明确指出：ShotOracle 审美体系缺少一个**自检/批判工具**。现有的质量检查偏技术维度（多样性/可行性/场景保真），缺少审美维度的结构化评估。

**「好看」是一个终点，不是工具。** 你需要的是在到达终点之前，知道这张照片在哪个审美维度上强、在哪个维度上弱、弱了多少、怎么改。

### 批判 ≠ 批评

批判（Critique）不意味着「找茬」。在艺术教育中，批判 = **结构化的审视和分析**。它关注的是：
- 这张照片试图做什么？（意图）
- 它做到了吗？（执行）
- 做到的程度如何？（评估）
- 怎样可以做得更好？（改进方向）

---

## 四大批判维度

### 维度 1：叙事完整性 · Narrative Completeness

**这张照片是否成功传达了它想传达的信息/情绪/故事？**

| 评估问题 | 评分线索 |
|---------|---------|
| 画面有明确的「主角」吗？ | 如果观众的第一反应是「我应该看哪里」→ 叙事不完整 |
| 画面的情绪基调是否一致？ | 暖光+温色+硬阴影——暖光和温色说「温柔」，硬阴影说「紧张」→ 情绪矛盾 |
| （组图）9 张放在一起是否构成故事？ | 翻完 9 张后，观众能说出「这组照片讲了什么」吗？ |
| 有没有信息冗余？（同样的信息说了好几遍） | 9 张有 6 张是相似的中景微笑 → 信息冗余 |
| 有没有信息缺失？（观众想问但答案不在画面中） | 「她在看什么？」画面中看不到 → 可能是留白叙事，可能是信息缺失 |

### 维度 2：调性统一度 · Tonal Coherence

**画面的视觉元素是否全部服务于同一个审美调性？**

| 评估问题 | 评分线索 |
|---------|---------|
| 色彩是否统一？（色温/色调/饱和度） | 有没有突然跳出来的颜色？（如整组低饱和中突然一张高饱和） |
| 光质是否统一？ | 有没有 6 张软光+3 张硬光但没有叙事理由？ |
| 质感是否统一？ | 有没有全柔的画面突然一张全锐？ |
| 调性矛盾是否是有意的？ | 如果第 5 张故意打破了统一调性——这是破格还是失误？ |
| （组图）9 张的整体审美基调在 3 秒内能被感知吗？ | 快速翻看 9 张小图——第一印象的色调和情绪方向是否一致？ |

### 维度 3：取舍合理性 · Editorial Judgment

**这张照片中「去掉了什么」和「保留了什么」的决策是否合理？**

| 评估问题 | 评分线索 |
|---------|---------|
| 有没有不该出现的元素？（视觉噪音） | 四角扫描：每个角有干扰物吗？ |
| 有没有不该去掉的元素？（过度减法） | 极简到画面中没有足够的信息——观众困惑 |
| 景别选择是否匹配叙事意图？ | 情绪人像用远景（距离太远）→ 取舍不当 |
| 焦段选择是否匹配空间叙事？ | 窄空间用超广角（变形干扰主体）→ 取舍不当 |
| 虚化程度是否匹配信息需求？ | 需要环境叙事的场景把背景全虚掉 → 信息损失 |
| （组图）每张照片的取舍是否和它在叙事弧中的位置匹配？ | 开场用特写 → 观众不知道「这是哪里」→ 取舍与序位冲突 |

### 维度 4：破格目的性 · Rule-breaking Intentionality

**如果打破了规则——为什么？值得吗？**

| 评估问题 | 评分线索 |
|---------|---------|
| 破格是否明显到能被感知？ | 倾斜 2° → 观众觉得水平没调好（危险）；倾斜 8° → 观众感知到「故意的」 |
| 破格是否让画面获得了新的审美维度？ | 打破规则后，画面是否比不打破时「多了什么」？ |
| （多条破格）所有破格是否服务于同一情绪？ | 森山大道：倾斜+直闪+颗粒+高反差都指向「生猛」 ✓ |
| 破格的「代价」是否值得？ | 代价 = 打破规则带来的不适感。如果代价 > 新增的审美维度 → 不值得 |
| （组图）破格方案是否出现在叙事弧的合适位置？ | 破格放在第 1 张 → 观众以为整组都是这个调性。放在转折点 → 冲击最大化 |

## 审美批判的评分系统

### 不是打分——是定位

批判框架的目的不是给照片打分（7/10），而是在四个维度上**定位强项和弱项**：

```
叙事完整性  ████████░░  8/10
调性统一度  ███████░░░  7/10
取舍合理性  ██████░░░░  6/10 ← 最大改进空间
破格目的性  ████████░░  8/10（无破格 = 8 分默认）
```

**定位后问自己**：最弱的那个维度，改进 1 分需要改变什么？

### 改进优先级

1. **取舍合理性 < 5**：先修这个——画面的基础组织有问题
2. **调性统一度 < 5**：先修这个——画面元素互相打架
3. **叙事完整性 < 5**：先修这个——观众不知道你在说什么
4. **破格目的性 < 5**：检查破格是否不经思考

---

## 批判的「三个不」

1. **不评判风格偏好**：「我不喜欢日系清新」不是批判——是个人偏好。批判应该问：在这个风格内，这张照片做得好吗？
2. **不脱离意图评价**：不要用电影感的标准评价一张日系清新照片。「太淡了」对日系清新不是缺点——是特征。
3. **不跳过「为什么」**：「这张不好看」不是批判——是结论。批判要求你解释「不好看的原因」——哪个维度弱了？弱了多少？

---

## 批判流程

```
1. 确定意图 → 这张照片（组照片）试图做什么？
2. 逐维审视 → 叙事/调性/取舍/破格——各得几分？
3. 定位弱项 → 哪个维度最需要改进？
4. 找出原因 → 弱项的具体原因是什么？（不要停在「构图不好」——具体到「主体左侧的亮色块把视觉重心带偏了」）
5. 提出改进 → 如果重拍，你会改变什么？
```

## 在方案生成中的使用

### 阶段 4（质量检查）增加审美批判维度

在现有质量检查（技术维度）之后，增加审美批判：

```
阶段 4 · 质量检查
├── 技术维度（现有）
│   ├── 构图多样性检查
│   ├── 设备可行性检查
│   └── 场景保真度检查
│
└── 审美维度（新增）
    ├── 叙事完整性：9 张是否构成故事？
    ├── 调性统一度：9 张的色彩/光质/质感是否协调？
    ├── 取舍合理性：每张的加减法决策是否成立？
    └── 破格目的性：如果有破格，目的是否成立？
```

### 输出格式中的批判摘要

```markdown
## 审美批判

| 维度 | 评分 | 一句话 |
|------|------|--------|
| 叙事完整性 | 8/10 | 故事清晰，留白叙事第9张做得好。第3-4张叙事密度重复 |
| 调性统一度 | 9/10 | 日系蓝绿基调统一。第7张的暖色偏移有意为之，但过渡稍大 |
| 取舍合理性 | 7/10 | 大部分取舍精准。第2张的背景亮区可以进一步虚化 |
| 破格目的性 | 8/10 | 第5张倾斜构图成立——增加动感 |

**改进方向**：如果重拍一组，给第3-4张分配不同的叙事角色（一张用动作叙事，一张用情绪叙事）。
```
