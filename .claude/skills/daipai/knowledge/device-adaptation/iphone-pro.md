# iPhone Pro 系列设备档案

## 设备识别

**适用型号**：iPhone 13 Pro / 14 Pro / 15 Pro / 16 Pro 及同代 Pro Max
**用户画像**：追求画质的手机摄影用户、博主、小红书/Instagram 内容创作者
**ShotOracle 默认设备**：如果没有指定设备，按此档案生成方案

---

## 一、焦段与传感器配置

| 焦段名称 | 等效焦距 | 传感器 | 像素 | 光圈 | 画质评级 |
|---------|---------|--------|------|------|---------|
| 超广角 | ~13mm | 小（~1/3"） | 12-48MP | f/2.2-2.4 | ⭐⭐ |
| 广角（主摄） | ~24mm | 大（~1/1.3"） | 12-48MP | f/1.5-1.8 | ⭐⭐⭐⭐⭐ |
| 长焦 | 77-120mm（因代而异） | 中小（~1/3"） | 12-48MP | f/2.8-3.5 | ⭐⭐⭐ |

**关键差异（按代际）**：
| 代际 | 长焦焦距 | 备注 |
|------|---------|------|
| 13 Pro | 77mm（3×） | 画质一般，人像模式主力 |
| 14 Pro | 77mm（3×） | 传感器增大 |
| 15 Pro | 77mm（3×） | 光圈增大到 f/2.8 |
| 16 Pro | 120mm（5×） | 大幅跃进但光圈 f/3.5 弱光受限 |

**缺失焦段**：50mm 标准中焦（2×）——部分代通过主摄裁切实现（24mm 裁 2× = 12MP 48mm），非独立光学。

## 二、核心优势

| 优势 | 说明 | 审美价值 |
|------|------|---------|
| **色彩科学** | 苹果色彩引擎——肤色还原最稳定，白平衡最"诚实" | 真实、不媚俗——安静真实/纪实/极简的首选 |
| **ProRAW** | 12-bit DNG，12-14 档动态范围，后期空间大 | 可以像相机一样后期调光比和影调 |
| **LiDAR** | 暗光下精确测距，夜景人像模式分离头发丝 | 暗光人像 = 手机最强 |
| **计算摄影克制** | 相比安卓旗舰，苹果的 AI 介入更保守——保留更多真实质感 | 反 AI 原生质感的首选设备 |
| **Live Photo** | ±1.5 秒时间窗口，自动记录按快门前后的帧 | 拍摄时机 → 非关键约束。决定性瞬间可以后期选帧 |
| **不引人注意** | 小巧、不显眼，被拍者放松 | 抓拍/街拍/亲密肖像的最佳设备形态 |

## 三、核心短板

| 短板 | 说明 | 方案规避策略 |
|------|------|------------|
| **无独立中焦（~50mm）** | 24mm 跳 77/120mm，中间 50mm 靠裁切——损失像素和画质 | 人像近景优先用 77mm→退后 1.5-2m；或用 24mm→靠近至 1m 但有轻微透视变形 |
| **长焦弱光差** | 长焦传感器面积仅为主摄 1/4-1/6，暗光下噪点多、对焦慢 | 弱光下避免长焦方案，改用 24mm 靠近+后期裁切 |
| **光圈固定** | 无法通过光圈控制景深——景深完全靠距离差策略 | 所有浅景深方案都翻译为「近距离+远背景」 |
| **无反光板/离机闪** | 补光手段有限 | 利用环境反光（白墙/沙地/水面）+ 另一台手机的屏幕补光 |
| **超广角畸变** | 13mm 边缘拉伸明显——人脸放边缘会严重变形 | 超广角方案必须注明「人必须居中」 |

## 四、知识→操作翻译表

### 焦段映射

| 理论语言 | iPhone Pro 操作 | 注意事项 |
|---------|----------------|---------|
| 超广角（<20mm） | 0.5×（~13mm） | 边缘变形；人必须居中 |
| 广角（24-35mm） | 1×（~24mm） | 主摄，最佳画质 |
| 标准-中焦（50mm） | 1× 靠近+后期裁切，或 ProRAW 48MP 2× 裁切 | 非独立光学，裁切后约 12MP |
| 中长焦（77-85mm） | 3×（13/14/15 Pro） | 人像/近景最佳焦段 |
| 长焦（120mm+） | 5×（16 Pro） | 压缩感强但弱光受限 |

### 景深控制

| 理论语言 | iPhone Pro 操作 |
|---------|----------------|
| 「浅景深、虚化背景」 | 1× 靠近至 0.5-1.5m + 背景离主体 5m+ → 物理虚化 + 人像模式 f/1.4-16 可选 |
| 「中等景深」 | 1× 在 2-5m 拍摄距离 → 手机天然中-深景深 |
| 「全景深、全清晰」 | 0.5× + 对焦远处 → 手机天然优势。f/2.2 超广角 = 等效全画幅 f/11 景深 |

**虚化操作细节**：
- **人像模式最佳范围**：1-3m 拍摄距离、2×-3× 焦段、简单背景（非镂空/非细密纹理）
- **何时关闭人像模式**：蕾丝帽檐/飞发/镂空衣物（边缘切割会穿帮）；夜景弱光（噪点多）；需要完整环境叙事
- **距离差策略**（最可靠）：相机离主体近 + 主体离背景远 = 纯物理虚化，不依赖计算摄影

### 曝光控制

| 理论语言 | iPhone Pro 操作 |
|---------|----------------|
| 「曝光以人脸为准」 | 点按人脸 → 锁定 AE/AF（长按）。上下滑动微调 ±2EV |
| 「保留高光」 | 点按画面最亮区域锁定 → 暗部自然暗 |
| 「保留暗部」 | 点按画面最暗区域锁定 → 亮部可能过曝 |
| 「高光比场景」 | 开启 HDR（自动）或拍 ProRAW 后期拉回 |
| 「低噪点」 | 优先 1× 主摄 + 尽可能低 ISO（自动模式已优化） |

### 时机与连拍

| 操作 | iPhone Pro 方式 |
|------|----------------|
| 连拍 | 按住快门左滑（或音量键按住不放） |
| 前后帧选择 | Live Photo 提供 ±1.5s——编辑中选择「关键照片」 |
| 无震动快门 | 音量键代替触摸屏；或 Apple Watch 远程快门 |
| 自拍/合影 | 3 秒计时器 + 连拍 |

## 五、弱光策略

### 焦段优先级（弱光下）

```
1× 主摄 >> 0.5× 超广角 >> 3×/5× 长焦
（传感器面积越来越小 → 弱光表现越来越差）
```

### 弱光方案决策树

```
夜景/室内暗光
│
├─ 模特可以保持静止？
│   ├─ 是 → 夜景模式（1-3 秒）+ 稳定支撑
│   └─ 否 → 放弃长曝光
│       ├─ 优先 1× 主摄（传感器最大）
│       ├─ 提高 ISO 接受噪点（ProRAW 后期降噪空间大）
│       └─ 有 LiDAR？ → 夜景人像模式可用
│
└─ 完全不可见/极暗？
    └─ 主动创造光源：另一台手机屏幕/手电筒/窗边路灯 → 不依赖设备硬扛黑暗
```

## 六、推荐设置

| 设置 | 推荐 | 理由 |
|------|------|------|
| 格式 | **ProRAW**（若支持） | 后期空间最大；如果不后期 → HEIF/JPEG |
| 网格线 | **开启** | 三分法/对称构图基础 |
| 水平仪 | **开启** | 海天交界/建筑对称必需 |
| 镜头校正 | **开启**（设置→相机） | 矫正超广角畸变 |
| Live Photo | **开启** | 拍摄时机的最佳保险 |
| 闪光灯 | **关闭** | 手机直闪光质差——除非故意模仿 CCD/Lofi 风格 |
| HDR | 自动 | 大部分场景有益 |

## 七、风格兼容性

| 风格 | iPhone Pro 兼容度 | 备注 |
|------|-----------------|------|
| 日系清新 | ★★★★★ | 色彩科学加分；24mm 最适合 |
| 电影感 | ★★★★☆ | ProRAW 后期调暗调/暖色；缺 50mm 中焦 |
| 极简高级 | ★★★★★ | ProRAW + 网格 + 水平仪 = 完美 |
| 纪实粗粝 | ★★★★☆ | 不引人注意 = 先天优势；缺高感颗粒（需后期加） |
| 安静真实 | ★★★★★ | 最佳设备——不引人注意+色彩不媚俗 |
| Lofi 直闪 | ★★★☆☆ | 直闪灯可用但光质偏硬；CCD 色偏需后期 |
| Grunge | ★★★☆☆ | 可以拍但粗粝质感需后期重颗粒+褪色 |
| 梦幻柔美 | ★★★★☆ | 人像模式柔焦效果好；逆光眩光漂亮 |
