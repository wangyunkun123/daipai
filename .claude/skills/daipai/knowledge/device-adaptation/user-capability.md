# 用户能力模型

## 一句话定义

**方案不是越专业越好——是用户拿着手机、站在原地、30 秒内能做到的才好。** 本文件定义手机用户的真实能力边界，所有方案生成必须在此边界内。

---

## 一、核心原则

### 1.1 用户不是摄影师

| 摄影师 | 手机用户 |
|--------|---------|
| 能控制光源方向和质量 | 窗户在哪光就在哪 |
| 有光圈环可以调景深 | 固定光圈，只能靠距离差 |
| 后期是完整工作流 | 相册里调亮度/对比度/滤镜 |
| 有充裕时间布光构图 | 心理预算通常 ≤ 30 秒 |
| 理解"侧光""逆光"等术语 | 只理解"站到这边""手机放低点" |

### 1.2 核心约束

**光是被动的。** 这是手机用户与摄影师之间最根本的差异。手机用户不能：

- 改变日光方向
- 把硬光变成软光（除非等阴天或拉窗帘）
- 精确控制景深（手机光圈固定）
- 执行复杂后期（超出相册编辑能力）

**方案必须从"在这个固定的光线下，用户能移动到哪个位置来利用它"出发——而不是从"这个场景适合什么光"出发。**

## 二、用户可操作动作分级

### 🟢 零成本动作（1-5 秒，不需准备）

| 动作 | 操作 | 摄影效果 |
|------|------|---------|
| 切焦段 | 点按 0.5×/1×/2×/3×/5× | 改变取景范围、空间关系 |
| 点按对焦/曝光 | 点屏幕不同位置 | 改变焦点、以不同亮度区为曝光基准 |
| 调曝光补偿 | 对焦后上下滑 ±2EV | 整体变亮/变暗 |
| 锁定 AE/AF | 长按屏幕 | 固定焦点和曝光——重新构图时不偏移 |
| 切换网格线 | 设置→相机→网格 | 三分法辅助线 |
| 切换闪光灯 | 关/开/自动 | 通常建议关 |
| 切换 Live Photo | 开/关 | 时机保险 ±1.5s |
| 切换人像模式 | 开/关 | 计算虚化 |

### 🟡 低成本动作（10-30 秒，微调即可）

| 动作 | 操作 | 摄影效果 |
|------|------|---------|
| 改变机位高度 | 站立/半蹲/蹲下/贴地 | 改变视角——俯拍/平视/仰拍 |
| 改变机位方向 | 绕主体走 2-5 步 | 改变光线相对于主体的方向（侧光→顺光→侧逆光） |
| 改变拍摄距离 | 靠近/退后 1-3 米 | 改变主体大小、景别 |
| 竖/横切换 | 旋转手机 90° | 改变画幅方向 |
| 移动被摄体 | 把物品挪到窗边/桌上另一位置 | 改变光线条件——用上了被动光的"主动"一面 |
| 清理背景 | 移走画面中杂物 | 减少视觉噪音 |
| 身体姿势配合 | 举高手机、手臂伸远、靠在固定物上 | 稳定支撑、特殊角度 |

### 🟠 中成本动作（30 秒-2 分钟，需要找辅助）

| 动作 | 操作 | 摄影效果 |
|------|------|---------|
| 前景框制造 | 拿一个物品放在镜头前 10-15cm | 虚化前景框——窥视感/层次感 |
| 天然反光利用 | 找白纸/白色桌面/浅色墙面做反光 | 给暗面补光——降低光比 |
| 光线柔化 | 拉纱帘/半透明物遮挡直射光 | 硬光→软光 |
| 反光消除 | 改变角度避开玻璃/塑料反光 | 减少杂光 |
| 等待时机 | 等云遮太阳（软光）/ 等云过去（硬光）/ 等风停/等人走过 | 改变光质或画面元素 |

### 🔴 高成本动作（需要设备或超出 2 分钟）

| 动作 | 操作 | 摄影效果 |
|------|------|---------|
| 额外光源 | 开台灯/手机手电筒/便携补光灯 | 主动补光 |
| 三脚架 | 架设稳定支撑 | 长曝光、夜景、定时自拍 |
| 外接镜头 | 微距/广角附加镜 | 扩展焦段 |
| 后期调色 | Lightroom/VSCO/Snapseed | 超出相册编辑能力的所有调整 |

### ❌ 不可行动作（手机用户做不到）

| 动作 | 为什么做不到 |
|------|------------|
| 改变日光方向 | 太阳不听你的 |
| 改变光质（硬→软） | 除非有纱帘或等阴天——需要外部条件配合 |
| 精确光圈控制 | 手机固定光圈 |
| 精确景深控制 | 只能靠距离差逼近，不可精确设定 |
| 后期精修 | 超出相册 App 能力——需跳转到专业软件 |

## 三、光线被动利用策略

对于手机用户，问题的起点不是"这个场景适合什么光"，而是"光已经固定了，你能站到哪去利用它"。

### 3.1 窗户在桌子前方（顺光位置）

```
光从用户背后照向桌面
→ 色彩还原准确、无硬阴影
→ 🟢 可用风格：安静真实、日系清新、极简高级
→ ⚠️ 注意：顺光下木纹/布面纹理不明显（缺少阴影→纹理"平"）
→ 💡 补偿：降低机位+侧向移动→把纯顺光变成侧顺光→纹理回来
```

### 3.2 窗户在桌子侧面（侧光位置）

```
光从左或右照向桌面
→ 纹理最明显、立体感最强
→ 🟢 可用风格：纪实粗粝、Grunge、质感动人
→ ⚠️ 注意：光比可能偏大（亮面亮暗面暗）→手机HDR通常够用
→ 💡 优势：侧光+低角度=木纹质感最大化的最佳组合
```

### 3.3 窗户在桌子对面（逆光位置）

```
光从桌子背后照向用户
→ 主体暗、背景亮
→ 🟢 可用风格：剪影、通透质感（透明/半透明物体发光）
→ 🟡 需要做：①以主体为曝光基准→背景过曝但主体可辨
            ②以背景为曝光基准→主体成剪影
            ③移动主体到侧面→变逆光为侧光
→ 💡 优势：透明物体（玻璃、塑料鸭、纱）在逆光下通透发光=天然美感
```

### 3.4 室内无窗或阴天（纯漫射光）

```
没有方向性光源→全方位柔光
→ 色彩表现佳、无硬阴影、光比小
→ 🟢 可用风格：安静真实、极简高级、日系清新
→ ❌ 不可用风格：Grunge（缺硬光纹理）、电影感（缺方向性光）
→ ⚠️ 注意：画面可能"太平"→靠构图增加张力（对角线/引导线/框架）
→ 💡 优势："不需要做任何事"——拿起就拍，这是最容易执行的光线条件
```

### 3.5 户外（日光）

```
太阳位置固定→但用户可以自由移动来选择光线方向
→ 参照 suncalc 计算太阳方位和高度
→ 🟢 黄金时刻（日落前后30min）：所有风格都可用，光暖+软+方向性
→ 🟡 正午顶光：阴影在眼窝→低头/侧头/移到阴影里/何藩式光影几何
→ 🟠 硬光：纪实/Grunge/黑白可用；柔美人像不可用
```

## 五、可执行性四级标记

方案生成时，每套方案必须带以下标记之一：

| 标记 | 含义 | 判定标准 | 用户看到后的反应 |
|------|------|---------|----------------|
| 🟢 **直接拍** | 不需要任何准备 | 只用到零成本动作（切焦段/点按曝光/调补偿） | "好，现在就能拍" |
| 🟡 **微调后拍** | 需要小调整，≤30秒 | 用到低成本动作（站位/高度/距离/挪物品） | "让我换个位置就行" |
| 🟠 **准备后拍** | 需要找辅助或等待，≤2分钟 | 用到中成本动作（反光板/纱帘/等光/前景框） | "我找个白纸来补个光" |
| 🔴 **需后期** | 需要相册App以外的后期处理 | 包含后期方向且超出相册编辑能力 | 提供替代方案：「如果不想后期，可以改为...」 |

### 标记使用规则

1. 9 套方案中 🟢+🟡 ≥ 7 套（多数方案零门槛）
2. 🟠 不超过 2 套
3. 🔴 不超过 1 套，且必须附带 🟡 替代方案
4. 不能有方案不带标记

## 六、方案生成硬约束

所有方案必须通过以下检查才能输出：

| # | 检查项 | 不通过处理 |
|---|--------|----------|
| 1 | 方案所需光线条件是否与场景实际光线匹配？ | 不匹配→修改方案或降级为替代策略 |
| 2 | 方案所需操作是否在用户能力边界内？ | 不可行→降级或标记为不可执行 |
| 3 | 方案建议是否翻译为用户动作语言？ | "用侧光"→"站到桌子侧面，让窗户在你左边" |
| 4 | 方案是否标注可执行性标记？ | 补标记 |
| 5 | 是否有不需要的任何道具/设备？ | 去掉或标注为可选 |

## 七、动作翻译对照表

方案中的摄影术语必须翻译为用户可执行的动作：

| 摄影语言（❌ 不给用户看） | 用户动作语言（✅ 输出用） |
|------------------------|------------------------|
| "使用侧光" | "站到桌子侧面——让窗户在你左边或右边" |
| "逆光+通透质感" | "让窗户在你拍的东西背后——光线穿过半透明的物体会让它发光。如果窗户不在那边，把东西移到窗户前面" |
| "软光策略" | "你现在的室内光已经是柔和的了——不需要做任何事。如果正午阳光直射进来太刺眼，拉上纱帘或等云遮一下太阳" |
| "浅景深虚化背景" | "手机靠近被拍的东西（0.5-1m），确保它背后有 3 米以上的空间——背景自然就模糊了" |
| "前景虚化框架" | "随手拿个东西（鼠标/杯子/胶带都行）放在镜头前 10cm——它会自动变成模糊的色块，被拍的东西在色块中间。像透过门缝看" |
| "低角度仰拍" | "手机贴到桌面——屏幕可能看不到，盲拍一张看看效果再调" |
| "曝光以主体为准" | "点按你想拍清楚的那个东西→长按锁定→上下滑调亮度到你喜欢的程度" |
| "降低光比" | "找张白纸或白色桌面，放在暗的那一侧——光会弹过去补一点亮度。没有白纸就算了，手机 HDR 也能处理大部分" |
| "俯拍全景" | "手机举高到桌面上方约 50cm，屏幕朝下。双手持机稳住——或者靠在高处的东西上" |
| "保留噪点" | "如果用的是 iPhone 17 Pro：设置里关掉 AI 降噪。其他手机：降低 ISO 或后期不要开降噪滤镜" |
| "高对比黑白" | "拍完后：编辑→滤镜→黑白→把对比度拉到最高。3 秒搞定，不用跳去别的 App" |
| "暖色调" | "不要调白平衡——现在室内光的暖色就很好，让画面保持现在这种温暖的感觉" |
