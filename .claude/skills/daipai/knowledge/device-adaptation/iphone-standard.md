# iPhone 标准版设备档案

## 设备识别

**适用型号**：iPhone 13 / 14 / 15 / 16（非 Pro 版本）
**用户画像**：最大用户群——日常拍摄、社交媒体分享、旅行记录。多数人不追求"专业摄影"但想要"好看的照片"
**ShotOracle 关键适配**：所有方案必须考虑「没有长焦」这一硬约束

---

## 一、焦段与传感器配置

| 焦段名称 | 等效焦距 | 传感器 | 像素 | 光圈 | 画质评级 |
|---------|---------|--------|------|------|---------|
| 超广角 | ~13mm | 小（~1/3"） | 12MP | f/2.2-2.4 | ⭐⭐ |
| 广角（主摄） | ~24-28mm | 中（~1/1.5"） | 12-48MP | f/1.5-1.8 | ⭐⭐⭐⭐ |
| ~~长焦~~ | **无** | — | — | — | — |

**致命缺失**：**没有长焦镜头。** 任何需要 50mm+ 焦段的方案都必须通过以下三种方式替代：
1. 1× 靠近模特（最近 0.3-0.5m 对焦距离）→ 透视会变
2. 1× 裁切（48MP 主摄裁 2× = 12MP 48mm）→ 像素损失可接受
3. 外接长焦附加镜 → 多数用户没有

## 二、核心优势

| 优势 | 说明 | 审美价值 |
|------|------|---------|
| **用户量最大** | iPhone 标准版销量远超 Pro | ShotOracle 最大的用户群 |
| **色彩科学（同 Pro）** | 肤色还原和白平衡与 Pro 一致 | 真实不媚俗 |
| **广角画质优秀** | 主摄与 Pro 同级 | 24mm 是大多数方案的主力焦段 |
| **不引人注意（同 Pro）** | 小巧不显眼 | 抓拍/街拍/亲密肖像 |
| **Live Photo** | ±1.5 秒时间窗口 | 拍摄时机有保障 |
| **操作简单** | 没有 Pro 的多余功能——用户不会困惑 | 方案生成可以更聚焦 |

---

## 三、核心短板

| 短板 | 说明 | 方案规避策略 |
|------|------|------------|
| **无长焦** | 这是最大的单点短板——远景压缩感、人像近景（50-85mm 标准人像焦段）、远距离细节全部缺失 | **绝不能用长焦方案**。所有远景/近景/特写需重新设计：远景用 1× + 退后；近景用 1× + 靠近（注意透视）；特写用 1× + 最近对焦距离 |
| **无人像模式 LiDAR** | 人像模式边缘切割靠纯软件，复杂场景（飞发/镂空）穿帮概率高 | 回避复杂边缘场景；或用人像模式但选简单的纯色背景 |
| **弱光人像差于 Pro** | 无 LiDAR + 传感器可能略小 | 弱光人像建议关人像模式，用物理虚化 |
| **无 ProRAW** | 后期自由度低 | 拍摄时更重视曝光准确性——后期补救空间小 |
| **无长焦 → 特写困难** | 不能远距离拍近景 | 特写方案需改成「物理靠近」而非「长焦拉近」 |

## 四、知识→操作翻译表

### 焦段映射（最关键的差异）

| 理论语言 | iPhone 标准版操作 | 替代方案 | 副作用 |
|---------|-----------------|---------|--------|
| 超广角（<20mm） | 0.5×（~13mm） | 同 Pro | 边缘变形 |
| 广角（24-35mm） | 1×（~24-28mm） | 同 Pro | — |
| 标准-中焦（50mm） | **1× 靠近至 1m + 后期裁切至 2×** | 48MP 型号可无损裁切 2× = 12MP 48mm | 透视轻微变宽（鼻子比 50mm 真实透视大 5-10%） |
| 中长焦（77-85mm） | **1× 靠近至 0.5-0.8m + 裁切** | 没有好的替代方案。这个距离下透视明显变形 | **建议：放弃 77mm+ 的方案，改为中景替代** |
| 长焦（>100mm） | **无法替代。完全不可用。** | 方案中所有长焦指令必须被拒绝或降级 | **硬约束——生成方案前检查焦段可行性** |

### 景深控制

| 理论语言 | iPhone 标准版操作 |
|---------|-----------------|
| 「浅景深」 | 距离差策略：1× + 靠近至 0.5-1m + 背景离主体 5m+。人像模式辅助（简单背景时） |
| 「中等景深」 | 1× 在 1.5-5m 距离 → 手机天然中景深 |
| 「全景深」 | 0.5× + 远距离 → 手机天然优势 |

### 曝光控制（同 Pro、无 ProRAW）

| 理论语言 | iPhone 标准版操作 |
|---------|-----------------|
| 「曝光以人脸为准」 | 点按人脸 → 锁定 AE/AF |
| 「保留高光」 | 点按亮区锁定 |
| 「高光比场景」 | HDR 自动——因为没有 ProRAW，后期拉回能力有限。拍摄时曝光取舍更关键 |

### 时机与连拍（同 Pro）

| 操作 | iPhone 标准版方式 |
|------|-----------------|
| 连拍 | 按住快门左滑 |
| 前后帧选择 | Live Photo ±1.5s |
| 无震动快门 | 音量键 |

## 五、弱光策略

与 Pro 版核心差异：**无 LiDAR → 暗光人像模式不可靠。**

```
夜景/室内暗光
│
├─ 模特可以保持静止？
│   ├─ 是 → 夜景模式（1-3 秒）+ 稳定支撑
│   └─ 否 → 
│       ├─ 必须用 1× 主摄（传感器最大）
│       ├─ 关闭人像模式（暗光下边缘切割很差）
│       ├─ 提高 ISO 接受噪点（无 ProRAW=后期降噪困难，尽量找光）
│       └─ 主动寻找光源 → 窗边/路灯/屏幕光
```

## 六、方案生成的硬约束

### 生成前必检

为 iPhone 标准版生成方案时，以下约束是**硬性的**：

| 约束 | 规则 |
|------|------|
| **禁用长焦方案** | 任何需要 >35mm 焦段的方案必须降级为 1× + 靠近或直接被替代 |
| **特写方案特殊处理** | 特写不能用「长焦远距离拍局部」→ 必须翻译为「1× + 物理靠近 + 最近对焦距离」 |
| **人像近景透视提醒** | 用 1× 拍近景（胸像）→ 需要在方案中注明「靠近至 0.8-1m，会有轻微透视变宽，可接受」 |
| **人像模式谨慎使用** | 只在简单纯色背景时推荐——复杂背景/飞发/镂空衣物时明确提醒关掉 |

### 方案降级示例

| 理论方案（设备无关） | iPhone Pro 执行 | iPhone 标准版 降级 |
|-------------------|----------------|-----------------|
| 「3× 长焦拍胸像」 | ✅ 3×（77mm）退后 1.5-2m | ⚠️ 降级为「1× 靠近至 0.8-1m 拍胸像 + 裁切。透视轻微变宽可接受」 |
| 「5× 拍远景人物剪影」 | ✅ 5×（120mm）拍远景 | ❌ 不可行。改为「拍中景代替远景——用 1× + 退后至人物占画面 15-25%」 |
| 「长焦特写拍手部细节」 | ✅ 3×/5× + 保持 1m+ 距离 | ⚠️ 降级为「1× + 靠近至最近对焦距离拍手部——注意勿挡光」 |

## 七、风格兼容性

| 风格 | iPhone 标准版兼容度 | 备注 |
|------|-----------------|------|
| 日系清新 | ★★★★☆ | 依赖 24mm 广角——大部分日系配方可用。近景需注意透视 |
| 电影感 | ★★★☆☆ | 缺长焦压缩感 → 电影感削弱。需通过构图+调色弥补 |
| 极简高级 | ★★★★★ | 24mm + 留白 = 完美。无长焦不影响极简 |
| 纪实粗粝 | ★★★★☆ | 不引人注意 + 24mm ≈ 手机街拍最佳组合 |
| 安静真实 | ★★★★★ | 最适配风格——24mm 日常视角 + 简单操作 |
| 梦幻柔美 | ★★★☆☆ | 缺 50mm+ 人像焦段 → 柔美人像受限 |
| Lofi 直闪 | ★★★★★ | 傻瓜机美学不需要长焦 |
| 杂志时尚 | ★★☆☆☆ | 缺长焦 + 无 ProRAW → 时尚人像严重受限 |
| 县城记忆 | ★★★★☆ | 24mm 纪实视角 + 安静观察 |
| 微观微距 | ★★★☆☆ | 缺长焦 → 微距只能靠「物理靠近」——拍花卉食物尚可，拍昆虫等不可 |
