# 怀旧 · Nostalgia

## 情绪定义

**怀旧 = 「那个回不去的美好年代」。** 照片看起来像从旧相册里翻出来的——不是当下的记录，是对过去的温柔回望。怀旧有忧伤的成分，但忧伤是甜的，不是苦的。

**用户常说的相关词汇**：怀旧、复古、旧时光、「以前的样子」、胶片感、年代感、回忆、「想回到过去」。

**区分**：怀旧（nostalgia）= 甜中带苦的回忆。忧伤（sadness）= 纯粹的悲伤。怀旧是「那段时光真好，虽然它过去了」。

---

## 视觉翻译

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩倾向 | **暖色 + 褪色**——暖黄、焦糖、褪色绿、奶油白 | 旧照片因为染料退化会偏暖偏黄 |
| 饱和度 | 全局 -20% ~ -40%——颜色被时间洗淡了 | 注意：不是降到零——旧照片有颜色，只是淡了 |
| 色温 | 偏暖——整体 +300K ~ +800K | 冷色也向暖偏移——蓝色变青、绿色变黄绿 |
| 黑场 | **没有纯黑**——黑色偏灰/偏褐 | 旧照片的暗部会因为褪色而发灰 |
| 白场 | **没有纯白**——白色偏奶油/偏黄 | 旧照片的白因为纸基老化而变黄 |
| 光质 | 软光优先 | 旧照片大多是自然散射光——那个时代没有多少人造控光 |
| 光比 | 中低（1:2 ~ 1:4） | 旧镜头的宽容度有限——大光比场景少 |
| 构图 | 不做特殊限制——怀旧感来自色彩和质感 | |
| 模特状态 | 若有所思、不经意的回眸、旧式的微笑 | 不是当下的即时反应——是「回忆中的那个表情」 |
| 景别倾向 | 中景为主——最接近「旧照片」的观看距离 | |
| 后期方向 | 褪色曲线 + 颗粒 + 暖色偏移 + 暗角 | |

## 氛围感元素

| 载体 | 怀旧情绪中的表现 |
|------|----------------|
| **空气质感** | 旧照片的「空气」是颗粒——均匀的、温暖的颗粒覆盖整个画面 |
| **动态细节** | 怀旧的动态是凝固的——照片本身就是冻结的时间 |
| **留白情绪** | 怀旧的留白是「已经不在的人/物的位置」——空椅子、空沙发、空摇篮 |

---

## 年代感分层

怀旧不是一个单一的视觉风格——不同年代有不同的怀旧色彩：

| 年代 | 色彩特征 | 颗粒 | 适合场景 |
|------|---------|------|---------|
| 70s 柯达 | 暖黄/橙 + 高饱和 + 粗颗粒 | 中高 | 夏日/度假/家庭 |
| 80s 富士 | 青绿偏移 + 中饱和 + 细颗粒 | 中 | 街拍/日常 |
| 90s 傻瓜机 | 闪光灯直打 + 暖色 + 中颗粒 | 中低 | 派对/室内/夜生活 |
| 00s Y2K | 冷色/银色 + 高对比 + 数码噪点（非颗粒） | 低 | 都市/夜店/时尚 |
| 昭和 | 暖黄褪色 + 低饱和 + 柔焦 + 粗颗粒 | 中高 | 街拍/室内/和风 |

## 廉价 vs 高级

| | 廉价怀旧 | 高级怀旧 |
|--|---------|---------|
| 表达 | 直接套用暖色滤镜 + 重颗粒 | 克制的褪色 + 精确的年代感色彩 |
| 颗粒 | 颗粒过多——像砂纸 | 颗粒适中——像银盐照片 |
| 色彩 | 全局偏黄——人的肤色也黄了 | 肤色自然 + 环境偏暖——分离处理 |
| 年代引用 | 混搭——柯达暖色 + Y2K 冷色 → 不伦不类 | 一个画面一个年代——色彩体系统一 |

## 场景适配

| 场景 | 适配度 | 说明 |
|------|--------|------|
| 街拍 | ★★★★★ | 老街道/旧建筑——场景本身就有年代感 |
| 咖啡厅/室内 | ★★★★★ | 旧物/木调/暖灯——室内怀旧的完美配方 |
| 公园 | ★★★★☆ | 自然场景不挑年代 |
| 海边 | ★★★☆☆ | 海边较难「旧」——除非有人文元素（老码头/旧船） |
| 游艇 | ★★☆☆☆ | 游艇太现代——与怀旧气质冲突 |

## 大师关联

- **William Eggleston**：彩色怀旧的先驱——70 年代美国南方的日常色彩
- **Nan Goldin**：私摄影怀旧——闪光灯 + 颗粒 + 亲密关系的记录
- **上田义彦**：日式怀旧广告摄影——暗调 + 暖色 + 极致的胶片质感

---

## 复合情绪

怀旧 + 温暖 = 「那段温暖的旧时光」——暖黄 + 金色光 + 家庭场景。
怀旧 + 浪漫 = 「那个回不去的爱人」——暖粉 + 柔焦 + 单人。
怀旧 + 忧伤 = 「再也回不去了」——褪色 + 冷调暗部 + 空场景。
