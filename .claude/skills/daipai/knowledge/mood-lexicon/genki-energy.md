# 元气感

## 情绪定义

**元气感 = 活力的更具体中文表达——不是"我很有能量"，是"我这个人本身就是能量来源"。** "元气少女"是独立搜索词，"元气感"比"活力"更强调青春感、明亮感和感染力。

**一句话**：画面里的人笑起来让你也想笑——不是"拍得真好"，是"这个人好快乐啊"。

## 核心视觉标志

| 维度 | 参数 |
|------|------|
| 色彩 | 明亮通透/中高饱和/色彩鲜明但不刺眼——暖色系为主 |
| 光质 | 明亮自然光——晴天的柔光最佳 |
| 密度 | 适中——不拥挤也不空旷 |
| 对比 | 中——通透但不戏剧性 |
| 动态 | **高动态**——跳跃/奔跑/转圈/回头，动作本身在传递能量 |

## 摄影翻译

- 晴天户外——明亮通透的自然光是元气感的必要条件
- 多抓拍动态瞬间：跳跃、奔跑、转圈、回头
- 表情：自然的笑——不是"茄子"的假笑，是被抓到的真实开心
- 色调：明亮暖调，不做暗调或冷调
- 构图：可以有动感——倾斜一点、不对称、人物偏一侧有运动方向

## 与已有情绪的关系

- 元气感 ⊂ 活力（energy）：元气感是活力的"青春版"——活力可以是任何年龄的能量感，元气感特指青春+明亮+感染力的组合
- 元气感 ≠ 多巴胺（dopamine）：多巴胺依赖色彩的刺激（高饱和撞色），元气感依赖情绪的感染（笑容+动态+明亮光）
