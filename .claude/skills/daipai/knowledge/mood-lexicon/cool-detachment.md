# 清冷感

## 情绪定义

**清冷感 = 不是孤独——是"我不想被打扰，而且我不需要你的关注"。** 韩系审美的核心情绪——冷白皮+低饱和+平静表情+疏离目光。和"孤独"的区别：孤独是被动的（没有人），清冷是主动的（我不需要人）。

**一句话**：画面里的人看起来像"你可以在远处看，但别走过来"。

## 核心视觉标志

| 维度 | 参数 |
|------|------|
| 色彩 | 冷白/低饱和/蓝灰偏移——"冷白皮"是清冷感的第一视觉锚点 |
| 光质 | 软光或阴天漫射光——不需要暖色光 |
| 密度 | 中低——留白给"疏离"创造空间 |
| 对比 | 低——柔和过渡，没有强烈情绪起伏 |
| 色温 | 偏冷（白平衡偏蓝）——但不是蓝调电影的戏剧性冷，是"不太想暖"的微冷 |

## 摄影翻译

- 白平衡调偏冷——让肤色呈现"冷白皮"
- 饱和度降低，尤其是暖色通道
- 表情：不笑或微抿嘴，眼神看镜头外——"我知道你在拍，但我不太在意"
- 场景：空旷/安静/简洁——不给"热闹"提供任何视觉线索

## 与已有情绪的关系

- 清冷感 ≠ 孤独（solitude）：孤独是"天地间一个人"，清冷是"我在人群中但我不属于人群"
- 清冷感 ≠ 宁静（serenity）：宁静是"时间停在这里很舒服"，清冷是"停在这里也可以，但我不需要"
