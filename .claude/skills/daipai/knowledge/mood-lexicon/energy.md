# 活力 · Energy

## 情绪定义

**活力 = 「活着这件事本身就很好」。** 画面充满动能、生命力、向前冲的能量。观众看完觉得「我也想动起来」。

**用户常说的相关词汇**：活力、元气、生命力、青春、能量、热情、动感、「满血复活」、燃。

---

## 视觉翻译

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩倾向 | **高饱和暖色为主**——红/橙/黄 + 高饱和蓝绿为辅 | 活力需要颜色的"能量感" |
| 饱和度 | 中高——颜色要有存在感 | 低饱和 = 冷静/克制 ≠ 活力 |
| 色温 | 中性到偏暖——5000-6500K | 冷色作为撞色时可以很冷 |
| 撞色策略 | 互补色高饱和碰撞（橙+蓝、红+绿） | 撞色 = 色彩层面的「动能」 |
| 光质 | **硬光优先**——阳光直射、直闪 | 硬光 = 能量的物理属性 |
| 光比 | 中高（1:4 ~ 1:8） | 强光比 = 强能量 |
| 构图 | 对角线（最强的动感构图）、闯入式 | 对称 = 静态 ≠ 活力 |
| 模特状态 | **动态**——跳跃、奔跑、旋转、大笑、身体舒展 | 静止 ≠ 活力 |
| 景别倾向 | 中景（看到动态）+ 近景（看到表情的能量） | 远景太远——能量传达不足 |
| 后期方向 | 中高对比 + 保留/增强饱和 + 高锐度 | |

---

## 氛围感元素

| 载体 | 活力情绪中的表现 |
|------|----------------|
| **空气质感** | 不需要空气质感——活力不需要「氛围」的模糊性，需要清晰 |
| **动态细节** | 跳跃的瞬间、奔跑的步伐、被风吹乱的头发、大笑时眯起的眼睛 |
| **留白情绪** | 活力不需要大量留白——活力是「满」的，是充实的 |
| **水花/尘土** | 运动中的飞溅——水花、尘土、花瓣——物理世界的动能微粒 |

---

## 廉价 vs 高级

| | 廉价活力 | 高级活力 |
|--|---------|---------|
| 表达 | 跳起来 + 比耶——最直白的「活力」 | 运动的优雅——身体线条在动态中的美感 |
| 色彩 | 全局高饱和——所有颜色都在喊 | 控制饱和——高饱和只给 1-2 个主角色 |
| 表情 | 用力过猛的笑——「我在努力快乐」 | 自然的笑——「我真的在享受这一刻」 |
| 构图 | 居中 + 正面——最安全的拍法 | 对角线倾斜 + 广角靠近——构图本身有动能 |

## 场景适配

| 场景 | 适配度 | 说明 |
|------|--------|------|
| 海边 | ★★★★★ | 奔跑 + 海浪 + 水花 = 活力的最佳舞台 |
| 公园/自然 | ★★★★☆ | 草地奔跑/跳跃——自然背景 |
| 街拍 | ★★★★☆ | 城市街头的动感 |
| 游艇 | ★★★☆☆ | 海风 + 动态——但空间有限制 |
| 夜景 | ★★★☆☆ | 城市灯光 + 动态模糊——夜生活的活力 |

## 技术联动

| 技术维度 | 建议 |
|---------|------|
| 焦段 | 广角（28-35mm 靠近增强动能）+ 标准-中焦（50mm 冻结动作） |
| 景别 | 中景 + 近景 |
| 光线 | 硬光 + 中高光比 |
| 色彩 | 高饱和暖色为主 + 冷色撞色 |
| 快门 | **高速 1/500-1/1000s**——冻结动态巅峰 |
| 连拍 | 必须——活力瞬间稍纵即逝 |
