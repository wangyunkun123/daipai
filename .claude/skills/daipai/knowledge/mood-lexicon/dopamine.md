# 多巴胺 · Dopamine

## 情绪定义

**多巴胺 = 「看到这个画面，心情自动变好了」。** 不靠叙事、不靠氛围、不靠隐喻——纯粹靠色彩的快乐能量直接刺激观众的视觉快感。这是最直接的「色彩作为情绪」的实践。

**重要：多巴胺有两个分支。** 主流认知是「高饱和色彩爆炸」，但小红书实际上存在另一个平行分支——「低饱和马卡龙多巴胺」，同样传达快乐但用完全不同的色彩策略。两者都是多巴胺，只是快乐的质地不同。

**用户常说的相关词汇**：多巴胺、快乐、色彩爆炸、「看完心情好」、元气、高饱和度、🌈、「好像吃了彩虹糖」、马卡龙色、「糖果色」。

**区分**：多巴胺（dopamine）= 色彩的纯粹快乐 + 无叙事负担。活力（energy）= 动态 + 动作 + 生命力。多巴胺可以完全静止——一张纯色背景的高饱和肖像 = 最高浓度的多巴胺。

---

## 视觉翻译

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩倾向 | **全色域高饱和**——红/橙/黄/绿/蓝/粉/紫全开 | 颜色越多越好——多巴胺不害怕「too much」 |
| 饱和度 | 高——全局 +10% ~ +30% | 这是唯一一个「过饱和不是错误」的情绪范畴 |
| 撞色策略 | **多组互补色同时存在**——红+绿 + 蓝+橙 + 黄+紫 | 通常最多一组撞色——多巴胺可以同时三组 |
| 色温 | 中性到偏暖——5000-6500K | 暖色带来生理上的温暖感=快乐的体感 |
| 明度 | 偏高——明亮的画面 = 明亮的情绪 | 暗调多巴胺存在（霓虹灯派对）但不是主流 |
| 光质 | **硬光优先**——直射阳光、闪光灯直打 | 硬光 = 色彩饱和度最大化（软光会稀释色彩） |
| 光比 | 中高——亮暗分明增强色彩对比 | |
| 构图密度 | 中高——画面可以满、可以挤 | 多巴胺不怕拥挤——拥挤 = 热闹 = 快乐 |
| 模特状态 | **笑容**——真笑，大笑，笑到眯眼 | 多巴胺不需要克制——可以「用力快乐」 |
| 景别倾向 | 中景（看到色彩环境+人）+ 近景（看到快乐的表情） | |
| 后期方向 | 中高对比 + 保留/略微增强饱和 + 高锐度 + 不加颗粒 |

## 氛围感元素

| 载体 | 多巴胺情绪中的表现 |
|------|----------------|
| **空气质感** | 不需要朦胧的空气——多巴胺需要清晰的、干净的空气，让色彩穿透 |
| **动态细节** | 跳跃/旋转/抛洒彩色粉末/水花飞溅——物理世界的色彩粒子在飞舞 |
| **留白情绪** | 多巴胺不需要留白——空白 = 缺少快乐。画面应该被色彩填满 |

## 多巴胺色彩组合

### 分支 A：高饱和多巴胺（主流）

| 组合名称 | 颜色配方 | 示例场景 |
|---------|---------|---------|
| **彩虹派对** | 6+ 色相同时出现 | 彩色气球/彩纸/彩色服装 |
| **粉黄蓝** | 粉 + 黄 + 天蓝——最安全的多巴胺入门 | 粉墙+黄裙+蓝天 |
| **红蓝撞色** | 红 + 蓝 + 白——美国国旗配色=活力 | 红裙+蓝天+白云 |
| **橙绿撞色** | 橙 + 绿 + 奶油白——温暖+生命力 | 橙色道具+草地+白色服装 |
| **全粉** | 不同明度的粉色——从浅粉到玫红 | 粉色花丛/粉色背景/粉色服装 |
| **霓虹夜** | 紫 + 粉 + 蓝 + 绿——霓虹灯管色 | 夜景+霓虹灯+闪光灯 |

### 分支 B：低饱和马卡龙多巴胺（小红书平行分支）

**同样传达快乐，但用柔和的、低饱和的、像糖果一样粉嫩的色彩。** 不是「色彩爆炸」而是「色彩软糖」——快乐的质地从「刺激」变成了「治愈」。

| 参数 | 与主流多巴胺的差异 |
|------|-----------------|
| 饱和度 | **低饱和**——全局饱和度降低 10-20%，颜色「粉」而不「炸」 |
| 色彩倾向 | 粉/紫/奶油黄/薄荷绿/婴儿蓝——所有颜色都带一层「奶白」 |
| 撞色策略 | **不撞色**——使用邻近色而非互补色，颜色之间柔和过渡 |
| 光质 | **软光优先**——柔和的散射光让颜色更「粉」 |
| 明度 | 偏高——保持明亮，但不能过曝 |
| 后期方向 | 低对比 + 降低清晰度（柔化质感）+ 高光加一层暖白 |

| 组合名称 | 颜色配方 | 示例场景 |
|---------|---------|---------|
| **马卡龙粉紫** | 奶油粉 + 淡紫 + 白 | 粉紫花丛/马卡龙甜点/粉墙 |
| **薄荷奶绿** | 薄荷绿 + 奶油白 + 淡黄 | 草地+白裙+奶黄色野花 |
| **婴儿蓝粉** | 婴儿蓝 + 浅粉 + 白 | 蓝天+粉色建筑+白色服装 |
| **奶油全色** | 所有颜色加 20% 白——像调色盘里每个颜色都加了白色颜料 | 马卡龙色背景纸/柔和色块道具 |

**廉价 vs 高级判断同样适用**——低饱和马卡龙多巴胺也需要「色彩有主次 + 光线有层次」，否则变成平淡的「褪色照片」。

---

## 廉价 vs 高级

| | 廉价多巴胺 | 高级多巴胺 |
|--|----------|----------|
| 色彩 | 全局饱和度拉到满——所有颜色都刺眼 | 高饱和但有主次——1-2 个主角色高饱和，其余中高饱和 |
| 光线 | 均匀平光——所有颜色「浮」在表面 | 侧光/逆光——颜色有明暗层次，高饱和但立体 |
| 构图 | 填满+居中——没有视觉组织 | 色彩有分布逻辑——暖色在前/冷色在后或反之 |
| 表情 | 假笑——「say cheese」的标准笑容 | 真笑——眼睛在笑，不是嘴巴在笑 |

## 大师关联

- **Martin Parr**：色彩多巴胺的定义者——高饱和 + 闪光灯 + 日常的荒诞快乐
- **蜷川实花**：日本多巴胺——花 + 金鱼 + 高饱和色彩 + 梦幻迷离
- **Tim Walker**：童话多巴胺——巨型道具 + 纯色背景 + 超现实色彩

---

## 复合情绪

多巴胺 + 自由 = 「快乐地在天地间奔跑」——高饱和 + 开阔空间 + 动态。
多巴胺 + 温暖 = 「被阳光和色彩双双充满电」——暖色高饱和 + 闭眼享受。
多巴胺 + 浪漫 = 「像糖果一样甜的爱情」——粉红 + 粉蓝 + 亲密互动。
