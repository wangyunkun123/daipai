# 温暖 · Warmth

## 情绪定义

**温暖 = 「这个世界对我是温柔的」。** 照片传达一种被接纳、被拥抱的安全感——观众看完觉得「心里暖暖的」。

**用户常说的相关词汇**：温暖、治愈、温馨、柔软、美好、暖洋洋、「被治愈了」、小确幸。

---

## 视觉翻译

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩倾向 | 暖色为主——橙/黄/金/奶油白 | 暖色波长长，生理上产生温暖感 |
| 色温 | 4000-5500K（偏暖但不黄） | 「暖」但不「热」——黄昏色温最佳 |
| 饱和度 | 中低——温暖不等于浓烈 | 过饱和的暖色 = 燥热，不是温暖 |
| 光质 | **极致软光**——散射光、窗边光、金色柔光 | 软光 = 被温柔对待，硬光 = 被现实刺痛 |
| 光比 | 1:2 ~ 1:3（极低光比） | 亮暗过渡越柔和，温暖感越强 |
| 构图密度 | 适中——不过度留白也不拥挤 | 留白太多 → 孤独。拥挤 → 烦躁 |
| 对比度 | 低——柔和高光过渡 | 强对比产生紧张感，破坏温暖 |
| 模特状态 | 微笑（真笑不是假笑）、闭眼享受、低头温柔 | 情绪的核心是「放松」 |
| 景别倾向 | 近景（亲密距离）+ 中景（对话距离） | 远景太远——温暖需要近距离 |
| 后期方向 | 低对比 + 暖色高光 + 提亮阴影 + 柔和肤色 | |

---

## 氛围感元素

参照豆包的氛围感三大载体：

| 载体 | 温暖情绪中的表现 |
|------|----------------|
| **空气质感** | 黄昏漫射光中的微尘、咖啡的热气、窗边的柔光——可见的「暖」 |
| **动态细节** | 发丝在微风中、裙摆轻摆、树叶轻晃——温柔的动态，不激烈 |
| **留白情绪** | 温暖的留白是「舒服的空」——阳光照在空椅子/空沙发/空桌子上 |

---

## 廉价 vs 高级

| | 廉价温暖 | 高级温暖 |
|--|---------|---------|
| 色彩 | 橙色过饱和 + 全局暖色滤镜 | 克制的暖色偏移——白衣服微暖，不黄 |
| 光线 | 没有光线逻辑的全局提亮 | 光源明确——逆光金色轮廓/窗边柔光 |
| 情绪 | 标准露齿笑——「茄子！」 | 嘴角微扬 + 眼睛在笑 + 身体语言放松 |
| 构图 | 填满+居中+比耶 | 留出呼吸空间——人在环境中被接纳 |

## 场景适配

| 场景 | 适配度 | 说明 |
|------|--------|------|
| 咖啡厅/室内 | ★★★★★ | 窗边光 + 暖色木调 + 咖啡热气 = 温暖的完美配方 |
| 公园/自然 | ★★★★☆ | 草地 + 树荫柔光 + 午后阳光 |
| 海边 | ★★★☆☆ | 黄昏海滩——暖色 + 软光（午间海边太硬） |
| 街拍 | ★★☆☆☆ | 需要找到暖光小巷或咖啡厅窗边 |
| 夜景 | ★★☆☆☆ | 暖灯 + 暗调背景可做但难度较高 |

## 技术联动

| 技术维度 | 建议 |
|---------|------|
| 焦段 | 广角（35mm）或标准-中焦（50mm）——自然透视，不压缩距离 |
| 景别 | 近景 ≥ 中景——需要看到表情 |
| 光线 | 黄金时刻逆光/侧逆光（金色轮廓）、窗边散射光 |
| 色彩 | 暖色为主，冷色作为微量对比——暖 80% + 冷 20% |
| 快门 | 可适度使用慢快门捕捉动态柔美感（发丝/裙摆微动） |

## 复合情绪

温暖 + 忧伤 =「笑着的悲伤」——最耐看的温暖不是纯粹的快乐，是经历过什么的温柔。
温暖 + 怀旧 =「那个回不去的美好时光」——胶片暖调 + 旧物 + 金色光。
