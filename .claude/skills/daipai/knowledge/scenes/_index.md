# 场景类型与勘察方法论

## 一句话定义

**到了一个新场景，不要立刻举起相机。先看 30 秒。** 场景勘察是方案生成的前置步骤——不是「这是什么地方」，而是「这个空间里有什么可用」。

---

## 原理

### Freeman 的「第一眼测试」

Freeman 提出一个简单但强大的方法：**进入一个空间后，闭上眼睛，再睁开。你的本能第一眼看哪里？**

那个方向 90% 有最好的画面——最好的光影、最好的构图元素、最有趣的视觉关系。这是人类视觉本能扫描的结果，比你理智分析快得多。

**为什么这很重要**：你的第一眼被吸引的方向，就是将来观众看照片时第一眼被吸引的方向。你的本能就是画面视觉重心的预览。

---

## 场景勘察清单

到达一个场景后，按以下清单走一遍（实际上只需要 1-3 分钟）：

### 1. 光勘察（30 秒）

```
□ 光从哪个方向来？走一圈感受光的角度变化
□ 哪个角度的光最讨喜？（转到侧面看侧光效果）
□ 哪个角度的光有氛围？（逆光方向，看看有没有发丝光/剪影的可能）
□ 有没有「光的区域」？（一束光从窗户/树荫漏下来——那是天然的聚光灯）
□ 现在是几点？光接下来会怎么变？（参考 light/_index.md → 黄金时刻时间窗口）
```

### 2. 空间勘察（30 秒）

```
□ 这个空间最有特点的地方是什么？（不是「哪里最漂亮」，是「哪里最有趣」）
□ 走一圈，每个方向看过去：
│   ├─ 这个方向有什么线条？（路/栏杆/海岸/建筑边缘）
│   ├─ 这个方向有什么框架？（门/窗/拱门/树枝空隙）
│   ├─ 这个方向有对称元素吗？（倒影/建筑中轴）
│   ├─ 这个方向有干净的大面积背景吗？（天空/墙面/海面）
│   └─ 这个方向有哪些需要避开的杂物？（垃圾桶/标志牌/杂乱人群）
□ 哪个方向的「构图元素最丰富」？
```

### 3. 最佳机位标注（30 秒）

```
□ 标记 2-3 个「肯定有好照片」的机位
│   ├─ 机位 A：（具体位置 + 为什么——因为有引导线+框？）
│   ├─ 机位 B：
│   └─ 机位 C：
□ 从每个机位试拍一张（不拍人，拍空景看构图骨架）
□ 确认摄影师站在哪里、模特站在哪里、光线方向
```

### 4. 限制评估（30 秒）

```
□ 用户设备的最大短板在此场景中是什么？
│   ├─ 光比太大？（正午室外）
│   ├─ 太暗？（室内/夜晚）
│   ├─ 太杂乱？（背景无法简化）
│   └─ 空间太窄？（退不开，只能用超广角）
□ 哪些构图方法在此场景中不可行？（无框→放弃框架构图、无对称元素→放弃对称）
□ 此场景的设备独有优势是什么？（可以放低拍倒影？可以不引人注意地街拍？）
```

## 场景分类

### 户外自然类

#### 海边/沙滩
- **光线特征**：开阔无遮挡，通常强光。水面反光（额外光源）
- **构图机会**：★★★★★
  - 海岸线 = 天然引导线
  - 海天交界 = 水平线（对称或三分法）
  - 沙滩上的足迹/贝壳/礁石 = 前景或特写
  - 海浪泡沫的边缘 = 动态的引导线
- **构图陷阱**：
  - 水平线倾斜——在海边这是最致命且最容易被忽略的错误
  - 天空和海面各占一半（无主次）
- **注意事项**：强光下取景困难（屏幕/取景器可见度下降）；沙子和海水对设备有风险

#### 公园/自然/森林
- **光线特征**：树冠过滤阳光→斑驳光影。阴天时柔和均匀。
- **构图机会**：★★★★☆
  - 曲径 = S 型引导线
  - 树木形成的天然垂直线条阵列
  - 树枝空隙 = 天然软框架
  - 草地/落叶 = 柔和的色彩基底
- **构图陷阱**：树枝「长在」人头上（背景树枝与人头重合）
- **注意事项**：斑驳光影下光比大——开启动态范围优化有益；绿色有时可能过度饱和

### 建筑/城市类

#### 街拍/城市
- **光线特征**：建筑遮挡产生锋利阴影。午后 = 深阴影 + 高对比。蓝调时刻 = 城市灯光 + 蓝色天空的冷暖对比最佳。
- **构图机会**：★★★★★
  - 建筑线条 / 道路 / 栏杆 → 引导线
  - 门廊 / 拱门 / 窗框 → 框架
  - 建筑对称立面 → 对称
  - 墙面 / 天空 → 留白
  - 光影在建筑表面形成的几何形 → 何藩风格
- **构图陷阱**：城市背景太杂乱 → 用标准-中焦/长焦压缩视野或用框架限定视野
- **注意事项**：不引人注意的小型设备是街拍优势；注意行人和车流的时机

#### 咖啡厅/室内
- **光线特征**：混合光——窗户光 + 室内暖灯。色温混杂可能是挑战也可能是氛围。
- **构图机会**：★★★☆☆（相对受限但质量高）
  - 靠窗座位 = 天然柔光 + 窗外街景作背景
  - 窗户 = 框架
  - 光影在桌面/墙面 = 几何
  - 镜子 = 反射/画中画
- **构图陷阱**：空间狭窄退不开 → 广角近距离拍人脸变形 → 换中长焦或换座位
- **注意事项**：室内弱光→需要稳定支撑或提高 ISO；窗边光比大→开启动态范围优化

### 特殊场景

#### 游艇/船
- **光线特征**：水面反光（从下方补光 = 独特的底光效果）。开阔无遮挡。
- **构图机会**：★★★★★
  - 船身侧边 = 对角线
  - 栏杆 = 引导线 / 框架
  - 船对称结构 = 对称
  - 白船+蓝天+蓝海 = 邻近色和谐（蓝白系统）
- **构图陷阱**：船在移动 → 水平线不稳定；风大 → 模特头发和衣物不可控
- **注意事项**：设备防水风险；船摇晃→稳定优先

#### 夜景/弱光
- **光线特征**：所有设备物理限制最大的场景。光线不足 + 混合色温 + 噪点多。
- **构图机会**：★★☆☆☆（构图不靠光线，靠光源）
  - 路灯 / 橱窗 / 车灯 = 人工光源
  - 水面反射城市灯光 = 对称 + 色彩
  - 蓝调时刻（日落后 15-30 分钟）的夜空 + 城市灯光 = 冷暖对比
- **构图陷阱**：太暗导致自动对焦失败→用手动对焦或先对焦在亮处再锁定
- **注意事项**：弱光模式（长曝光/多帧合成）在此场景是最佳工具。但需要模特保持静止。如果模特不能保持静止 → 放弃长曝光，提高 ISO 接受噪点。

## 场景文件使用说明

目前有 6 个场景的专项文件（`scenes/` 目录下），每个文件包含：
- 该场景的光线预判
- 推荐构图排行（从最适合到最不适合）
- 推荐景别分配
- 推荐大师风格
- 设备注意事项
- 常见拍摄陷阱

**但场景不是分类学——场景是起点。** 同一个咖啡厅，早晨的窗光和下午的窗光完全不同；同一个海边，日出和正午完全是两个拍摄环境。场景分类只是帮你快速定位，真正的分析靠勘察清单。
