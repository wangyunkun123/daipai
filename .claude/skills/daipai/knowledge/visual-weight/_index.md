# 视觉重心

## 一句话定义

**所有构图技法的最终目的是同一个：让观众的眼睛停在你想让它停的地方。** 视觉重心就是那个「你想让它停的地方」——构图是手段，重心是目的。

—— 框架参考 Freeman《摄影师的视界》

---

## 原理

### 眼球的第一落点

Freeman 的视觉心理学研究表明：观众看一张照片时，眼球在 0.2-0.5 秒内就找到了「第一落点」。这个落点不是随机的——是画面中视觉吸引力最强的区域。

**如果你的主体恰好在视觉吸引力最强的区域 → 构图成功了。**
**如果视觉吸引力最强的区域在画面边缘的垃圾桶上 → 构图失败了。**

眼睛在 0.2 秒内不会「分析」画面——它被以下东西自动吸引：

### 视觉吸引力的优先级

| 优先级 | 视觉引力源 | 强度 | 说明 |
|--------|----------|------|------|
| 🔴 绝对 | 人脸（尤其是眼睛） | ★★★★★ | 人脑有专门的面部识别模块，无法关闭 |
| 🔴 绝对 | 文字/数字 | ★★★★★ | 识字的人自动阅读画面中的文字 |
| 🟠 很高 | 最亮的区域 | ★★★★ | 光比越大，吸引越强 |
| 🟠 很高 | 最高饱和度的颜色 | ★★★★ | 在低饱和场景中一小块高饱和=绝对焦点 |
| 🟡 高 | 最高对比度的边缘 | ★★★ | 锐利边缘 > 柔和边缘 |
| 🟡 高 | 眼睛/视线方向 | ★★★ | 模特看哪里，观众看哪里 |
| 🟢 中 | 运动/动态元素 | ★★ | 静止画面中的任何移动 |
| 🟢 中 | 被线条指向的区域 | ★★ | 引导线输送注意力 |
| 🔵 低 | 画面几何中心 | ★ | 中心天然有引力但弱于以上所有 |

**关键原则**：优先级之间会互相竞争或叠加。
- 一张脸在最亮的区域 = 双重锚定（最强）
- 一张脸在暗处、但画面边缘有一盏亮灯 = 脸和灯争夺注意力（分裂）

## 确立视觉重心的 5 种方法

### 方法 1：明暗对比

**原理**：眼睛自动跳向画面中最亮的区域。这是所有动物共有的视觉本能（亮 = 安全/食物/信息），无法被「训练」或「品味」覆盖。

**操作**：
1. 分析场景的亮度分布
2. 确保模特/主体在画面最亮的 1/3 区域内
3. 如果不在 → 移动机位、改变角度、等待光线变化
4. 逆光场景中：背景最亮，人脸变暗 → 用曝光补偿提亮人脸，或主动选择剪影

**操作要点**：
- 对主体测光并锁定曝光——这是最直接的对「亮在哪里」的创作决策
- 开启 HDR/动态范围优化可减少大光比场景中暗部的沉没感

**大师关联**：
- 何藩：光本身就是主体。亮区是几何形，人是剪影。视觉重心从「人脸」转移到了「光影构成的几何」

### 方法 2：大小对比

**原理**：在一个空旷的画面中，即使很小的主体也自动成为视觉重心——不是因为大，是因为它和其他部分形成了「有 vs 无」的对比。

**操作**：
- 远景/留白：主体占画面 10-20%，周边大面积干净背景 → 观众的目光无处可去，只能看向主体
- 多人场景：最靠近镜头的那个人自动获得视觉优先权

**操作要点**：
- 小屏幕上预览时，主体太小可能看不清——但成片在大屏幕上效果很好
- 建议主体不少于画面的 5%，低于此阈值会失去存在感

### 方法 3：色彩隔离

**原理**：当主体的颜色与背景形成足够的差异（色相/饱和度/明度任一维度），主体自动从背景中「跳」出来。

**最有效的色彩隔离组合**：
| 主体色 | 背景色 | 机制 |
|--------|--------|------|
| 暖色（红/橙/黄） | 冷色（蓝/青/绿） | 互补色——最强 |
| 白色/浅色 | 暗色/深色 | 明度对比 |
| 高饱和 | 低饱和/褪色 | 饱和度对比 |
| 纯色 | 杂乱/多色 | 简洁感在杂乱中自成一区 |

**操作要点**：
- 自动色彩优化有时会过度提高全局饱和度，削弱色彩隔离的效果（所有颜色都饱和 → 没有颜色突出）
- 后期降低环境饱和度、保留主体饱和度，可以重建色彩对比

### 方法 4：线条引导

**原理**：见 `composition/_index.md` → 引导线构图。线条本身不确立重心，线条的终点确立重心。

### 方法 5：隔离（留白）

**原理**：当主体周围没有任何其他视觉元素时，观众的眼睛没有竞争者，只能停在主体上。这就是留白构图的底层逻辑。

## 视觉重心冲突：当你用光了所有技法

如果场景太复杂，视觉重心怎么建立？
- 一条引导线指向模特 ✅
- 模特站在最亮的地方 ✅
- 模特的衣服是场景中最鲜艳的颜色 ✅

**三个技法指向同一个重心 = 三重锚定 = 画面结构坚不可摧。**

如果场景无法同时满足多个条件？
- **优先做减法**：改变机位/角度来排除分散注意力的元素，而不是追加吸引注意力的元素
- **移动比添加有效**：往左走两步把一个红色标志牌从画面中排除 > 引导线 + 留白 + 任何技法来「补偿」这个标志牌的干扰

## 常见视觉重心错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 主体在暗处，同时画面中有亮区不在主体上 | 观众眼睛被亮区抢走 | 重构图：排除亮区 或 移动主体到亮区 |
| 画面中有文字/标志 | 观众会阅读文字，不理主体 | 重构图：排除文字 或 用景深让文字虚化（使用计算虚化模式或大光圈） |
| 模特看着某个方向，那个方向没有留白 | 视线「撞墙」，画面压抑 | 模特看向画面中空旷的一侧 |
| 多条引导线指向不同方向 | 观众不知道该跟哪条线走 | 所有线必须指向同一区域（至少指向同一侧） |
| 前景太抢眼（比例大/颜色亮/细节多） | 观众停在近景层，不进入画面深处 | 减小前景面积 或 降低前景亮度 |
