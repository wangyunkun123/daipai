# 留白构图

## 一句话定义

大幅度留出空旷区域，让人或主体在画面中只占一小部分。**留白不是「没东西」——留白是「呼吸」。** 空白越大，主体越重要。

---

## 原理

### 为什么成立

留白利用了视觉心理学中的**隔离效应**：当一个物体在视野中没有任何其他物体与之竞争时，它自动成为注意力的唯一焦点——无论它多小。

主体越小 → 观众越仔细看 → 这个「更认真的观看」让主体看起来更有分量。这是一个反直觉的心理回路：你用更少的信息，换来了更多的注意力。

Freeman 指出：**留白的力量不在于空白本身，在于空白与主体之间的比例悬殊。** 主体占比 5% + 背景占比 95% = 主体在画面中的每 1% 都比普通构图中 10% 的主体更有视觉分量。

### 视觉心理学

留白让观众「找」主体。普通构图 = 主体直接给你，留白构图 = 观众自己在画面中寻找主体。找的过程中观众被迫更仔细地看整个画面——这额外付出的注意力，是一种投资。投资过的东西，心理上更重视。

---

## 识别条件

- 大面积干净背景：天空（有云没云都行）、纯色墙面、大片水面、大片草地/雪地/沙滩
- 环境本身是「空的」但视觉上有质感或色彩渐变（非纯白）

**与三分法的区分**：三分法是任何场景的默认选项，留白构图要求场景中必须有一片足够干净、足够大的背景。对场景有要求也意味着一旦满足条件，留白构图的视觉冲击力远大于三分法。

## 执行指令

### 站位

**退后，再退后。** 留白构图的第一要求是距离——你离模特足够远，模特在画面中的占比才能小到 10-20%。不要站在原地放大缩小——移动你的脚。

### 角度

- **低角度仰拍**：天空作为留白区域。这是留白最常用的方式——低位向上拍，模特上半身 + 大面积天空
- **平视**：海面/水面/墙面作为留白。需要有足够大的干净背景空间
- **俯拍**：地面/草地/沙滩作为留白。高举俯拍

### 焦段

| 焦段 | 效果 | 适用 |
|------|------|------|
| 超广角 | 留白面积最大——天空/海面被夸张地纳入画面 | 天空留白、宏大自然场景 |
| 广角 | 留白与主体的关系最自然 | 大部分留白方案 |
| 标准-中焦 | 需要更大的退后距离才能达到 10-20% 主体占比 | 空间足够大时可用 |
| 长焦 | 不太适合留白——压缩后主体和背景的距离感消失了 | 不推荐 |

### 构图操作

1. 确认背景干净度——仔细扫描留白区域，排除杂物（一根电线、一个垃圾桶、一个路人在留白区域中会被放大成巨大的干扰）
2. 主体放在画面的非中心位置——下方（天空留白）、一侧（海面/墙面留白）、角落（极致的极简）
3. 主体占比：留白的核心判定标准不是固定百分比，而是**负空间（空白区域）的视觉权重是否大于主体**。参考区间：常规人像留白主体 10%-25%；极简风光可低至 3%-10%（如沙漠中一棵树）；主体 >30% 则负空间仅作衬托，不属于留白构图
4. 留白区域本身要有某种「内容」——天空的云层纹理、海面的微反光、墙面的油漆质感、阴影的渐变。纯白/纯灰的「空无一物」留白在多数情况下是乏味的

### 模特引导

- 小动作——站、坐、抬头看远方、侧身。大动作（跳跃、大开大合）与留白构图传递的「安静/渺小/诗意」基调矛盾
- 模特的「小」不是缺点——是留白的核心。观众不需要看清她的表情，需要感受到「她在这个广阔的天地之间」
- 全身 > 半身。远景和中景是留白构图的自然景别

### 光线利用

- 黄金时刻的天空（暖色渐变）+ 留白 = 氛围天花板
- 阴天的灰白天空 + 留白 = 极致的极简（但注意阴天天空可能太白太无聊——看云层是否有纹理）
- 逆光留白 = 模特变成一个小剪影在巨大的逆光天空下——这是留白构图的经典公式

## 留白构图的三种风格

### 天空留白

**特征**：模特在画面下方，大面积天空在上方。

**操作**：低角度仰拍。相机在腰部或更低位置，向上倾斜 20-30°。模特占画面下方 10-15%，天空占上方 70-80%。

**最佳条件**：天空有纹理（云层、色彩渐变）。纯蓝天也可以——简约，但不如有云的天空有层次。

### 环境留白

**特征**：模特在画面一侧，大面积单一色调的环境在另一侧。

**操作**：平视，模特靠左/右 1/3 处，另一侧是大片海面/墙面/草地。

**最佳条件**：环境的单一色调有微妙的渐变或纹理。纯白墙也很好（极简主义），但最好的墙面质感的留白——米白色老墙的青苔斑点、淡蓝色的粉刷笔触。

### 微观留白

**特征**：特写 + 留白的组合。一个极小的东西 + 大片模糊背景。

**操作**：长焦 + 极简背景。对焦在一个细节上（手环、帽檐、眼睛），背景完全虚化（计算虚化模式或大光圈）或天然干净。

**关键**：被虚化的背景仍然要干净——如果背景即使虚化了还有大块的颜色/物体，留白感就没了。

## 常见错误

| 错误 | 为什么错 | 修正 |
|------|---------|------|
| 留白区域不干净 | 一个垃圾桶/一根电线在留白区域中，因为有 80% 的画面被它占据，它的存在感被等比例放大 | 扫描留白区域——1 像素的杂物 = 巨大的干扰 |
| 主体太小（需根据场景判断） | 小屏幕上可能看不清——但在大屏幕上效果可能很好。极简风光中 3%-5% 的主体完全成立 | 根据场景类型和观看媒介选择比例。小屏预览不等于最终观看体验 |
| 主体太大（>30%） | 不是留白，是普通的中景构图 | 再退后或换更广的焦段 |
| 留白区域完全空白（纯白天空） | 没有纹理的纯白 80% 画面 = 观众感觉「这张照片还没加载完」 | 换有云/有色彩的天空，或选择有纹理的墙面 |
| 景物落在留白区域与主体的拆分线上 | 三景中的背景被留白区隔断 → 画面几何断裂 | 调整站位让主体 + 留白是完整的「一层」 |

## 场景适配

| 场景类型 | 适配度 | 说明 |
|---------|--------|------|
| 海边 | ★★★★★ | 海面 + 天空 = 双重留白。海边是留白构图最天然的实验室 |
| 街拍 | ★★☆☆☆ | 城市太杂乱，难找干净的足够大的背景。但一面干净的墙就够 |
| 游艇 | ★★★★☆ | 蓝天+海面是极好的留白背景 |
| 公园 | ★★★☆☆ | 大片草地/天空可用 |
| 室内 | ★★★☆☆ | 一面干净的大墙或一大面窗户 |
| 夜景 | ★★★☆☆ | 夜空留白——但星星/灯光就是留白区的纹理 |

## 设备注意

- 小屏幕预览时，主体只有画面的 10% 可能看不清——但在大屏上效果很好。信任比例
- 留白背景的纹理（云、水波）在小屏预览中可能看不清——拍完放大检查
- 超广角可以在空间不够大的地方制造「假大空间」——天空/海面被夸张地扩张
- 轻便设备→随时低角度仰拍或高举俯拍找留白角度
- 如果留白区域不够干净，后期裁剪可以裁掉边缘杂物同时保留留白感
- 后期修复工具可以移除留白区域中的小杂物——但场景选择和视角才是最根本的
