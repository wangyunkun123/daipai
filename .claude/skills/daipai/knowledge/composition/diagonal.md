# 对角线构图

## 一句话定义

让画面中的主要元素沿对角线方向延伸。**水平线 = 静止，垂直线 = 力量，对角线 = 运动。** 在所有构图方向中，对角线是唯一一个天然携带「动感」的方向。

---

## 原理

### 为什么成立

水平线在物理世界中最常见（地平线、海平面）——它代表重力方向上的静止和稳定。垂直线代表对抗重力的力量（柱子、站立的人）。而对角线代表「不稳定」——它在两个基准方向之间，暗示了运动、倾斜、变化。

在摄影的二维平面上，对角线利用了画框的对角线长度（> 任何水平或垂直方向的长度），用最大的画面跨度来制造延伸感。

**对角线构图 = 画面中最长的一条线 = 最强的方向性。**

### 视觉心理学

对角线的「不稳定」不是让人不安——是让人兴奋。它暗示了「下一刻这个状态会变」——倾斜的线条暗示了重力在下拉、风在吹、主体在移动。静态的照片中有动态的暗示 = 照片有了「活的感觉」。

---

## 识别条件

- 倾斜的结构元素：船身侧边、楼梯、斜坡、倾斜的建筑、斜拉索桥
- 光影形成的斜线：阳光穿过窗户在地面形成斜平行四边形、长影子
- 身体姿态的斜线：模特伸展的手臂、倾斜的身体轴线、踢出的腿
- 相机故意倾斜：在缺乏天然斜线的场景中，倾斜相机 10-20° 来制造对角构图（森山大道技法）

---

## 执行指令

### 站位

站在能拍摄到对角线延伸的位置。通常需要：
- 不和主体/场景正对——偏转到侧面，让场景的线条从画面一角延伸至对角
- 在有天然斜线的场景中——找到让线最长的那一端（从哪个角落到哪个角落对角线最长，就站那）

### 角度

两种主要策略：
1. **相机保持水平 + 寻找天然斜线**（自然、不刻意）
2. **相机故意倾斜**（Dutch Angle/倾斜构图）：轻度倾斜 10°-15° 制造柔和动感；森山大道街头风格倾斜 20°-35°，刻意制造不稳定张力。评判标准是画面有无稳定锚点，而非单一角度数值

具体角度选择取决于风格意图：10-15° 产生柔和的动态暗示，20-35° 进入森山大道式的侵略性不稳定性。评判标准不是角度数字本身，而是画面中是否有支撑性的构图结构（如斜线元素、视觉锚点）来使倾斜「成立」。

### 焦段

| 焦段 | 效果 | 适用 |
|------|------|------|
| 超广角 | 夸大对角线的近端、缩小远端——对角线的纵深感被夸张 | 创意对角线 |
| 广角 | 自然的对角线——斜线的两端比例均衡 | 大多数对角线方案 |
| 标准-中焦 | 压缩对角线的纵深——两端的大小差异减弱 | 建筑对角线、多斜线 |
| 长焦 | 强烈压缩——斜线变成画面中的一段而不是「延伸」 | 不太推荐（失去斜线的延伸感） |

### 构图操作

1. 找到场景中最主要的斜线元素
2. 将此元素从画面一角（如左下角）延伸至对角（右上角）
3. 模特放在对角线上或对角线的黄金分割点
4. **模特的身体姿态顺应对角线方向**——侧身、手臂伸展、身体倾斜来匹配对角线的方向
5. 如果场景中没有天然斜线 → 考虑故意倾斜相机 10-15°（尤其适合森山大道和街拍风格）

### 模特引导

- 身体轴线沿对角线方向倾斜——全身侧向伸展、手臂沿斜线方向、腿也向斜线方向延伸
- 走路抓拍中身体前倾 = 天然的对角线
- 倚靠在斜线元素上（斜栏杆、斜墙面）——身体轴线与场景斜线一致

### 光线利用

- 斜射的光影（低角度阳光产生的长影子）= 天然的对角线元素。不仅是结构斜线，光影也可以形成斜线
- 侧光产生明暗交界 = 这条边界通常是斜的（如果主体不是正对光或背对光）

## 变体

### 天然斜线

场景中确实存在倾斜的结构（楼梯、斜坡、船身）。相机水平但场景的线是斜的。

**这是最自然的对角线构图——不刻意，有机。**

### 相机倾斜（Dutch Angle/倾斜构图）

相机故意倾斜：轻度动感 10-15°；森山大道街头风格 20-35°。即使场景中的线条本来是水平和垂直的，倾斜后在画面中全变成了对角线。关键在于画面中是否有支撑性的构图结构（如斜线元素、视觉锚点）来使倾斜「成立」，而非单纯看角度数字。

**效果**：强烈的不稳定感、动态感、侵入感。森山大道标志性技法。

**何时用**：
- 街拍中想传达「闯入」「不请自来」的态度
- 单纯的场景缺乏张力——倾斜注入动态能量
- 想强调「这不是客观记录，这是我的主观视角」

**何时不用**：
- 需要传达安静/稳定/秩序的方案（对称构图 + 相机倾斜 = 矛盾）
- 大师模式中的滨田英明/Steve McCurry（他们几乎从不倾斜）

### 身体对角线

模特的身体本身构成对角线——一个人的全身姿态从画面一角延伸到对角。

**操作**：低角度仰拍 + 模特向镜头方向伸展手臂或上半身。超广角将靠近镜头的手放大到夸张——身体成为最强的对角线。

## 常见错误

| 错误 | 为什么错 | 修正 |
|------|---------|------|
| 倾斜角度与风格意图不匹配 | 需要柔和的动感但倾了 25°，或需要森山大道风格但只倾了 5° | 轻度动感 10-15°，侵略风格 20-35°。关键是有视觉锚点支撑 |
| 斜线不延伸到对角（停在中途） | 失去对角线构图的意义——变成「画面中有一条斜线」而不是对角线构图 | 换角度让斜线从角到角 |
| 对角线方向与模特动态方向矛盾 | 斜线往左下走，模特往右上方看——视觉分裂 | 模特姿态顺应对角线方向 |
| 没有斜线元素却硬要倾斜相机 | 画面倾斜但没有任何结构性的对角——感觉只是歪了 | 找天然斜线，或接受这个场景不适合对角线 |

## 场景适配

| 场景类型 | 适配度 | 说明 |
|---------|--------|------|
| 海边 | ★★★★☆ | 海岸线在斜侧方看就是对角线。海浪的泡沫线也是斜线 |
| 街拍 | ★★★★★ | 楼梯、斜坡、建筑斜面、斜射光影——城市是对角线的宝库 |
| 游艇 | ★★★★★ | 船身侧面 = 天然对角线。栏杆沿船身的斜线 |
| 公园 | ★★★☆☆ | 斜坡、山坡小路、斜生的树枝 |
| 室内 | ★★★★☆ | 楼梯是室内的对角宝库。走廊尽头从一个角看去 |
| 夜景 | ★★★★☆ | 路灯斜排、建筑物斜角灯光 |

## 设备注意

- 竖拍画幅天然适合对角线——竖画幅的对角线长度 > 横画幅的，视觉冲击力更强
- 轻便设备 → 单手倾斜相机 10-15° 非常自然且稳定
- 自动水平校正功能可能「修掉」你想要的倾斜——检查设置中是否有自动水平校正并关闭
- 斜线在小屏幕上可能看起来不够明确——确保斜线在画面中有足够的对比度和长度
- 如果使用故意倾斜，后期不再旋转回来——倾斜是创作选择，不是拍摄失误。在方案说明中明确写「相机倾斜 15°——森山大道风格」
