# 三方向卡片：设计意图与定位

## 一句话定义

三个方向不是"三种拍法"的罗列，而是针对三种用户心理状态的差异化入口。每个方向回答的不是"怎么拍"，而是"你敢不敢、你想不想、你能不能"。

## 三个方向的心理定位

### 🟢 不会出错

**目标用户心理状态**："我不太会拍照，只是想别拍得太难看。"

**设计意图**：**安全感**。这是焦虑型用户的 default choice。不需要任何技巧、不需要任何设备、不需要任何勇气——站过去就行，拍出来一定好看。

**方案特征**：
- prep 永远是"什么都不用准备"或等价的最小心理负担
- where 是最容易执行的空间锚点——"门口""窗边""这面墙前面"
- do 是最简单的动作——"站过去""蹲下来""手机平着拿"
- result 强调"一定好看""不会失败""怎么拍都行"
- 不给任何让用户犹豫的选择——一条路走到底

**选这个方向的用户在想什么**：
"我就是想拍张能看的。不用什么风格，不用什么创意。别让我做选择，告诉我怎么做就行。"

**这个方向的方案筛选标准**：
- 任何人（包括从没拿过手机拍照的人）都能在 30 秒内理解并开始执行
- 不需要移动任何东西、不需要等待光线变化、不需要别人帮忙
- 效果是有保障的——在最差的执行下也能看

### 🔥 朋友圈会问在哪拍的

**目标用户心理状态**："我想要一张发出去会被夸的照片。"

**设计意图**：**炫耀感**。这是社交驱动型用户的首选。比普通游客照好看，发出去会被赞、会被问"在哪拍的"、会被收藏为拍照参考。

**方案特征**：
- 有辨识度——一看就不是随手拍的
- 利用了场景中最特别的那个视觉元素（独特的光线、特别的建筑、罕见的色彩）
- 有一定的挑战性但不是太难——需要多花 2 分钟调整站位或等待时机
- result 强调社交反馈——"发出去会有人问在哪拍的""会被闺蜜收藏下次来打卡"

**选这个方向的用户在想什么**：
"我要一张能发的。花了时间来这个地方，化了妆，穿了好看的衣服——必须拍出能代表这一切的照片。"

**这个方向的方案筛选标准**：
- 有辨识度——和"到此一游照"的差异肉眼可见
- 利用了场景中最有特色的 1-2 个视觉元素
- 需要用户多花一点心思（调整站位/等待光线/换个角度）但不超过 2 分钟
- social media ready ——不需要后期就能发

### ✨ 还能这样拍？

**目标用户心理状态**："我想拍点不一样的。常规的那种我已经会了/没意思。"

**设计意图**：**惊喜感**。这是好奇心驱动型用户的选择。用户自己没想到可以这样拍——看到方案的瞬间会有"哦？这也可以？"的反应。

**方案特征**：
- 有意外性——不是常规思维会想到的拍法
- 可能需要一点勇气（蹲在奇怪的位置、把手机放在不寻常的地方、做不日常的动作）
- 利用了场景中容易被忽略的视觉元素
- result 强调意外发现——"拍完你会发现最好看的不是你想的那个"

**选这个方向的用户在想什么**：
"我想拍点不一样的。这个地方别人都那样拍——我不想。给我一个我没想到的想法。"

**这个方向的方案筛选标准**：
- 真的有意外性——不是换了种说法说同一件事
- 用户在 5 秒内会有"哦？"的反应
- 方案是可以执行的——意外的想法但不需要意外的设备
- 如果场景确实没有"脑洞"空间——宁可不给也不要硬凑

## 三个方向的关系

```
用户焦虑程度
   高 ──────────────────────── 低
   🟢 不会出错                  ✨ 还能这样拍
   "我怕拍不好"                 "我想拍不一样的"
         ↘                    ↗
              🔥 朋友圈会问
              "我要被夸"
```

三个方向不是平行选项——它们是递进的：
1. 焦虑型用户先看到 🟢——"好，至少不会翻车"
2. 然后翻到 🔥——"这个更好看！我想要这个"
3. 最后看到 ✨——"还有这种操作？有意思"

如果用户时间有限或耐心有限——🟢 就够了。如果用户愿意花时间——可以一直翻到 ✨ 找到最特别的那个。

## 方向为空的情况

**🔥 为 null 的条件**：
- 场景太普通，没有任何值得"发朋友圈炫耀"的独特元素
- 或者场景最特别的元素和 🟢 方案重叠了——没必要为区分而区分

**✨ 为 null 的条件**：
- 场景确实没有"脑洞"空间——再想就脱离实际了
- 这种情况在简单场景（一面白墙、一张桌子）中很常见
- 宁缺毋滥——"还能这样拍？"如果用户看到没有"哦！"的反应，就是失败的

**底线**：🟢 必须有实质内容。🔥 和 ✨ 至少有一个有实质内容。不能三个都是空的。

## 给 AI 的生成指南

当你为一张照片生成三方向时，用以下问题自检：

- 🟢：如果我是一个完全不会拍照的人，这个方案我能看懂吗？我能执行吗？
- 🔥：这个方案拍出来的效果，和普通游客照有肉眼可见的差异吗？
- ✨：我看到这个方案描述的第一秒，会有"哦？这也可以？"的反应吗？

如果不是——重写，不要为了凑三个方向而凑。
