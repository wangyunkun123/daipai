# 梦幻柔美

## 风格定义

**梦幻柔美 = 柔焦 + 逆光 + 粉彩色调 + 低对比 + 动态轻柔。** 画面看起来不属于现实世界——像做了美梦看到的画面，像童话书里的插画。

**一句话识别**：这张照片让你觉得「这真的发生过吗？还是我梦见的？」

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 粉、浅紫、浅蓝、奶油白、淡绿 | 所有颜色都是「淡」的——没有浓烈的颜色 |
| 饱和度 | 全局 -10% ~ -25% | 不过度降饱和——梦幻需要颜色，只是颜色要柔和 |
| 色温 | 偏暖——暖粉/暖金色高光 | 冷调梦幻存在（冰雪主题）但暖调是主流 |
| 明度 | 偏高——画面整体明亮轻盈 | 暗调 = 沉重，梦幻 = 轻盈 |
| 关键规则 | 没有纯黑——最暗的地方也是深灰/深蓝灰 | 黑色是「现实」的颜色，梦幻不需要现实 |
| 色彩组合 | 粉+白+金 / 紫+蓝+白 / 绿+奶油+金 | 每个方案不超过 3 个色相 |

---

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **极致软光** + 柔焦/光晕 | 梦幻的核心是「光本身可见」——光不只是照明，光是画面主体 |
| 逆光 | **逆光是梦幻的基石** | 逆光 → 发丝光 + 空气感 + 柔焦光晕 + 主体边缘发光 |
| 光比 | 极低（1:1.5 ~ 1:2） | 几乎没有阴影——亮面和暗面的差异只是微妙的过渡 |
| 柔焦方法 | ① 逆光 + 镜头前薄纱/丝袜 ② 柔焦滤镜 ③ 后期高斯模糊叠加层 | 柔焦不是跑焦——画面仍然有清晰的焦点，只是高光向外溢出 |
| 时段 | 黄金时刻（金色柔光）+ 蓝调时刻（紫蓝柔光） | 正午硬光无法梦幻 |
| 曝光策略 | 亮调——+0.7 ~ +1.0 EV | 故意过曝让亮部溢出 → 光晕 |

---

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 留白、对称、三分法 | 构图简单——梦幻感来自光，不来自构图复杂度 |
| 留白 | 中等——留白是梦幻的呼吸空间 | 留白区域最好是天空/浅色背景 |
| 焦段倾向 | 广角（35mm——环境梦幻）+ 标准-中焦（50mm——人像梦幻） | 长焦太「锐利」太「真实」 |
| 景别倾向 | 中景（环境 + 人）+ 远景（人小 + 天地梦幻）+ 特写（局部柔美） | 近景需要足够柔的光，否则过于真实 |
| 动态 | 可慢快门 1/30-1/60s——裙摆/纱/花的轻微动态模糊 | 动态柔和 → 梦幻感增强 |

---

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 极低——高光不炸但整体柔软 |
| 高光 | 加暖粉/暖金色调 |
| 阴影 | 提亮——不能有任何纯黑区域 |
| 柔焦叠加 | 复制图层 → 高斯模糊 15-25px → 混合模式「滤色/柔光」→ 透明度 15-25% |
| 颗粒 | 不加——梦幻需要光滑 |
| 锐化 | 低——锐 = 真实，柔 = 梦幻 |
| 光晕 | 可选：逆光处加径向柔光 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 闭眼享受、轻微笑意、仰望、旋转——身体语言轻盈 |
| 眼神 | 不看镜头——看向光的方向/看向远方/闭眼 |
| 姿势 | 动态轻柔——旋转、走路、撩裙摆、伸手触光 |
| 服装 | 轻薄的、飘逸的——纱裙、长裙、宽松的衣服。「飘」是梦幻的动词 |
| 道具 | 花、纱、透明伞、泡泡——轻盈半透明的道具 |

**核心原则**：梦幻模特的最高境界是「她好像随时会消失在光里」。

| 技术维度 | 梦幻柔美倾向 |
|---------|------------|
| 焦段 | 广角（35mm）+ 标准-中焦（50mm） |
| 景别 | 中景/远景/特写 |

| 色彩 | 粉彩 + 低饱和 + 无纯黑 |
| 快门 | 中低速 1/30-1/60s——轻微动态模糊 |
| 景深 | 中等——不过度虚化 |

## 常见错误

| 错误 | 为什么不像梦幻 | 修正 |
|------|-------------|------|
| 光太硬 | 硬光阴影破坏梦幻 | 等软光/加柔光手段 |
| 对比度太高 | 亮暗分明 → 现实感强 → 梦幻感消失 | 降对比 + 提阴影 |
| 柔焦过度 | 全场模糊 = 跑焦，不是梦幻 | 焦点必须清晰，柔的是高光溢出 |
| 色彩太浓 | 高饱和 = 现实世界的颜色强度 | 降饱和 10-25% |
| 背景太杂乱 | 现实细节太多 → 提醒观众「这是真的」 | 找干净背景或用浅景深虚化 |
| 模特姿势僵硬 | 僵硬 = 紧张 = 现实感 | 引导旋转/走路/自然动作 |

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **金色梦幻** | 黄金时刻暖金 + 柔焦——最通用的梦幻变体 |
| **蓝紫梦幻** | 蓝调时刻 + 冷色柔焦——冰雪/夜晚梦幻 |
| **暗调梦幻** | Deborah Turbeville 式——暗调 + 柔焦 + 忧郁 |
| **花丛梦幻** 🆕 | 花枝前景虚化 + 花卉人像——花与人同为画面主角，不是"人和花合影"，是"花在守护她" |

### 🆕 花丛梦幻 · 拍摄方案结构

> **核心概念**：花卉不是背景——是画面里的第二个主角。雨后柔光 + 花瓣雨滴 + 淡粉紫花色 = 梦幻花语的天然影棚。

**四种经典构图关系**（按叙事逻辑排序）：

| 顺序 | 构图 | 空间关系 | 景别 | 焦段 | 视觉逻辑 |
|:--:|------|------|------|------|------|
| 1 | 花枝前景虚化 | 花在镜前→人在花后 | 中近景 | 1× 人像模式 | 前景花瓣离镜头 15-20cm 形成柔焦层——"花守护人" |
| 2 | 仰拍花冠笼罩 | 花在上→人在下 | 中景 | 0.5× 超广角 | 低角度仰拍让树冠占画面上方 40%——"人进入花的世界" |
| 3 | 花人并列对话 | 花在左→人在右 | 中景 | 1× **横幅** | 花 40% + 空隙 20% + 人 40%——花和人同等重要 |
| 4 | 落花+细节收尾 | 花在地→人来过 | 近景/细节 | 2× 俯拍 | 不拍脸——只拍地上落花+脚踝——"她来过的证据" |

**技法要点**：
- **前景柔焦距离**：花枝离镜头 15-20cm 是甜点——太近成一团颜色，太远无梦幻感
- **雨后漫射光是最佳光线**：花瓣透亮、皮肤通透、无硬阴影、天然柔焦感
- **色彩公式**：粉紫花 + 白上衣 + 深绿背景 = 三色安全公式（≤3 主色相）
- **情绪引导**："被花取悦了"——不是摆拍的笑，是看到花后嘴角自然浮现的弧度
- **叙事完整性**：4 张构成完整故事弧线——守护→进入→对话→痕迹

**与主风格（梦幻柔美）的关系**：
- 共享：柔焦美学 + 低对比 + 粉彩色调 + 逆光/漫射光偏好
- 差异：花丛梦幻强调"花作为第二主角"的构图逻辑，花卉不只是柔焦载体——它是画面的情绪锚点
