# 便利店美学

## 风格定义

**便利店美学 = 深夜荧光灯 + 冰柜蓝光 + 商品色彩 × 冷暖双色温碰撞。** 以 24 小时便利店为天然灯光装置，在深夜无人时刻，利用人工光源的"缺陷"——荧光灯的绿偏色、冰柜的冷蓝光、顶灯的暖黄——将这些被日常忽略的光变成画面主角。情绪基调：孤独但温暖——「世界睡了，便利店的灯还为你亮着」。

**一句话识别**：画面看起来像被荧光灯和冰柜蓝光同时照亮——暖色顶灯打在商品上，冷蓝光从冰柜门透出来，玻璃上有反光和冷凝水珠，深夜里只有一个人或只有商品。

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 青蓝（冰柜光）、琥珀暖黄（顶灯）、品红（霓虹招牌）、深海军蓝（夜空底色） | 冷暖双色温并存是核心——不是二选一，是两者同时出现在画面中 |
| 饱和度 | 中高饱和（荧光色域保留甚至增强），背景阴影可降饱和 | 不是日系的"低饱和干净"路线——便利店的美来自商品包装色彩的丰富，但要通过阴影面积控制"不乱" |
| 色温 | 双色温并行——冷调青蓝（冰柜/荧光灯 7000K+）+ 暖调琥珀（室内顶灯/街灯 3000K），不统一 | 「统一色温」在这个风格里是错的——双色温的冷暖张力才是视觉锚点 |
| 明度 | 中低调——阴影深但有细节，高光不过曝 | 便利店内部明亮但外部黑夜形成天然暗框 |
| 关键色彩规则 | **画面中不超过 3 种明显色温的光源**；冷暖对位是核心构图工具；HSL 蓝色通道是后期关键 | 超过 3 种色温 → 光污染，画面变脏。冰柜蓝+顶灯暖黄+一个霓虹色=刚好 |
| 肤色处理 | 保留自然肤色暖调——用后期品红偏移抵消荧光灯绿色污染 | 荧光灯会把肤色照得发绿发灰，HSL 橙色/红色通道微调可以拉回 |

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **混合光**——荧光灯管（硬质/方向性不强）+ 冰柜漫射蓝光（柔质/方向性）+ 霓虹招牌（硬质/高饱和） | 便利店美学的光不是"一种光"——是 3-4 种不同色温、不同光质的光源同时存在于同一空间 |
| 光方向 | 顶光（荧光灯管）+ 侧光（冰柜门）+ 逆光（玻璃窗反射外界车灯/街灯） | 顶光在这个风格里不是敌人——荧光灯从上方照亮货架通道形成天然的"光之隧道" |
| 光比 | 高光比（室内明亮 vs 室外黑暗 ≈ 1:16 以上） | 玻璃窗内的暖光 vs 窗外的深蓝黑夜 = 天然的戏剧性对比 |
| 时段 | **日落后至凌晨**（蓝调时刻刚结束、店铺灯光成为唯一光源时最佳）；雨夜加分 | 白天失去夜光对比→风格失效。雨夜=地面反光双倍光源+玻璃水珠质感 |
| 曝光策略 | 以高光（荧光灯/招牌）为基准避免过曝，阴影自然暗；或高调曝光突出冰柜内商品色彩 | 两种策略：①保护高光→画面偏暗但灯光有"浮起来"的感觉；②以商品为准→冰柜里的饮料通透发光 |
| 特殊光线条件 | **需要混合色温环境**——单一色温反而失去风格特征。冰柜冷蓝光+顶灯暖黄光+霓虹招牌品红光=三色温交织 | 这是少数"光越复杂越好"的风格——但需要摄影师理解每种光源的角色 |

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 引导线（货架纵深感）、对称构图（货架排列）、框架取景（玻璃门/冰柜门框）、前景虚化（玻璃反光/冷凝水珠） | 三分法太"自然"——便利店是人工几何空间，对称和引导线更匹配 |
| 留白程度 | 中低留白（10-25%）——深夜空旷的店面通道就是留白载体 | 不是天空/白墙的留白——是"深夜没人的空间"作为负空间 |
| 画面密度 | 中高——货架商品天然密集，但通过景深控制让背景商品变成色彩块而非杂乱信息 | 前景商品清晰→中景商品半虚化→背景灯光光晕=三层密度管理 |
| 焦段倾向 | 标准广角（28-35mm 等效）——需要环境叙事和空间感；长焦（85mm+）用于冰柜内商品特写和压缩货架纵深感 | 超广角会让狭窄过道更窄但更有沉浸感；35mm 是最自然的"人在现场"视角 |
| 景别倾向 | 中景（环境肖像/货架全景）> 近景（商品特写/冰柜内）> 远景（夜幕下的便利店外观） | 便利店外观（夜幕中发光的玻璃盒子）是经典远景——Liam Wong 和 Todd Hido 都有这类作品 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 中高对比——保持黑色深度（阴影不灰），让灯光"浮"在暗色基底上 |
| 高光 | 保留暖色高光（顶灯/招牌）不偏色；青蓝高光（冰柜光）增强饱和度 |
| 阴影 | 偏蓝/青——营造冷调夜色基底，但保留暗部细节（不完全压黑） |
| 颗粒 | 微量（5% 以下）模拟胶片感——便利店美学有天然的"低保真"气质 |
| HSL 蓝色 | **饱和度 +15-40%、明度 -10-25**——这是便利店美学的后期核心！让冰柜蓝光更通透、更有"发光感" |
| 色温 | 不全局统一——分区域调整：冰柜区偏冷、顶灯区偏暖，保留双色温张力 |
| 特殊 | 可选褪色曲线（阴影提亮+高光微压）做胶片感；可选柔焦效果（Pro Mist 滤镜模拟）让荧光灯光晕扩散 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 不是在"拍照"——是在深夜顺便买东西。放松、不设防、有一点点疲惫但被便利店的灯光治愈 |
| 眼神 | 看货架（选东西的专注）> 看远方（透过玻璃窗看夜色）> 不看镜头 >>> 看镜头 |
| 姿势 | 伸手拿饮料（冰柜门开着）、蹲下看底层货架、靠在冰柜门上看配料表、推开自动门的瞬间回眸、坐在便利店门口台阶上喝饮料 |
| 身体语言 | 松弛——不是"站好了拍照"，是"刚好在这个地方做这件事"。肩膀自然下沉、重心偏向一侧 |
| 互动 | 与商品互动（拿/看/喝）> 与环境互动（冰柜门/玻璃窗反光/自动门）> 与镜头互动 |

**核心原则**：便利店美学的模特最高境界是「忘记摄影师的存在，像深夜顺便来买东西的顾客」——即使这就是专门来拍的。

## 常见错误

| 错误 | 为什么不像便利店美学 | 修正 |
|------|-----------------|------|
| 统一色温（全局白平衡校正） | 便利店美学的核心是双色温——统一校正后变成普通室内照，失去冷暖张力 | 保留暖色顶灯+冷色冰柜光的同时存在。后期分区调整而非全局调色温 |
| 白天去便利店拍 | 日光+荧光灯的混合完全不同于夜景+荧光灯——白天失去了"发光的玻璃盒子"的视觉锚点 | 日落后再去。蓝调时刻+刚亮灯的便利店=最佳时机 |
| 避开顶光 | 传统人像教学说"避免顶光导致眼窝阴影"——但便利店的顶光是画面结构的一部分，荧光灯管的排列本身就是视觉引导 | 不要让模特正对顶光——侧对或低角度让顶光变成"通道光"而非"面部灾难光" |
| 饱和度太高画面变乱 | 便利店商品色彩本就很杂——不做控制的话画面像超市促销广告而非深夜美学 | 控制色温种类≤3 种、用景深虚化背景商品、阴影区降低饱和——用"暗"来收住"乱" |
| 闪光灯直打 | 机顶直闪会破坏冰柜光+顶光的自然层次——把精心布置的多光源变成单一平面光 | 如用闪光灯：离机+CTO 橙色滤色片匹配环境暖光+功率宁欠勿过（比环境光低 0.5-1 档） |
| 忽略玻璃反光 | 便利店里到处都是玻璃（冰柜门/入口门/饮料柜）——不利用的话少了一层视觉深度 | 侧 45 度角拍冰柜减少反光干扰；或故意利用反光叠加内外世界（Todd Hido 式的多层空间） |

## 大师参照

- **Liam Wong**：赛博朋克夜光美学的定义者。他将便利店作为都市夜景的发光装置——蓝紫/品红/青蓝的高饱和霓虹调色 + 雨夜倒影双倍光源 + 深夜孤独感。代表作《TO:KY:OO》中便利店是反复出现的核心场景
- **Todd Hido**：郊区夜景的情绪大师。透过车窗/雾/雨拍摄夜间孤独发光的建筑——暖色窗户在深蓝夜色中像"暗中的灯塔"。他的"心理景观"概念直接适用于便利店：日常商业空间的情感化。代表作《House Hunting》《Outskirts》
- **川内伦子**：日常的诗意。柔和的闪光 + 低对比 + 日常细节的神圣化——便利店在川内的视角下不是赛博朋克而是「深夜的一碗关东煮冒热气」

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **赛博朋克便利店** | 更极端的冷暖色彩饱和度（蓝紫+品红为主），更强的后期风格化，更接近 Liam Wong 的调色。适合雨夜+霓虹招牌丰富的店面 |
| **日系胶片便利店** | 降低饱和度、加颗粒、褪色曲线——把便利店美学从"未来感"拉回"平成怀旧"。色温偏暖，接近川内伦子或胶片傻瓜机质感 |
| **极简空镜便利店** | 完全排除人物——只拍深夜空旷的货架通道和冰柜。更接近 Todd Hido 的心理景观路线，强调空间本身的孤独感和几何秩序 |
| **Lofi 直闪便利店** | 机顶直闪 + 过曝倾向 + 保留瑕疵——把便利店从"精致夜光美学"拉回"2008 年深夜买零食顺便拍了一张"的青春在场感 |
