# 纪实粗粝

## 风格定义

**纪实粗粝 = 高反差 + 重颗粒 + 倾斜构图 + 闯入式拍摄 + 黑白或低饱和。** 画面不追求「美」——追求「真」。粗粝本身就是一种审美立场：世界本来就不是光滑的。

**一句话识别**：这张照片看起来像是战地记者或街头摄影师在行进中拍的——不完美是故意的，力量感来自不完美。

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 首选 | **黑白**——去除色彩的干扰，让光影和质感成为全部内容 | 纪实粗粝的默认模式 |
| 保留色彩时 | 全局饱和 -50% ~ -70% | 颜色只能有一个主角（如红灯/黄色出租车） |
| 色温 | 不重要——黑白下色温无意义 | 保留色彩时偏冷或偏暖均可，但必须统一 |
| 黑色 | **深黑——可以纯黑** | 纪实粗粝不需要暗部细节——那是柔美风格的需求 |
| 白色 | 可以过曝——高光溢出是可接受的 | 粗粝不追求完美曝光 |

---

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **硬光优先**——强太阳光、直闪灯光 | 硬光 → 锐利阴影 → 最强的光影几何 |
| 光比 | 极高光比（1:8 以上） | 亮就是亮、暗就是暗——不妥协 |
| 直闪 | **机顶直闪是合法技法**——闪光灯直打主体 | 森山大道的标志：高反差 + 直闪 + 颗粒 |
| 时段 | 正午硬光（故意选择「错误」的光线） | 黄金时刻的柔美是纪实粗粝的反面 |
| 曝光策略 | 暗调（Low Key）或以高光为准——让暗部全黑 | 曝光不是「正确」，是「有力量」 |

---

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | **对角线（倾斜）** + 闯入式构图 | 水平线歪斜不是错误——是视觉张力 |
| 留白 | 少——街头就是满的 | 城市是拥挤的，构图也是 |
| 焦段倾向 | 广角（28-35mm）——**靠近、再靠近** | Capa：「如果你的照片不够好，是你靠得不够近」 |
| 景别倾向 | 近景（闯入距离）+ 中景（街头观察） | 远景太「安全」 |
| 画面密度 | 高——可以多层、多人、多元素 | 混乱本身就是内容 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | **极高** + S 曲线——中间调对比度拉满 |
| 颗粒 | **重颗粒 20-35%**——粗粝感的核心来源 |
| 清晰度/纹理 | +20-30%——增强质感锐度 |
| 暗角 | 可选 10-20% |
| 锐化 | 高——粗糙的锐度 |
| 裁切 | 可倾斜——不追求水平 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 不引导——捕捉真实状态。「摆拍」是纪实粗粝的死敌 |
| 眼神 | 不看镜头（被偷拍感）或直视镜头（对峙感）——两个极端都可以 |
| 姿势 | 不摆姿势——走路、等车、抽烟、发呆——生活中的真实动作 |
| 服装 | 不干涉——拍他们真实穿的衣服 |

**核心原则**：纪实粗粝不引导模特。摄影师是观察者，不是导演。

| 色彩 | 黑白为主 |
| 快门 | 高速快门——冻结街头的决定性瞬间 |

## 常见错误

| 错误 | 为什么不像纪实粗粝 | 修正 |
|------|-----------------|------|
| 构图太端正 | 「太完美」→ 失去了街头的生猛感 | 允许歪斜、切头、不完美 |
| 光线太软 | 软光 = 温情——粗粝需要硬光 | 等到有硬光或使用直闪 |
| 颗粒不够 | 数字感太强——粗粝感靠颗粒和对比度共同构建 | 颗粒 20-35% |
| 站得太远 | 偷拍感 → 缺少身临其境的冲击力 | 靠近到 1-2 米以内 |
| 摆拍 | 纪实粗粝的核心是「真实」 | 抓拍、等待、不干预 |

## 大师参照

- **森山大道**：粗粝美学的定义者——高反差黑白 + 重颗粒 + 倾斜构图 + 直闪 + 街头
- **William Klein**：纽约街头——广角闯入 + 倾斜 + 模糊 + 颗粒
- **Daido Moriyama**：日本的「野狗」视角——低角度 + 碎片化 + 高反差黑白

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **高反差黑白** | 画面近乎纯黑纯白两极——中间灰极少的极致版本 |
| **彩色纪实** | 保留 1-2 个高饱和颜色 + 其余消色 |
| **模糊纪实** | 故意慢快门 + 动态模糊——不确定性本身就是内容 |
