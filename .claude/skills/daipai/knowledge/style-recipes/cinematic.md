# 电影感

## 风格定义

**电影感 = 宽画幅比例 + 冷暖色调分离 + 浅景深 + 叙事性构图 + 胶片颗粒。** 画面看起来像从一部电影中截取的一帧——不是记录瞬间，是讲述故事。

**一句话识别**：把照片裁成 16:9 或 2.35:1，加上黑边，看起来就像电影截图。

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩结构 | **冷暖分离（Teal & Orange）** | 阴影偏青蓝（Teal），肤色/高光偏橙黄——这是好莱坞色彩科学的基石 |
| 饱和度 | 冷暖两侧中低饱和，中间色削减 | 不让任何颜色「跳」出来——所有颜色服务于整体氛围 |
| 色相数量 | 2-3 个——暖色侧（肤色/灯光）+ 冷色侧（天空/阴影） | 色相越少越「电影」 |
| 肤色 | 偏橙/琥珀色（保留自然感） | 电影肤色不是日系的粉白，是健康的琥珀色 |
| 黑色 | 不完全黑——暗部有微弱细节（Crushed Blacks） | 纯黑 = 视频感，微细节黑 = 电影感 |

**关键认知**：电影感的色彩不是「好看」——是「统一」。画面中每一个颜色都有它在这个场景中的叙事理由。

---

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **硬光与软光交替使用** | 硬光造戏剧性，软光造氛围——电影用光不偏食 |
| 光比 | 中高光比（1:4 ~ 1:8） | 亮暗分明——电影需要影调层次来叙事 |
| 主光源 | 单一明确的主光源 | 电影布光的第一原则：让观众知道光从哪来 |
| 轮廓光 | 必须——分离主体与背景 | 电影人像最常见的补光手段 |
| 时段 | 黄金时刻 + 蓝调时刻 | 电影最爱的两个自然光时段 |
| 曝光策略 | 中调或暗调（Low Key） | 亮调（High Key）很少用于电影感 |

---

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 画幅比例 | 16:9 / 2.35:1 / 1.85:1 | 宽于 4:3 即产生电影感——推荐 16:9 裁切 |
| 常用构图 | 引导线、框架、三分法（偏一侧） | 电影构图服务于叙事引导 |
| 留白 | 留白有方向——人物看向哪，留白在哪 | 「视线留白（Lead Room）」是电影构图的基础 |
| 空间层次 | **必须 3 层以上** | 前景虚化（过肩/前景物）+ 中景主体 + 背景氛围 |
| 焦段倾向 | 标准-中焦（50-85mm）+ 长焦（>100mm） | 浅景深 + 空间压缩 = 电影感的空间感 |
| 景别倾向 | 中景（叙事主力）+ 近景（情绪高潮）+ 远景（开场定调） | 电影景别有叙事节奏 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | S 曲线——中间调对比度增强，高光不炸、暗部不黑 |
| 色调分离 | 阴影加青蓝（Teal）+ 高光加橙黄（Orange） |
| 颗粒 | 加 5-15% 35mm 胶片颗粒 |
| 暗角 | 轻微暗角（5-10%）——引导注意力向画面中心 |
| 裁切 | 裁切为 16:9 或更宽比例 |
| 锐化 | 适度——电影感不是「锐」，是「有质感」 |
| 变形宽银幕效果 | 可选：拉丝高光（Streak Flare）+ 椭圆焦外 |

---

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 有叙事重量——不是笑，是「有故事的表情」 |
| 眼神 | 看向画面中或画面外的叙事焦点——不是空洞看远方 |
| 姿势 | 有意图的——站/坐/走都有「角色在场景中」的感觉 |
| 互动 | 与环境的关系明确——不只是站在那里 |
| 服装 | 颜色服务于整体色调——避免荧光色/杂乱花纹 |

**核心原则**：电影感模特的最高境界是「你知道这个人有过去，也有未来」。

## 技术层联动

| 技术维度 | 电影感倾向 |
|---------|---------|
| 焦段 | 标准-中焦（50-85mm）+ 长焦（>100mm）——浅景深必备 |
| 景别 | 中景/近景为主 + 远景定调 |
| 光线 | 单一主光源 + 轮廓光 + 中高光比 |
| 色彩 | 冷暖分离（阴影青蓝 + 高光橙黄） |
| 空间 | 必须 3 层以上——前景虚化是电影感的标志 |
| 景深 | 浅景深——分离主体与前后景 |

## 常见错误

| 错误 | 为什么不像电影感 | 修正 |
|------|----------------|------|
| 4:3 或 1:1 画幅 | 这不是电影/影集的画幅比例 | 裁切为 16:9 或 2.35:1 |
| 没有前景层 | 画面扁平——缺少电影的「过肩」感觉 | 增加一个虚化的前景元素 |
| 色彩太鲜艳 | 所有颜色都在「叫」→ 像广告不像电影 | 降饱和 + 统一色调 |
| 没有颗粒 | 数字感太强——缺少胶片的物质感 | 加 5-15% 颗粒 |
| 硬光但没轮廓光 | 主体和背景粘连 | 加轮廓光或用逆光分离 |
| 模特表情太日常 | 缺少叙事的重量感 | 引导模特进入「角色」状态 |
| 暗角过重 | 像 LOMO 不像电影 | 暗角控制在 5-10% |

## 大师参照

- **Roger Deakins**（《银翼杀手2049》《1917》）：极致的光影控制 + 冷暖对比
- **Emmanuel Lubezki**（《荒野猎人》《地心引力》）：自然光为主的电影感
- **Christopher Doyle**（《花样年华》《重庆森林》）：手持电影感 + 色彩饱和度控制
- **Hoyte van Hoytema**（《奥本海默》《敦刻尔克》）：暗调电影感 + 胶片质感

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **暖调电影感** | 橙黄为主，青蓝减少——适用于爱情/温馨叙事 |
| **冷调电影感** | 青蓝为主，橙黄极少——适用于悬疑/孤独叙事 |
| **手持电影感** | 不加暗角、轻微歪斜、抓拍感——Christopher Doyle 式 |
| **极简电影感** | 画面元素减到最少 + 宽画幅——适用于空旷场景 |
