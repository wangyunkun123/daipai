# 微观微距 · Macro & Micro Poetry

## 风格定义

**微观微距 = 「用最近的距离，看最日常的东西——然后它变成了你从没见过的东西。」** 不是自然微距（拍昆虫/花朵的科普向），而是将微距作为一种「发现日常中的新世界」的审美工具。

**情绪基调**：惊奇、亲密、「原来这个这么好看」、日常的神圣化
**最适场景**：任何场景——桌面上的物品/衣服的纹理/食物的表面/植物的局部/水渍的反光
**难度**：⭐⭐（技术门槛中等，但需要「发现微观景观」的审美眼光）

---

## 审美立场

微距摄影通常被归类为「技术摄影」（需要微距镜头/精确对焦/景深堆叠）。但微观微距风格把它重新定位为**审美工具**：

- 不是「拍清楚这个昆虫的复眼」——是「这片叶子的叶脉纹理像一幅抽象画」
- 不是「用微距镜头」——是「换一种观看距离」
- 不是科普——是诗意

川内伦子的核心方法：不拍整片海，只拍指尖与阳光交汇的那一小片温暖。微观微距就是这个方法在物理距离上的极致实践。

## 色彩配方

| 参数 | 取值 |
|------|------|
| 饱和度 | 中等到中高——近距离让色彩更饱和 |
| 色温 | 取决于被摄物的自然色温 |
| 色调风格 | 不强制统一——微观世界的色彩自有其逻辑 |

**关键**：微观微距的色彩不应该被「调」出来——因为近距离下的色彩通常已经很丰富了。后期只做微调。

---

## 光线配方

| 参数 | 取值 |
|------|------|
| 光质 | **软光优先**——散射光/阴天/窗边柔光。硬光在微距下阴影太锋利 |
| 光比 | 低——微距下的景深极浅，高光比会让暗部完全消失 |
| 特殊光线 | **逆光透射**——光线穿过半透明的花瓣/叶片/织物 → 揭示肉眼看不到的内部纹理 |
| 补光 | 小型反光板（白纸/手机屏幕）——填充微距下的局部阴影 |

---

## 构图配方

| 参数 | 取值 |
|------|------|
| 构图风格 | **「微观景观」**——把一小片纹理当作一个完整的世界来构图 |
| 填充画面 | 微距主体占画面 60-90% |
| 留白 | 微观留白——不是大面积天空，是纹理中的自然空隙 |
| 角度 | 正上方俯拍 / 侧面切向（光线穿过） |

**微观景观的关键**：一平方厘米的织物纹理 + 适当的光线和景深 → 可以像一片沙漠/山脉/海洋一样壮观。微观微距的乐趣在于这种「尺度的欺骗」。

---

## 后期方向

| 参数 | 取值 |
|------|------|
| 对比度 | 正常到略低——保留中间调的丰富细节 |
| 锐度 | 重点在焦平面——确保焦内绝对锐利 |
| 颗粒 | 不加——微观需要清晰，颗粒 = 模糊了微观的细节 |
| 裁剪 | 可以大胆裁剪——微距下 1/4 画面 = 一个新的构图 |

## 设备考虑

微距的设备门槛因设备类型差异很大：

| 设备类型 | 微距能力 | 备注 |
|---------|---------|------|
| 有微距模式的设备 | ★★★★ | 内置微距模式通过超广角镜头实现 |
| 长焦镜头 | ★★★ | 长焦 + 最近对焦距离——离远一点也能拍大 |
| 外接微距镜头 | ★★★★★ | 专业方案 |
| 标准设备 | ★★ | 靠最近对焦距离拍——不能太近但可以后期裁切 |

## 微观景观类型

| 类型 | 示例 | 审美效果 |
|------|------|---------|
| **织物纹理** | 毛衣的针织纹理、丝绸的褶皱、牛仔布的经纬线 | 人造纹理的抽象美 |
| **食物表面** | 面包的气孔、水果表皮的绒毛、咖啡表面的油脂纹理 | 吃的另一种观看方式 |
| **植物局部** | 花瓣的叶脉、叶子的边缘锯齿、茎上的绒毛 | 自然界的隐藏建筑学 |
| **液体** | 水珠在表面上的弧面、油和水的不溶纹理、咖啡渍的扩散边缘 | 流体物理的美 |
| **日常物品** | 纸的纤维、木头的年轮、金属的划痕、塑料的边缘 | 「原来这个东西长这样」的惊喜 |

## 在 9 套方案中的位置

微观微距最适合作为**特写方案**——用 1-2 张微观特写作为整组的「呼吸间隙」：

```
第 1-3 张：远景+中景——建立场景
第 4-6 张：近景+中景——人物叙事
第 7 张：微观微距——「你注意到这个了吗？」
第 8-9 张：中景+远景——收束
```

## 常见错误

| 错误 | 为什么不好 | 修正 |
|------|----------|------|
| 拍得太远——不是微距 | 没有「新世界」的感觉——只是一张离得比较近的照片 | 更近——直到被摄物变得像抽象画 |
| 光线太平 | 微距下的平光 = 看不到纹理的起伏 | 侧光或逆光透射——让纹理的三维结构显现 |
| 没有「尺度参照」 | 观众不知道这是多大——失去「尺度的欺骗」的乐趣 | 不是必需的——有时候「不知道多大」也是乐趣 |
| 微距和整组风格割裂 | 整组日系清新 + 一张昆虫复眼特写 → 审美断裂 | 微观微距的被摄物应该和场景有关联——拍大海场景 → 微距海水/沙粒/贝壳纹理 |
