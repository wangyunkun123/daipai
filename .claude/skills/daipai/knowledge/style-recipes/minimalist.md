# 极简高级

## 风格定义

**极简高级 = 极低色彩数量 + 大面积留白 + 几何化构图 + 精细质感。** 画面的力量来自「少」——少到每一件剩下的东西都有不可替代的存在理由。

**一句话识别**：这张照片让你觉得「好干净」——然后才注意到画面中唯一的那个东西有多好看。

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩数量 | **1-2 个色相**——不能再多 | 第三个颜色出现 = 极简崩塌 |
| 主色调 | 白/灰/米/黑/蓝灰/沙色 | 中性色基底——极简不谈「colorful」 |
| 饱和度 | 极低——全局 -40% ~ -70% | 接近消色但不完全黑白 |
| 色温 | 中性偏冷 | 温暖 = 人情味，极简要的是距离感和客观感 |
| 明度 | 偏高——干净感来自明亮 | 暗调极简存在但更难——需要精确的光线控制 |
| 关键规则 | 一个画面 = 一个主色（基底）+ 一个强调色（主体） | 强调色是画面中唯一「有色」的元素 |

---

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | 软光优先——柔和的阴影过渡 | 硬光产生复杂阴影 → 破坏极简的简洁感 |
| 光比 | 低光比（1:2 ~ 1:3） | 强光比 = 视觉复杂化 |
| 光源 | 单一明确的光源 | 多个光源 = 多个影子方向 = 视觉混乱 |
| 曝光策略 | 亮调（High Key）——干净明亮 | 暗调极简仅限特定场景（如单一窗口光） |
| 光线方向 | 侧光（产生柔和的立体感但不分裂画面） | 顶光/顺光/逆光根据场景选择 |

---

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 留白程度 | **留白占画面 50-80%** | 极简的本质：用空来定义满 |
| 常用构图 | 留白、对称、引导线（单一线条） | 框架/对角线太「复杂」 |
| 负空间 | 大面积纯色/近纯色的空旷区域 | 天空/白墙/水面/沙地 |
| 几何化 | 线条清晰、形状规整 | 不规则 = 视觉噪音 |
| 焦段倾向 | 广角（35mm）+ 标准-中焦（50mm） | 长焦压缩会增加画面复杂度 |
| 景别倾向 | 远景（小人 + 大天地）+ 特写（单一物体） | 中景/近景信息量太大 |

---

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 低对比——画面中没有纯黑和纯白之间的剧烈过渡 |
| 饱和度 | 全局 -40% ~ -70% |
| 杂色去除 | 移除画面中的干扰色块 |
| 颗粒 | 不加——极简需要的是光滑、干净、精确 |
| 锐化 | 适度——质感的锐度是重要的（少的东西必须精） |
| 畸变修正 | 必须修正——歪斜的线条破坏极简的几何感 |

---

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 安静、克制、疏离——不笑，不是悲伤，是「存在」 |
| 眼神 | 不看镜头、看向画面外的空旷处 |
| 姿势 | 静态——站/坐，身体线条简洁 |
| 服装 | **纯色、无图案、剪裁干净**——服装是极简构图的一部分 |
| 在画面中的比例 | 小——人是一个安静的点缀，不是画面的全部 |

---

## 技术层联动

| 技术维度 | 极简高级倾向 |
|---------|------------|
| 焦段 | 广角（35mm）——自然透视 + 大环境 |
| 景别 | 远景（人小景大）> 特写（单物体极致） |
| 光线 | 软光 + 单一光源 + 低光比 |
| 色彩 | 1-2 色相 + 极低饱和 |
| 空间 | 1-2 层——空间越简单越高级 |

## 常见错误

| 错误 | 为什么不像极简 | 修正 |
|------|-------------|------|
| 画面元素超过 3 个 | 每个元素都在争夺注意力 → 没有「极」也没有「简」 | 做减法：只保留主角 + 纯色背景 |
| 背景有纹理/杂物 | 干净感瞬间崩塌 | 换机位/换角度/换背景 |
| 色彩超过 2 个 | 颜色多样性 = 极简的反面 | 后期降低杂色饱和度或直接黑白 |
| 留白不够 | 画面太满 → 极简的呼吸感消失 | 退远、缩小主体占比 |
| 线条歪斜 | 几何不完美 → 极简的秩序感被破坏 | 水平仪 + 后期旋转修正 |
| 用硬光产生复杂阴影 | 阴影是画面中的一个新「元素」→ 增加复杂度 | 软光或单一方向侧光 |

## 大师参照

- **Michael Kenna**：极简黑白风光——一棵树 + 一片雾 + 大片灰白天空
- **杉本博司**（Hiroshi Sugimoto）：海景系列——海与天的分界线 = 一张照片的全部内容
- **Hiroshi Sugimoto**：剧院系列——一张照片 = 一块发光的白色银幕

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **日式侘寂极简** | 允许不完美、斑驳、旧物——「朴素的极简」而非「光滑的极简」 |
| **北欧极简** | 暖灰/米白基底 + 一点暖木色——比日式极简温暖 |
| **暗调极简** | 黑色/深灰基底——单一光源照亮主体的极小部分 |
