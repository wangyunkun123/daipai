# 风格配方库

## 一句话定义

**风格配方 = 色彩倾向 + 光线偏好 + 构图习惯 + 后期基调的可执行组合。** 每个风格不是一句形容词，而是一套完整的视觉参数组合——可以直接挂载到方案上，让 9 套方案拥有审美差异化。

---

## 原理

### 为什么需要风格配方

技术层解决了「能不能拍出来」——构图、光线、景别都对，但 9 套方案可能看起来都是一个味道。风格配方解决的是「拍出来有没有独特气质」。

**核心洞察**（来自 Claude 的提议）：
> 把零散的审美偏好整理成一个个有名字、可识别的风格包。每个风格是一套具体配方，而不是停留在「好看」这种空话上。

**核心洞察**（来自豆包的画面气质模块）：
> 拍摄前先定画面调性，再反向选择光/色彩/构图。调性先于技术。

### 风格配方的四维结构

每个风格配方由四个维度定义：

| 维度 | 内容 | 示例（日系清新） |
|------|------|-----------------|
| **色彩倾向** | 主色调、饱和度、色温偏好 | 低饱和、偏蓝绿、高明度 |
| **光线偏好** | 光质、光比、时段偏好 | 软光、低光比、黄金时刻 |
| **构图习惯** | 常用构图法、留白程度 | 大量留白、三分法为主 |
| **后期基调** | 对比度、颗粒、色调曲线 | 低对比、高光偏蓝、阴影提亮 |

### 风格 ≠ 滤镜

滤镜是后期一键套用的色彩映射。风格配方是**前期拍摄 + 后期方向的完整决策链**——从选择什么光线、站什么位置、用什么焦段开始，就已经在为风格服务。

### 配方结构模板

每个风格文件包含：

```
1. 风格定义 —— 一句话 + 情绪基调 + 适合场景
2. 色彩配方 —— 主色调/饱和度/色温/关键色彩规则
3. 光线配方 —— 光质/光比/时段/曝光策略
4. 构图配方 —— 常用构图法/留白程度/焦段倾向
5. 后期方向 —— 对比度/颗粒/色调曲线/特殊处理
6. 模特引导 —— 情绪/姿势/眼神
7. 技术层联动 —— 与该风格匹配的技术参数选择
8. 常见错误 —— 该风格最容易被拍"不像"的原因
9. 大师参照 —— 该风格的代表摄影师
10. 变体 —— 该风格的子类型
```

## one_liner 全局标识规范 🆕 v3

### 什么是 one_liner

**one_liner = 风格的全局唯一标识——一句话定义这个风格的审美核心。** 整个知识库中，所有文件对某个风格的引用，必须使用 `_index.md` 中定义的 one_liner 作为权威描述，而非各自重新描述。

### 为什么需要 one_liner

同一个"森系"在 3 个文件里可能用 3 种说法——`style-router.md` 说"户外自然温暖松弛"，`mood-router.md` 说"宁静舒适野生感"，方向卡片里写"不跟光线对抗"。AI 跨文件引用时产生语义漂移——风格推荐的一致性下降。

**one_liner 解决这个问题**：每个风格在系统里只有一个权威的一句话定义。其他文件引用时，使用 one_liner 而非自己重新描述。

### 引用规范

所有需要引用风格的模块，使用以下格式：

```markdown
**风格**：森系——在森林里待久了——身上沾了树叶和泥土的气息
```

而非：

```markdown
**风格**：森系——户外自然场景下的温暖松弛感（各文件自己的描述）
```

**自动校验**：当方案生成中引用了一个风格 → 检查使用的描述是否与 one_liner 一致 → 不一致则替换为 one_liner。

### 风格冲突检测

9 套方案如果全部使用同一种风格 → 单调。但如果 9 套方案混合过多风格 → 没有统一的审美基调。

**建议策略**：
- 9 套方案中，**主风格 5-6 套 + 变体风格 2-3 套 + 破格方案 1 套**
- 主风格定义整组照片的审美基调
- 变体风格在主风格基础上微调（如日系清新为主 + 2 套偏胶片复古的温暖变体）
- 破格方案故意打破主风格（如整组日系中插入一张高反差黑白）

## 在方案生成中的使用

### 阶段 2（方案生成）的审美步骤

```
场景分析 → 提取场景气质
         → 匹配可选风格列表
         → 用户偏好/默认风格
         → 为每套方案挂载风格标签
         → 根据风格参数微调色彩/光线/构图建议
```

### 方案输出格式中的风格字段

每套方案新增一个 `风格` 维度：

```
| 风格 | 日系清新 |
| 色彩倾向 | 低饱和、蓝绿偏移、高明度 |
| 光线策略 | 等待黄金时刻软光、降低光比 |
| 后期方向 | 低对比、高光偏蓝、阴影提亮 |
```
