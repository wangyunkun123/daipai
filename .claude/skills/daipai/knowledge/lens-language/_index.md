# 焦段语言

## 一句话定义

**焦段不是「放大缩小」——焦段改变了空间关系。** 超广角让近的更近、远的更远（夸张空间）；长焦把近和远压在一起（压缩空间）。选择焦段 = 选择你要怎么讲述空间。

—— 框架参考 Freeman《摄影师的视界》

---

## 原理

### 焦段改变的是什么

Freeman 强调：绝大多数人误以为长焦 = 「拉近」，超广角 = 「拍更多」。这是错的。

焦段真正改变的是**前后物体的相对大小关系**：

- **超广角**（<24mm）：前景物体被夸张放大，背景物体被推远缩小。一张脸靠近镜头时鼻子变巨大、耳朵变小——这不是畸变，是透视的极端表现
- **广角**（24-35mm）：接近人眼的自然视角，但仍有温和的前后大小差异
- **标准-中焦**（50-85mm）：空间关系最接近人眼感知，被摄体大小关系自然
- **长焦**（>100mm）：前后物体的大小差异被压缩，远处和近处的物体看起来「叠在一起」

**这不是镜头的问题，是距离的问题。** 用超广角拍一个东西 = 你必须靠近它才能让它占满画面。靠近就改变了透视。用长焦拍 = 你必须远离。远离就压缩了透视。

### Adams 的洞见

Ansel Adams 在《The Camera》中花了大量篇幅论述：**焦段选择是视觉意图的表达，不是取景的便利。** 先决定「我想让这个空间关系看起来如何」，再选焦段，而不是反过来。

## 四大焦段类别的视觉语言

### 超广角（<24mm 等效）

**视角**：>100° 对角线

**空间关系**：极度夸张的透视
- 近景物体被放大到夸张的比例
- 远景被压缩到画面中看起来非常遥远
- 画面边缘产生明显的桶形畸变（直线变弯）

**视觉语言**：
- 「我站在事件的最中心」
- 「这里非常宏伟/巨大」
- 「看这个不可思议的空间」
- 沉浸感、宏大感、突破感

**适合的创作意图**：

| 适合 | 不适合 |
|------|--------|
| 展示建筑内部的宏大空间 | 人像（人物在边缘会严重畸变） |
| 狭小空间「拍全」 | 主体不明确时画面杂乱 |
| 低角度仰拍：天空留白 + 人物下半身拉长 | 需要准确比例的商业摄影 |
| 创意第一人称视角（手伸向镜头方向） | 多人在画面边缘——边缘的人会变宽变斜 |
| 利用边缘汇聚线制造纵深 | — |

**操作要点**：
- 主体放画面中心，避开边缘畸变区
- 利用畸变作为创作元素——边缘的建筑/树木向内弯曲形成天然框架
- 弱光下超广角镜头通常感光能力弱于标准镜头，注意光线条件

### 广角（24-35mm 等效）

**视角**：≈63-84° 对角线

**空间关系**：温和的广角透视
- 接近人眼注意力的集中范围（不是视网膜范围，是注意力范围）
- 物体大小关系自然但有温和的前后差异

**视觉语言**：
- 「这就是你站在那里看到的样子」
- 自然的、不介入的、记录感
- 最诚实的焦段——不夸张也不疏离

**适合的创作意图**：

| 适合 | 不适合 |
|------|--------|
| 环境人像（人 + 场景的平衡叙事） | 远距离人像（要靠近才能拍半身，透视会显脸圆） |
| 引导线和框架构图 | 特写 |
| 室内外通用，最安全的焦段 | 需要极简背景时（视角太宽，纳入太多环境） |
| 街拍、纪实 | — |
| 中景和远景的主力焦段 | — |

**操作要点**：
- 拍人像半身需保持距离（≥1.5m），太近透视显脸圆
- 通常是系统中画质最好的镜头（最大光圈、最大传感器）
- 弱光首选

### 标准-中焦（50-85mm 等效）

**视角**：≈28-47° 对角线

**空间关系**：开始有明显但克制的空间压缩
- 前后物体的大小关系趋于均匀
- 视角更窄，排除背景杂物的能力强于广角

**视觉语言**：
- 「让我靠近一点看你」
- 「这个人是重要的」
- 半身人像的经典焦段
- 客观但有关注感

**适合的创作意图**：

| 适合 | 不适合 |
|------|--------|
| 半身人像——透视自然，人脸不变形 | 展示大环境 |
| 框架构图——压缩框架与模特的距离感 | 狭小空间（退不开） |
| 引导线——压缩使线的密度增加 | 需要前景夸张效果的创意构图 |
| 从稍远处抓拍，不打扰模特 | — |
| 人像模式/景深控制的最佳范围 | — |

**操作要点**：
- 拍半身人像距离约 1.5-3m，透视最自然
- 视角窄 → 手持需要更稳的快门速度（≥1/60s）
- 85mm 附近是传统人像焦段，面部透视最接近人眼社交距离的感知

### 长焦（>100mm 等效）

**视角**：<24° 对角线

**空间关系**：显著的空间压缩
- 前后物体的距离感被压缩，背景和模特「叠」在一起
- 摄影师可以站在远处拍摄，不打扰模特

**视觉语言**：
- 「我在观察你，但你不必知道我在这里」
- 压缩的空间感 = 亲密而疏离的矛盾感
- 适合特写和细节

**适合的创作意图**：

| 适合 | 不适合 |
|------|--------|
| 面部特写/半特写——最自然的人脸透视 | 任何需要环境叙事的构图 |
| 压缩背景与主体的距离（如山+人叠在一起） | 弱光（长焦镜头通常光圈较小） |
| 框架构图——框架与模特之间的空间被压缩为「一层」 | 手持稳定性要求高（长焦放大手抖） |
| 微距特写 | 引导线——线的延伸感被压缩后变弱 |
| 抓拍——远距离不打扰 | — |

**操作要点**：
- 长焦放大所有震动 → 手持快门速度 ≥ 1/焦距（等效值）
- 弱光下长焦的表现通常最弱，需要充足光线或稳定支撑
- 空间压缩感在 135mm 以上变得非常明显

## 焦段选择决策树

```
你的拍摄意图是什么？
│
├─ 展示宏大的空间/建筑/风景
│   └─ 选择超广角（<24mm）
│       注意：如果画面中有人，人放中心避开边缘畸变
│
├─ 环境人像（人+场景平衡）
│   └─ 选择广角（24-35mm）
│       注意：保持 ≥1.5m 距离，透视自然
│
├─ 半身人像/框架构图
│   └─ 选择标准-中焦（50-85mm）
│       注意：透视最自然的人像焦段
│
├─ 面部特写/细节/压缩空间
│   └─ 选择长焦（>100mm）
│       注意：弱光下谨慎使用，需要稳定支撑
│
├─ 创意夸张/第一人称/仰拍天空
│   └─ 选择超广角（<24mm）
│       注意：利用畸变作为创作元素
│
└─ 不确定 → 选择广角（24-35mm）
    理由：画质通常最好，视角最自然，后期裁切余地最大
```

## 焦段与构图的协同

| 焦段 | 最佳构图搭配 | 原因 |
|------|------------|------|
| 超广角 | 引导线、对角线 | 夸张的透视线强化线构图的效果 |
| 广角 | 三分法、引导线、框架 | 自然的空间关系，所有构图都适用 |
| 标准-中焦 | 框架、三分法 | 压缩感让框架「紧贴」主体 |
| 长焦 | 留白（压缩式留白）、框架 | 窄视角排除环境，主体天然被隔离 |

## 设备映射表

> 本节说明「焦段概念」如何映射到不同设备上。具体设备的操作细节见 `device-adaptation/_index.md`。

| 焦段概念 | 等效焦距范围 | 手机上典型实现 | APS-C 典型实现 | 全画幅典型实现 |
|---------|------------|--------------|--------------|--------------|
| 超广角 | <24mm | 0.5x (~12-14mm) | 10-16mm | 14-24mm |
| 广角 | 24-35mm | 1x (~24-28mm) | 16-24mm | 24-35mm |
| 标准-中焦 | 50-85mm | 2x-3x (~48-80mm) | 35-55mm | 50-85mm |
| 长焦 | >100mm | 5x (~120mm) 或以上 | 70-200mm | 135-200mm+ |

**关键提醒**：
- 不同品牌手机「0.5x/1x/2x/3x」对应的等效焦距不同（iPhone 主摄 ≈ 26mm，部分安卓旗舰主摄 ≈ 23mm）
- 部分手机的 2x 是主摄裁切而非独立光学镜头——裁切不改变透视关系
- APS-C 画幅的「等效焦距」= 镜头焦距 × 1.5（佳能 × 1.6）
- 中画幅的「等效焦距」= 镜头焦距 × 0.7-0.8（视具体画幅）

**ShotOracle 使用原则**：方案生成时使用焦段概念（超广角/广角/标准-中焦/长焦），设备筛选阶段再映射为具体操作。参见 `device-adaptation/_index.md`。
