# 方向选择引擎 v2.0

## 核心设计哲学

**v1.0 的问题**：两个默认方向（简单拍/最出片）+ 可折叠的展开更多。所有方向都在设备和光线的可执行范围内。结果是——方案"可实现"但"不惊喜"。用户觉得"还行"，不会兴奋。

**v2.0 的原则**：

```
不只给用户"现在能拍的"——也给他们"摄影的可能性"。
但不为了给而给——没东西就诚实不说。

🟢 现在就拍：每个场景都有。零门槛。解决"我能拍什么"
🔥 最出片：有才给。高辨识度方向是否存在。解决"怎么拍最好看"
✨ 脑洞大开：有才给。真正的观看方式变化是否存在。解决"摄影可以有多酷"

硬编比不编更差。平淡场景 → 一个🟢就够了 → 省token也省用户时间。
```

---

## 一、三方向定位

| 方向 | 标签 | 定位 | 约束 | 用户心理 |
|------|------|------|------|---------|
| 🟢 现在就拍 | 立刻出片 | 站着就能拍，30 秒出片 | 光线+设备双硬约束 | "我就想拍张好看的照片" |
| 🔥 最出片 | 高辨识度 | 稍微调整，社交验证过 | 光线硬约束，设备可🟡 | "我想拍一张发出去会被夸的" |
| ✨ 脑洞大开 | 摄影的可能性 | AI 自由发挥，不限技法 | 无硬约束（但如实标注条件） | "哇，原来摄影还可以这样拍" |

### 三方向的审美关系

```
现在就拍：最安全的审美——不出错
最出片：最验证的审美——不出格但出彩
脑洞大开：最大胆的审美——可能出格但一定出彩

三个方向构成一个审美梯度：
  安全 → 出彩 → 惊喜

用户心理旅程：
  "这个我能拍"（现在就拍）→
  "这个拍出来好看"（最出片）→
  "哇这个好酷！虽然现在拍不了但我想试试"（脑洞大开）
```

## 三、🟢 现在就拍 — 选择逻辑

### 目标

用户从拿出手机到按下快门 ≤ 30 秒。不需要改变光线、不需要后期、不需要特殊设备。**站在这就能拍。**

### 筛选规则

```
Step 1: 风格池 ∩ 可执行性 = 🟢
        排除所有需要改变光线/等待时段/特殊设备/后期才能出效果的

Step 2: 按"操作步数"排序
        0 步（直接拍）> 1 步（微调站位）> 2 步（改变构图方式）

Step 3: 按 style-router 匹配分数降序

Step 4: 按审美主张的 primary 创作方向优先

Step 5: 取 TOP 1

Step 6: 兜底
        如果没有任何 🟢 风格 → 取 🟡 中操作步骤 ≤ 2 步的
```

### 路由规则——什么风格进入🟢现在就拍

> ⚠️ **v2.3 术语修正**：以下不是"排除规则"——是**路由规则**。这些风格不会进入🟢，但它们完整保留在🔥最出片和✨脑洞大开的候选池中。"不进入🟢"≠"被删除"。

以下风格**路由到🔥或✨**（不进入🟢）：
- 需要特定光方向但当前光不满足的（如逆光通透场景当前是顺光）→ 去🔥（标注🟡）或✨
- 需要额外设备或道具的 → 去✨（脑洞大开不限设备）
- 需要等待特定时刻的（蓝调时刻、黄金时刻）→ 去✨（时空假设类脑洞）
- 需要复杂后期的（如 Grunge 在软光下）→ 去🔥（如果🟡标注支持）或✨

### 各题材典型结果

| 题材 | 软光场景 | 硬光场景 | 漫射光场景 |
|------|---------|---------|----------|
| portrait | 日系清新 / 安静真实 / 森系 | 杂志时尚 / 电影感 | 安静真实 |
| landscape | 极简高级 / 日系清新 | 纪实粗粝 / 极简高级 | 极简高级 |
| still_life | 安静真实 / 微观微距 | 极简高级 | 安静真实 |
| street | 县城记忆 / 胶片复古 | 纪实粗粝 | 纪实粗粝 |
| event | 纪实粗粝 / 安静真实 | 纪实粗粝 | 纪实粗粝 |

### 卡片文案风格

「现在就拍」的文案强调：**简单、不费力、生活感**
- "别叫她——就让她继续摸小狗"
- "站在这就能拍，不需要改变任何东西"
- "多云天的柔光已经帮你打好光了"

## 四、🔥 最出片 — 选择逻辑

### 目标

视觉冲击力最强、社交媒体验证过的、用户拍完就想发的。允许微调（改变站位、等待 5 分钟、简单后期），但不允许需要特殊设备或专业后期。

### 筛选规则

**有 0E 地点数据时**：
```
Step 1: 0E 地点情报中的当地流行风格 ∩ 可用风格池
Step 2: 排除「现在就拍」已选
Step 3: 按社交验证数量降序（小红书笔记数/Instagram 帖子数）
Step 4: TOP 1
Step 5: 无交集 → 走通用规则
```

**无 0E 数据时**（通用规则）：
```
Step 1: 可用风格池中，排除「现在就拍」已选

Step 2: 按"视觉辨识度"排序
        高辨识度：电影感 / 纪实粗粝 / 杂志时尚 / Grunge / 梦幻柔美 / Lofi直闪
        中辨识度：日系清新 / 胶片复古 / 微观微距 / 县城记忆 / 森系 / 便利店美学
        低辨识度：安静真实 / 极简高级
        → 优先选高辨识度

Step 3: 可执行性允许 🟡（微调可接受）

Step 4: TOP 1
```

### 路由规则——什么风格进入🔥最出片

> ⚠️ **v2.3 术语修正**：以下不是"排除"——是路由条件。不进入🔥的风格仍在🟢或✨的候选池中。

以下风格**路由到其他方向**（不进入🔥）：
- 与🟢现在就拍重复的风格（两个方向必须有审美差异）→ 留在🟢
- 可执行性 🔴 且无可行的🟡替代方案 → 去✨（脑洞大开不限条件）
- 无 0E 数据时、低辨识度风格 → 去🟢（更符合"现在就拍"的低门槛定位）

### 卡片文案风格

「最出片」的文案强调：**辨识度、社交验证、出彩**
- "小红书 89 篇笔记验证——这个机位就是出片的"
- "稍微退后两步，把河和天空收进来——画面立刻不一样"
- "这个风格辨识度最高——拍完就想发"

## 五、✨ 脑洞大开 — 选择逻辑 🆕

### 目标

**AI 自由发挥，给用户摄影的"可能性"——不限于设备、不限于光线、不限于可行性。** 

这不是给用户"现在就能执行的方案"，是给用户"摄影可以有多酷"的灵感。用户看了会兴奋，即使今天拍不了，下次有条件的时候会回来。

### 核心原则

```
脑洞大开 不是 "不切实际"——是 "不自我设限"。

现在就拍：在约束内找到最优解
最出片：在约束边缘找到最有辨识度的解
脑洞大开：暂时拿掉约束，找到最酷的解。然后如实告诉用户需要什么条件。

用户不傻。他们知道"这个需要长焦，你的手机做不到"的意思。
但他们会因为看到了这个方向而感到兴奋——
这证明这个 app 真的懂摄影，而不只是会推荐"安全"的方案。
```

### 筛选规则

```
Step 1: 取消设备硬约束
        → 不限制焦段（可以假设有长焦、大光圈、闪光灯）
        → 不限制光线（可以假设可以等黄金时刻、可以布光）
        → 但必须如实标注"实现这个方向需要什么条件"

Step 2: 保留光线物理约束
        → 顺光仍然不能拍逆光通透（这是物理，不是设备）
        → 但可以建议"如果换个时间来这里，逆光下可以拍..."

Step 3: AI 自由搜索
        搜索维度放开：
        - 不限于"手机能拍的"
        - 不限于"这个光线条件下"
        - 搜索全世界最好的摄影师在这个场景会怎么拍
        - 搜索艺术摄影/时尚摄影/电影画面的参考
        
        WebSearch × 3-4：
        - "{场景描述} creative photography inspiration editorial"
        - "{场景描述} art photography experimental technique"
        - "{类似场景} famous photograph iconic image"
        - "{场景元素} cinematography visual reference"

Step 4: 从最酷的方案中选 TOP 1
        选择标准：
        - 创意冲击力：用户看到会说"哇"
        - 审美启发性：即使用户今天拍不了，这个方向也让他们学到了新的观看方式
        - 可解释性：为什么这个方向是酷的——能说清楚

Step 5: 如实标注条件
        必须告诉用户：
        - 这个方向需要什么设备/光线/时机/后期
        - 他的设备能做多少（如实）
        - 如果他用现有设备尝试，最接近的效果是什么
```

### 脑洞方向的类型

| 类型 | 描述 | 示例 |
|------|------|------|
| **大师狂想** | 如果某位大师站在这里，他会怎么拍——不受设备限制 | "如果 Gregory Crewdson 在这里——他会用电影灯从左侧打一束硬光，让你和小狗站在光里，背景是全暗的树林" |
| **媒介跨越** | 不只是拍照——把摄影和其他媒介融合 | "不只拍照片——拍一个 3 秒的 Live Photo，让她摸小狗的动作变成慢动作视频。社交媒体发 Live Photo 比发静态照片更抓人" |
| **时空假设** | 如果换个时间/季节/天气来，能拍出什么 | "如果这是蓝调时刻——河面会变成深蓝色，对岸树林变成剪影，你和小狗站在浅溪边，水面倒映着最后一抹天光" |
| **技法极限** | 用最极致的摄影技法来诠释这个场景 | "用 85mm f/1.2 光圈全开，只拍小狗的眼睛——眼睛里倒映着她的身影。景深浅到只有 2mm——她的身影是虚的，但你知道那是她" |
| **概念重构** | 不把场景当"人像写真"——重新定义这是什么 | "这不是'人像写真'——这是一个关于'陪伴'的纪实项目的第一张。拍 10 张：她的鞋子+小狗的爪子、她的手+狗绳、她的影子+小狗的影子——不拍脸，不拍全身，只拍'在一起'的证据" |
| **跨界混搭** | 把不相关的审美系统嫁接到这个场景 | "用王家卫的方式拍这条河——慢快门让河水变成雾状、色彩往绿偏移、画面里只有她低头的侧脸和小狗的背影、加一句话字幕：'她在这条河边等了很久，但等的不是人'" |

### 排除规则

「脑洞大开」几乎不排除——但有一条红线：

- **不安全的不推荐**：不推荐危险机位（爬到树上、站在河中间等）
- **不尊重的不推荐**：不推荐把被摄者拍得难看的方案（即使是"艺术"）

除此之外，尽情发挥。

### 卡片文案风格

「脑洞大开」的文案强调：**惊喜、可能性、摄影的魅力**
- "如果 Gregory Crewdson 在这里——他会打一束光，只照亮你的手和小狗"
- "不只拍照片——拍你们在一起的那个 3 秒瞬间"
- "你的 iPhone 做不到这个。但下次你带上相机来这里的时候——"
- "这张照片需要蓝调时刻。但如果你愿意等 2 小时——"

### 条件标注格式

每个脑洞方案必须附带一个条件卡片：

```
📋 实现条件
├─ 设备：全画幅相机 + 85mm f/1.2（你的 iPhone 无法实现这个虚化效果）
├─ 光线：需要蓝调时刻（日落后 15-30 分钟）
├─ 时机：冬天河面结薄冰时效果最好
├─ 后期：需要 Lightroom 做色调分离
└─ 🟡 iPhone 替代方案：用 2× 人像模式 + 尽量靠近小狗，虚化效果接近 30%
```

## 六、题材切换时的方向重计算

当用户切换题材时，三个方向用相同的逻辑重新计算：

```
新题材 → 重新查 genre-router 获取风格优先级
       → 重新与 light-router 交叉过滤
       → 重新跑「现在就拍」「最出片」「脑洞大开」筛选
       → 输出新的方向卡片

不需要重新调视觉 API——场景信息不变，变的是"什么风格优先"
```

方向选择引擎应预计算至少 2 种题材的方向（默认 + 最可能的备选），切换时秒出。

## 七、脑洞大开的"安全阀"

脑洞大开不设技术和设备限制——但有用户心理的安全阀：

### 7.1 不要打击用户

❌ "你的 iPhone 拍不了这个，别想了"
✅ "这个方向需要长焦镜头——你的 iPhone 做不到这个虚化。但你可以用 2× 人像模式靠近小狗拍，效果接近 40%。剩下的 60% 是'如果以后你有相机'的念想。"

### 7.2 每个脑洞附带一个"现在就能做的小版本"

```
脑洞方向：85mm f/1.2 只拍小狗眼睛里的倒影
🟡 现在就能做：用 2× 人像模式尽量靠近小狗的脸，拍小狗的眼睛。
               虽然虚化不够、也拍不到眼睛里的倒影——
               但小狗的眼神本身就很动人。这是一个"迷你版"。
```

### 7.3 脑洞的最终目的是让用户更欣赏「现在就拍」

```
用户看到脑洞后 → "哇这个好酷"
                → 看条件标注 → "啊我现在拍不了"
                → 看迷你版 → "但这个我可以试试！"
                → 回去用「现在就拍」的方案
                
脑洞不是为了让用户沮丧——是为了让他们在知道"最好的可能是什么"之后，
更懂得欣赏"我现在能拍到的是什么"。
```
