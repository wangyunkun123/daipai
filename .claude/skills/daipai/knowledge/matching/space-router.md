# 空间匹配路由

## 路由规则表

### 空间深度 → 构图方式 + 景别

| 空间特征 | → 构图候选 | → 景别偏好 | → 理由 |
|----------|----------|----------|--------|
| 浅空间（平面/桌面/墙面/单层） | 三分法/留白/对称/对角线 | 近景/特写/中景 | 空间浅→靠构图制造张力，不能用远景（无环境可展示） |
| 中等空间（室内/桌到窗/2-3层） | 引导线/框架/三分法/对角线 | 中景/近景/特写 | 2-3 层=引导线和框架有素材可用 |
| 深空间（街道/长廊/室外大景） | 引导线/留白/对称/框架 | 远景/中景 | 深度=引导线天然素材+留白的大面积背景 |
| 杂乱空间（多层+不成秩序） | 框架/近景特写/留白(小面积) | 近景/特写 | 杂乱→窄视角排除干扰+框架隔离杂乱背景 |

### 前景元素 → 构图机会

| 前景特征 | → 构图方式 | → 操作 |
|----------|----------|--------|
| 有线状物（电线/栏杆/桌沿/道路） | 引导线/对角线 | 让线从角落出发指向主体 |
| 有框状物（门窗/间隙/物品间空隙） | 框架 | 前景框离镜头10-15cm→虚化成色块框 |
| 有对称物（倒影/并排柱/建筑中轴） | 对称 | 站到中轴线上——相机绝对水平 |
| 有大面积平面（桌面/墙面/天空/水面） | 留白 | 确认平面干净→主体占10-30% |
| 无突出前景 | 三分法 | 默认方案——打开网格线 |

### 背景特征 → 景别+构图策略

| 背景特征 | → 策略 | → 景别 |
|----------|--------|--------|
| 干净背景（纯色墙/天空/大虚化） | 留白构图——让背景成为主体的展示台 | 远景/中景 |
| 有纹理但统一（木纹/砖墙/水面） | 主体+纹理背景=质感对比——拍中景 | 中景 |
| 杂乱背景（无法清理） | ①近景/特写（窄视角排除背景）②框架构图（前景框隔离）③俯拍/仰拍（改变背景） | 近景/特写 |
| 有叙事内容的背景（街景/室内环境） | 中景——人与环境各半的叙事 | 中景 |
| 有反光/光斑背景（水面/玻璃/灯光） | 利用光斑作"自然的留白"或用逆光弱化背景 | 中景/近景 |

### 空间层次数 → 景深策略

| 层次 | → 景深策略 | → 设备操作（手机） |
|------|----------|-----------------|
| 1 层（平面） | 全景深——平面不需要虚化 | 默认拍摄距离 |
| 2 层（前景+主体 或 主体+背景） | 中景深——两层都可见但主体更清 | 距离差：主体清晰+另一层略虚 |
| 3 层+（前景+中景+背景） | 中浅景深——主体层清晰，其他层梯度虚化 | 靠近主体+背景保持距离 |

---

## 兜底规则

空间特征不在上表中 → 默认采用"三分法+中景"安全组合 + 标记"空间复杂度超出路由覆盖"。
