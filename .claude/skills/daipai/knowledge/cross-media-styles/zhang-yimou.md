# 张艺谋 · Zhang Yimou

## 风格识别

**出圈指数**：🔥 L2 热门 | **难度**：⭐⭐ 进阶 | **媒介**：中国电影

**一句话**：「大块的纯红、金黄、翠绿——颜色不是点缀，是主角。像张艺谋电影里的色彩——人不是画面中最重要的东西，色彩才是。」

**社交媒体热度**：张艺谋的中国色彩美学已经成为中国视觉文化的国际符号。《英雄》《十面埋伏》的红/绿/白/黑四色体系影响深远。

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | **高饱和单色大色块**——红/黄/绿/白/黑 | 张艺谋的色彩是「一个场景一个颜色」 |
| 色彩数量 | ≤ 2 个主色——一个主导色（占 70%+）+ 一个对比色 | 红色场景中只有红+黑；黄色场景中只有黄+红 |
| 饱和度 | **极高**——张艺谋不克制 | 色彩是影像的第一主角 |

### 构图

| 参数 | 取值 |
|------|------|
| 构图 | 对称（仪式感）+ 居中 | |
| 焦段 | 广角（大场面）+ 长焦（人物情感） | |
| 景别 | 远景（人在色彩中）+ 近景（色彩中的人脸） |
