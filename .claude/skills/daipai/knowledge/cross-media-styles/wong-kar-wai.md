# 王家卫 · Wong Kar-wai

## 风格识别

**出圈指数**：🌊 L3 亚洲现象级 | **难度**：⭐⭐ 进阶 | **媒介**：香港电影

**一句话**：「霓虹灯在晃动、人物有残影、绿色覆盖了所有阴影——像王家卫电影里一个记不住的瞬间。」

**社交媒体热度**：《繁花》2024 年再度引爆王家卫美学——慢快门残影 + 霓虹色调成为小红书/抖音「港风」摄影的核心视觉参照。

---

## 原始媒介特征

王家卫 + 杜可风建立的视觉语言：

| 特征 | 在电影中的实现 | 审美效果 |
|------|-------------|---------|
| **绿色偏移** | 阴影/暗部统一向绿色偏移——不是白平衡失误，是情绪色彩 | 「记忆中的画面是褪绿的」——绿色 = 时间流逝 |
| **慢快门残影** | 降低快门速度（低于 24fps 等效）→ 人物的运动留下拖影 | 「这一刻还没完全发生就开始消失了」 |
| **霓虹灯光** | 香港街头的霓虹灯是主要光源——不是白光照亮人脸，是红光/蓝光/绿光照亮人脸 | 色彩不是物体的属性——是光的属性 |
| **手持晃动** | 手持摄影机的微晃动——不是稳定器，是人的手 | 「有一个人正在经历这一刻」——主观视角 |
| **镜子/反射** | 大量使用镜子/玻璃/水面反射——人物被反射、被碎片化 | 「你看到的不一定是真的——是某个角度的某个瞬间」 |

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 阴影偏移 | **阴影向绿色偏移 10-25%**——这是王家卫最重要的色彩标志 | 不是全局偏绿——是高光正常、阴影偏绿 |
| 高光 | **高光向品红/暖金偏移**——肤色/灯光的暖黄+品红 | 品红高光 × 绿色阴影 = 王家卫的色彩公式 |
| 霓虹色 | 红/蓝/绿/品红——作为光源色，不是物体色 | 让人物站在霓虹灯/彩色灯光下 |
| 饱和度 | 阴影偏绿后略降饱和——绿色不应该是鲜绿的 | 暗绿的饱和度控制在低到中 |

**王家卫色彩公式**：高光暖金+品红 / 阴影暗绿 / 中间调保留正常的肤色和材质色。不是全局滤镜——是分层的色彩偏移。

### 光线配方

| 参数 | 取值 |
|------|------|
| 光源 | **混合色光源**——霓虹灯/街灯/窗光——不同颜色的光从不同方向来 |
| 光质 | 硬软混合——霓虹灯是硬光（点光源），但环境散射柔和了它 |
| 光比 | 中高——霓虹灯照亮的地方很亮，暗处沉入绿色阴影 |
| 时段 | 夜晚或黄昏——王家卫不拍正午 |

### 构图与拍摄技法

| 参数 | 取值 |
|------|------|
| 慢快门 | **1/15-1/30s**——手持轻微晃动 + 人物微动 = 残影 |
| 晃动 | 手持——不用三脚架——轻微但可感知的晃动 |
| 焦段 | 广角（28-35mm）——靠近 + 晃动——主观视角感 |
| 镜子/反射 | **尽量找**——镜子/玻璃/水面/不锈钢——人物的碎片化反射 |
| 景别 | 近景（暧昧距离）+ 中景（街头距离） |
| 构图 | 倾斜（微倾 3-8°）——「不太对」的角度 = 情绪角度 |

### 质感

| 参数 | 方向 |
|------|------|
| 对比度 | 中高——霓虹灯亮区很亮、阴影很深（但阴影是绿的，不是黑的） |
| 颗粒 | 加 10-20%——王家卫的画面有颗粒 |
| 锐度 | 中等——慢快门本身就有柔化效果 |
| 色彩分离 | 后期：阴影向绿 15-25%、高光保留暖黄 |

## 执行边界

### ✅ 摄影可以做
- 慢快门残影（手持 1/15-1/30s）
- 阴影绿色偏移（后期）
- 霓虹灯光源（找城市夜景/霓虹灯）
- 镜子/玻璃反射
- 微倾斜构图

### ⚠️ 需要特定条件
- 必须有霓虹灯/彩色灯光源——白天拍不了王家卫
- 慢快门 + 手持 = 成功率低——需要多拍

### ❌ 摄影做不了
- 电影的连续运动——慢快门残影在电影中是连贯的运动，静帧只能得到一个瞬间的快照
- 杜可风的「光绘」——电影中光在移动、人物在移动、摄影机在移动——三重运动的叠加

## 与摄影风格的交叉

| 摄影风格 | 重叠 | 差异 |
|---------|------|------|
| 电影感 | 宽幅+冷暖对比+颗粒 | 电影感偏「好莱坞」（Teal & Orange）；王家卫偏「香港」（Green & Neon） |
| 纪实粗粝 | 晃动+颗粒+街头 | 纪实偏黑白/低饱和；王家卫偏彩色霓虹 |
| 赛博朋克 | 霓虹+夜景 | 赛博朋克偏紫/蓝冷调；王家卫偏绿/暖黄 |

## 常见错误

| 错误 | 为什么不像王家卫 | 修正 |
|------|----------------|------|
| 全局偏绿 | 皮肤也绿了 = 白平衡失误 ≠ 王家卫 | 只给阴影加绿——高光/肤色保留正常 |
| 快门太高速 | 没有残影 = 所有瞬间都被冻结 = 太「确定」 | 降到 1/15-1/30s |
| 用了三脚架 | 稳 = 客观 = 不是「有人在经历」 | 手持——容许微晃动 |
| 白天拍摄 | 没有霓虹灯光源 = 王家卫美学失去了物理基础 | 夜景或黄昏 |
| 绿色太鲜艳 | 鲜绿 = 荧光绿 ≠ 王家卫的暗绿 | 阴影绿要低饱和 |
