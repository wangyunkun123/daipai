# 莫兰迪色系 · Morandi Palette

## 风格识别

**出圈指数**：🔥 L2 热门 | **难度**：⭐ 入门 | **媒介**：20 世纪意大利静物画

**一句话**：「所有的颜色都像被蒙了一层灰——粉色不再是粉色，是灰粉；蓝色不再是蓝色，是灰蓝。世界像被温柔地静音了。」

**社交媒体热度**：「莫兰迪色」在中文互联网已经成为一个独立的审美词汇——低饱和灰调 + 柔和过渡 + 静物凝视。从时装到家居到摄影，莫兰迪色系无处不在。

---

## 原始媒介特征

乔治·莫兰迪（Giorgio Morandi）一生画瓶子/罐子/碗：

| 特征 | 在绘画中的实现 | 审美效果 |
|------|-------------|---------|
| **灰调覆盖一切** | 所有颜色 + 灰——没有纯色——每一个颜色都经过灰的调和 | 「世界被温柔地静音了」 |
| **日常的神圣凝视** | 画瓶子画了一辈子——日常物品被凝视成史诗 | 「一个瓶子也可以是一整个世界」 |
| **柔和边缘** | 物体的边缘是柔和的——不是锐利的切割 | 「世界没有棱角」 |

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | **灰粉/灰蓝/灰绿/灰黄/灰褐**——任何色相 + 灰 | 莫兰迪色 = 色相 + 灰色混合——降低饱和的同时保持色相可辨识 |
| 饱和度 | 全局 -30% ~ -50% | 所有颜色的饱和都被压低了——但没有一种颜色完全消色 |
| 色温 | 中性——不刻意偏暖也不偏冷 | 莫兰迪的灰是「中性的灰」 |
| 明度 | 中——不过亮也不过暗 | 莫兰迪的瓶子放在中灰的桌面上、中灰的背景前 |
| 色彩数量 | 3-5 个色相——每个都是灰调的 | |

### 光线配方

| 参数 | 取值 |
|------|------|
| 光质 | **极致软光**——散射光、阴天、窗边柔光 |
| 光比 | 极低（1:1.5 ~ 1:2）——没有明显的阴影 |
| 光源 | 单一柔光——方向感弱 |

### 构图配方

| 参数 | 取值 |
|------|------|
| 构图 | 居中——静物在画面中央 | 莫兰迪的瓶子总是放在画面中央 |
| 留白 | 背景干净——纯色或近纯色的墙面/桌面 |
| 焦段 | 标准-中焦（50mm）——自然的静物距离 |
| 景别 | 中景/特写——物体在画面中占 30-60% |

### 质感

| 参数 | 方向 |
|------|------|
| 对比度 | 极低——柔和高光过渡，暗部不黑 |
| 饱和度 | 全局 -30% ~ -50% |
| 暗部 | 偏灰——没有纯黑 |
| 锐度 | 中等——边缘不要太锐利 |

## 执行边界

### ✅ 摄影可以做
- 低饱和灰调（后期 HSL 降低各色相饱和度）
- 水彩般的柔和过渡（降低对比度+提阴影）
- 静物/人像/场景都适用

### ⚠️ 需要的是审美判断
- 莫兰迪色系的操作难度低（主要是后期），但判断难度高——降多少饱和、加多少灰——需要精确的审美直觉

### ❌ 摄影做不了
- 莫兰迪的笔触感——油画的物质肌理

## 与摄影风格的交叉

| 摄影风格 | 重叠 | 差异 |
|---------|------|------|
| 极简高级 | 干净 + 单色/少色 | 极简偏白+高亮+1-2色；莫兰迪偏灰+中调+3-5个灰彩色 |
| 日系清新 | 柔和+低对比 | 日系偏蓝/绿+明亮；莫兰迪偏灰+中调 |

---

## 常见错误

| 错误 | 为什么不像莫兰迪 | 修正 |
|------|----------------|------|
| 饱和度降到零 | 变成黑白——莫兰迪有颜色，只是加了灰 | 每个色相单独降饱和 20-40%——保留色相辨识度 |
| 对比太高 | 亮暗分明 = 不是莫兰迪 | 降对比 + 提阴影 |
| 色彩太鲜艳 | 某个颜色跳出来 = 灰调被打破 | 检查所有色相——确保没有高饱和色 |
