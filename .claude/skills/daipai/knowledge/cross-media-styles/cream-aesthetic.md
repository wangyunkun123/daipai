# 奶油风

## 媒介源头

**社交媒体原生趋势。** 从家居设计领域溢出到摄影——米白/浅棕/奶咖统一色调+柔光+无硬阴影的"温柔到化开"的视觉系统。

## 一句话识别

画面里所有颜色都像被加了一勺牛奶——米白、奶咖、浅杏、燕麦，光线柔和到几乎没有阴影。

## 色彩

| 参数 | 取值 |
|------|------|
| 主色调 | 米白、奶咖、浅杏、燕麦色、奶油黄 |
| 饱和度 | 极低——莫兰迪的近亲但更暖更亮 |
| 色温 | 偏暖——暖黄色调是灵魂 |
| 关键规则 | **整个画面统一在一个暖色系里**——不能出现冷色或高饱和色破坏温柔感 |

## 光线

- **柔光是必须**——纱帘柔化的窗边光、阴天散射光
- 绝对不能有硬阴影！奶油风的"温柔感"来自全画面的柔和过渡
- iPhone鲜明度+83是奶油风调色的标志性操作

## 构图

- 中景为主——咖啡桌边/沙发/窗边
- 留白20-30%——奶白色墙面/桌面就是最好的留白载体
- 前景虚化（咖啡杯/花）增加层次

## 穿搭与场景

- 米白/浅杏/燕麦色系——针织/棉麻材质
- 纯白色在强光下容易过曝发灰→选米白/本白/奶白色
- 场景：暖色调咖啡厅/简约室内/窗边——背景不能杂乱

## 后期核心

- 鲜明度+80以上（iPhone）或对比度-8、高光-44（Lightroom）
- HSL橙色明亮度拉高——让肤色和暖色"发光"
- 色温+10~+15——暖色调是灵魂
