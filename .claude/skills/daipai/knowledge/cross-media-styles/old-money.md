# 老钱风 / 静奢风

## 媒介源头

**社交媒体原生趋势 + Slim Aarons 摄影传统。** 2023-24 年 TikTok/小红书现象级趋势——"低调地贵"：不堆 logo、不撞色、不炫耀，用大地色系和天然材质传达"我不用证明什么"的从容。

## 一句话识别

画面里的一切都很"贵"但没有一样东西在喊"我很贵"——中性大地色调、天然材质纹理、人物姿态松弛从容。

## 色彩

| 参数 | 取值 |
|------|------|
| 主色调 | 巧克力棕、驼色、象牙白、海军蓝、奶油色、卡其 |
| 饱和度 | 低——所有颜色都像被时间沉淀过 |
| 色温 | 中性偏暖——"壁炉旁的温暖"不是"阳光下的热烈" |
| 关键规则 | **同色系叠穿**——用同一色系内的明度/饱和度变化来制造层次，不做撞色 |

## 光线

- **自然柔光**——黄金时刻或纱帘柔化的窗边光
- 避免硬光和闪光灯——老钱风的"贵"来自光影的细腻过渡
- 室内：下午 2-4 点窗边自然光最佳

## 构图

- 负空间是刻意的视觉工具——人物偏一侧或下方，大面积留给环境
- 广一点——让人看到建筑/花园/书房这些"语境"
- 前景层次：门框/植物/家具做前景，增加空间深度

## 穿搭与场景

- 羊绒/真丝/亚麻/粗花呢——天然材质
- 无 logo、无鲜艳图案、无荧光色
- 场景：历史建筑/庄园/图书馆/马场/湖边/老牌酒店——"old money 不是买来的，是继承的"

## 代表

- **Slim Aarons**：定义了"有钱人在好看的地方做好看的事"的摄影美学
- **Tina Barney**：大画幅拍摄美国东海岸精英家庭的亲密日常
