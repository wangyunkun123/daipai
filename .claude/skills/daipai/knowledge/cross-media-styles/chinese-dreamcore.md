# 中式梦核 · Chinese Dreamcore

## 风格识别

**出圈指数**：🌊 L3 全球现象级（中国版） | **难度**：⭐⭐ 进阶 | **媒介**：互联网原生美学

**一句话**：「像你小时候做的一个梦——熟悉的场景，但有些不正常的细节。2003 年的客厅、老式电视机、窗外的蓝绿色光——你感觉快要醒了，但又没有。」

**社交媒体热度**：抖音「中式梦核」话题 17.8 亿播放。这是 Liminal Space 的中国本土化——不是空荡的美国走廊，是中国人的集体童年记忆空间。

---

## 原始媒介特征

中式梦核是互联网原生美学（类似蒸汽波、Liminal Space），由 AI 图像生成 + 3D 渲染 + 实拍三类内容共同构成。核心特征是：

- **熟悉的陌生感**：场景是你认识的（中国 90-00 年代的家庭空间），但有些东西不对劲
- **低质量的介质感**：像 VCD 画质、像 CRT 电视截帧、像旧 DV 带
- **空无一人但刚有人离开**：画面中没有人物，但桌子上有没喝完的水、椅子上搭着衣服
- **不自然的光源**：窗外是不正常的蓝绿色光、电视机的雪花屏是唯一光源

## 视觉翻译：摄影怎么拍

### 核心参数

| 参数 | 取值 |
|------|------|
| 场景 | 90-00 年代中国家庭空间——老式客厅（带防尘罩的沙发）、老式卧室（蚊帐/花床单）、旧楼道、录像厅、老学校 |
| 空间 | 空无一人但有人迹——桌上半杯水、椅子上搭的衣服、开着的电视（雪花屏或旧广告） |
| 色彩 | **褪色感**——饱和度降低 + 暖灰偏移 + 轻微黄绿偏色 |
| 光质 | **混合诡异光源**——窗外蓝绿光 + 电视/屏幕发出的冷光 + 老式白炽灯的暖黄光 |
| 光比 | 中低——灰调为主，没有纯黑也没有纯白 |
| 镜头焦段 | 广角（28mm）——略微夸张空间但不过度 |
| 构图 | 单点透视、走廊纵深、门框嵌套——像 Liminal Space 但场景是中国人的记忆空间 |

### 关键视觉元素

| 元素 | 说明 |
|------|------|
| **老式电视机/CRT 显示器** | 开机但无信号（雪花屏）、或播放模糊的老广告——屏幕是唯一的光源或主光源之一 |
| **防尘罩/老家具** | 老式皮沙发 + 白纱防尘罩、木制电视柜、摇头电风扇 |
| **花床单/蚊帐** | 80-90 年代中国家庭的标志性纺织品 |
| **旧楼道/走廊** | 绿墙裙 + 白墙、水泥地、声控灯、铁栅栏防盗门 |
| **窗外蓝绿光** | 窗外的光是不自然的蓝绿色——像深海、像另一个世界的光渗透进来 |
| **VCD/DVD 播放器** | 屏幕显示「读碟中」或蓝屏 |

## 执行边界

### ✅ 摄影可以做
- 实拍 90-00 年代风格空间——老街、旧居民楼、没有被翻修的老房子
- 后期处理模拟 VCD 画质——降低分辨率感、加轻微色散
- 空无一人的场景氛围

### ⚠️ 需要特定条件
- 真正的旧空间越来越少——新建空间缺少「时代感」
- 窗外不自然的蓝绿光需要物理滤色或后期合成
- CRT 电视/VCD 播放器等老物件需要实物或道具

### ❌ 摄影做不了
- 画面中「不正常的超现实细节」（如地面翻涌、空间扭曲）——这是 3D 渲染/AI 的领域
- 完全还原早期互联网低质量介质感——摄影的清晰度是物理限制

## 常见错误

| 错误 | 为什么不像 | 修正 |
|------|----------|------|
| 空间太新太干净 | 2026 年的客厅 = 没有怀旧触发 | 找旧空间——老街、老房子、没翻修的老小区 |
| 太亮或太暗 | 中式梦核需要灰调——不是 High Key 也不是 Low Key | 控制在中间的灰色地带 |
| 画面中有人物 | 中式梦核的核心是「空无一人但有人迹」 | 让「人不在场」但「人的痕迹在」 |
| 窗外的光太正常 | 正常的自然白光 = 没有梦核感 | 窗外加蓝绿色调——不正常的、像另一个世界的光 |

## 后期方向

| 参数 | 取值 |
|------|------|
| 对比度 | **降低**——整体发灰 |
| 黑色 | **提亮黑位**——让黑色变成深灰 |
| 白色 | **压低白位**——让白色变成浅灰 |
| 饱和度 | 降低 15-25% |
| 色调 | 暖灰偏移 + 窗外蓝绿 |
| 质感 | 加轻微模糊/柔化 + 轻微色散（模拟 VCD 画质） |
| 特殊 | 可选加轻微扫描线（CRT 效果） |
