# 空间层次

## 一句话定义

摄影是把三维空间压扁成二维平面。**空间层次的构建，就是在二维平面上重建三维的深度幻觉。** 前景把你拉进来，中景讲核心故事，背景给故事一个舞台。

---

## 原理

### 为什么照片需要深度

人眼的生理结构天然感知三维深度（双眼视差 + 晶状体调焦）。但照片是平的——所有东西在同一平面上。如果你的照片缺乏深度线索，观众虽然「看清了所有东西」，但感受不到空间——照片失去了「身临其境」的可能。

**深度线索是观众从「看到一张照片」到「感觉自己在那里」的桥梁。**

### Freeman 的三层空间模型

每一张有深度感的照片都可以拆解为三层：

```
┌──────────────────────────┐
│  背景层（Background）      │  ← 环境的舞台：天空/远景/建筑立面/海面
│  最远，交代地点和氛围      │     色彩往往偏淡/偏冷（大气透视）
├──────────────────────────┤
│  中景层（Midground）       │  ← 故事发生的地方：模特/主体
│  相机的焦点所在            │     清晰度最高，对比度最高
├──────────────────────────┤
│  前景层（Foreground）      │  ← 最近的元素：花草/栏杆/门框/人物的肩背
│  最近，制造「穿过」的入口  │     通常偏暗/偏虚，作为画面的「门」
└──────────────────────────┘
```

三层齐全 = 完整的空间深度。
缺一层 = 扁平感（不一定是坏的，看创作意图）。

---

## 三层分别怎么用

### 前景：画面的「门」

**作用**：
1. 制造「你从这里走进去」的心理入口
2. 增加从近到远的纵深梯度
3. 遮挡画面边缘的杂乱元素（前景遮丑比后期裁切更自然）
4. 提供参照物——观众通过前景的大小推断中景和背景的距离

**什么可以当前景**：
- 自然：花草、树叶、草帽边缘、栏杆、石头、水面反光
- 建筑：门框、窗户、柱子、拱门（天然框架 = 前景 + 构图双重功能）
- 人体：另一人的肩膀/后脑勺（增加叙事层次——观察者视角）
- 空白：什么都不放也可以是选择（无前景 = 直接进入，更直接）

**操作要点**：
- 前景虚化靠**物理距离差**：让前景物体极度靠近镜头（10-30cm）+ 对焦在远处。光圈大小不是关键——距离差才是
- 超广角焦段可同时保持前景和远景清晰（大景深）
- 计算虚化模式的前景处理可能不自然——注意前景和主体之间的边缘

**关键数字**：
- 前景占画面 5-15%（太多喧宾夺主，太少不够构成层次）
- 前景与镜头的距离 < 50cm（焦距越短，需要更近的前景才能产生虚化）

### 中景：故事的核心

**作用**：
1. 主体所在的位置
2. 画面的焦点
3. 最清晰、最高对比度、色彩最丰富的层

**对焦在哪**：
- 人像：对焦在最近的那只眼睛（不是鼻子、不是额头）
- 多人物：对焦在最重要的人（通常是最靠近镜头或最中心的人）
- 无人像/风景：对焦在兴趣点（画面的 1/3 深度处）

**操作要点**：
- 中景距离相机 1-5 米是大多数设备的最佳成像范围
- 标准-中焦/长焦焦段可以让中景主体更突出（窄视角排除背景干扰）
- 虚化模式通常在 1-3 米的中景距离效果最佳

### 背景：故事的舞台

**作用**：
1. 交代环境——在哪、什么氛围、什么故事
2. 提供负空间——背景中的天空/墙面/海面是留白的来源
3. 色彩和亮度的基调——背景的色调决定整张照片的色彩情绪

**背景策略**：
- 叙事型背景：保留有信息的环境元素（地标、建筑、风景）
- 减法型背景：干净的墙面/天空/海面 → 留白构图
- 压缩型背景：用长焦把背景「拉近」到与中景重叠 → 空间压缩感

**操作要点**：
- 如果设备无法靠浅景深虚化背景，靠两个补偿策略：
  - 选本身干净的背景（白墙/蓝天/大片水面/草地）
  - 让模特离背景更远（距离差越大，虚化效果越好）
- 计算虚化模式处理背景时，注意头发边缘/镂空衣物的处理（最容易出错的区域）

## 不同景别的空间层次分配

| 景别 | 前景 | 中景（主体） | 背景 |
|------|------|-----------|------|
| **远景** | 5% | 25% | 70% |
| **中景** | 10% | 60% | 30% |
| **近景** | 20% | 80% | —（几乎无背景） |
| **特写** | — | 100% | — |
| **创意** | 可变 | 可变 | 可变 |

## 线条与纹理作为空间元素

### 线条

不仅仅是引导线（那是构图的功能）。线条本身也是空间线索：

- **透视线**（道路、铁轨、海岸线从宽到窄）→ 最强的深度线索之一
- **垂直线**（柱子、树干、灯杆）→ 提供空间尺度参照（观众知道柱子的平均高度，从而推断空间大小）
- **曲线**（小路、河流蜿蜒）→ 「被遮挡的延伸」比直线更有深度感，因为拐弯暗示了「后面还有空间」

### 纹理

Barnbaum 强调纹理是「触觉的视觉等价物」。纹理的密度渐变（近处纹理清晰 → 远处纹理消失）是最自然的深度线索之一。

- 近景沙地/老墙/衣物的纹理 → 清晰
- 中景的纹理 → 减弱但可见
- 远景的纹理 → 完全消失（视觉简化）

**操作提示**：
- 近距离拍摄可以呈现丰富的纹理质感——这对川内伦子式的特写特别重要
- 确保稳定（靠在墙上/栏杆上或用三脚架），纹理的第一杀手是手抖

## 当空间扁平（没有深度线索可用时）

有些场景天然扁平：纯色墙、大雾天、平面广告牌前、极浅景深（但这在小传感器设备上很少见）。

**应对策略**：
1. **接受扁平，用它**：平面化的照片像插画/海报，有设计感和当代感
2. **用色彩层次替代空间层次**：前景高饱和 → 中景中饱和 → 背景低饱和，用色彩梯度替代空间梯度
3. **用光影制造假深度**：让侧光在平坦表面上产生阴影过渡（亮→暗的渐变 = 模拟深度）
