# 天气与大气条件

## 一句话定义

**没有坏天气，只有不匹配的创作策略。** 雾天是天然的层次感，雨后是天然的反光板，大风天是天然的动态元素。Ansel Adams 的核心理念——天气不是摄影的敌人，是合作者。

---

## 原理

### Adams 的「可视化」理念

Adams 强调：在按下快门前，先「可视化」最终的照片。天气条件改变了什么？不是改变了「能不能拍」，而是改变了「能拍出什么风格」。

**同样的场景，晴天和阴天是完全不同的两张照片。** 这不是妥协——这是创作选择。

### 天气改变光的三个属性

| 天气 | 光的方向 | 光的质量 | 光的色温 |
|------|---------|---------|---------|
| 晴天（正午） | 顶光/侧光 | 硬光 | ~5500K 中性 |
| 晴天（黄金时刻） | 低角度侧/逆光 | 软→中 | 暖 3000-4000K |
| 薄云 | 全方位散射 | 中软 | ~5500K |
| 阴天/厚云 | 完全散射→无方向 | 极软 | 冷 6500-8000K |
| 雨天 | 散射为主 | 软 | 冷 6500-7500K |
| 雾天 | 无方向+衰减 | 极软+低对比 | 中性-冷 |
| 大风天 | 不变（晴则硬，阴则软） | 不变 | 不变 |
| 雪天 | 全方位（地面反射） | 软（散射）+ 高对比（白雪） | 冷 6000-7500K |

## 各天气条件的创作策略

### 阴天

**物理事实**：云层 = 天然的巨大柔光箱。光从四面八方来，几乎没有阴影。

**这是问题也是机会**：
- ❌ 丢失：立体感（无阴影）、戏剧性（低对比）
- ✅ 获得：最柔和的人像光线（表情柔和、皮肤质感好）、最准确的色彩（无强烈色温偏差）、背景细节完整

**创作策略**：
1. **阴天是柔美人像的最佳光线**——滨田英明风格的理想条件。光均匀包裹人脸，没有眼窝黑洞和鼻子阴影
2. **构图必须增加张力**——因为光线「太平」，画面不能靠光影制造立体感，必须靠构图（引导线/框架/前景层次）来创造深度
3. **色彩饱和度在阴天天然偏低**——利用这个：走低饱和 + 克制的高级感路线，或者后期适度提饱和
4. **背景细节保留是优势**——晴天背景可能因为光比太大而失去细节，阴天背景和主体亮度接近，环境信息完整

**不适合**：需要戏剧性光影的风格（何藩、森山大道）。需要温暖氛围的照片（阴天色温冷）。

### 雨天

**物理事实**：不仅是「湿了」——雨改变了整个环境的视觉属性。

**创作机会**：
1. **湿地面 = 天然反光板 + 倒影屏幕**：雨后地面变成一面巨大的镜子。城市灯光、霓虹招牌、人像——全有倒影。这是雨天最大的视觉资产
2. **雨本身的纹理**：雨丝在逆光或侧光下是半透明的线条。暗背景 + 逆光 + 雨 = 雨丝的视觉化
3. **透明表面上的水滴**：玻璃/车窗上的雨滴 = 天然柔焦滤镜 + 框架。对焦在玻璃后的模特，雨滴形成前景纹理
4. **色彩饱和度提升**：湿润表面的颜色比干燥时更饱和（绿叶更绿、砖墙更深）
5. **人群减少**：户外景点人少 = 背景更干净

**设备注意**：
- 确认设备的防水能力——防水 ≠ 可水下使用
- 湿屏幕会干扰触摸操作——使用物理快门按钮代替
- 镜头上的水滴 = 柔焦——擦干再拍（或故意不擦作为风格）

### 雾天

**物理事实**：雾是空气中的微小水滴——它散射光 + 衰减远处物体的对比度。

**创作机会**：
1. **天然的层次感**：近景清晰 → 中景半透明 → 远景消失。这是任何后期都无法模拟的最自然的大气透视
2. **留白构图的极致条件**：远景消失在雾中 = 天然干净背景。不需要找白墙/蓝天——雾就是最干净的背景
3. **简约与孤寂感**：雾减弱了所有杂乱的背景细节。一棵树在雾中 > 一片森林在雾中
4. **逆光雾 = 体积光**：阳光穿过雾会产生可见的光柱/体积光——这是最梦幻的自然光效之一

**构图提示**：
- 引导线在雾中最有效——因为线的终点消失在雾中（未知的吸引力）
- 对称在雾中失去效果——对称需要两个清晰的半边，雾削弱了远侧
- 留白在雾中天然成立——不需要找背景，雾就是背景
- 框架在雾中效果减弱——远处的框架被雾模糊

**设备注意**：
- 雾降低对比度——自动增强对比度的算法可能「对抗」雾的效果，让画面看起来比实际更清晰。拍摄时降低对比度/饱和度保护雾的柔和氛围
- 雾天水汽可能在镜头上凝结——检查镜头是否干净

### 大风天

**物理事实**：风本身不可见，但风的「痕迹」到处都是。

**风的痕迹**：
- 头发飘起 → 动态、自由、生命力
- 裙摆/衣服飘动 → 增加画面的动感和张力
- 水面波纹 → 打破镜面，产生纹理
- 树枝/草摇曳 → 自然的动态元素
- 云快速移动 → 天空有流动感

**创作策略**：
1. **风是免费的动态助手**——不需要让模特走或转，风已经创造了动态
2. **风向 = 构图方向**：让模特面向风来的方向 → 头发向后飘 → 脸完全露出来
3. **逆风 + 逆光**：头发被吹起 + 逆光透过发丝 = 发丝发光的双重效果
4. **风的「静」对比**：模特保持静止（表情/眼神稳定）+ 头发和衣服被风吹动 = 内在的安静 vs 外在的动态

**不适合**：需要精确构图和静态对称的方案。需要模特头发整洁的方案（风不在乎发型）。

**设备注意**：
- 连拍模式是风天必备——头发每一帧位置不同，在连拍中选最美的一帧
- 轻型设备风吹时可能握不稳→稳定支撑（靠在固定物/用身体挡风）

### 雪天

**创作机会**：
1. **地面白雪 = 天然反光板**：雪反射 + 散射阳光，从下方给人物补光（极其柔和的底光——这是别的天气条件给不了的）
2. **高对比黑白的机会**：白雪 + 深色服装/建筑/树枝 = 天然的高反差黑白构图
3. **飘雪 = 动态纹理**：暗背景 + 逆光/侧光 + 慢一点快门 = 雪花形成白色轨迹
4. **极简构图**：大雪覆盖地面 → 所有杂乱消失 → 极致的留白环境

**设备注意**：
- 雪的场景整体亮度极高 → 自动曝光会偏暗（自动测光看到大面积白色会以为是「太亮了」→降低曝光）
- **关键操作**：拍雪景时手动上调曝光补偿（+0.3EV 到 +1.0EV），否则雪会是灰色的而不是白的
- 电池在低温下快速衰减——拍完把设备放回温暖处

## 天气决策树

```
今天的天气是？
│
├─ 晴天
│   ├─ 正午（顶光硬光）→ 参考 light/_index.md 顶光策略
│   ├─ 黄金时刻（日落前后 1h）→ 这是最佳光线，优先级最高的方案先拍
│   └─ 蓝调时刻（日落后 15-30min）→ 城市灯光 + 冷调天空 = 冷暖对比
│
├─ 薄云（太阳可见但边缘柔和）
│   └─ 近乎完美的全天候光线——柔和中仍有方向性
│       适合：所有景别和构图。尤其适合：柔美人像 + 色彩表现
│
├─ 阴天/厚云
│   └─ 软光 + 冷调
│       适合：柔美肖像、色彩准确的记录、滨田英明风格
│       不适合：戏剧性光影、逆光剪影、需要立体感的方案
│       补偿：构图必须更积极（引导线/框架/前景层次）
│
├─ 雨天
│   └─ 软光 + 湿地面反光
│       适合：倒影构图、雨丝纹理、玻璃/车窗框架、低饱和文艺
│       不适合：需要模特精致造型的方案
│       设备：防水 + 物理快门代替触摸 + 擦镜头
│
├─ 雾天
│   └─ 极软光 + 天然层次
│       适合：留白构图、引导线（终点消失在雾中）、极简
│       不适合：对称构图、需要展示远景的方案
│       设备：降低对比度保护雾的柔和感
│
├─ 大风天
│   └─ 光不变，动态元素增强
│       适合：动态抓拍、头发飘动、裙摆飞舞、水波纹理
│       不适合：静态对称、需要稳定构图的方案
│       设备：连拍模式必备
│
└─ 雪天
    └─ 软散射光 + 地面反光
        适合：极简留白、高对比黑白、飘雪纹理
        设备：上调曝光补偿 +0.3 到 +1.0EV
```

## 天气不是「能不能拍」的问题

是「能拍出什么不同风格」的问题。9 套方案中，至少有 1-2 套应该**主动利用当前的天气条件**，而不是在所有方案中把天气当作需要补偿的限制。

**例**：
- 阴天 → 至少 1 套方案走低饱和、柔和的滨田英明路线（而不是所有方案都在努力「补偿」阴天的平淡）
- 雨天 → 至少 1 套方案故意拍地面倒影（而不是只在方案中提醒「别让镜头沾水」）
- 大风天 → 至少 1 套方案用连拍抓头发飘起的瞬间（而不是所有方案都在寻找避风角度）
