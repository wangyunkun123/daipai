# 日系清新

## 风格定义

**日系清新 = 低饱和 + 软光 + 高明度 + 大量留白 + 自然瞬间。** 这是中文摄影社区需求最高的风格——「像滨田英明拍的那样」「像川内伦子看到的世界」。情绪基调：治愈、温柔、日常的诗意。

**一句话识别**：画面看起来像被阳光漂白过——颜色都在但都不浓烈，亮部偏蓝，暗部不黑。

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 蓝、绿、白、浅粉 | 以冷调浅色为色彩底座 |
| 饱和度 | 整体 -20% ~ -40% | 不做完全消色，保留色彩但降低浓度 |
| 色温 | 偏冷（高光加蓝 5-15%） | 日系的核心是「冷中带暖」——高光偏蓝，阴影保留暖色 |
| 明度 | 偏高（整体 +10% ~ +20%） | 画面整体明亮，暗部不黑 |
| 关键色彩规则 | 一个画面不超过 3 个色相 | 色彩克制是日系「干净感」的来源 |
| 肤色处理 | 保留肌理、不磨皮、不偏橙 | 自然肤色 > 完美肤色 |

---

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **软光优先** | 窗边光、开阔阴影、阴天散射光、黄金时刻 |
| 光比 | 1:2 ~ 1:3（低光比） | 亮暗面过渡柔和，暗部保留充分细节 |
| 时段 | 黄金时刻（最佳）、阴天全天 | 正午硬光不适合——如需拍摄，找开阔阴影 |
| 曝光策略 | 亮调（High Key）为主 | 以人脸为准 +0.3 ~ +0.7 EV，让画面偏亮 |
| 逆光 | 日系逆光 = 发丝光 + 柔焦感 | 不完全过曝背景，保留天空的淡蓝色 |
| 光线氛围 | 空气感——微尘/水汽在逆光中的可见微粒 | 这是日系「仙气」的视觉来源 |

---

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 留白、三分法、引导线 | 框架构图太「重」，不适合日系的轻盈感 |
| 留白程度 | **留白占画面 30-50%** | 天空、白墙、素色地面都是日系留白载体 |
| 画面密度 | 低——画面元素不超过 3 个视觉重点 | 「少就是干净」 |
| 焦段倾向 | 广角（35mm）为主 | 自然透视，不做刻意压缩 |
| 景别倾向 | 中景 ≈ 近景 > 远景 > 特写 | 中景是日系的「对话距离」 |
| 水平线 | 保持水平——日系不歪斜 | 歪斜会破坏日系的宁静感 |

---

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 降低 10-20%——高光不炸、暗部不死 |
| 高光 | 加蓝/青 5-15% |
| 阴影 | 提亮 10-20%，保留暖色基底 |
| 颗粒 | 不加或极少量 |
| 锐化 | 柔和——不追求锐利边缘 |
| 肤色 | 保留纹理，不磨皮 |

---

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 安静的愉悦——不是大笑，是嘴角微扬的微笑 |
| 眼神 | 看画面外的远方（「她在想什么」）> 看镜头 |
| 姿势 | 自然的、不经意的——撩头发、低头、走路、看远处 |
| 身体语言 | 松弛——不要挺胸收腹的摆拍感 |
| 互动 | 与环境互动（摸树叶、碰水面、倚栏杆）> 与镜头互动 |

**核心原则**：日系模特的最高境界是「忘记摄影师的存在」。

---

## 技术层联动

| 技术维度 | 日系倾向 |
|---------|---------|
| 焦段 | 广角（35mm 等效）——自然透视不做压缩 |
| 景别 | 中景为主（对话距离），近景为辅（情绪） |
| 光线 | 软光 + 低光比 + 亮调曝光 |
| 色彩 | 低饱和 + 冷色偏移 + ≤3 色相 |
| 空间 | 2-3 层，但背景干净不杂乱 |
| 姿势 | 自然瞬间 > 摆拍造型 |

## 常见错误

| 错误 | 为什么不像日系 | 修正 |
|------|-------------|------|
| 饱和度降太低 | 变成消色/黑白——日系是有颜色的，只是不浓 | 饱和度 -20% 即可，不要 -60% |
| 对比度太高 | 亮暗面割裂——日系需要柔和的过渡 | 降低对比度 + 提阴影 |
| 画面元素太多 | 杂乱——日系的核心是「干净」 | 做减法：排除无关元素 |
| 模特笑得太用力 | 糖水片感——日系的情绪是安静的 | 嘴角微扬 + 不看镜头 |
| 硬光拍摄 | 强阴影破坏日系的柔和感 | 改到软光条件或找阴影 |
| 暖色过头 | 变成「黄昏温暖风」而非日系 | 高光加蓝、控制暖色范围 |
| 使用长焦压缩 | 透视不自然——日系需要「我在场」的临场感 | 退回广角 |

## 大师参照

- **滨田英明**：日系清新的标杆——低饱和蓝绿调 + 家庭日常 + 明亮柔光
- **川内伦子**：日系诗意——日常细节 + 柔和闪光 + 低对比 + 6×6 方构图
- **小林纪晴**：日系旅行——广角 + 自然光 + 蓝调高光

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **日系暖调** | 色温偏暖（保留黄昏暖色），更接近「治愈温暖风」 |
| **日系冷调** | 色温更冷（高光加蓝 20%），更接近「清冷高级感」 |
| **日系胶片** | 加微量颗粒 + 褪色曲线，在日系基础上叠胶片质感 |
| **日系闪光** | 使用机顶直闪（川内伦子式），增加轻微过曝感和抓拍感 |
