# 新中式

## 风格定义

**新中式 = 低饱和青灰调 + 大量留白 + 传统元素×现代极简 + 松弛人物姿态。** 不是复刻古风——是把东方美学的"骨"（留白/对称/克制）放进现代的"气"（松弛/自然/不刻板）里。情绪基调：静、雅、简——「既有东方的骨，又有鲜活的气」。

**一句话识别**：画面里的人穿着素色改良旗袍或棉麻，站在白墙黛瓦或竹林间——留白占了画面1/3到1/2，色调偏青灰淡雅，人物姿态是松弛的而非"摆好等你拍"的。

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 米白、烟灰、豆绿、雾蓝、茶棕、藏青、藕粉 | 低饱和东方色系——所有颜色都像被水洗过一遍 |
| 饱和度 | 整体低饱和——"墨分五色"的克制 | 新中式拒绝浓墨重彩——那不是东方，是东方主义 |
| 色温 | 偏冷（青灰调）或中性偏暖（视场景），但不过暖 | 清冷感是新中式的默认情绪——"疏离但不冷漠" |
| 明度 | 中低调——暗部保留细节但不死黑 | 白墙的高光保留，但不过曝——白也有层次 |
| 关键色彩规则 | **低饱和+青灰偏移+不超过4个色相**。拒绝高饱和红/金/黄——那是"古风"不是"新中式" | 新中式的"新"就新在色彩克制——不要大红大绿 |
| 肤色处理 | 自然通透——不追求"白到发光"，追求"素颜般的干净" | 哑光底妆+淡眉+裸唇色 |

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **柔和漫射光或侧逆光**——避开正午顶光和直射强光 | 阴天拍清冷感最佳；雨天带水珠更有氛围 |
| 光方向 | 侧逆光（发丝光+轮廓感）、窗边柔光（纱帘后）、林间漫射光 | 光线从侧面或背后来——正面平光太"直白"，缺东方韵味 |
| 光比 | 中低光比——柔和的明暗过渡 | 东方美学不追求戏剧性的强明暗对比 |
| 时段 | 清晨 6:30-8:00、傍晚 16:30-18:00（蓝调时刻加分） | 蓝调时刻的白墙+暖灯=新中式最佳光线组合 |
| 曝光策略 | 中调——保护白墙高光不过曝，暗部保留细节 | 点测光对准人物面部或花瓣 |
| 特殊光线条件 | **窗边自然光+纱帘**——东方美学的"帘幕美学" | 纱帘=柔光+层次+东方感——新中式室内场景的灵魂 |

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | **留白构图**（人物占画面1/3或1/2）> 框架取景（门框/窗框/廊柱）> 对称构图 > 引导线构图 | "画面的空是为了衬托主体的灵"——留白是新中式的构图核心 |
| 留白程度 | **高留白（30-50%）**——白墙/天空/水面/空地做留白载体 | 这是新中式和其他风格最大的构图区别 |
| 画面密度 | 低——画面元素通常 ≤ 3 个视觉重点 | "少即是多"的东方极简 |
| 焦段倾向 | 标准（35-50mm）——自然透视；中焦（85mm）用于人像特写 | 广角会让留白区域变形，不推荐 |
| 景别倾向 | 中景（人在景中）≈ 远景（人小景大）> 近景 > 特写 | "人于景中，留白几许"——人物是景的一部分，不是景的全部 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | -10~-20——柔和过渡，像水墨画的氤氲感 |
| 高光 | -20~-42——保护白墙和天空的细节 |
| 阴影 | +15~+84——提亮暗部，让画面通透不沉闷 |
| 白色色阶 | -48——控制白色区域层次 |
| 黑色色阶 | -10——暗部保留灰度，不死黑 |
| 色温 | 偏冷（青灰调）——白平衡加蓝偏移 |
| 绿色 | 色相-26（偏青）、饱和度-59、明亮度+71——统一为暗调青灰 |
| 黄色 | 色相-21、饱和度-41——暖调不刺眼 |
| 蓝色 | 色相-14~-23——清冷感来源 |
| 颗粒 | 轻微（可选）——增加复古质感 |
| 去朦胧 | +10——增加画面层次感 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 静、柔、松——不是"我在被拍"，是"我刚好在这里呼吸"。有一点放空的沉静感 |
| 眼神 | 看镜头外 30° 带放空感 > 低头凝视道具 > 看远方 >>> 直视镜头 |
| 姿势 | 撑伞半遮脸、轻扶栏杆撩发、侧身45°低头垂眼、慢步走抓拍、手捧茶杯闭眼——核心：慢、静、柔 |
| 身体语言 | 求"曲"不求"直"——手肘微屈、膝盖轻并、重心稍偏一侧，如水墨线条有柔劲 |
| 互动 | 与道具互动（油纸伞/团扇/茶杯/书卷）> 与景互动（倚廊柱/过月门/触白墙）> 与镜头互动 |

**穿搭核心**：棉麻连衣裙/素色改良旗袍/低饱和纯色系（米白/烟灰/茶棕/墨绿/藏青）。拒绝花哨图案和艳色。配饰：油纸伞/团扇/折扇/木质发簪/珍珠细项链/素色丝巾。

## 常见错误

| 错误 | 为什么不像新中式 | 修正 |
|------|-----------------|------|
| 穿大红大金/龙凤刺绣 | 那是"古风写真"不是"新中式"——新中式的"新"在于色彩克制 | 棉麻/素色/低饱和——留白从穿搭开始 |
| 画面塞太满 | 没有留白=没有东方韵味——"塞满"是西方构图习惯 | 人物占画面 1/3~1/2，其余留给空景 |
| 正午顶光拍摄 | 硬光破坏东方美学的柔和氤氲感 | 清晨/傍晚/阴天拍摄 |
| 模特挺胸收腹摆拍 | 太硬——东方美学求"曲"不求"直" | 引导放松、自然、有"无意识感" |
| 背景出现现代杂物 | 电线杆/空调外机/垃圾桶——东方意境瞬间破功 | 提前清理或换角度 |
| 色彩太鲜艳 | 高饱和+强对比——像旅游纪念照不是新中式 | 后期降饱和+青灰偏移 |
