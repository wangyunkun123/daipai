# 杂志时尚

## 风格定义

**杂志时尚 = 高对比 + 精致控光 + 刻意摆姿 + 色彩大胆 + 完美执行。** 画面有明确的「被拍摄」意识——不是记录，是创作。每一寸画面都经过设计和控制。

**一句话识别**：这张照片看起来应该出现在时尚杂志的内页，而不是朋友圈。

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩策略 | **大胆**——撞色/单色调/高饱和都可以 | 杂志色彩不胆小 |
| 撞色方案 | 互补色高饱和碰撞（红+绿/蓝+橙/黄+紫） | 对比度不仅在明暗，也在色相 |
| 单色方案 | 同一色相 + 不同明度/饱和度构建层次 | 全蓝/全红/全粉——杂志封面的最爱 |
| 饱和度 | 中高——颜色要有「存在感」 | 低饱和是日系和极简的事 |
| 肤色 | 完美——允许磨皮、允许精修 | 杂志人像不追求「真实」，追求「理想」 |
| 色彩统一 | 主体服装色彩 + 背景色彩需要设计匹配 | 不是后期调色，是前期选择 |

---

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **硬光为主，精准控光** | 杂志用光是「设计过的硬」——加了柔光箱/蜂巢/挡板的硬光 |
| 光比 | 中高（1:4 ~ 1:8） | 强立体感——杂志人像的骨骼结构靠光比塑造 |
| 布光 | 至少 2 灯——主光 + 轮廓光/填充光 | 自然光不够精准——杂志需要控光 |
| 光线方向 | 侧光/侧逆光——最强的面部塑形方向 | 顺光太平、顶光太丑 |
| 时段 | 不依赖自然光——人工控光为主 | 户外可用黄金时刻但需要补光/控光 |
| 曝光策略 | 精准曝光——高光不过、暗部不黑 | 杂志需要印刷——曝光不准 = 印刷翻车 |

---

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 对称、框架、对角线、三分法 | 构图服务于「视觉冲击力」 |
| 留白 | 根据版式需求——可满可空 | 杂志留白是为了放字——但摄影阶段不考虑字 |
| 焦段倾向 | 标准-中焦（50-85mm）+ 长焦（>100mm） | 标准人像焦段 + 空间压缩 |
| 景别倾向 | 近景（情绪张力）+ 中景（造型展示）+ 创意（视觉惊喜） | 远景太少——时尚需要看到人 |
| 角度 | 微仰（力量感）+ 平视（亲密感）+ 俯视（掌控感） | 角度是态度 |

---

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 中高——清晰的光影结构 |
| 锐化 | 高——服装纹理、皮肤质感、眼神光都要锐 |
| 肤色 | 均匀化 + 保留结构——杂志皮肤是理想化但不塑料化 |
| 色彩 | 统一色彩方案 + 强化撞色对比 |
| 颗粒 | 不加或极少——杂志追求的是精致，不是粗粝 |
| 液化 | 可选——商业人像的常规流程 |
| 暗角 | 可选 5-10%——引导注意力但不风格化 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | **有态度的**——自信/冷峻/强势/挑逗/优雅——但不能是「温暖的日常」 |
| 眼神 | 直视镜头（掌控观众）+ 看画外（神秘感）——两个极端 |
| 姿势 | 大幅度、有张力的——身体线条要清晰、要伸展 |
| 肢体 | 肩膀后拉、下巴微抬、手指放松但有姿态——每个关节都有「意识」 |
| 服装 | 造型优先——服装是画面的一个重要视觉元素 |
| 互动 | 可以不与环境互动——杂志人像是「肖像」，不是「场景记录」 |

**核心原则**：杂志模特的最高境界是「我知道你在看我，而且我掌控了你的目光」。

## 常见错误

| 错误 | 为什么不像杂志 | 修正 |
|------|-------------|------|
| 光线太平 | 面部没有立体结构 → 像快照不像杂志 | 侧光 + 提高光比 |
| 姿势太日常 | 缺少视觉张力 → 像「记录」不像「创作」 | 引导模特做大幅度、有控制的姿态 |
| 色彩太保守 | 不敢用色 → 杂志需要视觉冲击力 | 大胆选择撞色或单色调方案 |
| 构图太安全 | 永远三分法 → 缺少惊喜 | 尝试对角/框架/极端角度 |
| 没有眼神光 | 眼睛是死的 → 杂志人像的眼睛必须有光 | 确保光源在模特前方/侧前方 |
| 衣服褶皱/杂乱 | 降低了精致度 | 前期整理服装或后期处理 |

## 大师参照

- **Annie Leibovitz**：叙事性时尚——不只拍衣服，拍「穿衣服的人的故事」
- **Peter Lindbergh**：真实主义时尚——保留皮肤纹理、拒绝过度修图、黑白为主
- **Tim Walker**：超现实时尚——纯色背景 + 巨型道具 + 童话色彩
- **Mario Testino**：性感时尚——暖色 + 亲密 + 身体的自信

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **极简时尚** | 纯色背景 + 单一光源 + 极简服装 |
| **街头时尚** | 户外自然光 + 城市背景 + 时尚造型——杂志感 + 纪实感混合 |
| **暗调时尚** | 暗调（Low Key）+ 单灯 + 大部分画面在黑中 |
