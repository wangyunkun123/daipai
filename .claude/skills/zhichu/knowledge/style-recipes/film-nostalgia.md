# 胶片复古

## 风格定义

**胶片复古 = 暖色偏移 + 胶片颗粒 + 褪色曲线 + 暗角 + 光晕。** 画面看起来像从旧相册里翻出来的——有温度、有年代感、有「那个回不去的美好年代」的情绪。

**一句话识别**：这张照片看起来像是用胶片机拍的，而且已经冲洗出来在相册里放了好几年。

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 暖黄、褪色绿、奶油白、焦糖棕 | 胶片色彩的特征是「暖但不艳丽」 |
| 饱和度 | 整体 -15% ~ -30%，暖色保留、冷色削减 | 绿色偏黄、蓝色偏青——冷色被「暖化」 |
| 色温 | 偏暖（整体 +200K ~ +500K） | 这是胶片复古的基调——白色不是纯白，带一点奶油黄 |
| 明度 | 中低——阴影偏灰，高光不过曝 | 胶片的暗部从来不是纯黑 |
| 关键色彩规则 | 黑不完全黑 + 白不完全白 | 黑色偏灰（褪色黑），白色偏黄（奶油白） |
| 肤色处理 | 偏暖偏焦糖——保留一定纹理 | 胶片肤色不是日系的粉白，是有温度的健康暖色 |

**胶片色彩参考**：
- 柯达 Portra 400：暖色基底 + 低对比 + 柔和肤色 → 人像胶片首选
- 柯达 Gold 200：暖黄为主 + 高饱和暖色 + 冷色褪化 → 日常记录首选
- 富士 Superia：青绿偏移 + 冷中带暖 → 日系胶片感
- 富士 Velvia：高饱和 + 冷暖强对比 → 风光胶片（不适合人像）

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **暖光优先**——日落、室内暖灯、烛光 | 冷光 + 胶片 = 不协调 |
| 光比 | 中低光比（1:2 ~ 1:4） | 胶片天然宽容度高——亮暗过渡柔和 |
| 时段 | 黄金时刻（最佳）、室内暖灯 | 正午硬光 + 胶片模拟 = 数字感暴露 |
| 曝光策略 | 中调——略微过曝 0.3EV（模拟胶片过曝宽容度） | 胶片不怕过曝、怕欠曝——数字模拟同理 |
| 光晕 | 逆光 + 镜头光晕（Lens Flare） | 老镜头的镀膜不佳 → 光晕是胶片时代的「缺陷美」 |

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 三分法、引导线、框架 | 构图方式不需要刻意复古——复古感来自色彩和质感 |
| 留白 | 适中——不过度留白 | 胶片时代的审美不是极简主义 |
| 焦段倾向 | 广角（35mm）+ 标准-中焦（50mm） | 模拟常见胶片相机的定焦焦段 |
| 景别倾向 | 中景为主 | 最通用的胶片记录距离 |
| 画面比 | 3:2（135 胶片比例）或 1:1（6×6 中画幅） | 比例本身就是时代信号 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 胶片 S 曲线——阴影提灰（不纯黑）、高光压暗（不纯白） |
| 色调曲线 | 褪色曲线——RGB 曲线底部抬起（黑变灰）+ 顶部下拉（白变奶油） |
| 颗粒 | **必须加** 8-20% 35mm 颗粒——这是胶片感最核心的质感标志 |
| 暗角 | 10-15%——老镜头的暗角比现代镜头重 |
| 光晕/柔焦 | 逆光时加柔光效果（模拟老镜头镀膜） |
| 锐化 | 柔和——胶片不追求数字锐度 |
| 色散/色差 | 可选：高光边缘加微量红/青色散 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 怀旧的微笑、不经意的回眸、若有所思——不是当下的快乐，是对过去的温柔回望 |
| 眼神 | 不看镜头 > 看镜头——「被偷拍」的瞬间感 |
| 姿势 | 自然的、不刻意的——走路、回头、整理衣服 |
| 服装 | 复古元素呼应：碎花、牛仔、毛衣、风衣、暖色系 |
| 道具 | 胶片相机、旧书、手写信、老式电话——但不堆砌 |

| 景别 | 中景为主 |
| 光线 | 暖光 + 中低光比 + 轻微过曝 |
| 色彩 | 暖色偏移 + 褪色黑 + 奶油白 |
| 景深 | 中等——不过度虚化（老镜头光圈没那么大） |

## 常见错误

| 错误 | 为什么不像胶片 | 修正 |
|------|-------------|------|
| 只加颗粒不改色彩 | 数字照片 + 颗粒 = 脏，不是胶片 | 颗粒 + 褪色曲线 + 暖色偏移必须同时做 |
| 颗粒太重 | 像砂纸——胶片颗粒是微妙的 | 颗粒控制在 8-20% |
| 饱和度降到零 | 变成黑白——胶片有颜色，只是不艳 | 保留色彩，降低饱和度 15-30% |
| 保留纯黑 | 数字黑（0,0,0）在胶片中不存在 | 阴影提灰：黑 +10-15 亮度 |
| 冷色没有暖化 | 蓝色太冷太数码 | 蓝色向青偏移、绿色向黄偏移 |
| 对焦太锐 | 胶片镜头没有现代镜头锐 | 适度柔化或接受轻微柔焦 |

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **柯达暖调** | 暖黄为主——Portra 400 风格，人像首选 |
| **富士青绿** | 冷色偏青绿——Superia 风格，日系胶片 |
| **过期胶片** | 更重褪色 + 更重颗粒 + 色偏更大 |
| **拍立得** | 正方形画幅 + 低动态范围 + 暖色闪光 + 白色边框 |
| **暗房漏光** | 画面边缘加红/橙色漏光效果 |
