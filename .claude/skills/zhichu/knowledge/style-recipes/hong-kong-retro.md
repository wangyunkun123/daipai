# 港风复古

## 风格定义

**港风复古 = 暖黄高饱和 + 青绿阴影偏移 + 霓虹招牌 + 胶片颗粒 + 柔焦朦胧。** 源自 80-90 年代香港电影和杂志的视觉美学——不是王家卫一个人的风格，而是整个黄金年代香港影视的集体视觉记忆。情绪基调：怀旧、暧昧、都市浪漫——「那个年代的香港，连空气都有颜色」。

**一句话识别**：画面看起来像从 90 年代香港电影截下来的——肤色暖黄但不腻，阴影偏青绿，霓虹灯光在画面里是主角不是背景，有一层柔焦的朦胧感。

---

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 暖黄、橙褐、红、青绿、霓虹蓝 | 暖色为主导、冷色做阴影——不是统一色温，是冷暖对撞 |
| 饱和度 | 中高饱和（红/橙/黄色域保留甚至增强），蓝/紫适当降低 | 港风不是低饱和风格——色彩浓郁但不刺眼，靠柔焦和颗粒来"收" |
| 色温 | 偏暖（4800K-5500K），高光暖黄、阴影青绿 | **高光加黄、阴影加青**——这是港风调色最核心的口诀 |
| 明度 | 中低调——曝光微欠（-0.1~-0.3EV），保留氛围感 | 港风不需要"明亮通透"——需要"有故事的暗" |
| 关键色彩规则 | **肤色暖而不黄、润而不腻**——橙色色相偏橙、明度提高；阴影青绿但人脸区域要保护；主色调不超过 3 种 | 肤色发青发灰是港风调色第一翻车点 |
| 肤色处理 | 哑光底妆+全包眼线+大红唇；HSL橙色提高明度+降低饱和度偏移，红色增强唇色 | 港风肤色=暖润不是惨白——"TVB电视剧里的肤色" |

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **侧光或侧逆光优先**——硬光可用但需要阴影来制造港片的"半明半暗" | 避免平光！港风的核心光线特征是人物面部半边亮半边暗的戏剧性 |
| 光方向 | 侧光勾勒轮廓 + 逆光制造氛围 + 霓虹/路灯做环境光 | 下午 3-5 点的侧逆光最佳；夜景用路灯侧光打亮人脸 |
| 光比 | 中高光比——亮面暖、暗面青绿 | 阴天不适合港风！没有阳光的港风会灰蒙蒙 |
| 时段 | 日落前 1 小时到蓝调时刻——暖黄路灯和冷蓝夜色同框最出片 | 夜景是港风最强场景 |
| 曝光策略 | 微欠曝（-0.1~-0.3EV），以高光为基准让霓虹灯牌不过曝 | 保留氛围感——港风不需要"暗部细节丰富" |
| 特殊光线条件 | **需要霓虹或暖色招牌环境光**——没有霓虹的港风缺少视觉锚点 | 红绿蓝霓虹灯牌是港风灵魂三色 |

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 引导线（街道纵深感）、框架取景（骑楼/窗户/招牌间隙）、居中构图（人像） | 港风构图不追求"创新"——追求"像电影截图" |
| 留白程度 | 中低留白（10-20%）——港风画面偏满，靠光影和色调来分层而非留白 | 拥挤感本身就是港风的一部分 |
| 画面密度 | 中高——招牌/街道/霓虹/人群都是画面叙事元素 | 但不是杂乱——靠色调统一来收住复杂度 |
| 焦段倾向 | 标准（35-50mm）为主——最接近人眼和电影视角；中焦（85mm）用于人像特写 | 广角会让港风变得像旅游快照而非电影截图 |
| 景别倾向 | 中景（环境人像）> 近景（半身/特写）> 远景（街景空镜） | 港风人像的核心景别是"人在霓虹灯下"的中景 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | +10~+25——增强明暗纵深，但不过度（配合柔焦来软化） |
| 高光 | -30~-73——让霓虹灯牌细节浮现，配合色调分离高光加暖黄（色相40-50，饱和度10-16） |
| 阴影 | +15~+41（街拍保留烟火气）或 -5~-15（人像突出轮廓）+ 阴影加青绿（色相180-210，饱和度10-16） |
| 颗粒 | +10~+20——港风胶片感的灵魂，但克制是高级感的前提 |
| 清晰度/纹理 | -10~-20——模拟老镜头柔焦特性 |
| 曲线 | RGB拉轻微S型+阴影起点上移至10（加灰调）+ 蓝通道暗部加青、红通道高光微提 |
| HSL关键 | 橙色：往橙偏+明度+8~12（肤色暖润）；绿色：偏黄+饱和-10~-20；蓝色：饱和-15~-62；紫色/洋红：饱和-100 |
| 柔焦 | 镜头前抹凡士林/柔光UV镜/欧根纱，或后期高斯模糊0.8-1像素+柔光模式叠底 |
| 暗角 | -15~-25——聚焦主体，复刻老镜头边角压暗 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 疏离又慵懒——不是微笑，是"我刚好在这里，你刚好拍到"。有一点距离感但不冷漠 |
| 眼神 | 回眸瞬间 > 倚窗凝视 > 低头浅笑 > 看远方 >>> 直视镜头大笑 |
| 姿势 | 自然行走抓拍、靠在栏杆上、回头看、手扶墨镜、抬手撩头发——动态瞬间比摆拍更港风 |
| 身体语言 | 松弛——肩膀自然下沉、重心偏向一侧。港风不是"站军姿" |
| 互动 | 与环境互动（靠在霓虹招牌旁/透过玻璃窗/在茶餐厅里）> 与镜头互动 |

**妆造必备**：哑光底妆+全包黑色眼线+大红唇+蓬松黑发（大卷或黑长直）。穿搭：复古红/牛仔蓝/黑白连衣裙/廓形白衬衫+牛仔外套。

## 常见错误

| 错误 | 为什么不像港风 | 修正 |
|------|-------------|------|
| 肤色发青发灰 | 阴影加青绿时没有保护肤色区域 | 在HSL中单独校准橙色/红色明度与饱和度；用蒙版排除人脸 |
| 阴天硬拍港风 | 没有阳光和霓虹的港风=灰蒙蒙的普通街拍 | 等晴天或换室内暖光场景（茶餐厅/霓虹灯旁） |
| 盲目套用预设 | 不同光源下白平衡差异大 | 先校正白平衡再调色 |
| 颗粒加太多 | 超过20=画面显脏显廉价 | 强度10-20即可 |
| 过度降低清晰度 | 港风≠低画质 | 保持主体锐利，仅背景轻微朦胧 |
| 滤镜套太多层 | 两层叠加是极限，再多就糊 | 柔焦+颗粒两层足够 |
| 画面太亮 | 港风需要"有故事的暗" | 微欠曝，保留氛围感 |
| 穿现代运动服拍港风 | 穿搭和场景年代错位 | 复古红/牛仔蓝/黑白/廓形西装 |

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **王家卫电影风** | 更极端的绿色阴影偏移+慢快门残影+镜子反射——偏"作者电影"。我们库里已有独立条目 |
| **港风夜景** | 更依赖霓虹灯和混合色温——偏夜景街拍。蓝调时刻+暖黄路灯同框 |
| **港风胶片** | 加更重的胶片颗粒+褪色曲线——偏胶片怀旧而非电影感 |
| **茶餐厅港风** | 室内暖光为主+柔焦更强+更生活化——偏日常记录 |
