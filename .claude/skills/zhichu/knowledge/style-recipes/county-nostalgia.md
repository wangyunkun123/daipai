# 县城记忆 · County Nostalgia

## 风格定义

**县城记忆 = 灰黄土调 + 破败质感 + 忧郁凝视 + 80/90年代服装 + 慢下来的时间感。** 这是中国互联网自发长出来的、最具本土辨识度的摄影风格——不是模仿日系，不是模仿欧美，是「电子乡愁」的中国式表达。

**一句话识别**：这张照片让你想起小时候住过的那个小县城——灰扑扑的、安静的、有点破旧的，但你想回去。

---

## 为什么这个风格必须独立存在

- 抖音「县城文学」话题累计播放 **7 亿次**（2024 年爆火至今）
- 抖音「中式梦核」话题播放 **17.8 亿次**
- 小红书「县城美学」同时发酵，分裂为「失意青年」和「时髦小姨」两条支线
- 这是 ShotOracle 面向中文用户最需要的本土审美——日系拍不出中国的乡愁

**底层逻辑**：中国城镇化进程中，2 亿+ 从小城镇迁移到大城市的年轻人，共享着一种「回不去的县城记忆」。县城文学是这种集体情绪找到了它的视觉语言。

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | **灰黄 + 褪色绿 + 铁锈红 + 水泥灰** | 这不是日系的蓝绿——是中国县城的颜色 |
| 饱和度 | 全局 -30% ~ -50% | 颜色被时间和尘土洗淡了 |
| 色温 | 偏暖但不金黄——「灰暖」而非「金暖」 | 黄昏的暖色 ≠ 县城的灰暖——灰暖是有灰尘感的暖 |
| 明度 | 中低——暗部偏灰，高光压暗 | 画面整体偏暗但不死黑——像阴天下午的室内 |
| 关键色彩规则 | 白不是纯白——是「发黄的白瓷砖」「褪色的白墙」 | 黑色不是纯黑——是「灰黑的煤渣」「深灰的水泥地」 |
| 肤色 | 不追求美——追求「像那个年代的人」 | 保留皮肤的质感、瑕疵、被生活磨过的痕迹 |

**色彩参考**：
- 张克纯《北流活活》：灰黄土调 + 中国景观中的小人
- 老照片褪色：旧相册里放了 20 年的 Kodak Gold ——黄但不艳
- 贾樟柯电影调色板：《站台》《三峡好人》的灰黄 + 铁锈 + 水泥

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **软硬均可——以自然光为主** | 县城的光不是设计过的——是「刚好有的光」 |
| 时段 | 阴天（最佳）> 傍晚 > 正午硬光 | 阴天的灰 = 县城最自然的光线状态 |
| 光比 | 中低（1:2 ~ 1:4） | 柔和过渡——县城的光不戏剧化 |
| 光源 | 单一——窗边光、门口光、路灯、老式日光灯管 | 人造光是「功能性」的——一盏裸露的灯泡，不是设计过的补光 |
| 曝光 | 中调或暗调——不做亮调 | 县城不是明亮的——它是有点暗的、有点旧的 |

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 居中（最直接的凝视）+ 框架（门框/窗框）+ 三分法 | 不追求复杂的构图技法——县城的朴素感需要朴素的构图 |
| 留白 | 中——不过度留白 | 县城是满的——物件、纹理、生活痕迹填满了空间 |
| 焦段倾向 | 广角（28-35mm）+ 标准-中焦（50mm） | 自然透视——你就是在那个空间里站着 |
| 景别倾向 | 中景（人在环境中）+ 远景（小人+县城全景）+ 特写（旧物细节） | 近景——需要模特有「那个年代」的表情 |
| 画面比 | 3:2（135 胶片比例）或 4:3 | 不做宽幅裁切——宽幅太「电影」太精致 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 低——亮暗过渡柔和，阴影偏灰 |
| 色温 | 偏暖但不金黄——「灰暖」——色温 +300K ~ +500K + 阴影加灰 |
| 饱和度 | 全局 -30% ~ -50% |
| 褪色曲线 | 黑色抬灰（+10-15）+ 白色压暗（-5-10） |
| 颗粒 | 加 8-15% 中颗粒——模拟老照片 |
| 锐化 | 柔和——不追求锐利 |
| 暗角 | 10-15%——老镜头的暗角 |
| 灰尘/划痕 | 可选：叠加微量的灰尘纹理——「旧」的视觉证据 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | **忧郁的凝视**——不是悲伤，是「我在想一些很远的事情」。不看镜头 > 看镜头 |
| 眼神 | 望向画面外——空中的某个点，或地上，或窗外 |
| 姿势 | 静态——靠墙、坐在门槛上、站在旧楼前、手插口袋、「不知道在等什么」 |
| 服装 | **80/90 年代中国日常服装**——碎花裙、白衬衫、的确良裤子、凉鞋、旧式校服。两个分支：失意青年（朴素暗色）、时髦小姨（鲜艳但土气的跳色） |
| 环境 | **最重要的是环境**——破旧砖瓦巷、掉漆木门、老式窗户、旧式理发店、水泥地、老家属楼、旧火车站 |

**核心原则**：县城记忆的模特不是「在拍照」——是「刚好被看到了」。摄影师是一个不打扰的观察者。

## 两个分支

### 分支 1：失意青年

- **情绪**：迷茫、忧郁、「走不出看不破」
- **服装**：暗色——灰衬衫、黑裤子、旧校服
- **环境**：破败巷子、旧楼道、废弃工厂
- **色调**：偏冷灰——更压抑
- **抖音主流**

### 分支 2：时髦小姨

- **情绪**：明媚但「土气」的独立女性
- **服装**：跳色碎花裙、垫肩西装、皮草、鲜艳吊带——那个年代的「时髦」
- **环境**：旧式小区、老街道、旧商场
- **色调**：偏暖黄——更鲜活但仍旧
- **小红书主流**

## 常见错误

| 错误 | 为什么不像县城记忆 | 修正 |
|------|-----------------|------|
| 色彩太鲜艳 | 现代感的色彩——破坏了「旧」的感觉 | 降饱和 + 褪色 + 灰黄偏移 |
| 环境太新/太干净 | 没有旧物的质感支撑 → 变回了普通怀旧人像 | 找旧环境——老街区/旧小区/老厂房 |
| 模特太精致 | 完美妆容 + 现代服装 → 「穿越剧」而不是「县城记忆」 | 淡妆 + 80/90s 服装 |
| 金色黄昏光 | 金色 = 浪漫 = 日系/欧美——不是中国县城的灰黄 | 阴天/傍晚——不要黄金时刻的金光 |
| 虚化太多 | 环境细节被虚化 → 看不到「县城」了 | 缩小光圈或退远——环境才是主角 |
| 拍成了日系清新 | 蓝绿调 + 高明度 → 这是日系不是县城 | 灰黄 + 中低明度 |

## 大师参照

- **张克纯**（《北流活活》）：中国景观摄影的标杆——灰黄土调 + 黄河 + 小人物 + 冷峻凝视
- **贾樟柯**（导演但视觉影响巨大）：县城美学的叙事奠基——《站台》《三峡好人》《山河故人》
- **冯立**：直闪 + 中国街头 + 荒诞 + 真实——中国本土街拍的极致
