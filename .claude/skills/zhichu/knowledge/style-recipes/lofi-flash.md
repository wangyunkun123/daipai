# Lofi 直闪 · Lofi Flash

## 风格定义

**Lofi 直闪 = 机顶直闪 + 低像素/高噪点 + 高反差 + 抓拍感 + 不完美美学。** 画面看起来像从 2008 年的傻瓜数码机里直接拿出来的——不追求画质，追求「那一刻真的发生过」的在场感。

**一句话识别**：这张照片看起来像是凌晨两点在派对上用闪光灯随手拍的——但它是故意的，而且很有感觉。

---

## 为什么这个风格在 2024-2025 爆了

三个平台的数据不会说谎：
- Instagram：Indie Sleaze 话题参与量 +35%，品牌投放回报率 +40%（Gen Z）
- 小红书：CCD 相机翻红——佳能 IXUS 从电子垃圾炒到 800-2000 元；#lofi低像素 话题月浏览 9200 万
- 抖音：「中式梦核」话题播放 17.8 亿——高噪点+千禧记忆

**底层逻辑**：Z 世代在 AI 完美图像的时代里，反向追求「人拍的一定不完美」的证据。直闪 + Lofi = 这张照片有一个真实的人在场按下了快门。

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 冷白闪光 + 偏色（青绿/品红偏移） | 老式闪光灯的色温不准确 → 肤色偏冷白或偏品 |
| 饱和度 | 中——不全降 | 傻瓜机的色彩比胶片鲜艳，但比现代手机素 |
| 白平衡 | **故意不准**——偏冷（闪光灯色温）或偏绿（屏幕荧光灯） | 「正确」的白平衡破坏 Lofi 感 |
| 肤色 | 闪光灯直打的冷白肤色——不是日系的暖粉 | 直闪肤色 = 偏冷 + 轻微油光 + 保留肌理 |
| 关键规则 | 色彩不能「好看」——好看 = 精致 = Lofi 的反面 | 偏色、色彩断层、色阶压缩都是审美元素 |

---

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光源 | **机顶直闪**——唯一光源 | 不使用跳闪/柔光罩/反光板——直闪的「硬」是风格核心 |
| 光质 | 极致硬光——小光源（闪光灯）→ 锐利阴影 | 阴影边缘清晰——尤其注意背后墙上的影子（这是 Lofi 的视觉签名） |
| 光比 | 极高（1:8 以上） | 前景（闪光照亮）极亮，背景（闪光覆盖不到）沉入黑暗 |
| 环境光 | 尽量暗——让闪光灯成为唯一光源 | 如果环境光太亮 → 闪光灯的 Lofi 效果不明显 |
| 红眼 | **保留红眼是合法选择** | 红眼是傻瓜机时代的标志——消除红眼 = 消除年代信号 |

**操作**：
- 手机 LED «闪光灯» 常亮或手电筒贴近镜头侧方 → 模仿傻瓜机闪光灯位置
- 拍摄距离 1-2 米——太远闪光灯覆盖不到、太近过曝
- 背景最好是暗的/夜晚的——亮背景下 Lofi 感大减

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 居中（直闪最常用的构图）+ 闯入式 + 歪斜 | 不需要精致构图——Lofi 的构图「不讲究」就是讲究 |
| 留白 | 少——派对/街头/室内是满的 | 满满当当 = 真实的现场感 |
| 焦段倾向 | 广角（28-35mm 等效） | 卡片机/傻瓜机的典型焦段——靠近拍 |
| 景别倾向 | 近景（派对距离）+ 中景（街头距离） | 太远闪光灯打不到 |
| 画面比 | 4:3 或 3:2——不做电影宽幅裁切 | 宽幅 = 电影感 = 太精致了 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 高——直闪的亮暗反差要保留甚至强化 |
| 白色色阶 | +10-20%——模拟闪光灯过曝 |
| 黑色色阶 | -10-20%——模拟闪光灯覆盖不到的暗角 |
| 噪点/颗粒 | **必须加** 10-25%——数字噪点不是胶片颗粒 | CCD 感光元件的噪点不同于胶片颗粒——更高频、更彩色 |
| 锐化 | 低——甚至降锐化 | 傻瓜机的镜头本身就不锐 |
| 色散/紫边 | **保留甚至增加** | 老镜头边缘的紫边/色散是 Lofi 的标志 |
| 白平衡偏移 | 轻微偏冷（-5 ~ -15 蓝色通道）或偏绿 | |
| 压缩感 | 可选：轻微的 JPEG 压缩痕迹 | 8-bit 色彩断层 → Lofi 的数码感 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 不引导情绪——捕捉派对/街头/室内的真实状态。「看镜头的惊讶」「被拍到的瞬间」「大笑到模糊」 |
| 眼神 | 直视镜头（闪光灯下的「被发现」感）> 不看镜头 |
| 姿势 | 不摆姿势——举杯、回头、靠墙、坐地上——生活中的自然动作 |
| 服装 | 不干涉——拍他们真实穿的衣服。Y2K 风格服装加分但不是必须 |

**核心原则**：Lofi 直闪不引导。摄影师是在场者，不是导演。最好的 Lofi 照片 = 「相机刚好在那里」。

## 技术层联动

| 技术维度 | Lofi 直闪倾向 |
|---------|-------------|
| 焦段 | 广角（28-35mm）——靠近拍 |
| 景别 | 近景/中景——闪光灯覆盖范围 |
| 光线 | 机顶直闪 + 暗环境 |
| 色彩 | 白平衡故意不准 + 色彩断层 |
| 快门 | 1/60-1/125s——同步闪光速度 |
| 连拍 | 可以——Lofi 不需要精确控制每一张 |

## 常见错误

| 错误 | 为什么不像 Lofi | 修正 |
|------|----------------|------|
| 用柔光/跳闪 | 光线太「好」了——Lofi 需要直闪的硬 | 关掉柔光、直打闪光 |
| 画质太好 | 太锐、太干净、太完美 → 不像老相机拍的 | 降锐化 + 加噪点 + 加色散 |
| 白平衡太准 | 「正确」的肤色 → 不像老闪光灯 | 故意偏冷或偏绿 |
| 环境光太亮 | 闪光灯效果不明显 | 找暗的环境或降低环境曝光 |
| 构图太讲究 | 精致构图 → Lofi 的灵魂是「随手拍」 | 允许歪斜、切头、不完美 |
| 后期太多了 | 过度调色 → Lofi 的随意感消失 | 后期做减法——只调对比度+噪点+白平衡偏移 |

## 大师参照

- **Terry Richardson**（争议人物但风格影响巨大）：直闪人像的定义者——白色背景 + 机顶直闪 + 高反差

## 变体

| 变体 | 与主风格的区别 |
|------|--------------|
| **派对 Lofi** | 暗环境 + 直闪 + 人多 + 动态模糊——最经典的 Indie Sleaze |
| **日间直闪** | 白天户外 + 直闪补光——Martin Parr 式的色彩饱和度 |
| **CCD 数码味** | 强调 JPEG 压缩感 + 色彩断层 + 紫边——小红书 CCD 风 |
| **中式梦核** | 高噪点 + 暖灰调 + 老物件 + 千禧年记忆——抖音 17.8 亿播放 |
