# 森系

## 风格定义

**森系 = 绿植背景 + 棉麻材质 + 逆光发丝 + 柔和低饱和 + 自然松弛。** 源于日本"Mori Girl"（森林女孩）美学——不是日系清新那种"被阳光漂白"的干净感，而是"在森林里待久了身上沾了树叶和泥土"的野生松弛感。情绪基调：宁静、舒适、与自然融为一体——「在森林里，不需要假装什么」。

**一句话识别**：画面里绿色占大面积但柔和不过饱和，人物穿着棉麻、逆光下头发边缘发光，表情是"忘记镜头存在"的松弛——像刚在草地上躺了一下午。

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 绿（主导）、米白、浅杏、大地棕、淡蓝天空 | 绿色是森系的视觉锚点——但不是高饱和绿，是"加了灰或被阳光漂淡"的绿 |
| 饱和度 | 整体降低 15-30% | 森系不追求色彩的冲击力——追求"自然的本来颜色" |
| 色温 | 偏暖（秋日金黄感）或略偏冷（夏日清新感），视季节而定 | 绿色可往青调或暖黄调微调，突出自然氧气感 |
| 明度 | 中调偏亮——阴影提亮让暗部通透 | 避免深色树叶带来的沉闷感 |
| 关键色彩规则 | **绿+白+大地棕三色系统**——不超过这个范围。避免鲜艳撞色和荧光色 | 森系的"干净"来自色彩克制，不是来自大面积留白 |
| 肤色处理 | 暖黄通透——肤色是森系画面中唯一的"暖色锚点" | 逆光下肤色容易偏暗，需要反光板或后期提亮 |

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **软光优先**——阴天散射光、林间漫射光、黄金时刻柔光 | 阴天是森系最佳天气！光线均匀柔和，树叶不会出现杂乱高光点 |
| 光方向 | **逆光或侧逆光**——让阳光从人物背后穿过树叶缝隙 | 逆光=发丝光+丁达尔光效（耶稣光）+树叶通透发光 |
| 光比 | 低光比（1:2~1:3）——阴天或林间自然光比就低 | 正午硬光穿过树叶会产生杂乱光斑→避免 |
| 时段 | **早晨 7-9 点**或**下午 3-5 点**——光线斜穿树林角度最佳 | 黄金时刻加分，但阴天全天可拍 |
| 曝光策略 | 以人脸为准 +0.3~+0.7 EV（逆光补偿），或以树叶高光为基准让人物成半剪影 | 反光板补光可以缩小光比、提亮阴影 |
| 特殊光线条件 | **需要树叶缝隙光**——不是大平光。阳光穿过树叶形成的斑驳光影是森系的核心视觉语言 | 完全没有阳光穿透的密林→画面过于沉闷 |

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 三分法、框架取景（树叶/窗户做天然画框）、前景虚化（花/叶子遮挡镜头边缘） | 森系构图要"自然感"——太对称或太几何化会破坏野生松弛感 |
| 留白程度 | 中低留白（10-25%）——树叶/草地本身就是"满"的背景 | 利用逆光高光部分做留白——过曝的天空区域就是天然留白 |
| 画面密度 | 中高——树叶/花草/光影填满画面，但通过景深虚化来分层 | 前景（虚化叶子）+中景（人物）+背景（树林）=三层密度 |
| 焦段倾向 | 中焦（50-85mm）大光圈（F1.2-F2.8）——虚化杂乱背景、拍出斑驳光斑 | 24-70mm 变焦最实用 |
| 景别倾向 | 中景 > 近景 > 全景 > 特写 | 半身+特写+全景搭配，呈现"在森林里的一天"的故事感 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 降低——追求柔和、清新、通透的画面感 |
| 高光 | 提亮——逆光高光区域（天空/发丝光）可以略过曝，增加梦幻感 |
| 阴影 | 提亮——让暗部通透，保留林间光影层次 |
| 色温 | 偏暖黄（秋日感）或略偏冷（夏日清新感），视季节和场景而定 |
| 绿色 | 色相往青调或暖黄调微调，饱和度 -10~-20，明亮度 +10~+20——让绿色"柔和不沉闷" |
| 柔光 | 轻微柔焦效果——让画面更柔和梦幻 |
| 颗粒 | +10~20%（可选）——营造胶片质感 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 宁静、舒适、松弛——不是"我好开心在拍照"，是"我好享受在森林里的这一刻" |
| 眼神 | 不看镜头——低头看花草、抬头看天空、闭眼感受阳光 >>> 看镜头 |
| 姿势 | 轻抚花草、抬头看天空、低头轻笑、闭眼感受阳光、手持花朵轻嗅、蹲下看地上的蘑菇 |
| 身体语言 | 自然放松——不要挺胸收腹的摆拍感。可以靠在树上、坐在草地上、躺在落叶上 |
| 互动 | 与自然互动（摸树叶/碰花瓣/踩草地）> 与道具互动（书本/草帽/花束）> 与镜头互动 |

**穿搭核心**：白色/米白/浅杏/淡绿棉麻连衣裙。材质=棉麻、纱质、蕾丝——轻盈能随风飘动。拒绝：化纤、亮片、荧光色、紧身运动服。

## 常见错误

| 错误 | 为什么不像森系 | 修正 |
|------|-------------|------|
| 穿鲜艳颜色（红/荧光粉/宝蓝） | 在绿色背景中过于抢眼——破坏了"与自然融合"的感觉 | 白色/米白/浅杏/淡绿——浅色系最安全 |
| 正午硬光拍森系 | 树叶产生杂乱高光点+人脸出现斑驳阴影——像"皮肤病了" | 改到阴天或下午3点后，或找树荫深处 |
| 背景太杂乱 | 枯枝+垃圾+路人+电线杆——森林变荒地 | 选场景时注意"色调统一、有层次感" |
| 绿色饱和度太高 | 像塑料假植物——不是"自然感"是"荧光绿" | HSL绿色饱和-10~-20、明度+10~+20 |
| 模特摆拍感太强 | 挺胸收腹+标准微笑+直视镜头=影楼写真，不是森系 | 引导模特不看镜头、自然动作、忘记摄影师存在 |
| 穿化纤/紧身衣 | 在自然环境中格格不入 | 棉麻/纱质/蕾丝——面料要和环境"对话" |
