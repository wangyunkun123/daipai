# 法式慵懒

## 风格定义

**法式慵懒 = 低饱和暖调 + 柔光漫射 + 生活化场景 + 不经意的松弛姿态。** "Pas besoin d'en faire trop"（不需要做太多）——法式慵懒的核心不是"怎么拍"，是"怎么不拍"。造型可以精致，但态度必须随性。情绪基调：自信、松弛、有一点距离感的优雅——「我好看是因为我自在，不是因为我努力」。

**一句话识别**：画面里的人正在做一件很日常的事——喝咖啡、翻书、撩头发、看窗外——但光线和色调让这个瞬间看起来像法国电影里的一帧。

## 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 卡其、米色、浅棕、奶油白、灰蓝、暗红（点缀） | 中性暖色系为主——法式从不用荧光色和高饱和撞色 |
| 饱和度 | 整体低饱和——"所有颜色都像被阳光晒褪了一点" | 不追求色彩的冲击力——追求色彩的"教养" |
| 色温 | 偏暖（暖黄/蜂蜜色调），但不橙不腻 | 温暖但不热烈——是"午后阳光"的暖，不是"夕阳"的暖 |
| 明度 | 中调偏暗——法式不追求"明亮通透" | 暗调更有电影感和亲密感 |
| 关键色彩规则 | **中性暖色系+不超过1个强调色**。避免跳色/撞色——法式的"高级"来自色彩克制 | 碎花/波点图案可以出现但底色必须统一在暖色系里 |
| 肤色处理 | 自然保留肌理——法式不磨皮。肤色=自然暖调，不过度提亮 | 法式审美接受雀斑、细纹、不完美——"完美是无趣的" |

## 光线配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 光质 | **软光**——纱帘柔化的窗边光、阴天散射光、黄金时刻柔光 | "避硬取柔"是法式光线的第一原则 |
| 光方向 | **侧光或侧逆光**——让面部有柔和的明暗过渡+发丝光 | 侧光让五官立体但不生硬；逆光制造梦幻发丝光 |
| 光比 | 低光比——柔和的光影过渡 | 法式不需要戏剧性的明暗对比——需要"像油画一样的柔和光影" |
| 时段 | 黄金时刻（日出后/日落前1小时），或阴天全天 | 下午4点后的斜射光+纱帘=完美法式窗边光 |
| 曝光策略 | 中调——不过曝不过暗 | 可以利用纱帘/柔焦滤镜柔化高光 |
| 特殊光线条件 | **需要纱帘或半透明柔光介质**——法式室内场景的灵魂道具 | 纱帘=把硬光变软光+画面自带柔焦+增加层次 |

## 构图配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 常用构图 | 前景虚化（花/杯子/纱帘遮挡镜头边缘）、三分法、框架取景（窗户/门框） | 法式构图追求"像不经意看到的画面"——不太对称不太几何化 |
| 留白程度 | 中等留白（20-35%）——天空、墙面、桌面做留白载体 | 法式留白不追求"极简"——追求"给人物呼吸的空间" |
| 画面密度 | 中等——人物+1-2个道具+环境背景 | 不拥挤也不空旷——"刚好有人在生活"的密度 |
| 焦段倾向 | 标准（35-50mm）——最接近人眼，"我在场"的感觉 | 长焦太"偷拍"、广角太"刻意"——35mm是法式最佳焦段 |
| 景别倾向 | 中景（咖啡厅桌边）≈ 近景（半身窗边）> 全景（街角） | 法式的核心距离=坐在同一张桌子对面 |

## 后期方向

| 参数 | 方向 |
|------|------|
| 对比度 | 降低——柔和过渡 |
| 高光 | 微压暗+加暖黄——保留细节但不刺眼 |
| 阴影 | 提亮——让暗部通透 |
| 黑色色阶 | 提亮——让暗部有"空气感" |
| 色温 | 偏暖（向暖黄/蜂蜜方向偏移） |
| 颗粒 | +3~5%——轻微胶片感 |
| 肤色 | HSL橙色降低饱和度保持自然，适度提亮明度 |

## 模特引导

| 维度 | 方向 |
|------|------|
| 情绪 | 自信、松弛——"我好看是因为我自在"。不计较哪个角度好看、不在乎小肚子 |
| 眼神 | 不看镜头是关键——托腮看窗外、低头翻书、看咖啡杯、撩头发看向远方 >>> 看镜头 |
| 姿势 | 随意靠在咖啡厅玻璃窗上、慵懒坐在沙发/长椅上、自然走动然后回眸、过马路时牵手回望 |
| 身体语言 | 引导而非指挥——给场景指令如"靠在窗边发呆""低头整理裙摆"，让模特自然流露 |
| 互动 | 与道具互动（咖啡杯/书本/花/墨镜）> 与环境互动（窗边/街角/石板路）> 与镜头互动 |

**穿搭核心**：丝绸/缎面/薄纱/棉麻材质；茶歇裙/衬衫+牛仔裤/廓形西装；墨镜/丝巾/珍珠/草编包是灵魂配饰。露肤度适度——V领或露背+衬衫解开几颗扣子=慵懒感来源。

## 常见错误

| 错误 | 为什么不像法式慵懒 | 修正 |
|------|-----------------|------|
| 模特太用力摆姿势 | 法式的核心是"不费力"——摆拍感=反法式 | 让模特做真实的事（喝咖啡/翻书/撩头发），摄影师抓拍 |
| 色彩太鲜艳 | 荧光色/高饱和撞色——像广告不是法式 | 中性暖色系+低饱和 |
| 光线太硬 | 正午直射光+无柔光介质——像证件照不是法式 | 等黄金时刻或拉纱帘 |
| 磨皮过度 | 法式审美接受皮肤纹理——"完美是无趣的" | 保留肌理、不磨皮 |
| 场景太现代/太干净 | 纯白极简咖啡厅——像MUJI不是法式 | 选有历史感的场景：老咖啡馆/石板路/旧公寓/花店 |
| 穿搭太运动/太街头 | 卫衣+球鞋+棒球帽——和法式优雅冲突 | 换一件衬衫/一条丝巾/一双平底鞋 |
