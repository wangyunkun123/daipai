# Grunge 脏感 · Grunge Aesthetic

## 风格定义

**Grunge = 「这张照片看起来像是从 1994 年的地下乐队排练室地上捡起来的」。** 脏、粗、不在乎——所有「精致摄影」的反面。

**情绪基调**：叛逆、不在乎、生猛、反精致、「我根本不 care 好不好看」
**最适场景**：街头、废墟、地下空间、排练室、旧车库、城市边缘
**难度**：⭐⭐（技术不复杂，但需要「脏得好看」的审美判断）

---

## 审美立场

Grunge 是对以下趋势的直接对抗：
- 过度精修（每一像素都被优化过）
- 商业美学（太干净 = 太商业 = 太假）
- AI 生成图像的完美感（Grunge 的脏和粗糙是反 AI 的「人类证明」）

2026 年的 Grunge 复兴 = 后 AI 时代的「真实感回归」——当 AI 可以生成完美无瑕的图像，Grunge 的脏、粗、不完美反而成了「这是人拍的」的标志。

## 色彩配方

| 参数 | 取值 |
|------|------|
| 饱和度 | **低饱和——全局降低 20-30%** |
| 色温 | 偏冷或脏暖——5500K 以下冷调 或 4000K 脏暖调 |
| 色调偏移 | **绿偏移或棕偏移**——不健康/不干净的色调 |
| 关键色 | 深绿、脏棕、褪色黑、灰蓝、旧黄 |

**色彩规则**：
- 没有「干净的颜色」——所有颜色都像被踩了一脚
- 黑色不是纯黑——是褪色黑（黑色 + 灰）
- 白色不是纯白——是脏白（白色像被烟熏过）

---

## 光线配方

| 参数 | 取值 |
|------|------|
| 光质 | **硬光优先**——直射日光、裸灯、直闪灯 |
| 光比 | **高反差**——亮面过曝倾向 + 暗面欠曝倾向 |
| 时段 | 正午硬光优先 / 夜晚荧光灯+闪光灯 |
| 补光 | 不补光——让暗面暗下去 |

---

## 构图配方

| 参数 | 取值 |
|------|------|
| 构图风格 | **故意的「坏构图」**——倾斜、切头、不居中的主体、随机的取景 |
| 角度 | 极端高角度或低角度——不舒适的观看角度 |
| 焦段 | 广角（28mm）——增加变形和侵入感 |
| 留白 | 不刻意——可以填满，可以空洞 |

---

## 后期方向

| 参数 | 取值 |
|------|------|
| 对比度 | **高**——增加 S 曲线，牺牲中间调细节 |
| 颗粒 | **重颗粒**——ISO 3200+ 级别的可见颗粒 |
| 锐度 | 正常 | 
| 特殊 | 增加晕影（边缘变暗）、轻微色散/色差——光学瑕疵是风格元素 |
| 色调曲线 | 提升黑位（让黑色变成深灰——褪色黑） |

---

## 质感

Grunge 是质感审美中最极致的「硬质 + 颗粒」组合：

| 质感元素 | 实现 |
|---------|------|
| 粗粝 | 高 ISO 颗粒 + 粗糙表面 |
| 脏 | 脏墙、铁锈、剥落油漆、烟熏痕迹、水渍 |
| 破 | 破洞、裂痕、磨损、划痕 |
| 旧 | 褪色、泛黄、折旧感 |

---

## 常见错误

| 错误 | 为什么不像 | 修正 |
|------|----------|------|
| 加了重颗粒但画面是干净明亮的 | 颗粒 + 干净 = 「噪点过多的干净照片」≠ Grunge | Grunge 需要从前期（场景/光线/色彩）就脏 |
| 模特穿得太干净太新 | 全白衬衫 + 全新马丁靴 = 不像 Grunge | 旧衣服、褪色、破洞、二手 |
| 构图太完美 | 三分法 + 留白 + 对称 = 不是 Grunge | Grunge 接纳「不完美构图」 |
| 光线太软太完美 | 黄金时刻的柔和光 = 太美了 | 硬光、正午光、荧光灯、闪光灯直打 |

---

## 与纪实粗粝的区分

| | Grunge | 纪实粗粝 |
|--|--------|---------|
| 审美立场 | 「我根本不在乎好不好看」 | 「真实比好看重要」 |
| 色彩 | 脏色偏移（绿/棕） | 高反差黑白或消色 |
| 颗粒 | 故意——颗粒是风格 | 结果——高 ISO 不得不有颗粒 |
| 情绪 | 叛逆、愤怒、不屑 | 真实、力量、见证 |
