# 构图决策树

## 一句话定义

构图不是背规则——是回答一个问题：**这张照片要表达什么？** 然后通过视觉秩序的建立——观众的眼睛先看哪、再看哪、最后停在哪——来服务这个表达。视线路径是手段，画面表达才是终点。

—— 框架参考 Michael Freeman《摄影师的视界》与 Barnbaum《摄影的艺术》

## 原理

### 构图是什么

构图的本质是**视觉秩序的建立**。人在看一张照片时，眼球不是随机扫描的，而是被画面中的某些元素天然吸引。构图的全部工作，就是控制这些吸引力的分布和顺序。

Freeman 将构图拆为三层：
1. **视觉引力**：画面中什么东西最吸引眼球？（亮部、高饱和色、人脸、文字）
2. **视觉路径**：引力点之间，眼睛按什么顺序移动？（线条引导、相似元素串联、大小递进）
3. **视觉终点**：眼睛最终停在哪里？（主体。如果停在画面外或杂乱区，构图失败了）

这三层合在一起，回答了一个问题：**你希望观众看到什么？以什么顺序看到？最终记住什么？**

### 构图不是美化

Barnbaum 的核心观点：构图不是为了「让照片好看」，而是为了「让照片表达你想表达的东西」。一张构图完美的对称照片表达的是秩序和稳定；一张故意打破三分法的倾斜构图表达的是不安和动态。两个都是对的——取决于你要说什么。

**在我们 ShotOracle 的语境里：** 每套方案的构图选择，不是随机分配 9 种技法，而是先确定「这张照片的核心看点是什么」，再选择最能服务这个看点的构图方式。

## 构图决策树

当分析一个场景时，按以下顺序判断：

```
场景分析
│
├─ 1. 场景中有明显的线条吗？
│   （道路、栏杆、海岸线、建筑边缘、楼梯、河流）
│   ├─ YES，线条指向一个方向 → 考虑「引导线构图」
│   ├─ YES，线条倾斜穿过画面 → 考虑「对角线构图」
│   └─ NO → 继续
│
├─ 2. 场景中有框状结构吗？
│   （门、窗、拱门、树枝空隙、栏杆间隙、镜子）
│   ├─ YES → 考虑「框架构图」
│   └─ NO → 继续
│
├─ 3. 场景中有对称元素吗？
│   （水面倒影、建筑中轴、对称排列的柱子/窗户）
│   ├─ YES → 考虑「对称构图」
│   └─ NO → 继续
│
├─ 4. 场景有大面积干净背景吗？
│   （天空、纯色墙面、大片水面、草地、沙滩）
│   ├─ YES → 考虑「留白构图」
│   └─ NO → 继续
│
└─ 5. 默认方案
    └─ 「三分法构图」—— 几乎所有场景适用，作为安全基准
```

**关键原则：构图选择是场景驱动的，不是偏好驱动的。** 看到什么元素，就用什么构图。不要在没有线的场景强行找引导线，也不要在没有框的场景强行制造框架。

## 六种构图法速查

### 引导线构图

**原理**：人的眼球天然追随画面中的线条。线条起点 → 线条方向 → 线条终点（应该是主体）。

**一句话**：用场景中的天然线条把观众的视线「运送」到主体身上。

**关键数字**：线最好从画面四角之一出发（左下角最自然，因为多数文化从左下开始阅读），指向画面中上部的模特。

**焦段建议**：超广角强化透视线的纵深拉伸感，但注意边缘人物不要畸变。广角是引导线最安全的焦段。

### 三分法构图

**原理**：画面中心点是最「无聊」的位置。将主体放在 1/3 分割线上，制造不对称的张力——这张力来自「主体偏离中心但画面仍然平衡」的心理效果。

**一句话**：打开网格线，把关键东西放在线上和交点上。

**关键数字**：地平线放在上 1/3（强调地面/前景）或下 1/3（强调天空/背景）。人眼/脸部放在上 1/3 线与左/右竖线的交点。

**操作建议**：始终开启取景网格线——大多数相机和手机都支持，是最容易立刻上手的构图辅助。

### 框架构图

**原理**：框架创造「画中画」。框架内是故事发生的地方，框架外是观众站的地方。这种结构天然产生「窥视感」或「仪式感」。

**一句话**：利用场景中的框状元素包围主体，创造层次感和窥视感。

**关键注意事项**：框架内外光比通常很大。始终以框架内的模特脸部曝光为准，让框架本身偏暗或偏亮都没关系——框架偏暗反而增强窥视感。

**操作建议**：将焦点锁在模特脸上，降低曝光以保护框架外高光——框架偏暗反而增强窥视感。

### 对称构图

**原理**：对称满足人类对秩序和平衡的本能渴望。但完美的对称也意味着「没有张力」——画面可以非常美，但可能少了一点动态感。

**一句话**：精确站在中轴线上，让左右（或上下）完美镜像。

**变体**：对称 + 破格 = 最大的视觉冲击力。模特站在中轴线上但视线看向一侧，或一只手臂打破对称线——一个破格元素让对称的「完美」有了人性。

**操作建议**：确保相机绝对水平。使用水平仪功能或后期微调旋转。0.1 度的歪斜在对称构图中会被放大到无法忽视。

### 留白构图

**原理**：空白不是「没东西」，是「呼吸」。大面积干净背景让主体在画面中的每一分存在感都被放大。主体占比越小，观众越认真看主体。

**一句话**：退后，让环境说话，让人成为环境中的一个标点符号。

**关键数字**：主体占画面 10-20%。低于 5% 会失去存在感，高于 30% 就不再是留白而是普通中景。

**操作建议**：留白构图对背景的「干净度」要求极高。如果设备无法靠浅景深虚化背景，必须选择本身就干净的背景。一盏路灯、一个垃圾桶、一个路人都会破坏留白。

### 对角线构图

**原理**：对角线是画面中最有动感的方向。水平线 = 静止，垂直线 = 力量，对角线 = 运动。

**一句话**：让画面中的主要元素沿对角线方向延伸，制造动感和纵深感。

**适用场景**：倾斜的船身、楼梯、斜坡、建筑侧面、光影的斜投影。

**画幅建议**：竖拍画幅（如 9:16、4:5、2:3）天然适合对角线构图——对角线长度接近画面对角线全长，视觉冲击力最大。

## 9 套方案的构图分配策略

要生成 9 套构图不重复的方案，按以下优先级分配：

| 轮次 | 构图 | 检查场景是否支持 | 备用方案 |
|------|------|----------------|---------|
| 方案 1 | 引导线 | 场景必须有线 | 若无线 → 三分法 |
| 方案 2 | 框架 | 场景必须有框 | 若无线 → 留白 |
| 方案 3 | 三分法 | 几乎总是有 | 无备用 |
| 方案 4 | 留白 | 必须有干净大背景 | 若背景杂乱 → 三分法（不同景别） |
| 方案 5 | 对称 | 必须有对称元素 | 若不对称 → 对角线 |
| 方案 6 | 对角线 | 必须有斜线元素 | 若无斜线 → 引导线（换条线） |
| 方案 7 | 三分法 | 全覆盖 | 与方案 3 不同景别和主体位置 |
| 方案 8 | 引导线 | 换一条不同的线 | 换框架里的不同框架 |
| 方案 9 | 创意组合 | 混合 2 种以上构图 | 如：引导线+留白，框架+三分法 |

**质量底线**：9 套方案至少覆盖 6 种不同构图方式。如果某个场景实在太简单（如纯色墙前），宁可不同景别 + 同一种构图也不硬凑。

## 构图与景别的配合规律

| 构图 | 最佳景别 | 不太适合 |
|------|---------|---------|
| 引导线 | 远景、中景 | 特写（线失去上下文） |
| 三分法 | 所有景别 | — |
| 框架 | 中景、近景 | 远景（框太小看不见） |
| 对称 | 远景、中景 | 特写（对称失去参照物） |
| 留白 | 远景、中景 | 近景、特写（留白消失） |
| 对角线 | 中景、创意 | 特写（斜线失去上下文） |
