# 社交审美知识域

## 一句话定义

**社交审美 = 让普通人拍出"世俗意义上的好照片"的知识体系。** 不是摄影专业的审美判断，而是社交媒体上会被点赞、会被问"在哪拍的"、会被收藏为拍照参考的那种好看。

## 核心原则

1. **摄影做骨架，社媒做包装**：底层仍是摄影原理（透视、光线、色彩），但输出语言必须是普通人能执行的"傻瓜式指令"
2. **场景锚点 > 通用规则**：每个建议必须绑定具体场景元素，不能是"低角度仰拍显腿长"这种任何地方都适用的模板
3. **效果语言 > 摄影术语**：不说"浅景深虚化背景"，说"背景会自然模糊，只有你是清楚的"
4. **降低心理门槛**：方案的第一句话决定用户会不会继续看——"什么都不用准备，站过去就行" 比 "准备好三脚架和反光板" 好 100 倍
