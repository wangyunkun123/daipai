# 咖啡厅/美食：拍出精致感的桌面摄影

## 一句话定义

普通人拍食物最大的问题是"拍出来像外卖"——同样的食物，换个拍法就能从"15块的盖饭"变成"150块的高级餐厅"。核心差异是光线方向、桌面构图和画面整洁度。

## 五大桌面公式

### 1. 窗边侧光（餐厅质感公式）

**规律**：食物放在窗边，光从侧面打过来。不是从头顶（餐厅顶灯），不是从正面（手机闪光灯），是从侧面。

**為什麼**：侧光=食物有立体感=质感。顶光=食物扁平=像外卖。正面闪光灯=食物发白反光=塑料感。侧面自然光=食物有光泽和阴影=高级。

**傻瓜指令**：
- "把盘子挪到窗边——让光从左边或右边照过来"
- "手机在食物正上方或45°，保持稳定——手肘撑在桌子上"
- "不要用闪光灯，不要开任何补光"
- "如果窗户光太强——拉一半窗帘，让光变柔和"

### 2. 俯拍桌面（ins风公式）

**规律**：手机完全平行于桌面，从正上方向下拍。画面里不仅要有食物，还要有桌面材质（木纹/大理石/桌布）、餐具、一只手（拿着叉子或杯子）。

**為什麼**：正俯拍=平面设计感=像杂志内页。桌面材质给画面背景，餐具给画面结构，手给画面故事——"有人正在享用这餐"。

**傻瓜指令**：
- "站起来，手机完全水平——和桌面平行"
- "盘子放画面中间偏上一点——下面留给餐具和桌面"
- "一只手入镜——拿着杯子或叉子，给画面加一点'有人'的感觉"
- "画面里不要超过 3 个东西——盘子+杯子+一只手就够了"
- "开九宫格辅助线——盘子放在上面两条线的交叉点"

### 3. 手持特写（"刚做好"公式）

**规律**：一只手拿着食物/杯子，举到和眼睛同高或略低。背景是咖啡厅环境（虚化）。焦点在食物上。快门速度要够快——室外光最好。

**為什麼**：手持=有"刚拿到手"的即时感=不像摆拍。背景虚化=注意力在食物上=环境氛围变成衬托。这是最接近"人眼看到的样子"的拍法。

**傻瓜指令**：
- "一只手拿起杯子，举到胸口高度——不是脸旁边"
- "背景要能看出来是咖啡厅——虚化没关系，但颜色和光要在"
- "手机靠近杯子——不是用变焦，是真的走近"
- "如果用人像模式，杯子边缘可能会被虚化吃掉——先用普通模式拍一张保底"

### 4. 桌面 45°（"人眼视角"公式）

**规律**：手机在你正常坐着的视角——和桌面成 45°，不是站起来俯拍，不是蹲下来仰拍。就是你坐在椅子上看到的那个角度。

**為什麼**：45°=最接近人眼自然视角=看照片的人感觉"我坐在这里"。正俯拍好看但不像人眼看到的——45°更有代入感。适合拍一桌子的菜而不是单个盘子。

**傻瓜指令**：
- "就坐在你的椅子上，不要站起来"
- "手机拿在和眼睛差不多的高度，稍微向下倾斜"
- "画面近处放最漂亮的那道菜，远处是桌子和环境"
- "如果远处有人——没关系，有人反而更像真实的餐厅体验"

### 5. 切面/细节（质感公式）

**规律**：不拍整盘食物——只拍最漂亮的一口。蛋糕的切面、咖啡的拉花、面条卷在叉子上的那一下。用 2× 镜头（如果有）靠近拍。

**為什麼**：整盘="我在拍食物"。细节="我在欣赏食物"。细节照片让观众看到质感——蛋糕的层次、咖啡的油脂、面条的光泽。这些是社交媒体上最容易让人"想吃"的照片。

**傻瓜指令**：
- "切一刀蛋糕，拍到切面——不是整块蛋糕"
- "手机靠近——近到画面里只有那一口的大小"
- "如果有 2× 镜头就开 2×，没有就靠近一点"
- "光线从你身后或者侧面来——不要挡住光"

## 咖啡厅拍照通用法则

| 法则 | 说明 |
|------|------|
| **光 > 构图** | 先找光线好的位置坐下，再考虑拍什么。窗边第一位，别坐角落里 |
| **清理桌面** | 拍照前把纸巾/账单/手机/钥匙拿走——画面里只留食物+餐具+1-2个装饰物 |
| **不要用滤镜预设** | 食物照片的滤镜感=塑料感。原生色彩+稍微提高亮度就够了 |
| **1× 为主，2× 辅助** | 1× 主摄画质最好。2× 用于特写。0.5× 一般不用——食物的透视变形不好看 |
| **趁热拍** | 刚上桌的食物状态最好——热菜有蒸汽、咖啡有油脂、沙拉还脆。等聊完天再拍就晚了 |
