# 宋画山水 · Song Dynasty Landscape

## 风格识别

**出圈指数**：🌱 L1 小众高级 | **难度**：⭐⭐ 进阶 | **媒介**：中国宋代绘画

**一句话**：「一座大山占据了画面 2/3、山脚下一个人小到几乎看不见——像范宽的《溪山行旅图》——天地巨大，人很渺小，但人在天地中是安定的。」

**社交媒体热度**：宋代美学复兴——「宋式美学」已成为中国高端审美消费的关键词。

---

## 视觉翻译：摄影怎么拍

### 构图

| 参数 | 取值 | 说明 |
|------|------|------|
| 主体 | 山、水、树——人在画面中占 3-5% | 「巨碑式山水」——主体（山）占据画面大部分 |
| 留白 | 天空/水面留白 20-30% | |
| 构图 | 垂直构图——强调「高远」 | 仰拍山体——增强崇高感 |

### 色彩

| 参数 | 取值 |
|------|------|
| 首选 | 黑白——墨色五层 |
| 可选 | 浅绛（淡赭石+花青）——宋画可以有淡彩 |
| 清晰度 | 远景微柔——「远山无皴」——远处的山不需要细节 |

### 光线

| 参数 | 取值 |
|------|------|
| 光质 | 软光/雾——散射光简化了山的层次 |
| 时段 | 清晨雾/阴天——最好有云雾在山间 |

### ⚠️ 限制

需要山+雾——城市和平原无法拍摄。长焦压缩远山是辅助手段。

## 与水墨的区别
