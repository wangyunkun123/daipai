# 赛博朋克 · Cyberpunk

## 风格识别

**出圈指数**：🌊 L3 全球现象级 | **难度**：⭐⭐ 进阶 | **媒介**：电影/游戏/文学

**一句话**：「霓虹紫+蓝+粉、永远在下雨、湿路面反射着全息光——像站在 2077 年东亚城市的街头。」

**社交媒体热度**：赛博朋克 2077 游戏引爆 + 《银翼杀手》持续影响 + 全球霓虹夜景摄影社区。赛博朋克是科幻美学中唯一一个可以被摄影「直接拍到」的风格——因为它本质上就是城市的夜景，只是更霓虹、更潮湿、更暗。

---

## 原始媒介特征

| 特征 | 在原始媒介中的实现 | 审美效果 |
|------|-----------------|---------|
| **霓虹灯海** | 紫/蓝/粉/青（Cyan）霓虹灯管覆盖城市 | 「科技渗透了城市的每一个角落」 |
| **雨夜湿路面** | 永远在雨后——地面反射所有霓虹光 | 「世界是一面巨大的湿镜子」 |
| **两极反差** | 霓虹亮区极亮 + 阴影极暗（近乎全黑） | 高科技（亮）+ 低生活（暗）的视觉隐喻 |
| **东亚元素** | 中文/日文招牌、密集建筑、街边摊 | 「未来的文化中心在东亚」 |

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | **紫（Magenta）+ 青（Cyan）+ 蓝**——这是赛博朋克的色彩签名 | 紫/品红主导暖色侧 + 青/蓝主导冷色侧 |
| 副色 | 粉/红（霓虹灯管的颜色） | 作为高光/点光源的颜色 |
| 黑色 | **可以纯黑**——赛博朋克的暗部不需要细节 | 暗部全黑是风格不是失误 |
| 饱和度 | 霓虹区高饱和 + 暗部消色（本来就是黑的） | 不全局降饱和——霓虹就是要鲜艳 |
| 白平衡 | 偏冷——让霓虹的紫/蓝/青更突出 | 如果白平衡太暖 → 紫变品红、蓝变绿 |

### 光线配方

| 参数 | 取值 |
|------|------|
| 光源 | **霓虹灯/招牌/街灯/车灯**——多色点光源——街头本身就是布光 |
| 光质 | 硬光（点光源 = 小光源 = 硬光） |
| 光比 | **极高**——亮区（霓虹下）vs 暗区（阴影中）可以差 5 档以上 |
| 时段 | **夜晚**——赛博朋克不存在于白天 |
| 雨/湿 | **雨刚停的地面**——湿路面的反射是赛博朋克的视觉灵魂 |

### 构图配方

| 参数 | 取值 |
|------|------|
| 构图 | 引导线（街道纵深/霓虹灯管方向）+ 框架（狭窄街巷）+ 对称（未来建筑） |
| 焦段 | 广角（28-35mm 街巷纵深感）+ 标准-中焦（50mm 霓虹招牌细节） |
| 景别 | 中景（街头人）+ 远景（城市天际线霓虹）——人在霓虹森林中 |
| 垂直 | 仰拍——未来建筑向上延伸 |

### 质感

| 参数 | 方向 |
|------|------|
| 对比度 | 极高——霓虹亮区不炸、暗部全黑 |
| 暗部 | 可以纯黑——赛博朋克暗部不需要提亮 |
| 锐度 | 高——霓虹灯管的边缘清晰、雨滴清晰 |
| 暗角 | 可以加重——注意力向画面中心霓虹汇聚 |
| 色彩分离 | 后期：高光向品红/青偏移，暗部黑+冷蓝偏移 |

## 执行边界

### ✅ 摄影可以做
- 霓虹灯光 + 多色点光源（找城市霓虹街）
- 雨夜湿路面反射
- 高反差 + 暗部全黑
- 仰拍密集建筑

### ⚠️ 需要特定条件
- **必须夜晚 + 霓虹街**——没有霓虹灯的城市拍不了
- **最好雨后**——湿地面反射是赛博朋克的灵魂
- 需要城市密集区——郊区/乡村拍不了

### ❌ 摄影做不了
- 全息投影/飞行汽车/巨型机器人——赛博朋克的科幻元素
- 赛博格/义体——人的身体改造

## 与摄影风格的交叉

| 摄影风格 | 重叠 | 差异 |
|---------|------|------|
| 电影感 | 高反差 + 冷暖对比 | 电影感偏 Teal & Orange（自然色）；赛博朋克偏 Magenta & Cyan（合成色） |
| 纪实粗粝 | 暗调 + 颗粒 | 纪实偏黑白；赛博朋克偏霓虹彩色 |
| 王家卫 | 霓虹 + 夜景 + 湿 | 王家卫偏绿+慢快门+晃动；赛博朋克偏紫蓝+清晰+稳定 |
| Lofi 直闪 | 夜景 + 暗调 | Lofi 偏派对/直闪；赛博朋克偏街头/霓虹 |

## 常见错误

| 错误 | 为什么不像赛博朋克 | 修正 |
|------|-----------------|------|
| 白天拍 | 赛博朋克不存在于白天 | 必须夜晚 |
| 没有霓虹灯 | 普通街灯 ≠ 霓虹——需要多色发光招牌 | 找霓虹街/夜市/商业区 |
| 地面是干的 | 干燥地面 = 没有反射 = 赛博朋克感减半 | 等雨后或自己洒水（小面积） |
| 暗部提亮了 | 赛博朋克的暗部应该纯黑 | 降阴影/黑色色阶 |
| 颜色太暖 | 暖黄街灯 ≠ 赛博朋克的紫/蓝/青 | 白平衡偏冷 + 后期品红/青偏移 |
