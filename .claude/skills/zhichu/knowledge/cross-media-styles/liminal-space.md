# 阈限空间 · Liminal Space

## 风格识别

**出圈指数**：🌱 L1 小众高级 | **难度**：⭐⭐ 进阶 | **媒介**：互联网原生美学

**一句话**：「空荡的走廊、深夜无人加油站、闭店后的商场——这些地方不是恐怖的，但有一种『不应该一个人在这里』的不安。你觉得这个地方你好像来过。」

**社交媒体热度**：Liminal Space 是「梦核」（Dreamcore）/「中式梦核」的西方源头——空荡的过渡空间让人产生一种熟悉又不安的「既视感」。

---

## 视觉翻译：摄影怎么拍

### 核心原则

**Liminal Space = 过渡空间 + 无人 + 时间错位**

| 参数 | 取值 | 说明 |
|------|------|------|
| 场景 | 走廊、楼梯间、空荡商场、闭店后的超市、地下通道、机场候机厅 | 「用来经过、不用来停留」的空间 |
| 氛围 | 空荡但不是废墟——物品是完好的，只是没有人 | 如果是废墟（墙壁剥落、杂草）→ 变成了「废弃美学」≠ Liminal Space |
| 时间 | 通常是夜晚或无人时段 | 正常营业时间的商场不 Liminal——空掉的深夜商场才 Liminal |

### 色彩

| 参数 | 取值 |
|------|------|
| 色温 | 冷荧光灯——办公/商场/医院的荧光灯色温 |
| 饱和度 | 中低——荧光灯下的颜色偏灰偏冷 |
| 整体 | 冷调 + 微绿偏移（荧光灯管的绿色色偏） |

### 构图

| 参数 | 取值 |
|------|------|
| 构图 | **单点透视**——走廊的纵深感——引导线向画面深处消失 |
| 对称 | 走廊/通道的对称 |
| 焦段 | 广角（28mm）——增强空间纵深 |
