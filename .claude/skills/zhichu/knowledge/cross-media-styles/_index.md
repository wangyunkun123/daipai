# 跨媒介风格翻译库

## 一句话定义

**跨媒介风格翻译 = 把非摄影视觉艺术中的风格（动画/电影/绘画/互联网原生美学），翻译为摄影可执行的色彩+光线+构图参数。** 用户说「我要吉卜力的感觉」——AI 需要知道这意味着：绿蓝自然调 + 柔光 + 手绘质感拍法 + 天空占比 40%+。

---

## 原理

### 为什么需要跨媒介翻译

摄影不活在真空中。社交媒体上的审美参照大量来自非摄影领域：

> 「想要吉卜力动画的那种治愈感」
> 「像韦斯·安德森电影那样对称」
> 「莫奈画里的那种光」

这些视觉逻辑不来自摄影。如果只在摄影理论里找答案——用户说「吉卜力」，你推荐「日系清新」，有重叠但不对。吉卜力的绿色和日系的绿色不是一个绿色，吉卜力的天空和日系的天空不是一个蓝色。

### 翻译方法

每个跨媒介风格按统一的「翻译模板」处理：

```
1. 原始媒介 → 核心视觉特征（为什么这种风格在原始媒介中成立）
2. 视觉翻译 → 摄影怎么再现这些特征（色彩/光线/构图/质感）
3. 执行边界 → 哪些可以做、哪些做不了（诚实标注限制）
```

## 文件结构模板

每个跨媒介风格文件包含：

```
1. 风格识别 —— 一句话 + 出圈指数 + 原始媒介 + 一句话识别
2. 原始媒介特征 —— 这种风格在原始媒介中为什么成立
3. 视觉翻译 —— 摄影可执行的色彩/光线/构图/质感参数
4. 执行边界 —— 哪些能做/哪些做不了/哪些只能后期
5. 与摄影风格的交叉 —— 与 style-recipes 中哪些风格重叠/互补
6. 常见错误 —— 该风格最容易被拍"不像"的原因
7. 变体 —— 该风格的子类型
```

## 与摄影风格的关系

跨媒介风格和摄影原生风格不是竞争关系——是互补的参照系：

| 用户说 | 用哪个域 | 为什么 |
|--------|---------|--------|
| 「我想要日系的感觉」 | → photography-styles/japanese-fresh | 这是摄影原生风格 |
| 「我想要吉卜力的感觉」 | → cross-media-styles/ghibli | 这是动画风格，需要翻译 |
| 「我想要电影感」 | → photography-styles/cinematic | 这是摄影原生风格 |
| 「我要王家卫的感觉」 | → cross-media-styles/wong-kar-wai | 这是导演风格，需要翻译 |

**区分规则**：如果参照物是摄影师 → photography-styles。如果参照物是动画/导演/画家/互联网梗 → cross-media-styles。

## 在方案生成中的使用

### 阶段 1（场景分析）增加跨媒介匹配

```
场景分析 → 提取场景气质
         → 匹配可选跨媒介风格（按 L3 > L2 > L1 优先级）
         → 如果用户提到了具体参照 → 直接映射
```

### 阶段 2（方案生成）的风格双轨

每套方案可以同时挂载：
- 一个摄影原生风格（photography-styles/）→ 给拍摄执行提供技术参数
- 一个跨媒介风格（cross-media-styles/）→ 给审美方向提供视觉参照

**示例**：
```
| 摄影风格 | 日系清新（低饱和蓝绿 + 软光 + 留白） |
| 跨媒介参照 | 吉卜力（天空占比 40%+ + 绿调向暖偏移 + 手绘柔光感） |
```
