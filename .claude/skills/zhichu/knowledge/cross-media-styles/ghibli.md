# 吉卜力 · Ghibli

## 风格识别

**出圈指数**：🌊 L3 全球现象级 | **难度**：⭐ 入门 | **媒介**：日本动画电影

**一句话**：「像宫崎骏动画里的一帧——天空的比例、草地的绿色、光穿过树叶的样子，都有一种『这个世界是温柔的』的感觉。」

**社交媒体热度**：2025 年 ChatGPT 吉卜力滤镜全球刷屏，OpenAI 被迫限流。吉卜力美学是 AI 图像生成时代第一个真正「破圈」的视觉风格——非摄影人群也认识。

---

## 原始媒介特征

吉卜力动画的视觉风格建立在以下基础上：

| 特征 | 在动画中的实现 | 审美效果 |
|------|-------------|---------|
| **天空** | 大面积的渐变蓝天+白云——天空不是背景，是「主角」 | 开阔、自由、童年记忆中的夏天 |
| **绿色** | 丰富的绿色层次——深绿/黄绿/嫩绿/蓝绿同时存在 | 「自然本身是多样的绿色」——不是一种绿，是一百种绿 |
| **光** | 柔和的散射光+光斑透过树叶——光在吉卜力中是可见的 | 光 = 温暖 = 被保护的感觉 |
| **细节** | 手绘的「不完美的完美」——草丛/水面/风中的细节 | 手绘 = 有人一笔一笔画了这个世界 = 有温度 |
| **人物** | 人物相对环境较小但不可忽视——「人在自然中」 | 人不是征服自然，是自然的一部分 |

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 天空 | 低饱和蓝 + 白云——蓝不是新海诚的超饱和蓝，是「温柔的蓝」 | HSL：蓝色相 200-210°，饱和度 -10%，明度 +10% |
| 绿色 | 暖偏移绿——吉卜力的绿偏黄/偏暖，不是冷绿 | HSL：绿色相 80-100°（偏暖），多个绿色层同时存在 |
| 整体调性 | 暖调——不是金色的暖，是「被太阳晒过的暖」 | 色温 +300K ~ +500K |
| 饱和度 | 中——保留色彩但不刺眼 | 不降饱和——吉卜力是彩色的 |
| 肤色 | 暖但不橙——自然肤色 | 保留纹理 |

### 光线配方

| 参数 | 取值 |
|------|------|
| 光质 | **软光**——散射日光、开阔阴影、透过树叶的光斑 |
| 光比 | 低（1:2 ~ 1:3）——画面中不能有「残酷的阴影」 |
| 时段 | 黄金时刻（最佳）或柔和的午后光 |
| 逆光 | **光斑树叶**——找到一棵树，让光从树叶缝隙中透过来——这是吉卜力感的物理核心 |
| 曝光 | 亮调——画面明亮但不刺眼 |

### 构图配方

| 参数 | 取值 |
|------|------|
| 天空占比 | **天空占画面 30-50%**——天空是吉卜力的情感容器 |
| 构图 | 留白 + 引导线（小路/溪流）+ 三分法 |
| 焦段 | 广角（28-35mm）——自然透视，不做压缩 |
| 景别 | 远景（人小天地大）> 中景（人在自然中） |
| 水平线 | 保持水平——吉卜力是宁静的，不歪斜 |

### 质感

| 参数 | 方向 |
|------|------|
| 锐度 | 柔和——不追求数字锐度 |
| 颗粒 | 不加——吉卜力是光滑的（手绘感≠颗粒感） |
| 后期 | 轻微柔光——模拟手绘的柔和过渡 |

## 执行边界

### ✅ 摄影可以做
- 天空占比 30-50% + 低饱和蓝 + 白云
- 软光 + 光斑穿过树叶
- 草坪/田野的暖偏移绿色
- 人物小 + 自然大的构图
- 亮调但不刺眼的曝光

### ⚠️ 需要特定条件
- 白云——需要好天气（后期可加但自然的最好）
- 丰富的绿色层次——需要有植被的场景（公园/田野/山间）

### ❌ 摄影做不了
- 吉卜力的「运动感」——风中的草、飘动的云——是动画的逐帧运动
- 手绘线条的笔触感——摄影的物质基础不同
- 奇幻元素（龙猫/城堡/飞行）——需要合成

## 与摄影风格的交叉

| 摄影风格 | 重叠 | 差异 |
|---------|------|------|
| 日系清新 | 软光 + 低光比 + 留白 | 日系的蓝更冷、绿更蓝绿；吉卜力的蓝更暖、绿更黄绿。日系可以做室内，吉卜力必须是户外 |
| 梦幻柔美 | 柔光 + 亮调 | 梦幻柔美靠柔焦；吉卜力靠自然光斑和天空比例 |

## 常见错误

| 错误 | 为什么不像吉卜力 | 修正 |
|------|----------------|------|
| 天空太小 | 吉卜力的天空是情感容器——天空 < 20% = 吉卜力感消失 | 天空占 30-50% |
| 绿太冷 | 冷绿 = 北欧/日系——吉卜力的绿是暖的 | 绿色向黄色偏移 |
| 光斑太刻意 | 人造光斑 = 假 | 找真实的树叶缝隙——让光自然地漏过来 |
| 人物太大 | 吉卜力是「人在自然中」——人太大 = 自然消失了 | 远景或大中景——人占 10-25% |
| 对比太高 | 强阴影 = 残酷 = 不是吉卜力的世界 | 软光 + 低光比 |
| 城市背景 | 吉卜力 90% 的经典场景在自然中 | 找自然场景——公园/田野/山/海边 |

| 变体 | 说明 |

| **龙猫的乡村** | 农田/大树/乡村小路——最经典的吉卜力自然 |

| **魔女宅急便的欧风** | 欧洲小镇 + 海 + 面包店——欧式吉卜力 |
| **幽灵公主的森林** | 深绿 + 雾气 + 苔藓——更神秘更深沉的吉卜力 |
