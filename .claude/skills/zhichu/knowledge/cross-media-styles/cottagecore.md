# 田园生活 · Cottagecore

## 风格识别

**出圈指数**：🔥 L2 热门 | **难度**：⭐ 入门 | **媒介**：互联网原生美学

**一句话**：「野花、棉麻裙子、手工面包、午后阳光从树叶间洒下来——像逃离城市以后、在乡下过上了最简单但最美的那种生活。」

**社交媒体热度**：Cottagecore 是 IG/Pinterest 常驻美学——「逃离城市的美梦」。与吉卜力重叠但更偏「手工」「乡村」「自制」。

---

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 |
|------|------|
| 主色调 | 奶油白、亚麻色、野花黄/粉/紫、草绿、干燥暖木 |
| 饱和度 | 自然——不刻意降也不拉高 |
| 色温 | 暖——午后阳光的暖 |

### 光线

| 参数 | 取值 |
|------|------|
| 光质 | 软光——透过树叶/窗户的散射阳光 |
| 光比 | 低——柔和明亮 |
| 时段 | 午后——Cottagecore 的默认时间是「下午三点」 |

### 场景与道具

| 元素 | 说明 |
|------|------|
| 野花/干花 | 雏菊、薰衣草、野玫瑰——不是精心插花，是「随手摘的」 |
| 棉麻织物 | 白色/米色棉麻裙、格子桌布、编织篮 |
| 手工感 | 手工面包、旧书、手写信、陶器——不是工业产品 |
| 自然环境 | 草地/花园/树林/小溪——不是城市 |

### 构图

| 参数 | 取值 |
|------|------|
| 焦段 | 广角（35mm）——自然透视 |
| 景别 | 中景/特写（细节） |
