# 蜘蛛侠漫画风 · Spider-Verse

## 风格识别

**出圈指数**：🔥 L2 热门 | **难度**：⭐⭐⭐ 专业 | **媒介**：动画电影/美式漫画

**一句话**：「像漫画书里的一格——有半调网点（Halftone Dots）、有对话框的视觉痕迹、高饱和撞色、动态模糊线——世界被印刷在纸上。」

**社交媒体热度**：《蜘蛛侠：平行宇宙》系列重新定义了动画的视觉可能性——将美式漫画的印刷语言（网点/框线/拟声词）直接用作视觉风格。

---

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | 红+蓝（经典蜘蛛侠）+ 高饱和原色 | 漫画色彩 = 原色（CMYK 印刷色逻辑） |
| 饱和度 | 极高——漫画不克制 | |
| 撞色 | 红+蓝、黄+紫——漫画的撞色是印刷油墨的撞色 | |

### 拍摄与后期

| 参数 | 取值 |
|------|------|
| 半调网点 | **后期叠加**——在画面中叠加半调网点图案（Halftone Pattern） |
| 框线 | 可选：画面上叠加漫画格子线（Panel Lines） |
| 速度线 | 可选：动作场景叠加动态模糊线 |
| 拟声词 | 可选：叠加「BOOM」「POW」等漫画拟声词（需要设计感） |

### ⚠️ 核心限制

蜘蛛侠漫画风的**大部分视觉特征是后期/合成的**——摄影能做的是提供色彩基础（高饱和撞色+动态构图），漫画化的质感（网点/框线/拟声词）需要后期。

**这是 cross-media-styles 中后期依赖度最高的风格。**
