# 中国水墨 · Chinese Ink

## 风格识别

**出圈指数**：🌊 L3 中国现象级 | **难度**：⭐⭐ 进阶 | **媒介**：中国传统绘画

**一句话**：「大面积留白、只有黑白灰、山在远处人在小处——像一幅宋画山水。」

**社交媒体热度**：新中式复兴 + 国潮推动——「拍出中国水墨画的感觉」成为小红书/抖音高频审美需求。水墨是唯一一个植根于中国本土文化基因的视觉体系。

---

## 原始媒介特征

中国水墨画的视觉基础：

| 特征 | 在绘画中的实现 | 审美效果 |
|------|-------------|---------|
| **墨分五色** | 焦/浓/重/淡/清——黑不是一种黑，是五种 | 「用最少的颜色层次做最深的空间」 |
| **留白** | 空白不是「没画」——是云、是水、是天、是呼吸 | 「无中生有」——空本身就是内容 |
| **写意** | 不追求形似——追求神似——一竿竹是「竹的精神」不是竹的照片 | 「拍到不等于拍到——拍到灵魂才算」 |
| **山水比例** | 人在山水中小到几乎看不见 | 「天地之间，一个人」——人与自然的关系不是征服，是融入 |
| **线条** | 笔触的线条是画的基础——线条有粗细、有干湿、有速度 | 线条本身有情绪 |

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 首选 | **黑白**——但黑白不是只有两种颜色 | 黑白 = 焦/浓/重/淡/清 五个灰度层次 |
| 保留色彩时 | 极低饱和——最多保留一个淡彩（如远山的蓝灰） | 水墨可以有「浅绛」——淡赭石色——但只能有一种颜色 |
| 黑 | 不是纯黑 (0,0,0)——是「浓墨黑」——RGB 10-20 | 水墨的黑有呼吸感——不是死黑 |
| 白 | 不是纯白 (255,255,255)——是「纸白」——RGB 240-245 | 宣纸的白不是屏幕的白 |

### 光线配方

| 参数 | 取值 |
|------|------|
| 光质 | **软光**——散射光、阴天、雾天、晨暮 | 硬光的锐利阴影 = 西方的光影逻辑 ≠ 水墨的光影逻辑 |
| 光比 | 中低——柔和过渡 | 水墨不靠光影的戏剧性——靠墨色的层次 |
| 雾/水汽 | **雾是水墨的天然滤镜**——雾简化了景物、增加了层次 | 雾 = 水墨的「淡墨」 |
| 时段 | 清晨（雾）+ 黄昏（柔和）+ 阴天（散射光） |

### 构图配方

| 参数 | 取值 |
|------|------|
| 留白 | **留白占 40-70%**——这是水墨最核心的构图原则 | 天空/水面/雾/白墙——空的地方 = 画的地方一样重要 |
| 构图 | 留白 > 引导线 > 三分法 | 不做复杂构图——水墨构图是「简」 |
| 焦段 | 广角（35mm 山水空间）或长焦（>100mm 压缩远山） | 标准-中焦用得少 |
| 景别 | 远景（山水中的人极小——占画面 3-10%） |
| 水平线 | 保持水平——水墨的宁静来自秩序 |

### 质感

| 参数 | 方向 |
|------|------|
| 对比度 | 低——柔和过渡——但灰度层次要丰富 |
| 白场 | 不完全白——轻微暖灰（模拟宣纸） |
| 黑场 | 不完全黑——轻微发灰（模拟墨色） |
| 颗粒 | 可选微量——模拟宣纸的纤维肌理 |
| 锐度 | 柔和——边缘不要太锐利 |

## 执行边界

### ✅ 摄影可以做
- 黑白 + 灰度层次 + 大量留白
- 雾天/阴天柔光简化景物
- 远景小人 + 山水构图
- 长焦压缩远山（山水画的空间压缩感）

### ⚠️ 需要特定条件
- 雾——没有雾也可以（靠大量留白），但雾是水墨的天然助手
- 山/水——需要自然景观——城市拍不了水墨山水
- 黑白转换——后期需要精确控制灰度层次

### ❌ 摄影做不了
- 毛笔的笔触——线条的粗细/干湿/速度是水墨的物质基础，摄影没有
- 「写意」的抽象——摄影是具象的——一棵树就是一棵树，不是「树的精神」

## 与摄影风格的交叉

| 摄影风格 | 重叠 | 差异 |
|---------|------|------|
| 极简高级 | 大量留白 + 元素稀疏 | 极简偏西方几何感（直线+对称）；水墨偏东方有机感（曲线+自然） |
| 县城记忆 | 中国本土审美 | 县城记忆是「小县城的日常生活」；水墨是「山水天地间的永恒」 |

## 最佳场景

| 场景 | 适配度 | 说明 |
|------|--------|------|
| 海边 | ★★★★☆ | 海天留白 + 小人 |
| 公园/自然 | ★★★★★ | 山水/湖面/雾——水墨的最佳舞台 |
| 山区 | ★★★★★ | 远山+云雾——天然水墨 |
| 街拍 | ★★☆☆☆ | 需要找到极简的街巷/白墙 |

## 常见错误

| 错误 | 为什么不像水墨 | 修正 |
|------|----------------|------|
| 留白不够 | 画面太满 = 没有「呼吸」= 不是水墨 | 留白占 40-70% |
| 纯黑+纯白 | 只有两种灰度 = 不是水墨的「墨分五色」 | 确保至少 5 个可辨识的灰度层次 |
| 锐度太高 | 太锐利 = 照片感太强 | 柔化边缘 |
| 人太大 | 水墨中的人是小到几乎看不见的 | 3-10% |
| 色彩太多 | 水墨不是彩色摄影 | 黑白或最多一个淡彩 |

## 变体

| 变体 | 说明 |
|------|------|
| **黑白山水** | 纯黑白 + 山/水/雾——最经典的水墨摄影 |
| **浅绛山水** | 黑白为主 + 一个淡彩（赭石/花青）——浅绛山水画传统 |
| **园林水墨** | 苏州园林——建筑+水+留白——城市中的水墨 |
| **街巷水墨** | 老城街巷 + 黑白 + 雨/湿——何藩的旧香港就是东方水墨+摄影 |
