# 暗调学院 · Dark Academia

## 风格识别

**出圈指数**：🔥 L2 热门 | **难度**：⭐⭐ 进阶 | **媒介**：互联网原生美学

**一句话**：「旧图书馆的深棕木桌、羊皮纸色的旧书、深金+深绿+深棕——像在牛津大学某个百年图书馆里、窗外是阴天、只有一盏台灯。」

**社交媒体热度**：Dark Academia 是 IG/Pinterest/TikTok 常驻美学——学院派复古浪漫。服装品牌（Ralph Lauren 等）大量使用这种视觉语言。

---

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | **深棕+深绿+深金（暗掉的暖色）+ 奶油/羊皮纸色** | 暗调但不冷——是「暖的暗调」 |
| 饱和度 | 中低——颜色沉下去 | |
| 色温 | 偏暖——深金/暗黄——但整体暗 | |
| 黑色 | 暖黑——不是冷黑 |

### 光线

| 参数 | 取值 |
|------|------|
| 光质 | 软光——窗边阴天光/台灯光 |
| 光比 | 中——环境暗+主体在有限的光区中 |
| 时段 | 阴天室内或傍晚——暗但不黑 |

### 场景与道具

| 元素 | 说明 |
|------|------|
| 旧书 | 皮革封面旧书、泛黄书页 |
| 木桌 | 深色旧木桌 |
| 台灯 | 暖色台灯/烛光 |
| 服装 | 深色毛衣/西装外套/围巾/牛津鞋 |

### 构图

| 参数 | 取值 |
|------|------|
| 构图 | 居中+对称——学院派的秩序感 |
| 焦段 | 标准-中焦（50mm） |
| 景别 | 中景（人在书堆中）+ 特写（书/手/羽毛笔细节） |
