# 蒸汽波 · Vaporwave

## 风格识别

**出圈指数**：🌊 L3 全球现象级 | **难度**：⭐ 入门 | **媒介**：互联网原生数字艺术

**一句话**：「粉紫蓝渐变 + 希腊石膏像 + Windows 95 弹窗 + 棕榈树剪影——像某个已经消失的 80 年代未来的明信片。」

**社交媒体热度**：2010s 最重要的互联网原生视觉美学——没有物理起源，纯粹从 Tumblr/Reddit 长出来的。粉紫蓝渐变已经渗透到时尚/音乐/品牌设计的一切领域。

---

## 原始媒介特征

蒸汽波是第一个「互联网原生」的视觉运动：

| 特征 | 在数字艺术中的实现 | 审美效果 |
|------|-----------------|---------|
| **粉紫蓝渐变** | 日落橙+紫+粉+蓝+青——热带天空的合成色版本 | 「永远在日落那一刻」 |
| **希腊石膏像** | 古典雕塑的数字复制品——剥离了原始语境 | 「过去的伟大被今天的网络变成了贴纸」 |
| **80-90s 科技** | Windows 95/早期 Mac/像素字体/录像带噪声 | 「那个我们以为未来会很美好的年代」 |
| **棕榈树/网格** | 迈阿密棕榈树剪影 + 霓虹网格线——对 80s 的怀旧 | 「一个从未存在过的热带未来」 |

## 视觉翻译：摄影怎么拍

### 色彩配方

| 参数 | 取值 | 说明 |
|------|------|------|
| 主色调 | **日落橙→粉→紫→蓝 渐变** | 这是蒸汽波的色彩 DNA——找到一个有这种渐变色的场景（黄昏天空）或后期创建 |
| 饱和度 | 中高——粉色和紫色要饱和 | 蒸汽波不克制——就是要「过度」 |
| 色温 | 暖色（日落侧）+ 冷色（天空侧） | 暖+冷同时存在于同一画面 |
| 霓虹蓝/粉 | 在暗调中加入霓虹蓝/粉色点光源 | |

### 光线配方

| 参数 | 取值 |
|------|------|
| 光质 | 软光——日落散射光 | 或者室内霓虹灯光（硬光）两种方向皆可 |
| 时段 | **黄昏/蓝调时刻**——这是蒸汽波的自然光源 | 大白天拍不出蒸汽波的天空 |
| 逆光 | 棕榈树/建筑剪影 + 日落天空 = 最简易的蒸汽波 |

### 构图配方

| 参数 | 取值 |
|------|------|
| 构图 | 居中（石膏像/主体在正中）+ 对称（80s 美学偏对称） |
| 剪影 | **多用剪影**——尤其是棕榈树、建筑轮廓、人物剪影 |
| 焦段 | 广角（35mm）+ 标准-中焦（50mm） |
| 水平线 | 网格感——水平线最好精确水平 |

### 质感

| 参数 | 方向 |
|------|------|
| 颗粒 | 可选——轻度的 VHS 噪点/录像带追踪线 |
| 锐度 | 柔和——80s 的 CRT 显示器/VHS 录像带不锐利 |
| 色彩分离/色差 | 可选：轻微的红/青色散（Chromatic Aberration）——模拟 CRT 显示器的色彩偏移 |
| 扫描线 | 可选：叠加细水平线——模拟 CRT 屏幕 |

## 执行边界

### ✅ 摄影可以做
- 黄昏/蓝调时刻天空（粉紫蓝渐变）
- 棕榈树剪影
- 石膏像道具（找博物馆/美术馆/画室）
- 霓虹灯 + 暗调
- 后期粉紫蓝色调 + 色彩分离

### ⚠️ 需要特定条件
- 棕榈树（非热带地区没有——可用其他剪影替代）
- 石膏像（除非有道具或去美术馆）

### ❌ 摄影做不了
- Windows 95 弹窗——需要后期合成
- 希腊雕像——如果没有道具/场景——只能后期合成

## 与摄影风格的交叉

| 摄影风格 | 重叠 | 差异 |
|---------|------|------|
| Lofi 直闪 | 低画质 + 怀旧科技 | Lofi 偏 2000s 派对；蒸汽波偏 80s 复古未来 |
| 赛博朋克 | 霓虹 + 暗调 | 赛博朋克偏冷+暗；蒸汽波偏暖+粉+亮 |

## 常见错误

| 错误 | 为什么不像蒸汽波 | 修正 |
|------|----------------|------|
| 白天拍 | 白天天空 = 没有粉紫蓝渐变 | 黄昏/蓝调时刻 |
| 没有粉/紫色 | 普通黄昏 ≠ 蒸汽波天空——需要后期推粉+紫 | 后期：品红偏移 + 蓝色向紫偏移 |
| 太锐太干净 | 4K 锐利 = 数字感 ≠ VHS/CRT 的「模糊记忆」 | 柔化+微量色散 |
| 太严肃 | 蒸汽波是有幽默感的——不要太严肃 | 允许一点点「土」和「俗」 |
