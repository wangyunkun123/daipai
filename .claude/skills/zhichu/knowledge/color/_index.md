# 色彩理论

## 一句话定义

**颜色没有绝对值，只有相对关系。** 同一片蓝色在橙色旁边看起来更蓝，在白色旁边看起来更淡。控制颜色之间的关系，就是控制观众的情绪反应。

—— 框架参考 Josef Albers《色彩的相互作用》

---

## 原理

### Albers 的核心洞见

> "In visual perception a color is almost never seen as it really is — as it physically is. This fact makes color the most relative medium in art."

Albers 证明了颜色不是客观属性，是被相邻颜色「定义」的。这意味着：

1. **你不能孤立地讨论一个颜色好不好看**——它好不好看取决于它旁边是什么颜色
2. **同一个场景，改变构图（改变各颜色在画面中的面积比例），就改变了色彩关系**
3. **服饰选择和场景选择，本质上是色彩关系的选择**

### 色彩的三维度

| 维度 | 定义 | 拍摄中的意义 |
|------|------|------------|
| **色相** (Hue) | 红/橙/黄/绿/蓝/紫 | 色彩对比和和谐的基础 |
| **饱和度** (Saturation) | 颜色的浓度，从纯色到灰色 | 高饱和=活力/年轻/热带；低饱和=克制/成熟/北欧 |
| **明度** (Lightness) | 颜色的亮暗程度 | 亮色天然吸引眼球，暗色天然退后 |

## 色彩关系

### 1. 互补色对比

色轮上相对的两个颜色：蓝↔橙、红↔绿、黄↔紫。

**效果**：放在一起时双方都显得更饱和，产生最大的视觉张力和活力。

**经典场景**：
- 蓝天（蓝）+ 暖色皮肤/落日（橙）= 最经典的户外人像色彩组合
- 红色裙子 + 绿色植物背景 = 强烈的视觉冲击
- 黄色灯光 + 蓝色夜空/阴影 = 冷暖对比（蓝调时刻的城市灯光）

**操作要点**：互补色对比天然产生「视觉重心」——高对比色区域比构图线条更抢眼。确保互补色交汇处靠近主体，而不是在画面边缘。

### 2. 邻近色和谐

色轮上相邻的颜色：蓝+青+绿、红+橙+黄、紫+蓝。

**效果**：和谐、平静、没有视觉冲突。适合柔美、安静、高级感的画面。

**经典场景**：
- 海边（蓝天+青色海面+白色）= 蓝白邻近系统
- 秋季（红+橙+黄+棕）= 暖色邻近系统
- 森林（绿+黄绿+棕）= 自然邻近系统

**操作要点**：邻近色和谐可能「太平淡」，需要通过构图（引导线/框架）或光影（侧光增加立体感）来补充视觉张力。

### 3. 强调色

大面积统一色调 + 一小块对比色。

**效果**：那块小面积对比色成为绝对的视觉焦点，效果比互补色各占一半更强烈。

**经典场景**：
- 蓝天白船（蓝白为主）+ 模特粉色手环（产品文档中的场景！）
- 灰色城市背景 + 一把红色雨伞
- 绿色森林 + 一个穿白色的人

**这个技法对 ShotOracle 特别重要**：当场景本身色彩单调时，可以利用模特身上最小的色彩元素（手环、帽子、丝巾、口红）作为强调色。

### 4. 单色调

同一色相的明度和饱和度变化。

**效果**：极致的统一感和情绪浓度。完全消除了色彩对比，观众注意力全在光影、纹理和构图上。

**经典场景**：
- 黑白摄影（单色调的极端形式）
- 大雾天（天然去饱和）
- 故意后期降低饱和度到 20-30%（电影感色调）

## 色彩的情绪权重

这份映射不是文化约定，是视觉心理学的跨文化规律（参考 Freeman）：

| 色调 | 情绪联想 | 适合场景 | 不适合 |
|------|---------|---------|--------|
| **暖色**（红/橙/黄） | 温暖、亲密、活力、食欲、怀旧 | 日落、家庭、美食、度假 | 需要冷静感的场景 |
| **冷色**（蓝/青/紫） | 冷静、距离、高级、忧郁、科技 | 海景、商务、极简、夜景 | 温馨家庭照 |
| **高饱和** | 活力、年轻、热带、热烈 | 夏天、节日、花卉、时尚 | 深沉/严肃主题 |
| **低饱和/褪色** | 克制、成熟、怀旧、北欧、日系 | 文艺、极简、滨田英明风格 | 活力的户外运动 |
| **高对比彩色** | 戏剧性、大胆、波普 | 蜷川实花风格、时尚摄影 | 日常生活记录 |
| **黑白** | 永恒、质感、结构、严肃 | 街拍、人像质感、何藩/森山大道 | 色彩是核心看点的场景 |

## 色彩作为构图引导

Freeman 指出：画面中**最饱和的颜色自动获得视觉优先权**——这和它在哪里无关，和构图线条无关。

这意味着：
1. 如果模特的衣服是场景中最鲜艳的颜色 → 她天然是视觉重心，不需要额外的构图强调
2. 如果场景中有一盏红灯/一朵红花在角落 → 观众的注意力会漏过去，需要排除或嵌入构图
3. 如果想突出模特但她的衣服颜色融入背景（邻近色和谐）→ 需要靠光线（让她站在更亮的地方）或构图（线条指向她）来建立重心

**色彩 + 光 = 双重引力**
- 画面中最亮的区域 = 视觉重心 #1
- 画面中最饱和的区域 = 视觉重心 #2
- 两个重合 → 最强的重心锚定
- 两个分离 → 观众的注意力在两个点之间摇摆（可能是张力，也可能是分裂）

## 色彩控制的操作要点

- 弱光下色彩饱和度显著下降——这是物理限制，选择光线充足的角度或接受低饱和风格
- LED 等窄光谱光源可能导致色彩失真——注意检查肤色还原
- 拍摄前可利用设备内置的色彩风格/滤镜预览色彩方向
- 后期调整色彩时，考虑「冷调留白」还是「暖调包围」的整体策略
