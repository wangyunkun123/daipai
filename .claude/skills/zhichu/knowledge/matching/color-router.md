# 色彩匹配路由

## 路由规则表

### 按色相数量 + 饱和度

| 色彩特征 | → 知识条目 | → 策略 | → 情绪倾向 | → 风格候选 |
|----------|----------|--------|----------|----------|
| 色相≤2 + 低饱和 | `aesthetic-grammar/restraint.md` §元素取舍 | 克制策略最易执行。色彩本身不抢——靠构图/质感/光 | 宁静/孤独/高级感 | 极简高级/安静真实 |
| 色相≤2 + 高饱和 | `color/_index.md` | 单色+高饱和 = 强烈视觉宣言。注意：高饱和单色容易疲劳 | 活力/能量 | 杂志时尚/Lofi直闪 |
| 色相3-5 + 低饱和 | `aesthetic-grammar/restraint.md` §色彩审计 | 色彩丰富但克制。主色调统一即可 | 松弛感/烟火气/怀旧 | 日系清新/胶片复古/安静真实 |
| 色相3-5 + 高饱和 | `color/_index.md` §色彩对比 | 丰富的色彩 = 画面活力。注意不让任一颜色过抢 | 多巴胺/活力/温暖 | Lofi直闪/杂志时尚/日系清新(分支B) |
| 色相>5 + 任意饱和 | `aesthetic-grammar/restraint.md` §色彩审计 | **需要克制策略**——裁剪取景减少色相数、降饱和统一、或黑白破格 | 复杂→需简化 | 纪实粗粝(降饱和)/Grunge(黑白) |

### 按主色调

| 主色调 | → 情绪映射 | → 推荐情绪词库 | → 风格候选 |
|--------|----------|--------------|----------|
| 暖棕/木色 | 温暖/烟火气/怀旧 | `mood-lexicon/warmth.md` / `mood-lexicon/nostalgia.md` | 安静真实/胶片复古/县城记忆 |
| 白/灰/黑 | 宁静/孤独/疏离/高级 | `mood-lexicon/serenity.md` / `mood-lexicon/solitude.md` | 极简高级/Grunge/纪实粗粝 |
| 蓝/青/绿 | 宁静/清冷/治愈 | `mood-lexicon/serenity.md` | 日系清新/电影感(冷调)/极简高级 |
| 粉/紫 | 浪漫/少女/梦幻 | `mood-lexicon/romance.md` / `mood-lexicon/dopamine.md` | 梦幻柔美/日系清新/Lofi直闪 |
| 红/橙/黄 | 活力/温暖/热情 | `mood-lexicon/energy.md` / `mood-lexicon/warmth.md` | 杂志时尚/胶片复古/Lofi直闪 |
| 多色混合（≥4色相） | 活力/烟火气/多巴胺 | `mood-lexicon/energy.md` / `mood-lexicon/dopamine.md` | Lofi直闪/胶片复古/安静真实(色彩变体) |

### 按饱和度

| 饱和度 | → 策略 | → 最适风格 |
|--------|--------|----------|
| 极低饱和（接近黑白） | 靠光影+纹理+构图支撑画面——色彩缺席=质感和构图成为主角 | 极简高级/Grunge/纪实粗粝 |
| 低饱和 | 最容易驾驭的区间。色彩不抢，留白空间大 | 安静真实/日系清新/极简高级/胶片复古 |
| 中饱和 | 自然色彩——像眼睛看到的。最"直出"的饱和度 | 安静真实/日系清新/胶片复古 |
| 高饱和 | 色彩是核心看点。注意不超过一个高饱和色相主导 | Lofi直闪/杂志时尚/多巴胺 |

### 按色温

| 色温 | → 策略 | → 最适风格 |
|------|--------|----------|
| 偏暖（<5000K） | 保留暖色调——温馨/怀旧/亲密。不"纠正"白平衡 | 安静真实/胶片复古/县城记忆/日系清新 |
| 中性（5000-6500K） | 色彩最准确——适合"直出"风格 | 安静真实/极简高级 |
| 偏冷（>6500K） | 可强调清冷感或等黄金时刻暖光。冷调=高级感/疏离 | 极简高级/电影感(冷调) |

## 色彩策略速查

| 如果想... | 操作 | 引用 |
|----------|------|------|
| 减少画面色相数 | 改变取景角度/机位排除杂色；虚化背景吃掉杂色 | `aesthetic-grammar/restraint.md` §色彩审计 |
| 统一色彩基调 | 后期统一色温方向（暖/冷）；或利用单一主光源的色温罩住全部 | `light/_index.md` §色温 |
| 保留丰富色彩但不成噪音 | 主色调占≥60%面积+其余色相小块点缀 | `aesthetic-grammar/unity-variety.md` |
| 制造色彩对比 | 冷暖对比（蓝背景+暖主体）、互补色对比（红/绿、蓝/黄）| `color/_index.md` |

## 兜底规则
