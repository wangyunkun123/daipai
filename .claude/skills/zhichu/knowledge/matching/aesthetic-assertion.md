# 审美主张引擎 v2.0

## 核心设计哲学

**v1.0 的问题**：把场景分类为"光驱动/色驱动/结构驱动/质感驱动/叙事驱动/情绪驱动"——这是一种分类学思维。分类告诉你一个场景属于哪个标签，但不会告诉你这个场景最动人的那个瞬间可能是什么。

**v2.0 的原则**：

```
分类学思维：这个场景是"叙事驱动"——因为女人和狗有互动关系
洞察思维：这个场景最动人的不是"她在做什么"，
         是"她和小狗之间那种安静的信赖关系"——
         没有任何表演，没有看镜头，就是生活本来的样子。
         多云柔光下，河水很浅，她穿着米白衬衫，
         低头看着小狗，小狗在闻地上的草。
         
         从这里，三个创作方向自然生长出来：
         • 川内伦子式微物神圣化——不拍脸，只拍手和狗耳朵
         • 滨田英明式空气感日常——退后让河和天空一起呼吸
         • 清冷北欧风——把色温拉冷，变成清晨薄雾的另一种安静

分类学给你一个标签。
洞察给你三个创作方向。
```

---

## 一、为什么需要审美主张引擎 v2.0

### v1.0 的断点

```
光线路由器 → "顺光+软光 → 安静真实/日系清新/胶片复古可用"
色彩路由器 → "绿+棕+米白，中低饱和 → 自然温和"
情绪路由器 → "温暖松弛 → 暖色软光低对比"
风格路由器 → "人像+户外软光+温暖松弛 → 森系"

然后呢？
然后 direction-selector 从候选池里挑"简单拍"和"最出片"。

问题是：这些输出都是"条件满足"式的结论。
没有人回答一个更根本的问题：
"这个场景，最值得被拍下来的那个瞬间，是什么？"
```

### v2.0 的定位

审美主张引擎是整个工作流中**唯一一个不做"条件判断"的模块**。它的任务不是回答"能不能"（这是规则护栏的职责），而是回答 **"应该拍什么"**。

```
所有路由器的输出：这是场景的条件（光线/色彩/空间/质感/情绪/题材）
审美主张引擎的回答：基于这些条件，最应该被拍下来的那个东西是什么

它是一句话。就是摄影师举起相机之前，
在脑子里闪过的那句"有了"。
```

## 二、新的生成流程

### 2.1 输入

| 输入 | 来源 | 内容 |
|------|------|------|
| 场景描述 | 豆包视觉识别 | 完整场景画面描述（不是标签，是描述） |
| 光照分析 | light-router | 方向/质量/光比/色温 + 光线价值评估 |
| 色彩分析 | color-router | 主色调/饱和度/色彩关系 |
| 空间分析 | space-router | 深度层次/前景元素/空间特征 |
| 情绪分析 | mood-router | 场景情绪基调 + 视觉参数 |
| 题材信息 | genre-router | 题材类型 + 审美优先级 |
| 设备档案 | user-capability.md | 硬约束 + 设备特有优势 |
| AI 匹配结果 | style-router v2.0 | AI 搜索发现的最佳风格方向 + 发现记录 |
| 审美语法 | aesthetic-grammar/ | 克制/平衡/统一与变化/破格——创作原则 |

### 2.2 生成步骤（5 步）

```
Step 1: 场景沉浸 🆕
  读取豆包视觉识别的完整场景描述。
  不是提取特征——是沉浸进去。
  
  问自己：
  - 如果我是现场的人，我会被什么打动？
  - 这个场景里最安静的那个角落在哪里？
  - 什么东西一闪而过就不会再来？
  - 什么东西一直在那里但没有人注意到？
  
  输出：一段 2-3 句的"在场感受"——不是技术分析，是人的感受。

Step 2: 洞察提炼 🆕
  从"在场感受"中提炼一句话洞察。
  
  洞察不是分类标签。洞察的结构：
  "这个场景最动人的是[什么]——因为[为什么]"
  
  例：
  ✅ "最动人的是她和小狗之间安静的信赖——没有任何表演，就是生活本来的样子"
  ✅ "最动人的是多云天下的河面反光——像一整条银灰色的丝绸铺在地上"
  ✅ "最动人的是那件米白衬衫在柔光下的质感——不是白，是被光浸泡过的暖白"
  ❌ "这个场景是叙事驱动——因为女人和狗有互动关系"（这是分类，不是洞察）
  
  如何判断是洞察还是分类：
  - 分类回答"它属于哪一类"
  - 洞察回答"它为什么动人"
  - 分类用名词结尾（"叙事驱动""光驱动"）
  - 洞察用感受结尾（"生活本来的样子""被光浸泡过的暖白"）

Step 3: 创作方向生长
  从洞察出发，生长出 3-5 个具体的创作方向。
  
  生长规则：
  - 每个方向必须可以直接追溯到洞察中的某个具体元素
  - 方向之间要有审美差异（不能是同一逻辑的微调）
  - 至少一个方向是"非显而易见的"（用户自己想不到的）
  - 至少一个方向充分利用了设备的优势（而非对抗局限）
  
  方向类型参考：
  ├─ 放大：把洞察中最动人的那个元素放大到极致
  │   例：她的手指和小狗耳朵的接触 → 只拍手和狗耳朵，不拍脸
  ├─ 呼吸：退后一步，让洞察中的元素在更大的空间里呼吸
  │   例：她和狗的安静关系 → 退后把河、天空、树林都收进来，人在自然中的渺小
  ├─ 转移：把洞察的核心情感从一个载体转移到另一个载体
  │   例：安静的信赖 → 不拍人也不拍狗，拍她们之间的那块草地
  ├─ 反转：把洞察中的某个参数反转，制造全新的审美
  │   例：温暖松弛 → 把色温拉冷，变成清冷的安静（不是温暖的安静）
  ├─ 致敬：用一个大师的观看方式来诠释这个洞察
  │   例：川内伦子的微物神圣化 → "不是拍她，是拍她和小狗的关系"

Step 4: 设备翻译
  将每个创作方向翻译为在当前设备上的具体执行方案。
  
  重要：设备翻译不是"降级"。是"用这个设备的优势重新理解这个创作方向"。
  
  例：
  创作方向：川内伦子式微物（需要 50mm+ 中焦，6×6 方构图）
  设备：iPhone 17 标准版（无长焦，1× 24mm + 2× 裁切 48mm）
  
  ❌ 降级思维："没有中焦→用 2× 裁切凑合一下"
  ✅ 优势思维："iPhone 最近对焦距离比相机更近→可以靠得更近→
               这个方向用手机拍反而比相机更有亲密感。
               2× 裁切 48mm 接近标准镜头视角，1:1 方构图裁切从 48MP 出完全够。
               手机不引人注意→她不会因为'被拍摄'而改变状态→真正的不打扰。"

Step 5: 排除决策
  基于洞察和创作方向，明确排除一些路线。
  
  排除不是因为"做不到"——是因为"不应该"。
  
  排除类型：
  ├─ 洞察冲突：这个路线跟场景最动人的东西背道而驰
  │   例：洞察是"安静的信赖"→ 排除需要她摆姿势看镜头的方向
  ├─ 统一性：这个路线会破坏场景天然的审美统一
  │   例：场景是软光统一色调 → 排除高反差黑白
  └─ 设备浪费：这个路线不能用设备的优势，反而暴露设备的短板
      例：场景需要 135mm 空间压缩 → iPhone 没有→ 但这个场景有更好的手机表达方式
```

## 三、与 v1.0 的关键区别

| 维度 | v1.0 | v2.0 |
|------|------|------|
| 核心产出 | 分类标签（光驱动/叙事驱动...） | 洞察陈述（"最动人的是..."） |
| 创作方向来源 | 从分类标签推导 | 从洞察中的具体元素生长 |
| 设备关系 | 约束限制方案 | 优势重新定义方案 |
| 排除依据 | 规则冲突 | 审美判断（"不应该"vs"做不到"） |
| 与 AI 搜索的关系 | 独立模块 | AI 搜索结果作为创作方向的参考和验证 |
| 用户感知 | 看不到这个层的输出 | 洞察陈述可能会出现在方案中让用户感受到"被理解" |

## 四、与审美语法的集成

审美语法四柱仍然是创作原则——但角色从 QC 检查变为创作工具：

| 审美语法支柱 | 在 v2.0 中的角色 | 操作方式 |
|------------|----------------|---------|
| **克制** | 帮助排除决策 | "洞察中最动人的东西只有一个。排除所有会分散注意力的方向。" |
| **平衡** | 帮助设备翻译 | "在设备的自然能力范围内找到最佳平衡点，不强行突破。" |
| **统一与变化** | 帮助方向生长 | "所有创作方向共享同一个洞察。但每个方向从洞察的不同元素生长出来——放大、呼吸、转移、反转、致敬。" |
| **破格** | 帮助张力机会 | "在统一中制造一个有意义的例外——故意打破一条规则，但这个打破必须从洞察中获得合法性。" |

## 五、设备前置原则（强化）

在 v2.0 中，设备约束在 Step 4 才介入——**在创作方向已经生长出来之后**。这确保了创作不被设备提前限制。

```
正确顺序：
  洞察 → 创作方向（自由生长） → 设备翻译（用优势重新定义）
  
错误顺序：
  设备约束 → 在约束内生长创作方向 → 方向被提前阉割

为什么正确顺序更好：
  - 先自由生长的方向可能"技术上需要长焦"
  - 设备翻译不是放弃这个方向，而是问：
    "这个方向要用手机拍，最好的方式是什么？"
  - 答案是"靠得更近"——反而比长焦更有亲密感
  - 如果没有先自由生长，这个方向可能在"需要长焦"那一步就被排除了
```

## 六、质量自检

| # | 检查项 | 不通过处理 |
|---|--------|----------|
| 1 | 洞察是否是一句话感受（不是分类标签）？ | 重新沉浸场景 |
| 2 | 每个创作方向是否可以直接追溯到洞察中的具体元素？ | 标注追溯链 |
| 3 | 方向之间是否有真实的审美差异（不是同一逻辑微调）？ | 检查方向类型是否重复 |
| 4 | 是否至少有一个"非显而易见"的方向（用户自己想不到的）？ | 增加放大/转移/反转/致敬类型 |
| 5 | 是否至少有一个方向充分利用了设备优势（而非对抗局限）？ | 检查 Step 4 设备翻译 |
| 6 | 排除决策是否基于审美判断（不是设备限制）？ | 区分"不应该"和"做不到" |
| 7 | 审美语法四柱是否每个在创作中都有体现？ | 逐柱检查 |
