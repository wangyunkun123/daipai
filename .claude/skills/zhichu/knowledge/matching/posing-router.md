# 姿势匹配路由

## 路由规则表

### 场景类型 → 姿势策略

| 场景类型 | 姿势核心策略 | 推荐姿势类别 | 避免 |
|---------|------------|------------|------|
| 高山/山顶观景 | 人物与宏大景观的尺度关系——姿势要有"呼吸感" | 背影远眺、侧身迎风、坐在边缘双腿悬空、双臂张开 | 剪刀手、看镜头微笑（缩小了景观的宏大感） |
| 花丛/公园/草地 | 融入环境——人物是花丛的一部分 | 蹲坐花丛中、手轻触花瓣、躺在草地上俯拍、花枝做前景虚化 | 站直俯拍（人被压缩成短粗比例） |
| 城市街拍 | 动态、不经意的被捕捉感 | 走路回头、过马路抓拍、靠墙抱臂、看手机、喝咖啡 | 面对镜头立正 |
| 咖啡馆/室内 | 生活感、私密感 | 双手握杯、托腮看窗外、翻书页、靠在沙发扶手 | 大动作（空间不够） |
| 海滩/水边 | 身体线条与水平线的关系 | 赤脚踩水、裙摆被风吹起、坐沙滩上侧身、背影+海平线 | 直面阳光（眯眼） |
| 夜景/弱光 | 光线造型——姿势为光线服务 | 侧脸被路灯光照亮、背影+城市灯光背景、手举光源道具 | 大幅度动态（快门不够快会糊） |
| 秋景/落叶 | 温暖的互动感 | 蹲坐落叶中手捧落叶、抛落叶连拍、围巾裹脸只露眼睛 | 冷色衣服与暖色落叶不搭 |
| 建筑/几何 | 身体线条与建筑线条的呼应 | 靠墙侧面直立、楼梯转角坐姿、框架构图站姿 | 随意靠在有涂鸦/脏的墙面 |
| 户外徒步 | 行进中的真实感、不刻意 | 登山杖撑地、背包调整肩带、喝水、擦汗、回望来路 | 摆拍定点姿势（与徒步的"在路上"感矛盾） |

### 景别 → 姿势引导重点

| 景别 | 姿势重点 | 不重要 | 核心指令类型 |
|------|---------|--------|------------|
| 远景 | 整体姿态、与环境的几何关系、轮廓线 | 面部表情、手部细节 | "往前走三步""双臂张开""站在那个点别动" |
| 中景 | 姿态 + 表情并重、上半身手位 | 脚部细节 | "回头看这边""手扶一下帽檐""深呼吸放松肩膀" |
| 近景 | 面部表情、眼神方向、手部在画框内的位置 | 腿部和脚 | "看窗外...现在回来看我""手指轻轻搭在领口" |
| 特写 | 局部质感、光线在皮肤/织物上的表现 | 整体姿态 | "手指自然微曲""嘴唇微张呼吸" |

### 构图方式 → 适配姿势

| 构图 | 适配姿势 | 原理 |
|------|---------|------|
| 三分法 | 侧身45° + 视线朝向留白方向 | 视线方向的空间=负空间=故事感 |
| 引导线 | 人物在线条汇聚点 + 行走方向与线条方向一致 | 线条引导视线→人物=最终落点 |
| 框架构图 | 人物居中偏下 + 安静站姿或坐姿 | 框内不需要大动作——框本身就是故事 |
| 负空间 | 人物在画面一侧 + 轮廓清晰的站姿或坐姿 | 剪影感——身体线条比表情重要 |
| 对角线 | 身体自然沿对角线方向延展——坐姿腿延伸/靠墙侧身 | 对角线是最长线——身体沿对角线=视觉上更长 |
| 对称 | 人物正中 + 轴对称姿势（双手同样动作/正面站立） | 对称构图需要姿势在视觉重量上两侧均衡 |

### 情绪 → 身体语言翻译

| 情绪标签 | 身体语言 | 动作指令（对模特说的话） |
|---------|---------|---------------------|
| 松弛感 | 重心单腿、肩线倾斜、手自然下垂或轻插口袋、头微歪 | "就像你站着等一个不着急的朋友" |
| 自由感 | 双臂张开或举起、迎风站立、大步走、头发被风吹起 | "深吸一口气，手臂慢慢打开" |
| 治愈感 | 闭眼、仰头面向阳光或天空、轻触植物或水面 | "闭上眼睛，感受风的方向" |
| 孤独感 | 背影、低头、远离镜头的小人物、手插口袋缩肩 | "慢慢往前走，不用回头看" |
| 浪漫感 | 撩头发、回眸、裙摆转动、手轻触嘴唇或锁骨 | "数到三回头看我——不是摆拍，是真的看到我那一刻" |
| 活力感 | 跳跃、跑步、大幅度肢体动作、连拍选中间帧 | "我数三二一你跳——别管好不好看，跳就对了" |
| 沉静感 | 坐姿端正、手放在膝盖上、正视前方或微低眉 | "坐好，深呼吸，吐气的时候放松眉头" |
| 俏皮感 | 歪头、吐舌、五指分开放在脸侧、单眼眨眼 | "做个鬼脸——越丑越好"→反而自然 |

## 户外徒步/登山场景 · 专项姿势模板

> 这是直出相机最核心的使用场景之一。以下模板从社交平台高赞徒步照片中提取并验证。

### 模板 1：登顶的背影
```
动作指令：「走到平台最前面，站住别动，看远处的山」
构图：人物在画面中下部偏右，上方2/3留给山和天空
景别：远景
情绪：成就感+沉静——不是"我征服了山"而是"山接纳了我"
手机提示：广角，人物脚部贴画面下边缘（显腿长）
```

### 模板 2：风吹过来的瞬间
```
动作指令：「面朝风来的方向，闭上眼睛，等一阵风来」
构图：人物侧身或半侧身，头发/衣角被风吹起的动态
景别：中景或近景
情绪：自由、与自然融为一体
手机提示：连拍模式——风来的时候按住快门，选发丝最自然的那帧
```

### 模板 3：低头看路
```
动作指令：「正常走路，看脚下——我会蹲下来拍」
构图：低角度，铺路砖或山路的纹理占画面下1/2，人物在上部
景别：近景（只拍下半身或全身）
情绪：沉静、旅途的质感
手机提示：超广角+蹲下，近处地面纹理极度清晰
```

### 模板 4：坐在边缘
```
动作指令：「坐到平台边上（注意安全），腿自然垂下去或盘腿，看远方」
构图：人物在画面一侧，另一侧让出景观和天空
景别：中景-远景都可以
情绪：松弛、思考、与景观的平等对话
手机提示：拍侧面——侧面坐姿的身体线条比正面好。让腿向镜头方向延伸
```

### 模板 5：回望来路
```
动作指令：「往前走五步，然后听到我说'回头'的时候就回头看我——不是摆拍，是真的回头」
构图：人物在前景偏侧，身后的山路/山脊线延伸到远方
景别：中景
情绪：故事感——"走过的路"的视觉化
手机提示：连拍。回头瞬间抓拍。第一个回头帧通常最好——后面就刻意了
```

### 模板 6：手与环境互动
```
动作指令：「伸手碰一下那个护栏/木桩/石头/花」
构图：手和物体在近景（清晰），人物在中景（可稍虚化），山在远景
景别：近景-中景
情绪：细腻、安静——手触碰自然物的瞬间
手机提示：靠近手——让触感纹理成为画面的第二视觉锚点
```

### 模板 7：同行者视角
```
动作指令：「正常走，我走在你旁边拍」
构图：人物偏侧，留出空间给前方的路——好像观者也在队伍里
景别：中景
情绪：陪伴感、旅行日记
手机提示：边走边拍——用1×或2×，保持和人物同样的步行速度
```

### 模板 8：整理装备
```
动作指令：「假装调整一下背包带/鞋带/帽子——别真的解开，就是手在那里动」
构图：聚焦手上动作和装备细节，人物面部可以不出镜
景别：近景-特写
情绪：真实旅途的碎片——比"站在风景前微笑"有质感十倍
手机提示：2×或更长，靠手近一点——让装备纹理清晰
```

## 手部姿势速查（适用所有场景）

| 手部动作 | 适合场景 | 视觉效果 |
|---------|---------|---------|
| 单手扶帽檐 | 户外、逆光 | 制造腋下三角空间→显瘦，帽檐阴影打在脸上→有层次 |
| 双肩背包肩带（拇指扣在背带上） | 徒步、旅行 | 最自然的"手有事做"，站姿立刻不僵硬 |
| 单手持登山杖/棍子 | 徒步 | 手臂自然弯曲=关节留白自动出现 |
| 手插前裤袋（拇指露外面） | 街拍、日常 | 拇指外露=手没有"消失"，比全插进去自然 |
| 一手插袋一手拿东西 | 城市、咖啡馆 | 双手不同动作=画面丰富 |
| 手背在身后 | 看风景时 | 适合背影——手背在身后比自然下垂更多一份"安静观看"的感觉 |
| 手轻触脸颊/锁骨 | 近景人像 | 引导视线到面部，但注意——手指微曲不并拢 |
| 双手握暖杯/水瓶 | 冷天户外、室内 | 生活感+暖意，手有明确任务=不僵硬 |

### 🆕 运动场地/球场

| 场景类型 | 姿势核心策略 | 推荐姿势类别 | 避免 |
|---------|------------|------------|------|
| 网球/篮球场 | 运动间隙的松弛感——"刚打完一局"比"站在场中央"更有故事 | 坐地休息/擦汗喝水/球拍搭肩/整理装备/望向远方 | 僵硬微笑摆拍、剪刀手、站军姿 |
| 塑胶跑道/操场 | 动态中的停顿——跑动→停下的中间状态 | 弯腰系鞋带/拉伸动作/扶着膝盖喘气/坐在跑道边缘 | 直视镜头立正 |
| 健身房/器械区 | 训练中的专注——不看镜头，注意力在身体和器械上 | 调整器械/擦汗/看手机选音乐/靠墙坐/对镜自拍（镜中人） | 刻意秀肌肉的健美姿势 |

### 运动场地专项姿势模板

#### 模板 M1：打完一局的喘息
```
动作指令：「坐着别动，拿水壶喝一口——不是摆拍，是真的喝」
构图：侧面拍，水壶在嘴边，手臂自然弯曲
景别：中景-近景
情绪：运动后的松弛——不是疲惫，是"刚才那一局打得不错"
手机提示：对焦在脸部→水壶可能轻微虚化→生活感自然。保持低机位（与坐姿齐平）
```

#### 模板 M2：球拍搭肩望向远方
```
动作指令：「球拍搭在肩上，看向对面场地——像是在想下一局怎么打」
构图：侧面或半侧面，人物在画面一侧，视线方向留白
景别：中景
情绪：专注、思考、"在比赛中"的临场感
手机提示：如果球场有围网或远处有树木，让人物视线朝向有景深的方向→空间感更强
```

#### 模板 M3：装备静物（无人物）
```
动作指令：无（拍摄者自己动手）
构图：俯拍或低角度——球拍+网球+水壶+毛巾散落在地面
景别：特写-近景
情绪：运动生活的切片——"人去哪了？刚还在这"
手机提示：球拍的粉色握把+翠绿场地+黄色网球=Eggleston式的色彩静物
```

#### 模板 M4：整理装备的瞬间
```
动作指令：「假装调整一下拍线/鞋带/护腕——不用真的解开，手在那里动就行」
构图：聚焦手部动作，人物面部可以不出镜
景别：近景-特写
情绪：真实的运动间隙——"准备上场"或"刚下场"的过渡状态
手机提示：2×长焦，靠近手部——让装备纹理清晰
```

## 🆕 多人/群组姿势编排

> 当前知识库的重大缺失：所有姿势引导假设单人。以下补全多人场景的姿势编排体系。

### 人数 → 空间编排策略

| 人数 | 编排策略 | 空间关系 | 视线分配 | 避免 |
|------|---------|---------|---------|------|
| 2人 | 一前一后（深度层次）/并排但不同高度（一站一坐）/面对面（互动叙事） | 利用高度差创造视觉三角——两人+镜头形成不等边三角形 | 1人看镜头+1人不看 / 2人都看不互动 / 2人互动都不看镜头 | 两人平行站立（军姿感） |
| 3人 | 三角形分布——1人前（坐）+2人后（站），或2前1后 | 前方人物做前景锚点，后方两人做背景层次 | 视线不全部朝同一方向——1人对镜头、2人之间互动 | 三人横向排成一排 |
| 4人 | 分组——2前（坐地/蹲）+2后（站立），或菱形分布 | 前组和后组之间保持1-2米距离→层次自然分离 | 至少1人看镜头建立连接，其余人可在互动中 | 四人面对镜头整齐排列 |
| 5人+ | 自然散布——不是"排好队"是"聚在一起" | 利用前景人物做框架/虚化，群组在纵深方向分布 | 找到一个"锚点人物"（通常是前方C位）→其他人围绕锚点展开 | "班级大合照"式的整排排列 |

### 多人场景的姿势原则

1. **不全部做同一件事**：如果4个人全部看镜头→像合影。至少1人看别处/做动作
2. **身体接触产生温度**：搭肩/牵手/头靠头→选择1-2处接触点，不需要所有人互相碰
3. **高度差 = 层次 = 好看**：最高的站、中间的靠、最低的坐→天然S型曲线
4. **锚点人物法则**：选1个人做"主角"（最靠近镜头/最清晰）→其他人做"配角"（可轻微虚化/在背景）

### 多人坐地休息专项

| 姿势组合 | 空间编排 | 动作指令 |
|---------|---------|---------|
| 2人并排坐 | 一人腿伸直一人屈膝——不同的腿部几何形状打破平行 | "你腿伸直撑在后面，你膝盖收起来——像在野餐不是在上课" |
| 2人前后坐 | 前方人背对镜头（背影），后方人面对镜头→形成深度 | "你坐前面挡住一点画面，不用管镜头；你从她肩膀后面看过来" |
| 3-4人散坐 | 三角形/菱形分布，利用场地线条（球场边线）做天然构图线 | "随便坐——不用排位置，像你们打到一半休息那样自然地散开" |
| 1人坐1人站 | 站的人在坐的人侧后方→高度差创造层次，站的人可以弯一点腰 | "你坐着就好，你站她旁边——手可以搭她肩上或者自然垂着" |

## 🆕 姿势指令的错误-修正回路

> 当前知识库只有"正确指令"，没有"说错了怎么办"。以下补全教学执行层的出错-修正分支。

### 标准对话链

```
摄影师发出指令
    │
    ▼
观察被拍者反应
    │
    ├─ ✅ 做对了 → 按快门
    │
    ├─ ❌ 太紧张（肩膀耸起/表情僵硬/手不知放哪）
    │   ├─ 第一反应："放松，就当我不在——你先喘口气"
    │   ├─ 给个任务："你转头看看那边有什么"
    │   └─ 物理重置："把肩膀放下...对，像刚叹了一口大气"
    │
    ├─ ❌ 没听懂比喻（照做了但效果不对）
    │   ├─ 换比喻：原"像等朋友" → 改"像排队等咖啡——不急，但也没在赶时间"
    │   └─ 降级到物理指令："手放这里，肩膀往后转一点点——就这样"
    │
    ├─ ❌ 身体受限做不出（柔韧性/关节/体态问题）
    │   ├─ 立刻换姿势："这个动作不舒服的话，试试把重心换到另一条腿"
    │   └─ 降级到最简单姿势："不做这个了——你就站在那就好，手自然放着"
    │
    └─ ❌ 笑场/尴尬（在被拍者之间互相看着笑）
        ├─ 先利用：连拍——笑场的瞬间通常是最好的（真实表情）
        ├─ 再拉回："刚才那个笑特别好——现在保持这个状态，但看向我"
        └─ 给任务转移注意力："你们俩聊一下刚才那局谁发球比较好"
```

### 常见问题速查

| 被拍者反应 | 原因 | 修正话术 |
|----------|------|---------|
| 肩膀耸起 | 紧张——身体进入防御状态 | "叹一口大气——对，就是叹气的感觉" |
| 下巴僵硬 | 在刻意收下巴/抬下巴 | "嘴微微张开一点点——不用刻意，像在呼吸就行" |
| 手不知道放哪 | 空手=焦虑 | 给手一个任务——递水壶/球拍/帽子/手机 |
| 眼神飘忽 | 不知道看哪里 | 指定具体方位："看围网那边第三个灯柱" |
| 假笑（嘴角上扬但眼睛没笑） | 在"做表情" | "想一件刚才发生的搞笑的事——不用告诉我是什么" |
| 身体绷直 | 潜意识"被拍照=立正" | "把重心放在一条腿上——随便哪条" |
| 手指并拢/握拳 | 紧张——手部肌肉收缩 | "手指自然张开——像你刚洗完手在晾干" |
