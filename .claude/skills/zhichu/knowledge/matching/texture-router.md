# 质感匹配路由

## 路由规则表

### 质感组合 → 策略 + 风格

| 质感组合 | → 知识条目 | → 策略 | → 风格兼容 |
|----------|----------|--------|----------|
| 通透主体+柔背景 | `texture-aesthetics/_index.md` §通透×柔=发光悬浮 | 通透物在柔背景前=主体"浮"在背景上，空气感强 | ⭐⭐⭐⭐⭐ 微观微距/梦幻柔美<br>⭐⭐⭐ 日系清新 |
| 通透主体+硬背景 | `texture-aesthetics/_index.md` §柔主体+硬背景 | 通透vs硬=脆弱vs坚固的质感冲突——高级 | ⭐⭐⭐⭐⭐ 极简高级<br>⭐⭐⭐⭐ 安静真实 |
| 柔主体+硬背景 | `texture-aesthetics/_index.md` §质感冲突=高级 | 最经典的质感对比——柔的显得更柔 | ⭐⭐⭐⭐ 安静真实/极简高级<br>⭐⭐⭐ 日系清新 |
| 硬主体+柔背景 | `texture-aesthetics/_index.md` §硬主体更突出 | 硬被柔衬托得更硬朗 | ⭐⭐⭐⭐ 极简高级<br>⭐⭐⭐ 杂志时尚 |
| 颗粒主体+光滑背景 | `texture-aesthetics/_index.md` §颗粒+光滑 | 颗粒=年代感/手工感，光滑=精致/现代 | ⭐⭐⭐⭐⭐ 纪实粗粝/Grunge<br>⭐⭐⭐⭐ 胶片复古 |
| 全柔组合 | `texture-aesthetics/_index.md` §同质感堆砌=单调 | ⚠️ 画面可能"绵软"缺锚点→靠构图/光影增加张力 | ⭐⭐⭐ 梦幻柔美<br>⭐⭐ 日系清新 |
| 全硬组合 | `texture-aesthetics/_index.md` §全硬=冰冷 | 画面硬朗/冷峻→适合黑白或高反差 | ⭐⭐⭐⭐⭐ Grunge/纪实粗粝<br>⭐⭐⭐ 极简高级 |
| 含数字瑕疵（噪点/色偏/摩尔纹） | `texture-aesthetics/digital-texture.md` | 数字瑕疵≠技术失败→可作为反AI真实性标志 | ⭐⭐⭐⭐⭐ Lofi直闪/Grunge<br>⭐⭐⭐⭐ 纪实粗粝 |
| 含AI过度处理痕迹（塑料脸/过饱和） | `texture-aesthetics/_index.md` §质感杀手 | ⚠️ 建议关闭AI美颜+降噪→恢复真实质感 | ⭐ 安静真实（需先关闭AI） |

### 主体质感 → 最佳用光

| 主体质感 | → 最佳光线 | → 理由 |
|----------|----------|--------|
| 通透/半透明（玻璃/塑料/纱） | **逆光** | 光穿过透明物→发光效果→通透感最大化 |
| 粗糙/颗粒（木纹/砖墙/织物） | **侧光** | 光擦过表面→凹凸产生明暗→纹理质感被看到 |
| 光滑/反光（金属/镜面/漆面） | **漫射光** | 硬光在光滑面产生刺眼高光→漫射光柔和均匀 |
| 柔软（皮肤/毛绒/花瓣） | **软光** | 硬光在柔软表面产生意外硬影→软光保持柔感 |
| 纹理丰富（老木/铁锈/剥漆） | **侧光+硬光** | 硬侧光=纹理清晰度的最大化组合 |

| 风格 | 主导质感 | 辅助质感 | 不可接受质感 |

| Lofi直闪 | 数字瑕疵 | 柔质 | AI过度处理 |

## 兜底规则

质感组合不在上表中 → 分析主体和背景各自归属（柔/硬/颗粒/通透）→ 应用质感对比法则（不同质感=高级，同质感=单调需构图补偿）→ 手动查 `texture-aesthetics/_index.md`。
