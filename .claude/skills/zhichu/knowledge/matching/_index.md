# 匹配路由层 · 总纲 v2.0

## 一句话定义

**匹配路由层 = AI 引擎主导 + 规则护栏约束 + 知识缓存加速。** AI 不是兜底——AI 是引擎。规则不是驱动——规则是护栏。知识库不是真理——知识库是缓存。

---

## 一、v1.0 → v2.0 的核心变化

### v1.0 的架构问题

```
豆包视觉识别 → "室内漫射软光、暖色调"
                    │
         ┌──────────┴──────────┐
         │  7 个路由器并行查表    │
         │  各自输出独立结论      │
         │  没有人说"这个场景     │
         │  最动人的是什么"      │
         └──────────┬──────────┘
                    │
         审美主张引擎 → 分类标签
                    │
         方向选择器 → 简单拍/最出片
                    │
         兜底 → "匹配不到→最接近的行"
         
问题：
1. AI 是兜底，不是引擎——规则跑完了才轮到 AI
2. 兜底逻辑让用户无感——"还行"但没惊喜
3. 知识空白永远不补——兜底替代了发现
4. 审美主张是分类学，不是洞察
```

### v2.0 的新架构

```
┌─────────────────────────────────────────────────────────────┐
│                    🧠 AI 引擎层（主导）                        │
│                                                              │
│  场景输入 → AI 沉浸理解场景                                   │
│          → AI 搜索全球最佳风格匹配                             │
│          → AI 洞察最动人的那个瞬间                             │
│          → AI 从洞察生长创作方向                               │
│          → AI 发现知识空白并自动填补                           │
│                                                              │
│                    ↓ 约束传入                                 │
│                                                              │
│  🛡️ 规则护栏层（约束，不驱动）                                 │
│  ├─ 光线物理约束：硬排除（顺光拍不了逆光通透）                   │
│  ├─ 设备硬约束：硬排除（没长焦拍不了空间压缩）                   │
│  └─ 安全边界：不推荐危险机位（唯一不变量）                      │
│                                                              │
│                    ↓ 结果沉淀                                 │
│                                                              │
│  📚 知识缓存层（加速，不限制）                                  │
│  ├─ 已验证匹配 → 快速通道（验证 N 次）                         │
│  ├─ 新发现匹配 → 自动注册（标记 discovered）                   │
│  └─ 每次使用都是知识发现机会                                   │
└─────────────────────────────────────────────────────────────┘
```

## 二、匹配工作流 v2.1

> **v2.1 架构变更：规则从"匹配前过滤器"变为"匹配后诚实标注"。AI 在开放世界里搜索，规则站在门口告诉你——哪个你现在就能拍，哪个需要等一等。**

```
阶段 1A：豆包视觉识别 → 场景完整描述
        │
        ▼
阶段 1B：场景理解 + 设备能力加载
        ├─ genre-router  → 题材检测 + 审美优先级权重
        └─ device-adapter → 设备能力档案（硬约束 + 设备优势）
        注意：此阶段不做风格排除——只做理解
        │
        ▼
阶段 1C：AI 引擎（自由搜索 + 全局发现）🆕 v2.1
        ├─ Step 1: AI 搜索发现 → 在开放世界搜索全球最佳风格匹配
        │   （不预过滤——AI 能看到所有可能性）
        ├─ Step 2: 规则诚实标注 → 对每个 AI 发现的风格标注可执行性
        │   ├─ light-router    → 光线条件匹配度（🟢完美/🟡可模拟/🔴需等待）
        │   ├─ color-router    → 色彩策略推荐
        │   ├─ space-router    → 构图候选 + 景别偏好
        │   ├─ texture-router  → 质感策略 + 风格兼容
        │   ├─ mood-router     → 情绪→视觉参数翻译
        │   ├─ master-router   → 大师匹配 + 可翻译技法
        │   └─ device-adapter  → 设备可执行性（🟢/🟡/🟠 + 替代方案）
        ├─ Step 3: 知识缓存对比 → AI 发现 ∩ 缓存已有 → 快速通道
        │              AI 发现 - 缓存已有 → 新发现，自动注册
        └─ Step 4: 安全兜底 → 仅排除危险机位，不做风格排除
        │
        ▼
阶段 1C.5：审美主张引擎 v2.0 🆕
        输入：AI 全局搜索结果 + 诚实标注 + 设备约束
        输出：场景洞察（不是分类标签）
              → 创作方向生长（放大/呼吸/转移/反转/致敬）
              → 设备翻译（用优势重新定义方向）
              → 排除决策（不应该，不是做不到）
        │
        ▼
阶段 1D-2：方向选择器 v2.0 🆕
        ├─ 🟢 现在就拍：从全局最优中选可执行性最高的
        ├─ 🔥 最出片：从全局最优中选辨识度最高的
        └─ ✨ 脑洞大开：从全局最优中选最酷的（不限条件）
        │
        ▼
阶段 3：方案生成（从洞察和创作方向展开）
        │
        ▼
阶段 3.5：自动知识沉淀 🆕
        检查匹配关系是否在缓存中
        → 不在 → 自动注册
        → 在 → 验证计数 +1
```

## 四、冲突解决优先级 v2.1

> **v2.1 核心变更：规则不再在匹配阶段一票否决——改为在评估阶段诚实标注。AI 先看完整个世界，规则再告诉用户"你能拍哪个"。**

```
安全红线（危险机位）            ← 唯一的一票否决——永远不推荐危险机位
    ↓
AI 搜索发现                     ← 最高优先级——AI 在开放世界中自由搜索
    ↓
审美洞察                       ← 决定"最应该拍什么"
    ↓
规则诚实标注                    ← 对每个发现标注可执行性（不是排除，是标注）
    ├─ 光线匹配度：🟢完美 / 🟡可模拟(效果约X%) / 🔴需等待(换个时间)
    ├─ 设备可执行性：🟢直接拍 / 🟡需要微调 / 🟠需要替代方案
    └─ 风格兼容性：🟢天然匹配 / 🟡可尝试 / 🟠需要理解原理
    ↓
知识缓存加速                    ← 纯加速层——已验证匹配走快速通道，新发现自动注册
    ↓
色彩/质感/情绪兼容性            ← 软约束，可被审美洞察覆盖
```

具体规则：
1. **危险机位** → 唯一硬排除。安全是底线。
2. **光线物理极限** → 不排除，诚实标注。顺光拍不出逆光通透 → 标注"🟡 可利用地面反射模拟逆光，效果约 70%"
3. **设备硬约束** → 不排除，诚实标注。无长焦拍不了空间压缩 → 标注"🟡 可用 2× 裁切+靠近主体替代，效果约 60%"
4. **AI 推荐与缓存不一致** → AI 优先。缓存是历史，AI 搜索是现在。标记差异供后续验证。
5. **审美冲突** → 不排除。冷色调+暖情绪可以是复合高级表达。

## 五、核心设计原则 v2.1

1. **AI 先看世界，规则再告诉你"能拍哪个"**：AI 在开放世界自由搜索最佳风格——不受预过滤限制。发现完成后，规则诚实地给每个发现标注可执行性。用户看到的是"全局最优"+"诚实评估"——不是"规则笼子里的局部最优"。
2. **规则从"过滤器"变成"翻译官"**：光线路由器不再说"顺光→排除逆光通透"——改为说"逆光通透需要逆光→🟡 可用地面反射模拟，效果约 70%"。设备约束不再说"无长焦→排除空间压缩"——改为说"空间压缩需要长焦→🟡 用 2× 裁切+靠近主体替代，效果约 60%"。
3. **兜底不存在**：匹配不到 → AI 搜索发现 → 找到答案 → 入库。不是"降级到最接近的行"。
4. **每次使用都是知识发现**：方案生成 → 检查匹配关系 → 不在缓存 → 自动注册。知识库是活的。
5. **洞察优于分类**：不回答"这个场景属于哪一类"——回答"这个场景最动人的那个瞬间是什么"。
6. **惊喜感是功能，不是 bonus**：脑洞大开不是附加功能——是保证用户记住这个 app 的核心机制。
7. **安全是唯一红线**：危险机位 → 一票否决。其余全部诚实标注，不替用户做排除决策。
