# 曝光三角

## 一句话定义

**光圈、快门、ISO——摄影的三个物理变量。** 改变任何一个都会改变曝光，但每个也同时改变画面的另一个属性。这三个变量之间的关系，是所有摄影技术决策的底层逻辑。

---

## 原理

### 曝光三角

```
                   光圈 (Aperture)
                   控制：进光量 + 景深
                       /\
                      /  \
                     /    \
                    /      \
                   /  曝光  \
                  /  三角    \
                 /            \
                /______________\
        快门 (Shutter)        ISO (感光度)
        控制：曝光时间        控制：传感器灵敏度
        + 运动模糊            + 噪点
```

三者遵守**互易律**（Reciprocity Law）：如果增加一个变量一档（×2 光量），减少另一个变量一档（÷2 光量），**总曝光量不变**——但画面效果变了。

**举例**：
- 同样曝光量的两张照片：
  - f/2.8 + 1/500s + ISO 100 = 浅景深 + 冻结运动 + 无噪点
  - f/8 + 1/60s + ISO 100 = 深景深 + 可能运动模糊 + 无噪点
- 两个画面亮度一样，但效果完全不同。

**这就是曝光三角的意义：不是算曝光，是选择画面效果。**

### 互易律的创作含义

互易律意味着：同一种曝光量有无数种光圈/快门/ISO 的组合。你的工作不是「找到正确曝光」，而是**在正确曝光的前提下，选择让画面呈现你想要的效果的那个组合**。

---

## 三个变量详解

### 光圈（Aperture）

**定义**：镜头中光通过的面积。数值是 f/x——f/1.4 是大光圈（洞大），f/16 是小光圈（洞小）。

**改变光圈同时改变**：
- 进光量：大光圈 = 更多光 → 可以用更快快门或更低 ISO
- 景深：大光圈 = 更浅的景深 → 主体清晰、背景虚化

**光圈的创作决策**：

| 光圈选择 | 景深效果 | 适用场景 |
|---------|---------|---------|
| 大光圈（f/1.4-f/2.8） | 浅景深，主体从背景中分离 | 人像、特写、需要简化背景时 |
| 中光圈（f/4-f/8） | 中景深，主体清晰+背景可辨识 | 环境人像、旅行、中景 |
| 小光圈（f/11-f/22） | 深景深，从前到后都清晰 | 风光、建筑、需要环境叙事时 |

**注意**：部分设备（多数手机、固定镜头相机）的光圈是固定的，无法调整。在这种情况下，「光圈选择」退化为不可变因素——景深由其他三个变量（焦距、物距、主体-背景距离）控制。参见 `depth-of-field/_index.md`。

### 快门速度（Shutter Speed）

**定义**：传感器暴露在光下的时间。1/1000s（很快）→ 30s（很慢）。

**改变快门同时改变**：
- 进光量：更慢快门 = 更多光 → 弱光下可以拍到更亮的画面
- 运动表现：更快快门 = 冻结运动；更慢快门 = 运动模糊

**手持安全快门法则**（设备通用）：
- 广角（24-35mm）：快门 ≥ 1/30s（稳手 ≥ 1/15s）
- 中焦（50-85mm）：快门 ≥ 1/60s
- 长焦（>100mm）：快门 ≥ 1/100s
- **有防抖系统的设备可降低 1-3 档**，但不稳定平台（船、车）上需要提高

**快门作为创作工具**：

| 快门速度 | 画面效果 | 适用 |
|---------|---------|------|
| 1/500s+ | 冻结几乎所有运动（跑步、跳跃、飞溅水花） | 动态抓拍、运动、风中飘发 |
| 1/125-1/250s | 冻结慢速运动（走路、转头、手势） | 日常人像 |
| 1/30-1/60s | 微微的运动模糊（走路的人有轻微拖影） | 静态人像，手持下限 |
| 1/4-1/15s | 明显运动模糊（流水变成丝状、车灯成线） | 需要三脚架，创意长曝光 |
| 1s+ | 极端长曝光（海面变雾、人流消失） | 必须三脚架 + 长曝光/夜景模式 |

### ISO（感光度）

**定义**：传感器对光的敏感度/增益。ISO 100（低）→ ISO 6400+（高）。

**改变 ISO 同时改变**：
- 画面亮度：更高 ISO = 更亮
- 噪点：更高 ISO = 更多噪点（信噪比下降）

**ISO 的决策逻辑**：

| ISO 范围 | 画质特征 | 适用场景 |
|---------|---------|---------|
| 低（ISO 50-200） | 近乎无噪点，最佳画质 | 充足光线：白天室外、摄影棚 |
| 中（ISO 200-800） | 轻微噪点，一般不可见 | 中等光线：室内、阴天、阴影 |
| 高（ISO 800-3200） | 噪点可见但不破坏画面 | 弱光：夜景、室内暗光 |
| 极高（ISO 3200+） | 噪点显著，需作为风格选择 | 极端弱光，或高噪点风格化创作 |

**关键认知**：噪点是风格选择，不是绝对缺陷。森山大道式的高反差粗颗粒、黑白纪实摄影的质感——噪点在这些语境中是资产而非技术缺陷。

## 曝光作为创作工具

曝光不只是「让照片不黑不白」。曝光的本质是选择让画面的哪一部分落在「正常」亮度、哪一部分故意偏亮或偏暗。

> **关于 Adams 区域系统**：Ansel Adams 的 Zone System 是一套完整的影调管理方法论——将画面各处影调「预视觉化」后分配到 Zone 0（纯黑）到 Zone X（纯白）十个区，并通过测光、曝光、冲洗来精确控制。本节提供的是该精神的简化应用——保留「主体放在哪个亮度区域」这一核心决策——而非区域系统本身。

### 三种影调策略

| 决策 | 操作 | 画面效果 | 适用 |
|------|------|---------|------|
| 以主体为准 | 对主体测光并锁定 | 主体正常，背景可能过曝/欠曝 | 人像为主 |
| 以亮部为准 | 对亮部测光，暗部沉下去 | 亮部保留细节，主体可能成剪影 | 剪影、氛围 |
| 以暗部为准 | 对暗部测光，亮部过曝 | 暗部提亮，亮部牺牲 | 逆光补光、阴影中主体 |

### 三种曝光风格

| 风格 | 特征 | 适合情绪 |
|------|------|---------|
| **亮调（High Key）** | 以主体为准，背景亮到接近过曝 | 轻盈、清新、日系（滨田英明） |
| **暗调（Low Key）** | 以主体为准，背景暗到接近全黑 | 深沉、戏剧性、质感（Peter Lindbergh） |
| **中调** | 均匀曝光，信息完整 | 自然、记录感、真实 |

## 弱光决策流程

```
场景光线条件
│
├─ 充足光线（白天室外）
│   └─ 曝光参数宽裕，无需特别干预
│       注意：冻结动态时确认快门速度 ≥ 1/250s
│
├─ 中等光线（室内/阴天/阴影）
│   └─ ISO 偏高，快门降至手持临界
│       → 决策 A：保持当前参数，稳定手持
│       → 决策 B：开大光圈（如果可调），降低 ISO
│       → 决策 C：找支撑物（墙/栏杆/桌子）
│
└─ 弱光（夜景/室内暗光）
    └─ ISO 高 + 快门低于手持极限
        → 决策 A：三脚架/稳定支撑 + 低 ISO + 长快门（最佳画质）
        → 决策 B：提高 ISO + 接受噪点（森山大道式风格选择）
        → 决策 C：找额外光源（路灯、橱窗）
        → 决策 D：承认条件不够，不强拍
```

## 手动控制的场景

并非所有设备都支持手动控制，但当设备支持时，以下场景值得手动干预：

| 参数 | 手动控制的场景 |
|------|-------------|
| **快门速度** | 运动模糊创作（瀑布丝状=1/4s）、冻结高速动作（>1/500s）、弱光下防止自动模式快门过慢 |
| **ISO** | 强制低 ISO 保证画质（需要长快门+三脚架）、故意高 ISO 制造噪点纹理 |
| **手动对焦** | 自动对焦在弱光下反复「拉风箱」无法锁定时；故意脱焦创作（氛围感人像） |
| **白平衡** | 混合光场景（室内灯+窗外日光），自动白平衡左右摇摆时锁定 |

**底线原则**：如果你不确定手动参数对不对，**信任自动模式**。现代相机的测光系统在大多数场景中比手动参数更聪明。手动模式是「自动模式给不了我想要的效果时」才用的工具。

## 常见错误

| 错误 | 为什么错 | 修正 |
|------|---------|------|
| 只关注亮度不看快门速度 | 自动曝光降低了快门 → 亮度对了但照片糊了 | 弱光下注意快门速度。低于安全快门需要稳定支撑 |
| 弱光强行手持 | 手抖 + 慢快门 = 每张都是糊的 | 找支撑物（墙/栏杆/桌子），或提高 ISO 接受噪点 |
| 过度依赖长曝光模式 | 长曝光需要被摄体保持静止——不是所有场景都适用 | 如果被摄体无法静止 → 放弃长曝光，提高 ISO |
| 不理解「互易律」盲目调整 | 降低 ISO 来减少噪点 → 自动曝光降低快门 → 照片糊了 | 快速快门（清晰但可能噪点）vs 低噪点（但可能糊），选择你最不能接受哪个 |

## 设备附录：不同平台的曝光控制差异

| 设备类型 | 光圈 | 快门 | ISO | 手动模式 |
|---------|------|------|-----|---------|
| 手机 | 固定（不可调） | 自动/部分可手动 | 自动/部分可手动 | 部分机型支持专业模式 |
| 固定镜头相机 | 可变 | 可手动 | 可手动 | 通常支持 |
| 微单/单反 | 可变（取决于镜头） | 可手动 | 可手动 | 完整支持 |
| 中画幅 | 可变（取决于镜头） | 可手动 | 可手动 | 完整支持 |

> 各设备的具体曝光操作策略，参见 `device-adaptation/_index.md`。
