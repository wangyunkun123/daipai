# 后期意识 · 前期拍什么、后期调什么

## 核心理念

**直出相机不是"不后期"，而是"前期把后期需要的素材拍到位"。**

手机摄影的后期能力有限——不是 Lightroom/Photoshop 的简化版，而是一个完全不同的工具。理解手机编辑的能力边界，反过来指导前期拍摄决策。

---

## 一、手机编辑能力边界

### 能力清单

| 能做（且做得好） | 勉强能做 | 做不到 |
|-----------------|---------|--------|
| 曝光 ±2EV | 局部调亮/压暗（笔刷精度差） | 恢复已过曝的高光 |
| 对比度/高光/阴影 | 色彩分级（分离高光/阴影色调） | 恢复已死黑的暗部 |
| 饱和度/自然饱和度 | 降噪（会损失细节） | 改变光的方向/光质 |
| 色温/色调 | 锐化（容易过度） | 修复严重模糊/失焦 |
| 裁剪/旋转/透视矫正 | 去除小杂物（修复工具） | 添加不存在的元素 |
| 晕影/颗粒 | 曲线调整（多数手机没有） | 精确蒙版/图层合成 |
| 滤镜预设 | HSL 分色调整（少数 App 有） | 景深合成/焦点堆叠 |

### 核心约束

```
手机后期 ≠ 电脑后期的简化版
手机后期 = 全局调整为主 + 极有限的局部能力
```

→ **前期拍摄必须把最关键的信息采集到位。后期只能"强化"，不能"创造"。**

## 二、前期拍摄的"后期意识"原则

### 2.1 曝光：宁可稍欠，不要过曝

```
手机传感器对过曝的容忍度远低于欠曝。
→ 高光一旦"死白"，任何 App 都救不回来
→ 暗部欠曝 1-2 档，后期可以提亮（会有噪点，但能用）

操作：点按画面最亮的部分对焦 → 长按锁定 → 向右拖一点找到平衡点
```

**各风格的曝光策略**：

| 风格 | 前期曝光建议 | 后期调整方向 |
|------|------------|------------|
| 安静真实 | 准确曝光，保留高光细节 | 微调对比度 → 暗部稍提亮 |
| 日系清新 | +0.3~0.7EV 轻微过曝 | 暗部再提亮 → 降低对比度 |
| 纪实粗粝 | -0.3EV 轻微欠曝 | 加对比 + 加颗粒 |
| 电影感 | 保留高光，暗部可稍欠 | 加对比 → 加晕影 |
| 极简高级 | 准确曝光 | 统一暗部 → 去色或降饱和 |
| Grunge | -0.7EV 欠曝 | 大幅加对比 + 加颗粒 |
| Lofi直闪 | 闪光灯自动 | 加暖色温 + 加颗粒 |
| 胶片复古 | 准确偏欠 | 暖化色温 + 加颗粒 + 暗部提绿 |

### 2.2 构图：留出裁剪空间

```
手机编辑最常用的操作 = 裁剪 + 旋转。
→ 前期构图时，四边各多留 5-10% 的画面
→ 不要"拍到刚刚好"——留给后期重新构图的余地
→ 特别是需要水平校正时，旋转会裁掉四个角

例外：特写/微距——构图就是最终构图，不留裁剪空间
```

### 2.3 色彩：RAW 不是万能的

```
iPhone Pro 系列支持 ProRAW → 后期空间大很多
但绝大多数用户的照片是 HEIC/JPEG → 后期色彩调整空间有限

策略：
  HEIC/JPEG → 前期拍准白平衡（后期只能微调）
  ProRAW   → 前期可以不管白平衡（后期随意调）
  
→ 不确定时：拍一张 HEIC + 拍一张 ProRAW（如果设备支持）
```

### 2.4 光线：后期改不了方向

```
后期可以调亮度，但不能把顺光变侧光、侧光变逆光。
→ 纹理、立体感、通透效果——全部依赖前期的光位
→ 如果现场光是漫射光，后期加对比 ≠ 侧光立体感

结论：光位决策是前期唯一的、不可逆的决策。拍错了就错了。
```

## 三、风格专属的"前期+后期"配合

### 3.1 安静真实（直出感最强的风格）

```
前期重点：准确曝光 + 白平衡锁定（不要 AWB 飘来飘去）
后期操作（≤3 步）：
  1. 微调曝光（±0.3EV 以内）
  2. 暗部提亮 5-10%（保留阴影细节但不过度）
  3. 可选：极轻微暖化色温（+50-100K）

→ 追求"像没调过一样"的效果
```

### 3.2 微观微距（逆光通透）

```
前期重点：曝光以高光为准（背景过曝可以接受）
后期操作：
  1. 降低高光 → 恢复透光物的纹理细节
  2. 加一点对比度 → 强化透光和不透光区域的差异
  3. 暗部稍压暗 → 让透光区更突出

→ "通透"感来自高光-暗部的对比，不是单纯提亮
```

### 3.3 电影感

```
前期重点：光源方向明确 + 画面有暗角潜力
后期操作：
  1. 加对比度（15-25%）
  2. 加晕影（暗角 10-20%）
  3. 色温偏暖（+200-500K）或偏冷（-200-500K 蓝调）
  4. 可选：降一点点饱和度（-5-10%）

→ 电影感的核心是"暗角+统一色调"
```

### 3.4 Grunge / 纪实粗粝

```
前期重点：欠曝 -0.3~0.7EV + 硬光 + 有明显纹理的表面
后期操作：
  1. 大幅加对比（30-50%）
  2. 加颗粒/噪点（10-20%）
  3. 黑白转换 — 或 — 大幅降饱和（-50-70%）+ 保留某一色调
  4. 暗部压暗到失去细节（故意的）

→ Grunge 是少数"后期比前期重要"的风格
→ 但前期必须有硬光纹理——软光场景无法通过后期补偿
```

## 四、不做后期也能出片的策略

> 以下风格几乎不需要后期，适合"拍完就发"的使用场景：

| 风格 | 完全直出的条件 | 为什么可以不调 |
|------|-------------|-------------|
| 安静真实 | 准确曝光 | 追求的就是"没调过"的观感 |
| 日系清新 | +0.3EV 拍摄 | 轻微过曝本身已接近日系效果 |
| Lofi直闪 | 开闪光灯拍 | 闪光灯自带风格——后期反而破坏 |
| 极简高级 | 准确曝光+干净背景 | 极简依赖构图，不依赖后期 |
| 微观微距·通透 | 逆光准确曝光 | 逆光的通透感是物理现象，不是后期 |

## 五、常见后期陷阱

| 陷阱 | 表现 | 避免方式 |
|------|------|---------|
| 过度锐化 | 边缘白线、皮肤塑料感 | 锐化 ≤ 15%；人像不锐化 |
| 过度 HDR | 画面灰平、无阴影 | 保留一些纯黑和纯白区域 |
| 过度饱和 | 色彩溢出、不自然 | 饱和度 ≤ +15%；多用"自然饱和度" |
| 过度降噪 | 皮肤像蜡像 | 接受一点噪点——是真实感的一部分 |
| 滤镜过重 | 看不出原来拍的什么 | 滤镜强度 ≤ 50% |
| 提暗过猛 | 暗部发灰、噪点爆炸 | 暗部就是暗部——不全提亮 |
