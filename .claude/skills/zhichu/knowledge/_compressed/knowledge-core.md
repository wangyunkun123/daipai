## 三、风格匹配逻辑 v2.0 🆕

### AI 驱动发现 + 知识缓存加速

**v1.0**：题材+光线+情绪 → 查 19 行静态表 → 匹配不到走兜底
**v2.0**：场景 → AI 搜索全球最佳匹配 → 规则护栏过滤 → 知识缓存加速

### 匹配流程

```
Step 1: 规则护栏 — 硬过滤
  light-router → 排除物理不可行（顺光拍不了逆光通透）
  user-capability → 排除设备做不到（没长焦拍不了空间压缩）

Step 2: AI 搜索发现 — 主匹配
  WebSearch × 3-5：搜索这个场景条件下的全球最佳风格
  输出：3-5 个推荐风格 + 每个的理由和参考

Step 3: 知识库对比
  AI 推荐 ∩ 知识库已有 → ✅ 直接使用（快速通道）
  AI 推荐 - 知识库已有 → 🆕 新发现！采纳并自动注册
  AI 推荐包含已有风格变体 → 🔄 变体发现，标注 sub-type

Step 4: 输出匹配
  primary + alternatives + discoveries + excluded
```

| 活力感 | 跳跃、跑步、大幅度肢体动作、连拍 | "我数三二一你跳——别管好不好看，跳就对了" |
| 沉静感 | 坐姿端正、手放膝上、正视前方或微低眉 | "坐好，深呼吸，吐气的时候放松眉头" |

### 手部速查

| 手部动作 | 适合场景 | 视觉效果 |
|---------|---------|---------|
| 单手扶帽檐 | 户外、逆光 | 腋下三角→显瘦，帽檐阴影→层次 |
| 双肩背包肩带（拇指扣背带上） | 徒步、旅行 | 最自然的"手有事做" |
| 单手持运动器材 | 运动场 | 手臂自然弯曲=关节留白 |
| 手插前裤袋（拇指露外面） | 街拍、日常 | 拇指外露=手没"消失" |
| 一手插袋一手拿东西 | 城市、咖啡馆 | 双手不同动作=画面丰富 |
| 手背在身后 | 看风景时 | 背影+安静观看 |
| 双手握暖杯/水瓶 | 冷天户外、室内 | 生活感+暖意 |

### 🆕 多人/群组姿势

| 人数 | 编排策略 | 空间关系 | 避免 |
|------|---------|---------|------|
| 2人 | 一前一后（深度）/并排（平等）/面对面（互动） | 利用高度差（一站一坐）创造层次 | 两人完全平行站立（僵硬） |
| 3-4人 | 三角形/菱形分布——不排成一条线 | 视线方向要有人"对内"有人"对外"，避免全部看镜头 | 横向排成一排 |
| 5人+ | 分组——前排坐+后排站，或自然散布 | 利用前景人物做框架/虚化，群组在纵深方向分布 | 全部正对镜头整齐排列 |

### 🆕 坐地姿势专项（地面，非椅子）

| 姿势 | 动作指令 | 构图要点 | 适用场景 |
|------|---------|---------|---------|
| 屈膝抱腿 | "膝盖收起来，手臂轻轻环住——不是抱紧，是搭着" | 侧面拍，脊柱形成C型曲线 | 运动后休息、草地野餐 |
| 双腿侧放 | "腿往一边自然放着，上面的手撑在身后" | 对角线构图——腿沿画面对角线延伸 | 网球场/操场地面 |
| 盘腿坐 | "盘腿坐好，手自然放膝盖上——像打坐但不用那么端正" | 正面或45°，手在膝盖上形成三角 | 草地、户外地面 |
| 一人坐一人站 | "你坐着，你站她旁边——不用弯腰凑近，正常站着就行" | 高度差=天然层次，低角度拍 | 运动场、公园 |
| 手撑身后仰 | "手撑在身后，上半身微微后仰，脸朝向阳光" | 侧面拍——手臂支撑线+身体斜线 | 海滩、草地、运动场 |

### 姿势指令的错误-修正回路

```
指令 → 观察效果 →
  ├─ 做对了 → 按快门 ✅
  └─ 没到位 →
      ├─ 原因A（太紧张）→ "放松，就当我不在——你先喘口气"
      ├─ 原因B（没听懂比喻）→ 换物理指令："手放这里，肩膀往后转一点点"
      └─ 原因C（身体受限）→ 换姿势："这个动作不舒服的话，试试把手放口袋里"
```

## 八、审美批判四维速查

| 维度 | 核心问题 | <6分信号 |
|------|---------|---------|
| 叙事完整性 | 这张照片在讲什么？观者看完记住什么？ | "和X方案讲同一件事" / "看完没感觉" |
| 调性统一度 | 色彩/光质/质感统一吗？矛盾是有意的吗？ | "没啥冲突但也没记忆点" / "哪张都行" |
| 取舍合理性 | 保留了什么、排除了什么？理由成立吗？ | "什么都在画面里" / "没有果断的取舍" |
| 破格目的性 | 破格获得了什么？没破格是否太安全？ | "太稳了" / "和其他8张没本质区别" |

### 评分标准
- **8-10**：有明确艺术意图，观者能感知"这是故意的" → 保留 ✅
- **6-7**：技术没问题但缺记忆点 → "平淡方案" ⚠️（保留最好的1-2套，其余淘汰）
- **<6**：有明显问题 → 淘汰 ❌

### 缺陷→大师→修复方向

| 缺陷维度 | 需要的能力 | 对应大师 | 修复方向 |
|---------|----------|---------|---------|
| 叙事弱 | 用画面讲故事 | Crewdson(电影单帧)/Eggleston(日常隐喻) | 加一个叙事锚点（一个动作/一个物体/一道光） |
| 调性平淡 | 色彩/光质做态度 | Gruyaert(色彩对位)/Leiter(透过介质) | 强化一个色彩关系或加一层遮挡 |
| 取舍无胆 | 敢做减法 | Wolf(极致密度)/Sugimoto(极简到概念) | 去掉画面中可有可无的元素 |
| 破格不够 | 打破安全区 | Moriyama(高反差粗粝)/Tillmans(什么都可以) | 故意打破一条规则并标注意图 |
| 构图中规 | 不常规视角 | Rodchenko(极端角度)/何藩(几何光影) | 换一个没有人用过的机位 |
| 情绪缺位 | 让人感受到情绪 | Goldin(亲密日记)/滨田英明(空气感温柔) | 找到一个真实的情绪触发点 |

> → 典藏层：`aesthetic-grammar/critique-framework.md` + `matching/master-router.md`

## 十二、方向选择速查表 v2.0 🆕

### 三方向审美梯度

| 方向 | 定位 | 约束 | 用户心理 |
|------|------|------|---------|
| 🟢 现在就拍 | 零门槛，30 秒出片 | 光线+设备双硬约束 | "我就想拍张好看的照片" |

| ✨ 脑洞大开 | 摄影的可能性 | 无硬约束（如实标注条件） | "哇，原来摄影还可以这样拍" |

### 🟢 现在就拍筛选

```
Step 1: 可用风格池 ∩ 可执行性 = 🟢
Step 2: 操作步数排序（0 步 > 1 步 > 2 步）
Step 3: style-router 匹配分数降序 + 审美主张 primary 方向优先
→ TOP 1。兜底：🟡 中操作 ≤ 2 步的
```

| 题材 | 软光场景 | 硬光场景 | 漫射光场景 |
|------|---------|---------|----------|
| portrait | 日系清新 / 安静真实 / 森系 | 杂志时尚 / 电影感 | 安静真实 |
| landscape | 极简高级 / 日系清新 | 纪实粗粝 / 极简高级 | 极简高级 |
| still_life | 安静真实 / 微观微距 | 极简高级 | 安静真实 |
| street | 县城记忆 / 胶片复古 | 纪实粗粝 | 纪实粗粝 |
| event | 纪实粗粝 / 安静真实 | 纪实粗粝 | 纪实粗粝 |

### 🔥 最出片筛选

```
有0E数据: 当地流行风格 ∩ 可用池 → 排除「现在就拍」→ 社交验证降序 → TOP 1
无0E数据: 可用池 → 排除「现在就拍」→ 高视觉辨识度优先 → TOP 1
```

高辨识度：电影感 / 纪实粗粝 / 杂志时尚 / Grunge / 梦幻柔美 / Lofi直闪
中辨识度：日系清新 / 胶片复古 / 微观微距 / 县城记忆 / 森系 / 便利店美学
低辨识度：安静真实 / 极简高级（不用于「最出片」）

### ✨ 脑洞大开筛选 🆕

```
Step 1: 取消设备硬约束（可以假设有长焦/大光圈/闪光灯）
        保留光线物理约束（顺光不能拍逆光通透）
Step 2: AI 自由搜索——不限于手机能拍的
        WebSearch × 3-4：
        - "{场景} creative photography inspiration editorial"
        - "{场景} art photography experimental technique"
        - "{类似场景} famous photograph iconic image"
Step 3: 从最酷的方案中选 TOP 1
        标准：创意冲击力 + 审美启发性 + 可解释性
Step 4: 如实标注条件（设备/光线/时机/后期）
        + 🟡 iPhone 替代方案
        + 迷你版（现在就能做的小版本）
```

**脑洞类型**：
- 大师狂想：如果某位大师站在这里会怎么拍
- 媒介跨越：不只拍照——Live Photo/慢动作/组图项目
- 时空假设：换个时间/季节/天气来能拍出什么
- 技法极限：用最极致的摄影技法诠释这个场景
- 概念重构：重新定义"这是什么"（不是人像，是关于陪伴的纪实）
- 跨界混搭：把不相关的审美系统嫁接过来

**安全阀**：
- 不安全的机位不推荐
- 每个脑洞附带"🟡 现在就能做的小版本"
- 脑洞的最终目的是让用户更欣赏「现在就拍」

> → 典藏层：`matching/direction-selector.md` v2.0
