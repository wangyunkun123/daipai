# 光线决策树

## 一句话定义

摄影是用光作画。光有四个物理属性——**方向、质量、光比、色温**——每一个都可以成为创作工具，而不是被动接受的条件。

—— 框架参考 Hunter《Light Science & Magic》

---

## 原理：光的四个物理属性

Hunter 将光的核心变量拆解为方向（direction）、质量/软硬（quality）、反差/光比（contrast），色温（color temperature）则是常被补充讨论的第四个维度：

### 1. 方向（光从哪来？）

光的方向决定了**阴影落在哪**。阴影的分布定义了画面的立体感和空间感。

- **顺光**（光从摄影师背后照向模特）：阴影藏在主体后面，色彩还原准确、无大面积阴影。但纯正面顺光画面扁平、面部立体感弱、易显油光。改良方案：光源抬高 45° 形成高位顺光，保留轻微轮廓层次。适合极简静物、日系清新平涂人像
- **侧光**（光从侧面照来，与相机-模特轴线成 90°）：阴影落在主体一侧，产生最强的立体感。人脸一半亮一半暗，适合强调面部结构和质感
- **逆光**（光从模特背后照向相机）：模特正面在阴影中，但轮廓被光照亮。适合氛围感人像、剪影、发光发丝效果
- **顶光**（光从正上方照下）：眼窝、鼻子下方产生深阴影。通常被认为最不讨喜的人像光线。改良方案：① 补反光板填充眼窝阴影 ② 模特低头弱化眼下阴影 ③ 转移至建筑阴影中拍摄 ④ 主动利用顶光进行抽象光影创作（参考黑白建筑摄影与街头摄影中利用强顶光制造几何光影的手法）

### 2. 质量（光硬还是软？）

光的质量由**光源的相对大小**决定——不是光源的绝对尺寸，是光源相对于被摄体的大小。

- **硬光**：小光源 → 锐利阴影、高对比、清晰的阴影边缘。太阳（虽然巨大但因为距离远在天空中视直径只有 0.5°）是典型的"小光源"，产生硬光
- **软光**：大光源 → 柔和阴影、低对比、平滑的阴影过渡。阴天的天空（整个天空穹顶就是一个巨大的散射光源）产生软光。窗边光也是软光（窗户 = 大面积光源）

**硬光 vs 软光不是好坏之分，是风格之分：**
- 硬光 → 戏剧性、力量感、几何感、黑白摄影（森山大道）
- 软光 → 柔美、舒适、色彩表现、人像（滨田英明）

### 3. 光比（亮面和暗面的亮度差）

光比是独立于方向和质量的第三个物理变量——它决定了画面的反差程度和戏剧张力。

- **光比 1:2 ~ 1:4**：柔和、自然、暗部保留充分细节。适合柔美人像、日常记录。HDR/动态范围优化通常在 1:4 以内效果最佳
- **光比 1:8 以上**：戏剧性、高反差、暗部接近纯黑。适合黑白摄影、剪影、森山大道风格。小传感器设备在这个光比下暗部可能产生明显噪点——当作风格接受而非技术缺陷
- **光比控制**：顺光光比最小（亮暗面接受的几乎是同一光源），侧光光比中等，逆光光比最大。反光板/白色墙面/水面可以降低光比（给暗面补光）

### 4. 色温（光是什么颜色？）

- **暖光**（2000-4000K）：日出日落约 3000-4000K、白炽灯约 2700K、烛光约 1800K → 温馨、怀旧、亲密
- **中性光**（5000-6500K）：正午日光约 5500K、电子闪光灯约 5500-6000K → 色彩还原准确、客观
- **冷光**（7000-10000K+）：阴天/开阔阴影约 7000-8000K、蓝调时刻约 9000-10000K → 清冷、忧郁、高级感

**关键认知**：人眼会自动白平衡，所以你不会「感觉到」室内灯光是橙色的。但相机会忠实记录色温差。利用这个差异——保留暖色调是一种风格选择，不是技术失误。

**白平衡实操**：自动白平衡（AWB）在混合光场景（室内暖灯 + 窗外日光）中可能左右摇摆——画面忽冷忽暖。如果场景色温复杂，锁定白平衡或后期统一色温方向（选择暖调或冷调为主导）。

```
├─ 1. 光从哪个方向来？
│   ├─ 顺光（光在你背后）
│   │   └─ 策略：
│   │       ├─ 色彩优先方案：用色彩作为画面的核心看点
│   │       ├─ 侧移机位：走到侧面 2-3 步，把顺光变成侧光
│   │       └─ 适合：服装细节、鲜艳色彩、蓝天白云
│   │
│   ├─ 侧光（光从侧面来）
│   │   └─ 策略：
│   │       ├─ 这是最佳人像光线，无需补偿
│   │       ├─ 注意：光比（亮面与暗面的亮度差）
│   │       │   ├─ 光比小（暗面仍有细节）→ 柔美人像
│   │       │   └─ 光比大（暗面接近黑）→ 戏剧性、黑白
│   │       └─ 开启 HDR/动态范围优化可压缩光比保留暗部细节
│   │
│   ├─ 逆光（光从模特背后来）
│   │   └─ 策略：
│   │       ├─ 方案 A：人像补光 → 以人脸为曝光基准 + 适当提高曝光补偿
│   │       │   （牺牲背景高光，背景会过曝但人脸正常）
│   │       ├─ 方案 B：剪影 → 以天空/亮部为曝光基准 + 降低曝光补偿
│   │       │   （人脸成纯黑剪影，天空和轮廓正常曝光）
│   │       ├─ 方案 C：发丝光 → 用模特的头挡住太阳主体，
│   │       │   偏一点让阳光从头发边缘透出形成发光轮廓
│   │       └─ 方案 D：利用反光 → 找白色地面/浅色墙壁/水面作为天然反光板
│   │
│   └─ 顶光（正午，光从头顶下来）
│       └─ 策略：
│           ├─ 方案 A：移到阴影里（找建筑阴影/树荫）
│           ├─ 方案 B：仰拍 → 让天空变成背景，顶光就变成...还是顶光但人脸的阴影被帽子/头发挡住
│           ├─ 方案 C：低头/侧头 → 避免眼窝黑洞
│           ├─ 方案 D：何藩策略 → 不拍人脸，拍光影的几何构成，人是剪影或配角
│           └─ 方案 E：等待 → 正午前后 2 小时是光线最差的时段，如果可以等...
│
├─ 2. 光硬还是软？
│   ├─ 硬光（正午太阳/直射灯）
│   │   └─ 策略：
│   │       ├─ 利用阴影的几何感 → 引导线/对角线/对称
│   │       ├─ 黑白/高反差 → 森山大道风格
│   │       ├─ 找半透明遮挡（树荫/薄云/窗纱）→ 把硬光变成软光
│   │       └─ 不适合：柔美人像、婴儿/儿童照
│   │
│   └─ 软光（阴天/阴影/窗边/黄金时刻）
│       └─ 策略：
│           ├─ 柔美肖像的最佳光线 → 适合近景和特写
│           ├─ 色彩表现佳 → 服装/场景的色彩能准确呈现
│           └─ 注意：软光可能「太平」，需要靠构图增加张力
│
├─ 3. 色温是什么？
│   ├─ 温暖光线（日落/黄昏/室内灯）
│   │   └─ 保留暖色调！这是氛围资产，不是白平衡需要「纠正」的东西
│   ├─ 冷调光线（阴天/阴影/蓝调时刻）
│   │   └─ 可以强调清冷感，或等黄金时刻的自然暖光来中和
│   └─ 混合色温（室内灯+窗外日光）
│       └─ 选择一方为主导色调，或利用冷暖对比的视觉张力
│
└─ 4. 需求曝光的创作选择
    ├─ 亮调（High Key）：以脸部为准，背景亮到接近过曝
    │   └─ 风格：轻盈、清新、日系（滨田英明）
    ├─ 暗调（Low Key）：以脸部为准，背景暗到接近全黑
    │   └─ 风格：深沉、戏剧性、质感（Peter Lindbergh）
    └─ 中调：均匀曝光，信息完整
        └─ 风格：自然、记录感、真实
```

## 黄金时刻专项

### 什么是黄金时刻

日落后/日出前约 20-40 分钟。太阳在地平线下，但天空仍然明亮——整个天空变成巨大的柔和光源。

**为什么黄金时刻的光线无可替代：**
- 方向：从地平线下方向上照，是全天唯一的「底光」来源——光从下方来，在眼窝下方产生微妙的补光
- 质量：巨大光源（整个天空穹顶）→ 极致柔软的散射光
- 色温：从暖金黄（日落初期）过渡到蓝紫（蓝调时刻）→ 15 分钟内上天入地的色温变化

### 黄金时刻时间窗口

| 时段 | 距日落 | 光色 | 适合 |
|------|--------|------|------|
| 黄金时刻前期 | 日落前 30min-日落 | 暖金黄 | 暖调人像、逆光剪影 |
| 黄金时刻后期 | 日落后 0-15min | 粉-紫渐变 | 柔和色彩、人像 |
| 蓝调时刻 | 日落后 15-30min | 深蓝-紫 | 城市灯光+蓝色天空、冷调氛围 |

### 黄金时刻操作要点

- 黄金时刻光比仍然可能很大（天空亮、地面暗）
- 以人脸为曝光基准时天空会过曝——这是可接受的（金黄色的过曝天空比正常曝光的灰天空好看）
- 蓝调时刻光线已经很暗（EV 可能只有 5-7），手持拍摄需要稳定支撑
- **最关键的一条**：黄金时刻的光变得很快。先拍最有价值的方案，再拍锦上添花的。15 分钟后光就不一样了

## 曝光作为创作工具

曝光不只是「让照片不黑不白」。曝光的本质是选择让画面的哪一部分落在「正常」亮度、哪一部分故意偏亮或偏暗。

> **关于 Adams 区域系统**：Ansel Adams 的 Zone System 是一套完整的影调管理方法论——将画面各处影调「预视觉化」后分配到 Zone 0（纯黑）到 Zone X（纯白）十个区，并通过测光、曝光、冲洗来精确控制。本节提供的是该精神的极简移植——仅保留了「主体放在哪个亮度区域」这一核心决策——而非区域系统本身。

### 曝光的三个创作决策

| 决策 | 操作 | 画面效果 | 适用 |
|------|------|---------|------|
| 以人脸为准 | 对人脸测光 → 锁定曝光 | 人脸正常，背景可能过曝/欠曝 | 人像为主 |
| 以天空/亮部为准 | 对亮部测光 → 降低曝光补偿 | 天空保留细节，主体成剪影 | 剪影、氛围 |
| 以暗部为准 | 对暗部测光 → 提高曝光补偿 | 暗部提亮，亮部过曝 | 逆光补光 |

### 曝光补偿的操作方法

1. 对焦在你想「正常曝光」的区域
2. 锁定 AE/AF（自动曝光/自动对焦锁定）
3. 在 ±2EV 范围内调整曝光补偿
4. 在极端光比下（如逆光人像），设备可能无法同时保留天空和脸部——**这是物理限制不是错误，选择你要保留的那个**

## 光线与构图的结合

光是构图的骨架。Barnbaum 和 Freeman 都强调：**光影的分布本身就是一种构图。**

- 一束光从窗户照进来在地上形成一个亮块 → 这个亮块就是天然的「视觉重心」（引导线 + 光 = 双倍引力）
- 一排柱子投下的阴影形成交替的亮暗条纹 → 这就是天然的「节奏感」
- 何藩的整个摄影体系就是这句话的终极示范：**光画出了几何，几何就是构图**
