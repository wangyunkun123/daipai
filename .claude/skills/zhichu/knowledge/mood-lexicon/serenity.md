# 宁静 · Serenity

## 情绪定义

**宁静 = 「时间停在这里」。** 画面中没有焦虑、没有紧迫、没有噪音——观众看完觉得呼吸慢了下来。宁静不是空洞的无聊，是充实的不动。

**用户常说的相关词汇**：宁静、安静、治愈、禅意、慢下来、静的、「好想待在这里」。

**区分**：宁静（serenity）= 静态 + 平静 + 充实。孤独（solitude）= 一人 + 距离 + 空。温暖（warmth）= 暖色 + 亲密。三者可以重叠但不相同。

---

## 视觉翻译

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩倾向 | 冷调浅色——淡蓝、淡绿、灰白、奶白 | 冷色降低心率——有生理基础 |
| 饱和度 | 低——全局 -20% ~ -40% | 浓色 = 刺激，淡色 = 平静 |
| 色温 | 中性偏冷——5000-6500K | 不冷到疏离，但也不暖到兴奋 |
| 光质 | **软光**——散射光、阴天光、窗边漫射光 | 硬光的锐利阴影 = 视觉紧张 |
| 光比 | 极低（1:1.5 ~ 1:2） | 几乎没有阴影——画面中没有冲突 |
| 对比度 | 低——柔和高光过渡 | 视觉上没有「刺激点」 |
| 构图密度 | 低——元素稀疏 | 元素多 = 信息多 = 大脑忙碌 |
| 模特状态 | 静止——闭眼、低头、静坐、看向平静水面 | 没有任何「正在做」的动态 |
| 景别倾向 | 中景（安静的存在）+ 远端特写（水的波纹/树叶） | 太近 = 亲密关系 = 打破宁静的旁观视角 |
| 后期方向 | 低对比 + 冷色偏移 + 柔和锐化 | |

## 氛围感元素

| 载体 | 宁静情绪中的表现 |
|------|----------------|
| **空气质感** | 晨雾、静水面的反光、静止空气中的微尘 |
| **动态细节** | **几乎不需要动态**——宁静的极致是「没有事情在发生」 |
| **留白情绪** | 宁静的留白是「不必填满」——平静水面的大面积留白、空白的天空 |

---

## 廉价 vs 高级

| | 廉价宁静 | 高级宁静 |
|--|---------|---------|
| 表达 | 「什么都没有」→ 无聊 | 「一切都刚好，不必更多」→ 满足的静止 |
| 色彩 | 饱和度降到零 → 死气沉沉 | 有颜色但淡雅——像水彩画 |
| 光线 | 没有光线设计——随便拍的阴天 | 阴天散射光的柔和 + 微妙的明暗变化 |
| 噪点 | 高 ISO 噪点 → 视觉不安静 | 干净的画质 → 视觉上没有干扰 |

## 场景适配

| 场景 | 适配度 | 说明 |
|------|--------|------|
| 海边 | ★★★★★ | 平静海面 + 低对比天空——宁静经典 |
| 公园/自然 | ★★★★★ | 湖水/树荫/草地——自然自带宁静 |
| 咖啡厅/室内 | ★★★★☆ | 窗边 + 书 + 一杯茶 |
| 夜景 | ★★☆☆☆ | 蓝调时刻可做，深夜较难 |
| 街拍 | ★★☆☆☆ | 需要清晨空荡街道 |

## 复合情绪

宁静 + 温暖 = 「治愈」——阳光落在安静的角落。
宁静 + 孤独 = 「静谧的独处」——一人 + 大环境 + 绝对安静。
宁静 + 怀旧 = 「旧时光里的安静下午」——暖灰调 + 旧物 + 软光。
