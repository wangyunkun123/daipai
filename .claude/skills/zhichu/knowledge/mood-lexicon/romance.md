# 浪漫 · Romance

## 情绪定义

**浪漫 = 「像电影里最好的那场戏」。** 画面传达的是温柔的心动、金色的亲密、被珍视的瞬间。浪漫不是色情——浪漫是「这一刻值得被记住」。

**用户常说的相关词汇**：浪漫、心动、唯美、甜蜜、「电影里的爱情」、温柔到想哭、梦幻、金色时刻。

---

## 视觉翻译

| 参数 | 取值 | 说明 |
|------|------|------|
| 色彩倾向 | **暖色为主**——金色、琥珀、暖粉、奶油白 | 金色 = 浪漫的默认色 |
| 饱和度 | 中——保留暖色的浓度但不刺眼 | 金色需要一定饱和度来发光 |
| 色温 | 偏暖——4000-5000K | 黄昏色温 3000-4000K 最浪漫 |
| 光质 | **极致软光** + 逆光/侧逆光 | 逆光 = 发光轮廓 = 浪漫的视觉标志 |
| 光比 | 中低（1:2 ~ 1:4） | 保留柔和阴影——不是没有阴影，是阴影很温柔 |
| 对比度 | 中低——柔和高光过渡 | 金色高光向奶油色溢出 |
| 构图密度 | 中——不过度留白也不拥挤 | 浪漫需要语境——有人 + 有环境 |
| 模特状态 | 亲密互动——对视、牵手、拥抱、额头相抵 | 不一定需要两个人——一个人的浪漫是「等待/思念中的浪漫」 |
| 景别倾向 | 近景（亲密）+ 中景（语境） | 远景太远——看不到浪漫的情绪 |
| 后期方向 | 暖色高光 + 柔和对比 + 可选柔焦 | |

## 氛围感元素

| 载体 | 浪漫情绪中的表现 |
|------|----------------|
| **空气质感** | 逆光中的微尘/水雾——金色微粒漂浮在空气中 |
| **动态细节** | 发丝在逆光中发光、裙摆轻摆、两人手之间的空隙、对视的瞬间 |
| **留白情绪** | 浪漫的留白是「为对方留的空间」——画面中一个人看向画外的空处，等另一个人走进来 |

---

## 廉价 vs 高级

| | 廉价浪漫 | 高级浪漫 |
|--|---------|---------|
| 表达 | 过度亲密动作 + 强光 + 高饱和暖色 | 克制的亲密——手指相触、对视未吻、一人等待的背影 |
| 色彩 | 全局暖色滤镜——橙色皮肤 | 肤色自然 + 环境暖色——人是人，光是光 |
| 光线 | 不分光质强行暖光 | 逆光金色轮廓 + 柔光 |
| 动作 | 标准情侣 pose | 有叙事感的互动——像电影中的一个场景 |

**核心**：高级浪漫不是「看我们多甜蜜」，是「这一瞬间的温柔值得被记住」。

## 场景适配

| 场景 | 适配度 | 说明 |
|------|--------|------|
| 海边 | ★★★★★ | 海边黄昏——金色水面 + 逆光剪影 = 浪漫的终极配方 |
| 公园/自然 | ★★★★☆ | 花丛/树下/草地——自然浪漫 |
| 咖啡厅/室内 | ★★★★☆ | 窗边双人 + 暖灯——室内浪漫 |
| 游艇 | ★★★★★ | 海上日落 + 海风 + 双人——奢侈浪漫 |
| 夜景 | ★★★☆☆ | 城市灯光 + 双人剪影——城市浪漫 |

## 技术联动

| 技术维度 | 建议 |
|---------|------|
| 焦段 | 标准-中焦（50-85mm）——压缩距离 = 拉近两人的关系 |
| 景别 | 近景 + 中景——亲密到对话距离 |
| 光线 | 逆光/侧逆光 + 金色时刻 + 柔光 |
| 色彩 | 暖色为主 + 保留自然肤色 |
| 构图 | 三分法（视线的方向留白）、框架（框住两人的世界） |

## 大师关联

- **Valenzuela**（《拍出绝世美姿》）：浪漫人像的姿态管理——身体的亲密 ≠ 照片的亲密，视觉的亲密来自线条的交汇
- **Tim Walker**：童话浪漫——不只是两人的浪漫，是「整个世界都变得浪漫」

---

## 复合情绪

浪漫 + 怀旧 = 「那个回不去的浪漫时刻」——胶片暖调 + 褪色。
浪漫 + 忧伤 = 「笑着的眼泪」——暖色调 + 疏离的表情。
浪漫 + 自由 = 两人在开阔天地间——「世界很大，但我们在彼此身边」。
