# 情绪词库

## 一句话定义

**情绪词库 = 中文互联网审美词汇 → 视觉参数的翻译层。** 用户说「我要松弛感」，AI 需要知道这意味着：大留白 + 自然光 + 非摆拍瞬间 + 低对比度 + 暖色偏移。

---

## 原理

### 为什么需要情绪词库

中文摄影社区（小红书、微博、Instagram 中文圈）自发生长出了一套独特的审美语言——「氛围感」「松弛感」「高级感」「破碎感」——这些词不是传统摄影教材的术语，却是真实用户在描述「想要什么感觉的照片」时使用的词汇。

**核心洞察**（来自 Claude 的提议）：
> 如果 ShotOracle 面向中文用户，这套词汇本身就该是审美层的一个独立子域，需要给每个词做「视觉翻译」。

**核心洞察**（来自豆包的模块 2）：
> 氛围感是「环境 + 光影 + 情绪细节」的综合审美，廉价氛围感靠堆滤镜，高级氛围感靠少元素、弱对比、柔和过渡、留想象空间。

### 审美词汇的视觉翻译机制

每个中文审美词汇，对应一组可量化的视觉参数：

```
用户说的词 → 分解为：色彩倾向 + 光质 + 构图密度 + 对比度 + 模特状态 + 后期方向
```

**示例：「松弛感」的视觉翻译**

| 参数 | 取值 |
|------|------|
| 色彩倾向 | 暖色偏移、低饱和 |
| 光质 | 软光、低光比 |
| 构图密度 | 大量留白、画面元素稀疏 |
| 对比度 | 低对比、柔和高光过渡 |
| 模特状态 | 不经意的瞬间、不看镜头、自然动作 |
| 后期方向 | 低对比曲线、暖色高光、保留肤色纹理 |
| 景别倾向 | 中景为主（对话距离） |
| 焦段倾向 | 广角（35mm 等效）→ 自然透视 |

| 情绪 | 英文 | 核心视觉标志 | 一句话 | 最适风格 |
|------|------|-------------|--------|---------|
| 温暖 | Warmth | 暖色 + 软光 + 亲密距离 | 「这个世界对我是温柔的」 | 日系清新 |

### 每个情绪文件的结构

```
1. 情绪定义 —— 一句话 + 用户常说的相关词汇
2. 视觉翻译 —— 色彩/光质/构图/对比度/模特状态/后期
3. 氛围感元素 —— 空气质感/动态细节/留白情绪（豆包框架）
4. 廉价 vs 高级 —— 该情绪容易踩的坑
5. 场景适配 —— 什么场景最适合表达这种情绪
6. 技术联动 —— 焦段/景别/光线/色彩的具体参数
7. 大师关联 —— 哪位大师最擅长这种情绪
8. 破格方案 —— 什么时候反着来更高级
```

## 情绪浓度与审美判断

### 情绪的适度原则

情绪在照片中不是越多越好——**情绪的克制表达比满溢表达更耐看**。

| 浓度 | 效果 | 问题 |
|------|------|------|
| 太少 | 画面冷感、无情绪、「不知道这张照片要表达什么」 | 观众无法建立情感连接 |
| 适中 | 情绪可感知但不直白、给观众留解读空间、耐看 | — |
| 过多 | 糖水片、情绪绑架、「用力过猛」 | 直白的甜/悲 → 一次性消费品 |

**高级情绪 = 可感知但不点破。** 让观众自己去「发现」情绪，而不是把情绪标签贴在照片上。

### 情绪复杂度

最高级的照片情绪不是单一的——是复合的、甚至矛盾的情绪并存：

- 温暖 + 忧伤 = 「笑着的悲伤」→ 比单纯的温暖或忧伤耐看 10 倍
- 自由 + 孤独 = 「天地间只有我一个人，但我是自由的」→ 何藩的大部分作品
- 浪漫 + 疏离 = 「我们很近，但我们很远」→ 电影感的核心情绪配方

→ 复合情绪的具体操作见各情绪文件。

## 在方案生成中的使用

### 阶段 1（场景分析）的情绪分析步骤

```
场景分析 → 提取场景自带情绪基调
         → 匹配可强化的情绪方向
         → 用户输入情绪词汇 → 查表翻译为视觉参数
         → 输出：场景情绪基调 + 用户情绪偏好 = 方案情绪方向
```

### 阶段 2（方案生成）的情绪注入

每套方案从情绪词库中继承一个**情绪标签**，该标签决定：
- 色彩倾向的冷暖偏移
- 光线的软硬选择
- 留白的多少
- 模特的表情和眼神方向
- 后期的对比度和色调曲线

### 输出格式中的情绪字段

```
| 情绪 | 温暖（暖色偏移 + 软光 + 低对比 + 中景亲密距离） |
```
