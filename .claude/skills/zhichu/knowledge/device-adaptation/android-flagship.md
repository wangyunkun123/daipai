# 安卓旗舰设备档案

## 设备识别

**适用型号**（2024-2026 旗舰）：华为 Pura 70/80 Ultra、Mate 70/80 Pro；小米 14/15 Ultra；vivo X100/200 Pro/Ultra；OPPO Find X7/X8 Pro/Ultra；三星 Galaxy S24/S25 Ultra
**用户画像**：最大的中国市场用户群，焦段覆盖最全，AI 摄影最激进
**ShotOracle 关键适配**：品牌差异巨大——需要抽象共性 + 预留品牌特定适配空间

---

## 一、品牌差异总览

安卓旗舰不像 iPhone 那样统一——五个品牌，五种摄影哲学：

| 品牌 | 联名/核心技术 | 色彩科学倾向 | 长焦特色 | 人像风格 |
|------|------------|------------|---------|---------|
| **华为** | XMAGE | 偏暖、浓郁的"中国审美"——蓝天更蓝、肤色更红润 | 长焦微距（最近 5cm 对焦）| 默认美颜力度大 |
| **小米** | Leica | Leica 双画质：Leica Authentic（自然） / Leica Vibrant（鲜艳） | 多个中长焦（75mm + 120mm）| Leica 人像——偏暗调、保留质感 |
| **vivo** | ZEISS | ZEISS 自然色彩——偏真实但比 iPhone 暖 | 2 亿像素长焦（85mm）| ZEISS 人像包（Biotar/Sonnar/Distagon 虚化风格） |
| **OPPO** | Hasselblad | Hasselblad 自然色彩——最接近 iPhone 的安卓色彩 | 双潜望长焦（65mm + 135mm）| Hasselblad 人像——偏暖调、电影感 |
| **三星** | 无 | 偏冷/偏艳——"三星色"有争议 | 10× 超长焦（230mm）| 默认美颜适中 |

**对 ShotOracle 的意义**：不能像 iPhone 那样给出精确的操作指令（"用 3×"在三星上是 72mm、在华为上是 90mm）→ 方案生成时**用设备无关的焦段概念语言（超广角/广角/中焦/长焦）**，设备筛选层再翻译为各品牌的具体操作。

---

## 二、焦段与传感器配置（抽象共性）

安卓旗舰的共同特征：**四摄覆盖从超广角到超长焦的完整焦段。**

| 焦段类型 | 等效焦距范围 | 传感器面积 | 画质评级 | 备注 |
|---------|------------|----------|---------|------|
| 超广角 | 12-16mm | 中小 | ⭐⭐⭐ | 比 iPhone 超广角普遍更好 |
| 广角（主摄） | 22-24mm | 1 英寸或接近 | ⭐⭐⭐⭐⭐ | 1 英寸传感器（小米/vivo/OPPO）——手机画质天花板 |
| 中焦 | 50-90mm | 中 | ⭐⭐⭐⭐ | **这是安卓旗舰对 iPhone 的最大优势——有独立的 50-85mm 人像中焦** |
| 长焦/超长焦 | 100-230mm | 中小 | ⭐⭐⭐ | 100mm+ 全系覆盖；三星 230mm 独步 |

### 焦段优势对比（vs iPhone Pro）

| 焦段 | iPhone Pro | 安卓旗舰 | 胜出 |
|------|-----------|---------|------|
| 超广角 | 13mm f/2.2 | 12-14mm f/1.8-2.2 | 安卓（光圈更大） |
| 广角 | 24mm f/1.8 | 22-24mm f/1.4-2.0（1 英寸） | 安卓（传感器更大） |
| **中焦（50-85mm）** | **无独立——靠裁切** | **3-3.5×（65-90mm）独立光学** | **安卓大幅胜出** |
| 长焦（100-120mm） | 5× 120mm f/3.5 | 5-6×（120-135mm）f/2.6-3.5 | 安卓（光圈更大） |
| 超长焦（>135mm） | 无 | 10× 230mm（三星） | 安卓独占 |

## 三、核心优势

| 优势 | 说明 | 审美价值 |
|------|------|---------|
| **焦段覆盖最完整** | 12mm 超广角 → 230mm 超长焦——所有焦段方案都可以原生执行 | 所有摄影风格都有对应的原生焦段——方案不需要降级 |
| **中焦独立光学** | 50-85mm 人像焦段是独立镜头（非裁切）——透视和人像比例比 iPhone 裁切准确得多 | 人像摄影（近景/胸像/特写）的最大优势 |
| **1 英寸传感器** | 小米 14/15 Ultra、vivo X100 Ultra、OPPO Find X7 Ultra 的主摄达到 1 英寸——动态范围接近入门微单 | 弱光 + 动态范围 = 手机画质天花板 |
| **长焦微距** | 华为/小米/OPPO 的长焦可对焦至 5-10cm——用长焦拍微距 | 微观微距风格的完美设备 |
| **AI 场景识别** | 自动识别场景并优化（蓝天/绿叶/食物/人像/夜景） | 不需要用户懂参数——自动出片 |
| **夜景模式领先** | 多帧合成 + AI 降噪——弱光表现整体优于 iPhone | 暗光人像/夜景街拍/蓝调时刻 |

## 四、核心短板

| 短板 | 说明 | 方案规避策略 |
|------|------|------------|
| **AI 过度处理** | 最大短板——皮肤磨皮过度（塑料感）、蓝天过饱和、暗部过度提亮。AI 努力「美化」但结果不自然 | 建议关闭美颜/降低 AI 介入强度；或拍 RAW |
| **色彩科学不稳定** | 品牌间差异巨大 + 同品牌不同场景色彩不同——不像 iPhone 的「所见即所得」 | 方案中降低对精确色彩的依赖；依靠后期微调 |
| **品牌间操作不一致** | 华为的「3×」= 某焦距 / 小米的「3.2×」= 另一焦距 / 三星的「3×」= 又一个 → 不能给统一的「用 3×」指令 | 方案用设备无关语言（「中焦 50-85mm」）→ 设备筛选层翻译 |
| **快门延迟不一** | 部分品牌连拍速度/快门反应不如 iPhone 稳定 | 方案中不过度依赖「精确到 0.1 秒」的时机 |
| **白平衡偏移** | 部分品牌室内暖光下白平衡偏黄/偏绿 | 方案中建议后期微调白平衡 |
| **系统更新改变成像** | 安卓厂商在系统更新中调整相机算法——今天好看的色调下次更新可能变 | 方案不能过度绑定某品牌的特定色彩风格 |

## 五、知识→操作翻译表

### 焦段映射（设备无关 → 各品牌）

| 理论语言 | 通用指令 | 华为 | 小米 | vivo | OPPO | 三星 |
|---------|---------|------|------|------|------|------|
| 超广角 | 0.5-0.6× | 0.5× | 0.5× | 0.6× | 0.6× | 0.6× |
| 广角 | 1× | 1× | 1× | 1× | 1× | 1× |
| 中焦（50mm） | 2-2.5× | 2× | 2×（裁切） | 2× | 2× | 2× |
| 中长焦（70-90mm） | 3-3.5× | 3.5×（90mm） | 3.2×（75mm） | 3.7×（85mm） | 3×（65mm） | 3×（72mm） |
| 长焦（100-135mm） | 5-6× | — | 5×（120mm） | — | 6×（135mm） | 5×（110mm） |
| 超长焦（>135mm） | 10× | — | — | — | — | 10×（230mm） |

### 景深控制

| 理论语言 | 安卓旗舰操作 |
|---------|------------|
| 「浅景深」 | 1× 主摄（1 英寸传感器 = 比 iPhone 浅）+ 距离差策略。或 3-3.5× 中焦拍人像（最佳组合：中焦 + 靠近 + 背景远） |
| 「中等景深」 | 默认拍摄距离 2-5m |
| 「全景深」 | 0.5× 超广角 + 远距离——手机天然优势 |
| 「人像虚化风格」 | 各品牌人像模式可选虚化风格（vivo ZEISS Biotar = 旋转焦外 / 旋焦；小米 Leica = 暗调+质感保留） |

### AI 处理控制（关键操作）

| 想要的效果 | 操作 |
|-----------|------|
| 保留真实肤色纹理（不想要塑料脸） | **关闭美颜**——各品牌路径：人像模式 → 美颜 → 关/0；或在相机设置中降低 AI 场景优化 |
| 自然色彩（不要过饱和蓝天） | 关闭 AI 场景增强——华为：关闭「AI 摄影大师」/ 小米：选「Leica Authentic」/ vivo：选「ZEISS 自然」 |
| 最大后期空间 | 拍 RAW——各品牌路径不同但大多支持：华为 Pro 模式 / 小米 Pro 模式 / vivo 专业模式 / 三星 Expert RAW |

## 六、弱光策略

安卓旗舰的弱光表现普遍优于 iPhone（传感器更大 + AI 降噪更强）：

| 场景 | 策略 |
|------|------|
| 暗光人像 | 优先 1× 主摄（1 英寸）+ 中焦（3-3.5×）——两者传感器都够大。关闭人像模式（暗光下边缘切割差），用物理虚化 |
| 夜景手持 | 夜景模式（3-5 秒多帧合成）——安卓旗舰的夜景合成稳定性和画质领先 |
| 极暗 | 1× 主摄 + 夜景模式 + 稳定支撑。三脚架模式（部分品牌自动检测三脚架 → 启用 30 秒长曝光） |
| 蓝调时刻 | 超广角 + 夜景模式 = 城市夜景最强组合。安卓的超广角弱光表现优于 iPhone |

## 七、风格兼容性

| 风格 | 安卓旗舰兼容度 | 备注 |
|------|-------------|------|
| 日系清新 | ★★★★☆ | 中焦 50-85mm = 人像比例准确。需关闭 AI 过饱和 |
| 电影感 | ★★★★★ | 最佳设备——全焦段 + RAW + 暗调人像 |
| 杂志时尚 | ★★★★★ | 中焦 85mm + 1 英寸主摄 + ZEISS/Leica 人像 = 手机时尚摄影最强组合 |
| 纪实粗粝 | ★★★★☆ | 需关闭 AI 美颜 + 选自然色彩。三星 230mm 远距离抓拍 = 独占优势 |
| 极简高级 | ★★★★★ | 全焦段 + 大传感器 = 完美 |
| 微观微距 | ★★★★★ | 长焦微距（5-10cm 对焦）——华为/小米/OPPO——手机微距最强 |
| 梦幻柔美 | ★★★★★ | 中焦 85mm + 人像虚化（ZEISS Biotar 旋焦）= 梦幻感最佳 |
| Lofi 直闪 | ★★★★☆ | 可以，但 CCD 色偏感需后期 |
| Grunge | ★★★☆☆ | AI 倾向「美化」→ 需要手动关闭 AI + 后期加颗粒/褪色 |
| 县城记忆 | ★★★★☆ | 全焦段 + 需关闭 AI 过饱和 |
| 安静真实 | ★★★☆☆ | AI 过度处理是最大敌人——需要严格关闭所有AI优化 |

## 八、推荐设置

| 设置 | 推荐 | 理由 |
|------|------|------|
| AI 场景优化 | **关闭或最低** | 避免过度饱和/过度锐化/过度美颜 |
| 美颜 | **关闭或 0** | 保留皮肤纹理——「塑料脸」是真实感的最大杀手 |
| 色彩模式 | **自然/真实模式** | Leica Authentic（小米）/ ZEISS 自然（vivo）/ Hasselblad 自然（OPPO）/ 关闭 AI 大师（华为） |
| 网格线 | **开启** | 构图基础 |
| 水平仪 | **开启** | 对称构图必需 |
| 文件格式 | RAW + JPEG（若支持） | 后期空间大；直出 JPEG 作为参考 |
| 闪光灯 | **关闭** | 安卓闪光灯普遍生硬 |
