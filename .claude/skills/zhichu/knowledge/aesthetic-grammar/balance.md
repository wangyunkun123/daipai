# 平衡 · Balance

## 一句话定义

**视觉平衡 = 画面左右/上下的视觉重量达到一种「安定」的状态。** 平衡不是对称——是对各种视觉重量的精确分配，让观众的眼睛在画面中感到「对了」。

—— 框架参考 豆包·顶层1 平衡审美 + Freeman 视觉重量理论

---

## 原理

### 平衡的物理隐喻

Freeman 论述：人用物理世界的重力经验来理解画面中的视觉平衡——左边有一个重物，右边就需要一个等重的物体或更大的空间来「撑住」，否则画面会感觉「向左倒了」。

这不是比喻——视觉平衡有神经科学的依据。人在看一个不平衡的画面时，会产生微弱的生理不适感——和看到倾斜的家具时的感觉类似。

### 视觉重量的计量

画面中每个元素的「视觉重量」由以下因素决定（见 `visual-weight/_index.md`）：

| 因素 | 轻 | 重 |
|------|----|-----|
| 大小 | 小 | 大 |
| 明暗 | 暗（融入背景） | 亮（跳出画面） |
| 饱和度 | 低饱和 | 高饱和 |
| 位置 | 画面中心（被支撑） | 画面边缘（需要更大的反向力量） |
| 人脸 | 没有人脸 | 有人脸（×10 的视觉重量） |
| 文字 | 没有文字 | 有文字（自动阅读） |

## 两种平衡模式

### 静态平衡

**左右/上下的视觉重量完全相等。对称、规整、安静。**

- **适用场景**：建筑、极简风光、正式肖像、产品摄影
- **构图选择**：对称构图、居中构图
- **情绪表达**：秩序、稳定、仪式感、永恒感
- **注意**：静态平衡的弱点是可能「无聊」——需要在对称中寻找微小的不对称来增加生命（如对称建筑中走过一个人）

**操作**：
1. 将主体或对称轴放在画面的垂直中线上
2. 确保左右两侧的元素在视觉重量上匹配
3. 利用水平仪确保绝对水平——静态平衡中 0.5° 的倾斜都会被感知

### 动态平衡

**不对称但稳定——一侧有一个重物，另一侧有更大的空间或较多的轻元素来平衡。**

- **适用场景**：人像、街头纪实、叙事性场景
- **构图选择**：三分法（主体在 1/3，留白占 2/3）、对角线
- **情绪表达**：张力、运动、叙事、自然感

**操作**：
1. 确定主体的视觉重量（亮不亮/大不大/饱和吗/有人脸吗）
2. 在主体的对侧分配「反向重量」——可以是留白空间、引导线的起点、次要元素
3. 反向重量不需要等重——距离画面中心越远，需要的重量越大

**动态平衡的视觉权重层级**：

物理公式「重物 × 距中心距离 ≈ 轻物 × 距中心距离」可以作为初步直觉，但实际视觉权重的排序是：

```
人脸（×10 的视觉重量，无论大小）
  > 高光区域（亮区自动吸引注意力）
    > 高饱和色彩（暖色 > 冷色）
      > 文字/符号（自动阅读本能）
        > 物体物理大小
```

**关键纠正**：一个在画面 1/3 处的小面积人脸，其视觉重量远大于对侧的大面积留白或大块物体。只用「面积 × 距离」来算是不准确的——视觉重量不是物理重量，神经科学的优先级才是真正的衡量标准。

**操作上**：
1. 先识别画面中最高优先级的视觉元素（有人脸吗？有高光吗？有高饱和色块吗？）
2. 在主体的对侧分配反向平衡元素——反向元素需要和主体在视觉重量层级上匹配
3. 人脸主体 → 对侧需要大面积空间或第二个次要人脸来平衡
4. 物体主体 → 对侧可以用留白或较小的高光/高饱和元素来平衡

## 平衡方法的匹配

| 你想表达的情绪 | 平衡方式 |
|--------------|---------|
| 安静、秩序、仪式感 | 静态平衡（对称） |
| 自然、动态、叙事、张力 | 动态平衡（不对称） |
| 不安、紧张、失序 | **主动打破平衡**——见 `breaking-rules.md` |

---

## 常见失衡错误

| 错误 | 为什么失衡 | 修正 |
|------|---------|------|
| 主体太靠边 + 对侧无留白 | 画面「倒了」——视觉重量全在一边 | 主体移向中心 或 对侧增加留白 |
| 模特看向画外但看的方向没有留白 | 视线「撞墙」——视觉重量在视线方向找不到着陆点 | 模特看的方向留白至少占画面宽度 1/3 |
| 多人分散两侧 + 中间空 | 画面被「撕裂」为两个独立区域 | 让两侧的人有视线/身体方向的连接 |
| 亮块在边缘 + 暗块在中心 | 观众的注意力被拉到画面外 | 亮块移动到中心附近或排除 |

---

## 在方案生成中的平衡检查

为每套方案执行平衡检查：

1. **「倒了吗」检查**：遮住画面一半，看两半是否感觉重量均衡
2. **视线检查**：如果模特看向某一侧，那一侧是否有足够空间？
3. **亮度分布检查**：画面最亮的 3 个区域分布是否均衡？
4. **平衡意图检查**：你选择的是静态还是动态平衡？这个选择是否匹配你想要的画面情绪？
