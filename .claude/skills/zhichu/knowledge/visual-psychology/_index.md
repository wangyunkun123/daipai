# 视觉心理学 · Gestalt & Visual Psychology

## 一句话定义

**人在看到画面的前 0.1 秒，大脑已经完成了一套无意识的视觉组织——把碎片的形状、颜色、线条自动归类为「图形」和「背景」、「群体」和「个体」、「已知」和「未知」。** 这套视觉认知的铁律，是审美语法四柱的神经科学底层。

——框架参考 Arnheim 格式塔艺术理论 + Freeman 视觉设计原理

---

## 原理

### 为什么格式塔是审美语法的底层

审美语法的四根支柱（克制/平衡/统一与变化/破格）不是凭空产生的审美偏好——它们有神经科学的基础：

| 审美语法 | 格式塔底层 | 神经机制 |
|---------|----------|---------|
| 克制（做减法） | 图地关系——大脑自动分离图形和背景，无关元素消耗认知资源 | 视觉系统对「干扰物」的本能排斥 |
| 平衡 | 视觉重量 + 完形倾向——大脑自动把不对称的形「推向」对称 | 前庭系统（平衡器官）与视觉的跨模态联动 |
| 统一与变化 | 相似性原则 + 连续性 + 共同命运——统一来自相似，变化来自打破预期 | 大脑的模式识别本能 + 新奇检测机制 |
| 破格 | 打破期待——违反格式塔规律的刺激获得更强的注意力分配 | 杏仁核/前扣带回的「预期错误」信号 |

### 视觉认知的 0.1 秒法则

在观众看清照片的具体内容之前（0.1 秒内），以下判断已经完成：
1. 哪里是「图」（主体），哪里是「地」（背景）——图地分离
2. 哪些元素属于同一组——分组完成
3. 画面的整体情绪基调（亮/暗/暖/冷/安全/威胁）——杏仁核评估

**这意味着**：如果你的构图在这 0.1 秒内没有建立清晰的图地关系和视觉层级，观众会在后续的观看中持续感到隐约的不适——即使他们说不清为什么。

## 格式塔七原则

### 1. 图地关系 · Figure-Ground

**大脑自动将画面分为「图形」（被关注的对象）和「背景」（不被关注的环境）。**

| 条件 | 更容易被识别为「图」 | 更容易被感知为「地」 |
|------|-------------------|-------------------|
| 大小 | 小 | 大 |
| 位置 | 被包围 | 包围 |
| 形状 | 规则的、闭合的 | 不规则的、延伸到画面外的 |
| 明暗 | 亮的 | 暗的 |
| 焦点 | 清晰的 | 模糊的 |

**摄影应用**：
- 主体清晰+背景虚化 = 格式塔图地关系的最直接实现
- 主体被框架包围 = 「图被地包围」→ 主体性最强的构图
- **反面**：主体和背景亮度相同 + 饱和度相同 = 图地关系模糊 → 观众的眼睛「找不到落脚点」

### 2. 接近性 · Proximity

**空间上靠近的元素被自动感知为一组。**

**摄影应用**：
- 两个人站在一起 → 被感知为「一对」
- 三个人中两个靠得近+一个远离 → 被感知为「一对+一个孤独的」
- 群体人像中，站位间距直接决定了观众感知到的「谁和谁是一起的」
- **陷阱**：主体头部和背景树枝太接近 → 被自动分到同一组 → 「树枝长在头上」

### 3. 相似性 · Similarity

**在形状、颜色、大小、纹理、方向上相似的元素被自动感知为一组。**

**摄影应用**：
- 统一色调 = 相似性原则——9 张照片共享色调 → 被感知为「一组作品」
- 色彩呼应 = 相似性原则——第 3 张的粉色手环 + 第 7 张的粉色花 → 跨照片的「组」感知
- 统一的构图风格 = 相似性原则在组图尺度的应用

### 4. 连续性 · Continuity

**眼睛倾向于沿着已经建立的线条、曲线、方向继续移动。对齐的元素被感知为连续的线。**

**摄影应用**：
- 引导线 = 连续性原则——一旦眼睛开始沿着线移动，就会自动继续到线的终点
- 视线引导 = 连续性——模特看向某方向 + 那个方向有空间 = 眼睛自动沿着视线移动
- **陷阱**：引导线通向画面外或通向干扰物 → 眼睛被引导到错误的地方

### 5. 闭合性 · Closure

**大脑会自动「补全」不完整的形状。看到一个缺口的圆，大脑会把它感知为完整的圆。**

**摄影应用**：
- 半张脸出画 → 观众自动补全完整的脸（高阶克制的格式塔底层）
- 框架构图只露一部分 → 观众自动想象框架外的世界
- 被遮挡的主体 → 大脑补全被遮挡的部分 → 参与感增强
- **关键**：残缺必须有足够的信息让大脑完成闭合。给的信息太少 → 闭合失败 → 观众困惑

### 6. 共同命运 · Common Fate

**朝同一方向运动的元素被自动感知为一组。**

**摄影应用**：
- 一群人朝同一方向走 → 被感知为「一支队伍」
- 一个人反向走 → 自动从群体中「跳出来」成为焦点
- 风吹头发 + 飘起的裙摆 → 同一方向 → 被感知为同一阵风的效果
- 多人的视线指向同一方向 → 被感知为「大家都在看同一个东西」→ 观众的注意力也被引导到那个方向

### 7. 视觉预期 · Past Experience / Prägnanz

**大脑倾向于用最简单、最熟悉的解释来组织视觉信息。人会看到他们「期待看到」的东西。**

**摄影应用**：
- 观众的文化背景影响他们对画面的解读
- 日系清新在中国观众眼中 = 「温暖治愈」（因为与日剧/动漫的联想）
- 县城记忆在中国观众眼中 = 「乡愁+忧郁」（因为与贾樟柯电影的联想）
- **这意味着**：风格配方的选择需要考虑目标观众的视觉经验库

## 格式塔在摄影中的诊断工具

当一张照片「感觉不对」但说不清为什么时，按格式塔七原则逐一排查：

1. **图地关系**：主体在哪？观众 0.1 秒能找到吗？
2. **接近性**：哪些元素被错误地分到一组了？
3. **相似性**：有哪些元素因为太相似而混淆了？
4. **连续性**：引导线通向哪里？视线是否遇到了「死胡同」？
5. **闭合性**：残缺的元素给了足够的补全线索吗？
6. **共同命运**：动态元素的方向一致吗？有不和谐的动态吗？
7. **视觉预期**：这个画面是否符合目标观众的文化经验？

## 与审美语法的映射

```
视觉心理学（格式塔）→ 审美语法四柱

图地关系 ──────────→ 克制（确保主体不被干扰）
接近性 + 相似性 ────→ 统一（组织元素的归属关系）
连续性 + 共同命运 ──→ 平衡（视觉动线的稳定）
闭合性 + 预期违反 ──→ 破格（故意违反格式塔预期）
```
